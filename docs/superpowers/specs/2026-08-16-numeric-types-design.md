# Core 数值类型设计：dex（精确小数）+ apx（后端变换许可）

日期：2026-08-16
状态：已批准（brainstorming 会话）
修订：2026-08-23 — int 语义改为无上限整数（i64 快路径 + 溢出自动升级堆上 BigInt，无溢出错误）；spec-design §9.4 随改

## 一、哲学与决策链

1. **核心类型 = 数学语义，零硬件惯例**：核心类型不得携带「行为绑定硬件」的语义——惯例（IEEE 754 等）只允许以「后端实现选择」或「可忽略注解」的形式存在
2. **范式普适**：语言要跨越所有范式（量子、往后未知范式）——数学语义对所有范式成立，硬件惯例只属于发明它的范式；搁浅程序的不是数值类型，是「实现定义」的语义
3. **无生态 = 零兼容成本**：Core 无外部用户，float 直接移除 + 机械迁移，不设兼容层
4. **IR 语义保鲜**：IR 只携带纯精确语义；近似是用户授权的后端变换，不进 IR 语义
5. **安全性优先于性能**：默认精确（慢但安全），近似需显式授权

## 二、核心类型系统

```
int      = 整数（精确，无上限）——数学整数语义（任意精度，永不溢出）；实现 = i64 快路径，装不下时自动升级为堆上 BigInt（Python 模型）；整数永远成立（精确算术任何范式都有）
dex      = 精确小数——默认实数语义（缩放整数/定点实现，精度内置）
bool / char / string / 结构体 / 枚举 / 数组    ← 现状不动
```

- **dex 是实数类的默认**：`3.14` 字面量默认精确；BigInt 扩展库不需要（int 内建任意精度——BigInt 语义即 int 本体，不是扩展——YAGNI）
- 字面量：`3.14` → dex（精确）；`42` → int（整数快路径）

## 三、apx 标签（后端变换许可）

```
x : ., apx = 3.14    ← 变量级标签（与 mut/pub 同族，零新语法）
```

- **语义**：授权后端对 dex 运算做**语义级变换**（结果可以变——近似实现）；不是性能提示
- **位置**：前端只透传注解（挂 IR 节点，不参与类型语义——dex 永远是 dex，检查器零规则变化）；**兑现是后端的事**
  - CPU 后端：看到 apx 附注 → dex 运算降级为 binary64 FPU 快路径
  - 其他范式：忽略附注 → 精确缩放整数运算（契约内回退）
- **与 @fast 的区别（不共用通道，禁止污染）**：
  - `@fast` = 性能提示：忽略 → 行为零变化（纯优化，语义无关）
  - `apx` = 语义级许可：授权「结果可以变」；忽略 → 精确回退
  - 实现：apx 独立 IR 附注（IR_APPROX），与 IR_FAST 零共享，优化 pass 无权处置
- **语义契约**：「精确，或经授权的近似」——带 apx 的计算，所有范式都满足契约（CPU 近似、他范式精确）

## 四、落点

| 层 | 动作 |
|---|---|
| 字面量 | `3.14` → dex；`42` → int（i64 快路径，装不下自动升级 BigInt） |
| 类型系统 | TYP_BASE 新增 dex（精确小数，缩放整数实现）；变量标签字段加 apx 位；int 类型不变，实现层加升级机制（i64 → 堆上 BigInt） |
| 检查器 | `x : dex` 类型规则（精确语义）；apx = 注解透传，无语义规则 |
| IR | 语义保持纯精确（dex 运算 = 缩放整数指令序列）；IR_APPROX 附注（非语义） |
| 后端 | CPU：apx 附注的 dex 运算 → binary64 FPU；其他范式：忽略 apx → 精确 |
| 验证层 | apx 授权记录随 IR 到达验证器——验证器知道用户允许近似（规格 §9.4 决策点随本设计落定：默认数学语义 + 显式授权机器语义） |

## 五、过渡：float 移除 + 机械迁移

- `float` 类型名删除（无别名、无糖、无兼容层）
- 机械迁移：全仓库 `x : float` → `x : dex, apx`（旧语义 = binary64 = apx 在 CPU 上的兑现，行为逐位保持）
- 范围：编译器自身 + stdlib + 测试 + 文档 + EBNF + TY_FLOAT 常量 + 后端 XMM/SysV 路径（float_str_bits → dex 打印，保留为 apx 路径实现）
- `_f32`/`_f64` 后缀保留：暂作 apx 的 CPU 位宽标注（精确标注语法后议）

## 六、明确不做（YAGNI）

- BigInt 扩展库（int 即任意精度——i64 快路径 + 溢出自动升级堆上 BigInt 内建，扩展库不需要）
- 定点/有理数扩展库（dex 即定点语义）
- 隐式数值转换（所有数值转换显式——Coq 式分离，安全性 = 显式性）
- 字面量重载（Coq Numeral Notation 式——有需要再议）
- 扩展类型注册机制（TYP_EXT——本设计不依赖它，dex 是核心类型不是扩展类型）

## 七、命名

| 名称 | 含义 |
|---|---|
| `dex` | 精确小数（默认实数语义） |
| `apx` | 近似授权（后端变换许可，变量级标签） |
| `BigInt` | int 的实现层升级机制（堆上任意精度整数，i64 装不下时自动启用；不是独立类型，无用户可见名） |
| `float` | 删除（迁移为 `dex, apx`） |
