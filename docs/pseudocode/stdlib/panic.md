## 函数 内部：恐慌写（_panic_write）

### 作用

向标准错误输出（文件描述符 2）写入裸字节。仅当字符串非空时才执行系统调用。

### 逻辑

令 sl = 字符串长度（s）
如果 sl 大于 0，那么：
    令 r1 = 系统调用3（1, 2, s, sl）  // write(2, s, len)
返回

### 测试要点

1. 空字符串时不调用系统调用
2. 非空字符串写入 stderr（fd 2）

## 函数 内部：恐慌写行（_panic_writeln）

### 作用

向标准错误输出写入字符串后追加换行符。

### 逻辑

内部：恐慌写（s）
令 r1 = 系统调用3（1, 2, "\n", 1）
返回

### 测试要点

1. 写入字符串后自动换行
2. 调用 panic_write 和 write("\n")

## 函数 带位置恐慌（panic_at）

### 作用

核心恐慌入口——打印信息与位置信息到标准错误输出，然后调用 _exit(1) 终止进程。输出格式仿照 Rust 的 default_hook。

### 逻辑

内部：恐慌写（"panicked at "）
内部：恐慌写（file）
内部：恐慌写（":"）
内部：恐慌写（整数转字符串（line））
内部：恐慌写（":"）
内部：恐慌写（整数转字符串（col））
内部：恐慌写行（":"）
内部：恐慌写行（msg）
令 r1 = 系统调用3（60, 1, 0, 0）  // _exit(1)，系统调用号 60

### 测试要点

1. 正常调用时输出完整诊断信息后进程退出
2. file 为空字符串时输出 "panicked at :行:列:"
3. line/col 为 0 时输出 "0"
4. 调用后不会返回（exit 终止进程）

## 函数 恐慌（panic）

### 作用

不带位置信息的简化恐慌入口。输出 "panicked at:" 后跟消息，然后退出。

### 逻辑

内部：恐慌写行（"panicked at:"）
内部：恐慌写行（msg）
令 r1 = 系统调用3（60, 1, 0, 0）  // _exit(1)

### 测试要点

1. 输出 panic 信息后进程退出
2. 不包含文件和行号信息
