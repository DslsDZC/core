## 函数 交换元素（swap）

### 作用

交换定长整数数组中两个指定索引处的元素值。索引甲等于索引乙时元素不变（自交换无副作用）。

### 逻辑

函数 交换元素（swap）（数组 数组（arr）：整数定长数组，索引甲 索引（i）：整数，索引乙 j：整数）
    令 临时值（tmp）= 数组[索引甲]
    令 数组[索引甲] = 数组[索引乙]
    令 数组[索引乙] = 临时值

### 测试要点

1. 索引甲 等于 索引乙 时元素不变（自交换）
2. 索引甲 和 索引乙 不同时正确交换
3. 边界情况：索引甲 等于 0，索引乙 等于 数组长度 减 1

## 函数 反转数组（reverse）

### 作用

原地反转数组的元素顺序。使用双指针从两端向中间交换。

### 逻辑

函数 反转数组（reverse）（数组 数组（arr）：整数定长数组）
    令 左指针（i）= 0
    令 右指针（j）= 数组长度 减 1
    循环（当 左指针 小于 右指针 时）：
        令 临时值（t）= 数组[左指针]
        令 数组[左指针] = 数组[右指针]
        令 数组[右指针] = 临时值
        令 左指针 = 左指针 加 1
        令 右指针 = 右指针 减 1

### 测试要点

1. 奇数长度数组反转正确，中间元素不动
2. 偶数长度数组全部反转
3. 数组长度 等于 0 时循环不执行（左指针 等于 0，右指针 等于 负 1，左指针 小于 右指针 为假）
4. 数组长度 等于 1 时 左指针 等于 0，右指针 等于 0，不交换

## 函数 包含判断（contains）

### 作用

判断数组中是否包含指定值。线性扫描，找到即返回真。

### 逻辑

函数 包含判断（contains）（数组 数组（arr）：整数定长数组，目标值 值（val）：整数）-> 布尔
    令 循环索引（i）= 0
    循环（当 循环索引 小于 数组长度 时）：
        如果 数组[循环索引] 等于 目标值，那么：返回 真
        令 循环索引 = 循环索引 加 1
    返回 假

### 测试要点

1. 目标值在数组开头找到，立即返回真
2. 目标值在数组末尾找到，返回真
3. 目标值不在数组中，返回假
4. 数组长度 等于 0 时循环不执行，返回假

## 函数 最小元素（min_element）

### 作用

返回数组中的最小元素。数组长度等于 0 时返回 0。

### 逻辑

函数 最小元素（min_element）（数组 数组（arr）：整数定长数组）-> 整数
    如果 数组长度 等于 0，那么：返回 0
    令 当前最值（m）= 数组[0]
    令 循环索引（i）= 1
    循环（当 循环索引 小于 数组长度 时）：
        如果 数组[循环索引] 小于 当前最值，那么：令 当前最值 = 数组[循环索引]
        令 循环索引 = 循环索引 加 1
    返回 当前最值

### 测试要点

1. 正常数组返回最小值
2. 数组长度 等于 0 返回 0
3. 所有元素相等时返回该值
4. 含负数时正确找最小值

## 函数 拷贝数组（copy）

### 作用

将源数组的所有元素拷贝到目标数组中。要求两个数组长度相同（均为数组长度）。

### 逻辑

函数 拷贝数组（copy）（源数组 src：整数定长数组，目标数组 dst：整数定长数组）
    令 循环索引（i）= 0

### 测试要点

## 函数 数组相等比较（equals）

### 作用

判断两个数组（长度分别为数组长度 次数（N） 和数组长度 M）是否逐元素相等。长度不等直接返回假，长度相等则逐元素比较。

### 逻辑

函数 数组相等比较（equals）（数组甲 变量甲（a）：整数定长数组，数组乙 变量乙（b）：整数定长数组）-> 布尔
    如果 数组甲长度 不等于 数组乙长度，那么：返回 假
    令 循环索引（i）= 0
    循环（当 循环索引 小于 数组甲长度 时）：
        如果 数组甲[循环索引] 不等于 数组乙[循环索引]，那么：返回 假
        令 循环索引 = 循环索引 加 1
    返回 真

### 测试要点

1. 长度不等返回假
2. 长度相等且元素全等返回真
3. 长度相等但存在不同元素返回假
4. 数组甲长度 等于 数组乙长度 等于 0 返回真

## 函数 切片求和（slice_sum）

### 作用

返回数组在起始位置（含）到结束位置（不含）范围内的元素之和。同时检查结束位置和数组长度的边界。

### 逻辑

函数 切片求和（slice_sum）（数组 数组（arr）：整数定长数组，起始位置 开始（start）：整数，结束位置 结束（end）：整数）-> 整数
    令 累加和（s）= 0
    令 循环索引（i）= 起始位置
    循环（当 循环索引 小于 结束位置 且 循环索引 小于 数组长度 时）：
        令 累加和 = 累加和 加 数组[循环索引]
        令 循环索引 = 循环索引 加 1
    返回 累加和

### 测试要点

1. 正常范围返回切片之和
2. 结束位置 大于 数组长度 时仅求和到 数组长度 减 1
3. 起始位置 大于等于 数组长度 时返回 0（循环条件 循环索引 小于 结束位置 可能成立但 循环索引 小于 数组长度 不成立）
4. 起始位置 等于 结束位置 时返回 0
