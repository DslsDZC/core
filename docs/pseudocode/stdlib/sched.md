# 调度（sched）.cr 伪代码

> 源文件：src/stdlib/调度（sched）.cr（205 行）
> 功能概要：M:次数（N） 调度器——M 个操作系统线程，次数 个协程。通道为单生产者/单消费者边，因此运行时无需锁：每个工作机器（M）拥有自己的本地运行队列，只有其所属线程操作该队列。

## 函数 调度器初始化（sched_init）

### 作用

初始化整个协程调度系统：初始化竞技场系统（1 兆字节内存池，64 千字节分块），创建首个工作机器和主协程（编号为 0），注册主协程为当前运行协程。仅在首次调用时执行（幂等性）。

### 逻辑

函数 调度器初始化（sched_init）-> 无返回
    如果 调度器已初始化标记 不等于 0，那么：返回
    初始化竞技场（1048576，65536）
    令 机器指针（m）= 分配（32）
    写 64 位（机器指针，0，0）
    写 64 位（机器指针，8，-1）
    写 64 位（机器指针，16，-1）
    写 64 位（机器指针，24，-1）
    令 机器数组 = 机器指针
    令 机器计数 = 1
    令 当前 M 索引 = 0
    令 主协程句柄（main_g）= 分配（80）
    写 64 位（主协程句柄，0，0）
    写 64 位（主协程句柄，8，1）
    写 64 位（主协程句柄，16，0）
    写 64 位（主协程句柄，24，0）
    写 64 位（主协程句柄，32，-1）
    写 64 位（主协程句柄，40，-1）
    写 64 位（主协程句柄，48，-1）
    写 64 位（主协程句柄，56，0）
    写 64 位（主协程句柄，64，0）
    写 64 位（主协程句柄，72，0）
    写 64 位（机器指针，8，主协程句柄）
    设置当前协程（主协程句柄）
    令 调度器已初始化标记 = 1

### 测试要点

1. 首次调用时初始化竞技场、创建工作机器和主协程
2. 主协程的编号为 0，状态为运行中（值为 1）
3. 主协程的栈指针在首次让出时由纤程切换填入栈指针寄存器
4. 重复调用直接返回（幂等性）
5. 初始化后同个工作机器上可进行协程调度

## 函数 调度当前 M 索引（sched_current_m_idx）

### 作用

返回当前正在执行的工作机器的索引。汇编码的协程包装器调用此函数来解析当前工作机器，因为调度函数被设计为无参数调用。

### 逻辑

函数 调度当前 M 索引（sched_current_m_idx）-> 整数
    返回 当前 M 索引

## 函数 调度入队（sched_enqueue）

### 作用

将协程添加到当前工作机器的本地运行队列尾部。使用单向链表通过协程结构体的下一个协程字段（偏移 48 字节）连接。无共享全局队列，因此无跨线程竞争——每个工作机器仅操作自己的队列。

### 逻辑

函数 调度入队（sched_enqueue）（协程句柄（g）：整数）-> 无返回
    令 当前 M 索引（m_idx）= 调度当前 M 索引（）
    如果 当前 M 索引 小于 0，那么：当前 M 索引 = 0
    令 机器指针（m）= 机器数组 加 当前 M 索引 乘以 32
    令 运行队列头部句柄（head）= 读 64 位（机器指针，16）
    如果 运行队列头部句柄 小于 0，那么：
        写 64 位（机器指针，16，协程句柄）
        写 64 位（机器指针，24，协程句柄）
    否则：
        令 运行队列尾部句柄（tail）= 读 64 位（机器指针，24）
        写 64 位（运行队列尾部句柄，48，协程句柄）
        写 64 位（机器指针，24，协程句柄）
    写 64 位（协程句柄，48，-1）

### 测试要点

1. 队列为空时，运行队列头部和尾部都指向新入队的协程
2. 队列非空时，追加到尾部协程的下一个协程字段并更新尾部
3. 入队后协程的下一个协程字段始终为 -1（标记链表末尾）

## 函数 调度出队（sched_dequeue）

### 作用

从指定工作机器的本地运行队列头部弹出协程。队列为空时返回 -1。

### 逻辑

函数 调度出队（sched_dequeue）（当前 M 索引（m_idx）：整数）-> 整数
    如果 当前 M 索引 小于 0，那么：当前 M 索引 = 0
    令 机器指针（m）= 机器数组 加 当前 M 索引 乘以 32
    令 运行队列头部句柄（head）= 读 64 位（机器指针，16）
    如果 运行队列头部句柄 小于 0，那么：返回 -1
    写 64 位（机器指针，16，读 64 位（运行队列头部句柄，48））
    如果 读 64 位（机器指针，16）小于 0，那么：
        写 64 位（机器指针，24，-1）
    写 64 位（运行队列头部句柄，48，-1）
    返回 运行队列头部句柄

### 测试要点

1. 队列为空时返回 -1
2. 单元素队列出队后运行队列头部和尾部都设为 -1
3. 多元素队列出队后运行队列头部前移到下一个协程

## 函数 调度让出（sched_yield）

### 作用

当前协程协作让出处理器：若当前协程仍为可运行状态（既非等待中也非已死亡），则将其重新入队；然后调用调度调度函数切换到下一个协程。等待中（值为 2）的协程由其通道等待列表管理，已死亡（值为 3）的协程永不重新入队。

### 逻辑

函数 调度让出（sched_yield）-> 无返回
    令 当前协程（cur_g）= 调度获取当前协程（）
    如果 当前协程 大于等于 0，那么：
        令 协程状态（st）= 读 64 位（当前协程，8）
        如果 协程状态 不等于 2 且 协程状态 不等于 3，那么：
            写 64 位（当前协程，8，0）
            调度入队（当前协程）
    调度调度（）

### 测试要点

1. 可运行状态的协程重新入队后切换到下一个协程
2. 等待中状态（值为 2）的协程不重新入队（保留在通道等待列表中）
3. 已死亡状态（值为 3）的协程不重新入队
4. 当前协程小于 0 时直接执行调度调度

## 函数 调度调度（sched_schedule）

### 作用

切换到当前工作机器本地运行队列中的下一个可运行协程：从队列头部出队一个协程，保存旧协程的栈指针（在纤程切换内部完成），载入新协程的栈指针，执行纤程切换。若旧协程不存在（首个协程），直接启动新协程而不保存栈。

### 逻辑

函数 调度调度（sched_schedule）-> 无返回
    令 当前 M 索引（m_idx）= 调度当前 M 索引（）
    令 下一个协程（next_g）= 调度出队（当前 M 索引）
    如果 下一个协程 大于等于 0，那么：
        令 旧协程（old_g）= 读 64 位（机器数组，当前 M 索引 乘以 32 加 8）
        写 64 位（机器数组，当前 M 索引 乘以 32 加 8，下一个协程）
        设置当前协程（下一个协程）
        写 64 位（下一个协程，8，1）
        如果 旧协程 大于等于 0，那么：
            令 旧栈指针地址（old_sp_addr）= 旧协程 加 16
            令 下一个栈指针（next_sp）= 读 64 位（下一个协程，16）
            纤程切换（旧栈指针地址，下一个栈指针）

### 测试要点

1. 队列中有协程时切换到下一个协程
2. 队列为空时函数返回（无协程可调度）
3. 旧协程的栈指针在纤程切换中保存
4. 新协程状态设为运行中（值为 1）

## 函数 调度工作线程运行（sched_worker_run）

### 作用

工作线程的主循环：设置当前工作机器的标识和索引后，持续从其本地运行队列中出队并运行协程。当前无工作时自旋等待。

### 逻辑

函数 调度工作线程运行（sched_worker_run）（当前 M 索引（m_idx）：整数）-> 无返回
    写 64 位（机器数组，当前 M 索引 乘以 32，当前 M 索引）
    令 当前 M 索引 = 当前 M 索引（参数值）
    循环：
        令 下一个协程（next_g）= 调度出队（当前 M 索引）
        如果 下一个协程 大于等于 0，那么：
            令 旧协程（old_g）= 读 64 位（机器数组，当前 M 索引 乘以 32 加 8）
            写 64 位（机器数组，当前 M 索引 乘以 32 加 8，下一个协程）
            设置当前协程（下一个协程）
            写 64 位（下一个协程，8，1）
            如果 旧协程 大于等于 0，那么：
                令 旧栈指针地址（old_sp_addr）= 旧协程 加 16
                令 下一个栈指针（next_sp）= 读 64 位（下一个协程，16）
                纤程切换（旧栈指针地址，下一个栈指针）

### 测试要点

1. 工作线程设置自己的标识和当前工作机器索引
2. 持续从本地队列出队运行协程
3. 无协程时自旋等待（不会退出循环）

## 函数 调度启动协程（sched_go）

### 作用

启动一个新协程：创建一个容量为 1、元素大小为 8 字节的通道用于收集结果，通过协程分配函数创建协程，将结果通道存入协程结构体的偏移 40 字节处，将协程入队，返回结果通道供调用方通过通道接收函数等待结果。

### 逻辑

函数 调度启动协程（sched_go）（函数指针（fn_ptr）：整数，协程参数（arg）：整数）-> 整数
    令 结果通道（ch）= 创建通道（8，1）
    令 协程句柄（g）= 协程分配（函数指针，协程参数，0）
    写 64 位（协程句柄，40，结果通道）
    调度入队（协程句柄）
    返回 结果通道

### 测试要点

1. 返回的通道可由调用方通过通道接收函数获取结果
2. 通道容量为 1，元素大小为 8 字节
3. 新协程入队等待调度

## 函数 调度启动工作线程（sched_spawn_workers）

### 作用

创建指定数量个工作线程。分配相应数量的工作机器结构体（每条 32 字节）并初始化所有字段，更新全局机器数组和机器计数，然后通过汇编桩代码启动实际工作线程。线程数小于等于 1 时直接返回（单线程模式已由调度器初始化设置）。

### 逻辑

函数 调度启动工作线程（sched_spawn_workers）（工作线程数（n）：整数）-> 无返回
    如果 工作线程数 小于等于 1，那么：返回
    令 M 数组总缓冲区（total_ms）= 分配（工作线程数 乘以 32）
    令 循环索引（mi）= 0
    循环（当 循环索引 小于 工作线程数 时）：
        写 64 位（M 数组总缓冲区，循环索引 乘以 32，循环索引）
        写 64 位（M 数组总缓冲区，循环索引 乘以 32 加 8，-1）
        写 64 位（M 数组总缓冲区，循环索引 乘以 32 加 16，-1）
        写 64 位（M 数组总缓冲区，循环索引 乘以 32 加 24，-1）
        循环索引 = 循环索引 加 1
    令 机器数组 = M 数组总缓冲区
    令 机器计数 = 工作线程数
    令 全局工作线程数（g_num_workers）= 工作线程数 减 1
    启动工作线程桩代码（工作线程数）

### 测试要点

1. 工作线程数为 0 或 1 时直接返回
2. 每个工作机器的标识设为其自身索引
3. 所有工作机器初始当前协程为 -1（无运行协程）
4. 工作线程数全局变量设为传入线程数减 1（索引为 0 的工作机器为主线程）
