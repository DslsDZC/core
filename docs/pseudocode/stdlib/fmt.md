# fmt.cr 伪代码

> 源文件：src/stdlib/fmt.cr（192 行）
> 功能概要：Core 标准库字符串格式化与类型转换模块。提供字符串操作（长度、切片、比较、拼接）、整数与字符串互转、以及格式化字符串插值功能。所有函数均为纯函数（无副作用）。

## 函数 字符串长度（str_len）

### 作用

读取 Core 字符串的头部信息获取字符串实际长度。字符串布局：[-8..-1] 存储分配的总字节数（含 null 终止符），实际长度 = 总字节数 - 1。

### 逻辑

令 hdr = 加载 64 位（s, -8）  // 字符串头：分配的总字节数（含 null）
如果 hdr 不大于 0，那么：返回 0
返回 hdr 减 1  // 排除 null 终止符

### 测试要点

1. 空字符串 "" 返回 0（hdr = 1, hdr - 1 = 0）
2. 字符串 "abc" 返回 3（hdr = 4, hdr - 1 = 3）
3. s 为无效指针时行为未定义（编译器假定合法）

## 函数 字符构造（chr）

### 作用

将一个整数（ASCII 码点）转换为单字符字符串。分配 2 字节（字符 + null 终止符）。

### 逻辑

令 res = 分配（2）
写单字节（res, 0, c）
写单字节（res, 1, 0）
返回 res

### 测试要点

1. c = 65 返回 2 字节字符串 "A\0"
2. c = 0 返回 "\0\0" 即空字符串等价物

## 函数 取字符串第 N 字符（get_char）

### 作用

获取字符串中第 idx 位置的字符，返回单字符字符串。越界时返回空字符串。

### 逻辑

令 sl = 字符串长度（s）
如果 idx 小于 0 或 idx 不小于 sl，那么：返回 ""
令 c = 按字节读取（s, idx）
令 res = 分配（2）
写单字节（res, 0, c）
写单字节（res, 1, 0）
返回 res

### 测试要点

1. idx = 0 获取首字符
2. idx 超出范围返回空字符串
3. idx 为负数返回空字符串
4. 空字符串上的任何索引返回空字符串

## 函数 字符串切片（str_sub）

### 作用

从字符串 s 中提取 [start, start+len) 范围的子串。越界时自动截断。

### 逻辑

令 slen = 字符串长度（s）
如果 start 小于 0 或 start 不小于 slen，那么：返回 ""
令 actual_len = len
如果 start 加 actual_len 大于 slen，那么：actual_len = slen 减 start
如果 actual_len 不大于 0，那么：返回 ""
令 res = 分配（actual_len 加 1）
令 i = 0
循环（当 i 小于 actual_len 时）：
    令 c = 按字节读取（s, start 加 i）
    写单字节（res, i, c）
    i = i 加 1
写单字节（res, actual_len, 0）
返回 res

### 测试要点

1. 正常范围返回子串
2. start + len 超出字符串末尾时自动截断
3. len <= 0 返回空字符串
4. start 越界返回空字符串

## 函数 字符串相等比较（str_eq）

### 作用

逐字节比较两个字符串是否内容完全相同。长度不等直接返回假（0）；长度相等则逐字节比较。

### 逻辑

令 la = 字符串长度（a）
令 lb = 字符串长度（b）
如果 la 不等于 lb，那么：返回 0
令 i = 0
循环（当 i 小于 la 时）：
    如果 按字节读取（a, i）不等于 按字节读取（b, i），那么：返回 0
    i = i 加 1
返回 1  // 注意：循环自然结束才到此处，但源文件末尾有 return 0（死代码）

### 测试要点

1. 相等字符串返回 1（真）
2. 长度不等返回 0
3. 长度相等但内容不同返回 0
4. 两个空字符串返回 1（长度均为 0，循环不执行）

## 函数 字符串比较（str_cmp）

### 作用

字典序逐字节比较两个字符串。类似 C 的 strcmp：相等返回 0，a < b 返回 -1，a > b 返回 1。以 null 终止符为结束标记。

### 逻辑

令 i = 0
循环：
    令 ca = 按字节读取（a, i）
    令 cb = 按字节读取（b, i）
    如果 ca 等于 0 且 cb 等于 0，那么：返回 0  // 同时到达末尾
    如果 ca 等于 0，那么：返回 -1  // a 较短
    如果 cb 等于 0，那么：返回 1   // b 较短
    如果 ca 小于 cb，那么：返回 -1
    如果 ca 大于 cb，那么：返回 1
    i = i 加 1

### 测试要点

1. 相同字符串返回 0
2. "a" < "b" 返回 -1
3. "b" > "a" 返回 1
4. "ab" < "abc" 返回 -1（ca = 0 先到达）
5. 空字符串 "" < "a" 返回 -1

## 函数 字符串拼接（concat）

### 作用

将两个字符串连接为一个新字符串。分配新内存，先拷贝 a 再拷贝 b。

### 逻辑

令 aa = a
令 bb = b
令 lena = 字符串长度（aa）
令 lenb = 字符串长度（bb）
令 res = 分配（lena 加 lenb 加 1）
令 i = 0
循环（当 i 小于 lena 时）：
    令 c = 按字节读取（aa, i）
    写单字节（res, i, c）
    i = i 加 1
令 j = 0
循环（当 j 小于 lenb 时）：
    令 c = 按字节读取（bb, j）
    写单字节（res, lena 加 j, c）
    j = j 加 1
写单字节（res, lena 加 lenb, 0）
返回 res

### 测试要点

1. 两个非空字符串正常拼接
2. 一方为空字符串时返回另一方
3. 两个空字符串拼接返回空字符串

## 函数 整数转字符串（int_str）

### 作用

将整数转换为十进制字符串表示。处理负号（'-' 前缀）和零值特例。

### 逻辑

如果 n 等于 0，那么：返回 "0"
令 val = n
令 neg = 0
如果 val 小于 0，那么：
    neg = 1
    val = 负 val  // val = -val
令 tmp = val
令 ndigits = 0
循环：
    ndigits = ndigits 加 1
    tmp = tmp 除以 10
    如果 tmp 等于 0，那么：跳出循环
令 extra = neg  // 负数需要额外一个字符放 '-'
令 buf = 分配（ndigits 加 extra 加 1）
令 end = ndigits
令 pos = ndigits 减 1
循环：
    令 rem = val 取模 10
    写单字节（buf, pos, rem 加 48）  // 数字→ASCII：'0' = 48
    val = val 除以 10
    如果 pos 等于 0，那么：跳出循环
    pos = pos 减 1
如果 neg 等于 1，那么：
    令 k = ndigits
    循环（当 k 不等于 0 时）：
        令 ci = 按字节读取（buf, k 减 1）
        写单字节（buf, k, ci）  // 所有数字后移一位
        k = k 减 1
    写单字节（buf, 0, 45）  // '-' = 45
    end = end 加 1
写单字节（buf, end, 0）
返回 buf

### 测试要点

1. n = 0 返回 "0"（特例）
2. n = 42 返回 "42"
3. n = -42 返回 "-42"
4. n = 2147483647（最大正数）正确转换
5. n = -2147483648（最小负数）正确转换（负负得正时需注意溢出）

## 函数 字符串转整数（str_int）

### 作用

将十进制字符串解析为整数。支持负号前缀，遇到非数字字符时停止解析。

### 逻辑

令 slen = 字符串长度（s）
如果 slen 等于 0，那么：返回 0
令 i = 0
令 neg = 0
令 c0 = 按字节读取（s, 0）
如果 c0 等于 45，那么：  // '-' = 45
    neg = 1
    i = 1
令 res = 0
循环（当 i 小于 slen 时）：
    令 c = 按字节读取（s, i）
    如果 c 小于 48 或 c 大于 57，那么：跳出循环  // 非数字字符
    res = res 乘以 10 加（c 减 48）
    i = i 加 1
如果 neg 等于 1，那么：返回 负 res
返回 res

### 测试要点

1. "42" 返回 42
2. "-42" 返回 -42
3. "0" 返回 0
4. "" 返回 0
5. "42abc" 返回 42（遇到 'a' 停止）
6. "-" 返回 0（仅有负号无数字）

## 函数 字符串格式化（format）

### 作用

简单的字符串插值：将格式串中的 "{0}" 替换为第一个参数 a0。类似格式化占位符替换。

### 逻辑

令 fl = 字符串长度（fmt_str）
令 a0l = 字符串长度（a0）
令 out_buf = 分配（fl 加 a0l 加 16）  // 预分配足够大的缓冲区
令 ri = 0  // 写位置
令 fi = 0  // 读位置
循环（当 fi 小于 fl 时）：
    令 c = 按字节读取（fmt_str, fi）
    如果 c 等于 123 且 fi 加 2 小于 fl 且 按字节读取（fmt_str, fi 加 1）等于 48 且 按字节读取（fmt_str, fi 加 2）等于 125，那么：
        // 遇到 "{0}"：替换为 a0
        令 ai = 0
        循环（当 ai 小于 a0l 时）：
            写单字节（out_buf, ri, 按字节读取（a0, ai））
            ri = ri 加 1
            ai = ai 加 1
        fi = fi 加 3  // 跳过 "{0}" 三个字符
    否则：
        写单字节（out_buf, ri, c）
        ri = ri 加 1
        fi = fi 加 1
写单字节（out_buf, ri, 0）
返回 out_buf

### 测试要点

1. "Hello {0}!" 和参数 "world" 返回 "Hello world!"
2. 格式串不含 "{0}" 时原样返回参数
3. 多个 "{0}" 时全部替换为同一参数
4. 格式串以 "{0" 开头但不完整（如 "{0x"）时原样输出

## 函数 整数格式化（format_int）

### 作用

将整数转换为字符串后进行格式化插值。

### 逻辑

返回 字符串格式化（fmt_str, 整数转字符串（val））

### 测试要点

1. format_int("val = {0}", 42) 返回 "val = 42"
2. val = 0 返回 "val = 0"
3. val 为负数返回 "val = -N"
