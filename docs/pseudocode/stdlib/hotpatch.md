## 函数 热补丁加载配置（hp_load_config）
签名：`函数 热补丁加载配置（hp_load_config）（）-> 整数`
### 作用

重新读取热补丁配置文件内容到全局配置缓冲区。可在信号处理器上下文中安全调用（内核保存/恢复寄存器）。

### 逻辑

令 临时配置内容（tc）= 读取文件（".hotpatch.toml"）
如果 字符串长度（临时配置内容）大于 0，那么：
    令 热补丁配置 = 临时配置内容

### 测试要点

1. 热补丁配置文件存在且有内容时更新热补丁配置
2. 文件不存在或为空时热补丁配置保持不变
3. 在信号处理器上下文中调用安全（不分配内存）

## 函数 热补丁进行中计数加一（hp_inflight_inc）
签名：`函数 热补丁进行中计数加一（hp_inflight_inc）（函数版本号（fn_ver）：整数）-> 整数`
### 作用

递增指定函数版本的进行中请求计数。用于追踪有多少个线程或协程正在执行该函数的某个版本。

### 逻辑

令 当前值（cur）= 读 64 位（热补丁进行中计数，版本号（fn_ver）乘以 8）
写 64 位（热补丁进行中计数，版本号 乘以 8，当前值 加 1）

### 测试要点

1. 初始值 0 时加一后变为 1
2. 多次调用正确累加
3. 版本号在 0 至 63 范围内

## 函数 热补丁进行中计数减一（hp_inflight_dec）
签名：`函数 热补丁进行中计数减一（hp_inflight_dec）（函数版本号（fn_ver）：整数）-> 整数`
### 作用

递减指定函数版本的进行中请求计数。饱和于 0（不会变为负数）。

### 逻辑

令 当前值（cur）= 读 64 位（热补丁进行中计数，版本号（fn_ver）乘以 8）
如果 当前值 大于 0，那么：
    写 64 位（热补丁进行中计数，版本号 乘以 8，当前值 减 1）

### 测试要点

1. 当前值 等于 1 时减一变为 0
2. 当前值 等于 0 时保持为 0（饱和，不变成负数）
3. 多次减一不会导致负值

## 函数 热补丁初始化（hp_init）
签名：`函数 热补丁初始化（hp_init）（）-> 整数`
### 作用

在启动时初始化热补丁系统：分配进行中计数缓冲区（64 槽位，每槽 8 字节），清零所有槽位，加载初始配置。

### 逻辑

令 热补丁配置 = ""
令 热补丁进行中计数 = 分配（64 乘以 8）  // 64 个版本槽位，每槽 8 字节
令 循环索引（i）= 0
循环（当 循环索引 小于 64 时）：
    写 64 位（热补丁进行中计数，循环索引 乘以 8, 0）
    循环索引 = 循环索引 加 1
热补丁加载配置（）

### 测试要点

1. 分配 512 字节的进行中计数缓冲区
2. 所有 64 个槽位初始化为 0
3. 调用后热补丁配置已加载（若热补丁配置文件存在）
