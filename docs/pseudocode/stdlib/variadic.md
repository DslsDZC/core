## 函数 可变参数：参数个数（va_count）

### 作用

从变参数据包中读取参数总数。变参包的头部 8 字节存储参数个数。

### 逻辑

如果 字符串长度（参数包）小于 8，那么：
    返回 0
返回 读 64 位（参数包，0）// 头部 8 字节为参数计数

### 测试要点

1. 空参数包或长度不足 8 字节时返回 0
2. 正常参数包返回头部存储的参数个数

## 函数 可变参数：获取参数（va_arg）

### 作用

从变参数据包中取出第 n 个参数的 IR 变量索引（整数）。参数存储在第 1 个槽位之后（槽位 0 是计数）。

### 逻辑

如果 字符串长度（参数包）小于 （n 加 1）乘以 8 再加 8，那么：
    返回 -1（越界）
返回 读 64 位（参数包，（n 加 1）乘以 8）

### 测试要点

1. n = 0 获取第一个参数，读取偏移 8 处的值
2. n 超出参数包长度时返回 -1
3. 空参数包（长度不足）返回 -1

## 函数 可变参数：函数是否有行号（va_fn_has_ln）

### 作用

检测函数名是否以 "ln" 结尾（如 println）。用于区分 print/println 的变参包装逻辑。

### 逻辑

令 函数名长度 = 字符串长度（函数名）
如果 函数名长度 不小于 4，那么：
    如果 按字节读取（函数名，函数名长度 减 2）等于 108 且 按字节读取（函数名，函数名长度 减 1）等于 110，那么：
        返回 真
返回 假

### 测试要点

1. 函数名 "println"（末尾为 ln）返回真
2. 函数名 "print"（末尾不是 ln）返回假
3. 函数名长度小于 4 时返回假（如 "a"、"ab"）
4. 函数名 "plan"（倒数第 2 字符不是 'l'）返回假
