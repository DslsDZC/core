## 函数 可变参数：参数个数（va_count）

### 作用

从变参数据包中读取参数总数。变参包的头部 8 字节存储参数个数。

### 逻辑

函数 可变参数：参数个数（va_count）（参数包（pack）：字符串）-> 整数
    如果 字符串长度（str_len）（参数包）小于 8，那么：
        返回 0
    返回 读 64 位（r64）（参数包，0）

### 测试要点

1. 空参数包或长度不足 8 字节时返回 0
2. 正常参数包返回头部存储的参数个数

## 函数 可变参数：获取参数（va_arg）

### 作用

从变参数据包中取出指定序号（n）参数的 IR 变量索引（整数）。参数存储在第 1 个槽位之后（槽位 0 是计数）。

### 逻辑

函数 可变参数：获取参数（va_arg）（参数包（pack）：字符串，参数序号（n）：整数）-> 整数
    如果 字符串长度（str_len）（参数包）小于（参数序号 加 1）乘以 8 再加 8，那么：
        返回 -1
    返回 读 64 位（r64）（参数包，（参数序号 加 1）乘以 8）

### 测试要点

1. 参数序号（n）等于 0 获取第一个参数，读取偏移 8 处的值
2. 参数序号（n）超出参数包长度时返回 -1
3. 空参数包（长度不足）返回 -1

## 函数 可变参数：函数是否有行号（va_fn_has_ln）

### 作用

检测函数名是否以 换行标记（ln）结尾（如 输出行（println）函数）。用于区分 输出字符串（print）与 输出行（println）的变参包装逻辑。检查末尾两个字符是否依次为字母（l）（编码（ASCII）108）和字母（n）（编码（ASCII）110）。

### 逻辑

函数 可变参数：函数是否有行号（va_fn_has_ln）（函数名（fn_name）：字符串）-> 布尔
    令 函数名长度（fnl）= 字符串长度（str_len）（函数名）
    如果 函数名长度 大于等于 4，那么：
        如果 按字节读取（load8）（函数名，函数名长度 减 2）等于 108 且 按字节读取（load8）（函数名，函数名长度 减 1）等于 110，那么：
            返回 真
    返回 假

### 测试要点

1. 函数名 输出行（println）（ln）返回真
2. 函数名 输出字符串（print）（ln）返回假
3. 函数名长度小于 4 时返回假（如单字符名 "a"、双字符名 "ab"）
4. 函数名 计划（plan）（末尾倒数第 2 字符不是 l）返回假
