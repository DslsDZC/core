## 函数 绝对值（abs）

### 作用

返回整数 x 的绝对值。

### 逻辑

如果 x 小于 0，那么：返回 负 x
返回 x

### 测试要点

1. x = -5 返回 5
2. x = 0 返回 0
3. x = 5 返回 5

## 函数 取最小值（min）

### 作用

返回两个整数中较小的一个。

### 逻辑

如果 a 小于 b，那么：返回 a
返回 b

### 测试要点

1. a < b 时返回 a
2. a > b 时返回 b
3. a == b 时返回 b

## 函数 取最大值（max）

### 作用

返回两个整数中较大的一个。

### 逻辑

如果 a 大于 b，那么：返回 a
返回 b

### 测试要点

1. a > b 时返回 a
2. a < b 时返回 b
3. a == b 时返回 b

## 函数 钳制（clamp）

### 作用

将值 val 约束在 [lo, hi] 区间内：小于 lo 则返回 lo，大于 hi 则返回 hi，否则返回原值。

### 逻辑

如果 val 小于 lo，那么：返回 lo
如果 val 大于 hi，那么：返回 hi
返回 val

### 测试要点

1. val 在区间内返回原值
2. val 小于 lo 返回 lo
3. val 大于 hi 返回 hi
4. val 等于 lo 或 hi 返回原值

## 函数 幂运算（pow）

### 作用

计算 base 的 exp 次幂（exp 为非负整数）。

### 逻辑

令 r = 1
令 i = 0
循环（当 i 小于 exp 时）：
    r = r 乘以 base
    i = i 加 1
返回 r

### 测试要点

1. exp = 0 时返回 1（任何数的 0 次幂）
2. exp = 1 时返回 base
3. base = 2, exp = 3 返回 8
4. base 为负数时按乘法规则计算

## 函数 最大公约数（gcd）

### 作用

使用欧几里得算法计算两个整数的最大公约数。

### 逻辑

令 x = a
令 y = b
循环（当 y 不等于 0 时）：
    令 t = y
    y = x 取模 y
    x = t
返回 x

### 测试要点

1. gcd(12, 8) = 4
2. gcd(0, 5) = 5
3. gcd(5, 0) = 5
4. gcd(0, 0) = 0
5. gcd 为负数时按绝对值计算

## 函数 最小公倍数（lcm）

### 作用

计算两个整数的最小公倍数。若任一为 0 则返回 0。

### 逻辑

如果 a 等于 0 或 b 等于 0，那么：返回 0
返回 （a 除以 最大公约数（a, b））乘以 b

### 测试要点

1. lcm(4, 6) = 12
2. lcm(0, 5) = 0
3. lcm(5, 0) = 0
4. lcm(12, 8) = 24

## 函数 判断偶数（is_even）

### 逻辑

## 函数 判断奇数（is_odd）

### 作用

### 逻辑

### 测试要点

2. n = 0 返回假
3. n = -1 返回真

## 函数 阶乘（factorial）

### 作用

计算 n 的阶乘（n!）。n <= 1 时返回 1。

### 逻辑

如果 n 不大于 1，那么：返回 1
令 r = 1
令 i = 2
循环（当 i 不大于 n 时）：
    r = r 乘以 i
    i = i 加 1
返回 r

### 测试要点

1. n = 0 返回 1
2. n = 1 返回 1
3. n = 5 返回 120
4. n 为负数时返回 1（n <= 1）
