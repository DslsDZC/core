## 函数 绝对值（abs）

### 作用

返回给定整数的绝对值：若输入为负数则返回其相反数（取负），否则返回原值。

### 逻辑

函数 绝对值（abs）（输入值 变量甲（x）：整数）-> 整数
    如果 输入值 小于 0，那么：
        返回 负 输入值
    返回 输入值

### 测试要点

1. 输入值为负数（如 -5）：返回正数 5
2. 输入值为零：返回 0
3. 输入值为正数（如 5）：返回原值 5

## 函数 取最小值（min）

### 作用

返回两个整数中较小的一个。若两者相等则返回第二个参数值。

### 逻辑

函数 取最小值（min）（第一个值 变量甲（a）：整数, 第二个值 变量乙（b）：整数）-> 整数
    如果 第一个值 小于 第二个值，那么：
        返回 第一个值
    返回 第二个值

### 测试要点

1. 第一个值 小于 第二个值：返回 第一个值
2. 第一个值 大于 第二个值：返回 第二个值
3. 第一个值 等于 第二个值：返回 第二个值

### 逻辑

函数 取最大值（max）（第一个值 变量甲（a）：整数, 第二个值 变量乙（b）：整数）-> 整数

        返回 第一个值

### 测试要点

2. 第一个值 小于 第二个值：返回 第二个值
3. 第一个值 等于 第二个值：返回 第二个值

## 函数 钳制（clamp）

### 作用

将给定值约束在下限和上限所定义的闭区间内：若值小于下限则返回下限；若值大于上限则返回上限；否则返回原值。

### 逻辑

函数 钳制（clamp）（待钳制值 值（val）：整数, 下限 lo：整数, 上限 hi：整数）-> 整数
    如果 待钳制值 小于 下限，那么：
        返回 下限
    如果 待钳制值 大于 上限，那么：
        返回 上限
    返回 待钳制值

### 测试要点

1. 待钳制值在下限和上限之间（含相等）：返回原值
2. 待钳制值严格小于下限：返回下限
3. 待钳制值严格大于上限：返回上限
4. 待钳制值等于下限：返回原值（即下限）
5. 待钳制值等于上限：返回原值（即上限）

## 函数 幂运算（pow）

### 作用

计算底数的指数次幂（指数为非负整数）。指数为 0 时返回 1。通过循环累乘实现。

### 逻辑

函数 幂运算（pow）（底数 base：整数, 指数 exp：整数）-> 整数
    令 累积结果（r）= 1，可变（mut）
    令 循环计数（i）= 0，可变（mut）
    循环（一直执行）：
        如果 循环计数 大于等于 指数，那么：
            跳出循环
        累积结果 = 累积结果 乘以 底数
        循环计数 = 循环计数 加 1
    返回 累积结果

### 测试要点

1. 指数等于 0：任何底数均返回 1
2. 指数等于 1：返回底数本身
3. 底数等于 2，指数等于 3：返回 8
4. 底数为负数，指数为奇数：结果为负数
5. 底数为负数，指数为偶数：结果为正数

## 函数 最大公约数（gcd）

### 作用

使用欧几里得算法（辗转相除法）计算两个整数的最大公约数。当第二中间值归零时，第一中间值即为最大公约数。

### 逻辑

函数 最大公约数（gcd）（第一个数 变量甲（a）：整数, 第二个数 变量乙（b）：整数）-> 整数
    令 第一中间值（x）= 第一个数，可变（mut）
    令 第二中间值（y）= 第二个数，可变（mut）
    循环（一直执行）：
        如果 第二中间值 等于 0，那么：
            跳出循环
        令 临时暂存（t）= 第二中间值
        第二中间值 = 第一中间值 取模（%） 第二中间值
        第一中间值 = 临时暂存
    返回 第一中间值

### 测试要点

1. 输入（12, 8）：返回 4
2. 输入（0, 5）：返回 5（0 与任何非零数的最大公约数是该非零数）
3. 输入（5, 0）：返回 5（任何非零数与 0 的最大公约数是该非零数）
4. 输入（0, 0）：返回 0

## 函数 最小公倍数（lcm）

### 作用

计算两个正整数的最小公倍数。利用公式：最小公倍数等于第一个数乘以第二个数再除以两数的最大公约数。为避免溢出，先除后乘。若任一输入为 0，则返回 0。

### 逻辑

函数 最小公倍数（lcm）（第一个数 变量甲（a）：整数, 第二个数 变量乙（b）：整数）-> 整数
    如果 第一个数 等于 0 或 第二个数 等于 0，那么：
        返回 0
    返回 （第一个数 除以 最大公约数（gcd）（第一个数, 第二个数））乘以 第二个数

### 测试要点

1. 输入（4, 6）：返回 12
2. 输入（0, 5）：返回 0
3. 输入（5, 0）：返回 0
4. 输入（12, 8）：返回 24

## 函数 判断偶数（is_even）

### 作用

判断给定整数是否为偶数。计算方法为取模 2 并检查余数是否等于 0。

### 逻辑

函数 判断偶数（is_even）（输入数 数量（n）：整数）-> 布尔（bool）
    返回 输入数 取模（%） 2 等于 0

### 测试要点

1. 输入数等于 0：返回真（0 是偶数）
2. 输入数等于 2：返回真
3. 输入数等于 1：返回假
4. 输入数等于 -2：返回真（负偶数）

### 测试要点

3. 输入数等于 -1：返回真（负奇数）

## 函数 阶乘（factorial）

### 作用

计算给定非负整数的阶乘。若输入小于等于 1 则直接返回 1（0的阶乘与1的阶乘均为 1）。其他情况通过循环从 2 累乘至输入数。

### 逻辑

函数 阶乘（factorial）（输入数 数量（n）：整数）-> 整数
    如果 输入数 小于等于 1，那么：
        返回 1
    令 累积结果（r）= 1，可变（mut）
    令 循环计数（i）= 2，可变（mut）
    循环（一直执行）：
        如果 循环计数 大于 输入数，那么：
            跳出循环
        累积结果 = 累积结果 乘以 循环计数
        循环计数 = 循环计数 加 1
    返回 累积结果

### 测试要点

1. 输入数等于 0：返回 1（0 的阶乘定义为 1）
2. 输入数等于 1：返回 1
3. 输入数等于 5：返回 120
4. 输入数为负数：返回 1（触发小于等于 1 分支）
