# chan.cr 伪代码

> 源文件：src/stdlib/chan.cr（181 行）
> 功能概要：带类型的 FIFO 通道（channel），协程安全，含等待队列。通道操作自动触发调度器初始化。支持创建、发送、接收和关闭操作，阻塞等待时使用直接转交（handoff）机制。

## 函数 内部：确保通道初始化（_chan_ensure_init）

### 作用

延迟初始化：在首次通道操作时自动调用调度器初始化，设置全局标记避免重复初始化。

### 逻辑

函数 内部：确保通道初始化（_chan_ensure_init）
    如果 通道已初始化标记 等于 0，那么：
        调度器初始化（sched_init）（）
        令 通道已初始化标记 = 1

### 测试要点

1. 通道已初始化标记 等于 0 时触发调度器初始化
2. 通道已初始化标记 等于 1 时直接跳过，不重复初始化

## 函数 创建通道（chan_make）

### 作用

创建一个指定元素大小和容量的新通道。分配 64 字节通道结构和环形缓冲区，初始化所有字段。

### 逻辑

函数 创建通道（chan_make）（元素大小 elemsize：整数，通道容量（cap）：整数）-> 整数
    内部：确保通道初始化（）
    令 通道句柄（ch）= 分配（64）  // 64 字节通道结构体
    令 环形缓冲区（buf）= 分配（通道容量 乘以 元素大小）
    写 64 位（通道句柄, 0, 环形缓冲区）     // 偏移 0：环形缓冲区指针
    写 64 位（通道句柄, 8, 通道容量）        // 偏移 8：通道容量
    写 64 位（通道句柄, 16, 0）              // 偏移 16：当前长度 等于 0
    写 64 位（通道句柄, 24, 0）              // 偏移 24：头索引 等于 0
    写 64 位（通道句柄, 32, 元素大小）        // 偏移 32：元素大小
    写 64 位（通道句柄, 40, 负 1）            // 偏移 40：发送等待列表头 等于 空（负 1）
    写 64 位（通道句柄, 48, 负 1）            // 偏移 48：接收等待列表头 等于 空（负 1）
    写 64 位（通道句柄, 56, 0）               // 偏移 56：关闭标记 等于 开启（0）
    返回 通道句柄

### 测试要点

1. 通道初始状态为空（当前长度 等于 0）
2. 等待链表均为空（负 1）
3. 关闭标记为假（0 表示开启）

## 函数 通道发送（chan_send）

### 作用

向通道发送一个值。按以下优先级处理：
1. 若有等待中的接收者，直接将值转交给第一个接收者（绕过缓冲区）
2. 若环形缓冲区有空位，写入缓冲区
3. 若缓冲区满，将当前协程加入发送等待链表并让出执行权

### 逻辑

函数 通道发送（chan_send）（通道句柄 ch：整数，待发送值 值（val）：整数）
    内部：确保通道初始化（）
    令 环形缓冲区（buf）= 读 64 位（通道句柄, 0）
    令 通道容量（cap）= 读 64 位（通道句柄, 8）
    令 当前长度（len）= 读 64 位（通道句柄, 16）
    令 头索引（head）= 读 64 位（通道句柄, 24）
    令 元素大小（esize）= 读 64 位（通道句柄, 32）
    // 第一步：检查是否有等待中的接收者（直接转交，最高优先级）
    令 接收等待列表头（recv_wait）= 读 64 位（通道句柄, 48）
    如果 接收等待列表头 大于等于 0，那么：
        // 直接转交：将值写入第一个等待接收者的临时值存储（偏移 72），唤醒它
        令 链表下一节点（nxt）= 读 64 位（接收等待列表头, 48）  // 保存链表后继指针，避免被后续写入覆写
        写 64 位（接收等待列表头, 72, 待发送值）               // 将值写入接收者协程的临时值存储
        写 64 位（接收等待列表头, 8, 0）                        // 将接收者状态设为可运行
        调度入队（sched_enqueue）（接收等待列表头）              // 将接收者加入运行队列
        写 64 位（通道句柄, 48, 链表下一节点）                   // 从接收等待链表中移除该接收者
        返回
    // 第二步：缓冲区有空位时直接写入
    如果 当前长度 小于 通道容量，那么：
        令 环形缓冲区尾部索引（tail）=（头索引 加 当前长度）取模 通道容量
        写 64 位（环形缓冲区, 环形缓冲区尾部索引 乘以 元素大小, 待发送值）
        写 64 位（通道句柄, 16, 当前长度 加 1）  // 当前长度 递增
        返回
    // 第三步：缓冲区满——阻塞当前协程
    令 当前协程句柄（g）= 调度获取当前协程（sched_get_curg）（）
    如果 当前协程句柄 大于等于 0，那么：
        写 64 位（当前协程句柄, 72, 待发送值）     // 在临时值存储中保存待发送值，供将来接收者取用
        写 64 位（当前协程句柄, 8, 2）              // 状态设为等待中
        写 64 位（当前协程句柄, 48, 负 1）          // 链表下一节点 等于 负 1（标记链表末尾）
        // 将当前协程追加到通道的发送等待链表末尾
        令 发送等待遍历指针（sw）= 读 64 位（通道句柄, 40）  // 发送等待链表头
        如果 发送等待遍历指针 小于 0，那么：
            写 64 位（通道句柄, 40, 当前协程句柄）  // 链表为空，直接设为头节点
        否则：
            循环：
                令 链表下一节点 = 读 64 位（发送等待遍历指针, 48）  // 读取当前节点的链表后继
                如果 链表下一节点 小于 0，那么：
                    写 64 位（发送等待遍历指针, 48, 当前协程句柄）  // 到达链表末尾，将新节点挂载
                    跳出循环
                令 发送等待遍历指针 = 链表下一节点  // 继续向链表尾部遍历
    // 让出执行权——调度器在有接收者到来时通过通道接收唤醒本协程
    调度让出（sched_yield）（）

### 测试要点

1. 有等待接收者时触发直接转交（不经过缓冲区），值写入接收者的临时值存储
2. 缓冲区有空位时直接写入环形缓冲区
3. 缓冲区满时发送者阻塞到发送等待链表
4. 阻塞后调用调度让出让出执行权
5. 直接转交时正确维护接收等待链表（移除被唤醒的接收者）

## 函数 通道接收（chan_recv）

### 作用

从通道接收一个值。按以下优先级处理：
1. 若有等待中的发送者，直接从第一个发送者的临时值存储取值（绕过缓冲区）
2. 若环形缓冲区有数据，从缓冲区读取
3. 若通道已关闭且缓冲区空，返回 0
4. 若缓冲区空且未关闭，将当前协程加入接收等待链表并让出执行权

### 逻辑

函数 通道接收（chan_recv）（通道句柄 ch：整数）-> 整数
    内部：确保通道初始化（）
    令 环形缓冲区（buf）= 读 64 位（通道句柄, 0）
    令 通道容量（cap）= 读 64 位（通道句柄, 8）
    令 当前长度（len）= 读 64 位（通道句柄, 16）
    令 头索引（head）= 读 64 位（通道句柄, 24）
    令 元素大小（esize）= 读 64 位（通道句柄, 32）
    令 关闭标记（closed）= 读 64 位（通道句柄, 56）
    // 第一步：检查是否有等待中的发送者（直接转交，最高优先级）
    令 发送等待列表头（send_wait）= 读 64 位（通道句柄, 40）
    如果 发送等待列表头 大于等于 0，那么：
        // 直接转交：从第一个等待发送者的临时值存储读取值，唤醒它
        令 取得的值（val）= 读 64 位（发送等待列表头, 72）          // 读取发送者协程临时值存储中保存的值
        令 链表下一节点（nxt）= 读 64 位（发送等待列表头, 48）      // 保存链表后继指针
        写 64 位（发送等待列表头, 8, 0）                             // 将发送者状态设为可运行
        调度入队（sched_enqueue）（发送等待列表头）                    // 将发送者加入运行队列
        写 64 位（通道句柄, 40, 链表下一节点）                        // 从发送等待链表中移除该发送者
        返回 取得的值
    // 第二步：缓冲区有数据时从环形缓冲区读取
    如果 当前长度 大于 0，那么：
        令 取得的值 = 读 64 位（环形缓冲区, 头索引 乘以 元素大小）
        写 64 位（通道句柄, 24,（头索引 加 1）取模 通道容量）  // 头索引 等于（头索引 加 1）取模 通道容量
        写 64 位（通道句柄, 16, 当前长度 减 1）                 // 当前长度 递减
        返回 取得的值
    // 第三步：通道已关闭且缓冲区空
    如果 关闭标记 不等于 0，那么：返回 0
    // 第四步：缓冲区空——阻塞当前协程
    令 当前协程句柄（g）= 调度获取当前协程（sched_get_curg）（）
    如果 当前协程句柄 大于等于 0，那么：
        写 64 位（当前协程句柄, 8, 2）              // 状态设为等待中
        写 64 位（当前协程句柄, 48, 负 1）          // 链表下一节点 等于 负 1
        // 将当前协程追加到通道的接收等待链表末尾
        令 接收等待遍历指针（rw）= 读 64 位（通道句柄, 48）
        如果 接收等待遍历指针 小于 0，那么：
            写 64 位（通道句柄, 48, 当前协程句柄）  // 链表为空，直接设为头节点
        否则：
            循环：
                令 链表下一节点 = 读 64 位（接收等待遍历指针, 48）
                如果 链表下一节点 小于 0，那么：
                    写 64 位（接收等待遍历指针, 48, 当前协程句柄）  // 到达链表末尾
                    跳出循环
                令 接收等待遍历指针 = 链表下一节点
    调度让出（sched_yield）（）
    // 被唤醒后，值应该已经由发送者写入了本协程的临时值存储（偏移 72）
    令 取得的值 = 读 64 位（当前协程句柄, 72）
    返回 取得的值

### 测试要点

1. 有等待发送者时触发直接转交，从发送者的临时值存储取值
2. 缓冲区有数据时从环形缓冲区头部读取
3. 已关闭且缓冲区空（当前长度 等于 0）时返回 0
4. 缓冲区空时接收者阻塞到接收等待链表
5. 阻塞让出后被唤醒时从临时值存储（偏移 72）读取发送者写入的值
6. 直接转交时正确维护发送等待链表（移除被唤醒的发送者）

## 函数 关闭通道（chan_close）

### 作用

关闭通道：设置关闭标记为真，遍历发送等待链表和接收等待链表，将所有等待中的协程唤醒（设为可运行并入队），最后清空两个等待链表。

### 逻辑

函数 关闭通道（chan_close）（通道句柄 ch：整数）
    内部：确保通道初始化（）
    写 64 位（通道句柄, 56, 1）  // 偏移 56：关闭标记 等于 真（1）
    // 唤醒所有等待中的发送者
    令 发送等待遍历指针（sw）= 读 64 位（通道句柄, 40）  // 发送等待链表头
    循环：
        如果 发送等待遍历指针 小于 0，那么：跳出循环
        令 链表下一节点（nxt）= 读 64 位（发送等待遍历指针, 48）  // 保存链表后继指针
        写 64 位（发送等待遍历指针, 8, 0）                         // 状态设为可运行
        调度入队（sched_enqueue）（发送等待遍历指针）                // 将发送者加入运行队列
        令 发送等待遍历指针 = 链表下一节点                          // 继续遍历链表
    写 64 位（通道句柄, 40, 负 1）  // 清空发送等待链表头
    // 唤醒所有等待中的接收者
    令 接收等待遍历指针（rw）= 读 64 位（通道句柄, 48）  // 接收等待链表头
    循环：
        如果 接收等待遍历指针 小于 0，那么：跳出循环
        令 链表下一节点 = 读 64 位（接收等待遍历指针, 48）
        写 64 位（接收等待遍历指针, 8, 0）                         // 状态设为可运行
        调度入队（sched_enqueue）（接收等待遍历指针）                // 将接收者加入运行队列
        令 接收等待遍历指针 = 链表下一节点
    写 64 位（通道句柄, 48, 负 1）  // 清空接收等待链表头

### 测试要点

1. 关闭标记设为 1
2. 所有等待发送者被唤醒并入队
3. 所有等待接收者被唤醒并入队
4. 唤醒后等待链表头均被清空（设为 负 1）
5. 无等待者时循环不执行（链表头为 负 1）
