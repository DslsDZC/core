## 函数 追踪断言（trace_assert）

### 作用

轻量级运行时条件断言：当条件不满足（为假）时输出警告信息。与断言模块（assert.cr）的 断言（assert）不同，追踪断言（trace_assert）不会终止程序，仅输出诊断信息。

### 逻辑

函数 追踪断言（trace_assert）（条件（cond）：整数，诊断消息（msg）：字符串）
    如果 条件 不等于 0，那么：
        返回  // 条件成立，无需输出
    输出行（println）（诊断消息）

### 测试要点

1. 条件为真（非零）时，不产生任何输出
2. 条件为假（等于零）时，输出 诊断消息（msg）字符串并换行

## 函数 追踪调试输出（trace_dbg）

### 作用

输出整数值并原样返回。用于表达式内嵌调试（类似参照语言（Rust）的调试取值宏（dbg!）设计）。

### 逻辑

函数 追踪调试输出（trace_dbg）（名称（name）：字符串，值（val）：整数）-> 整数
    输出整数（print_i）（值）
    返回 值

### 测试要点

1. 输出 值（val）的十进制字符串表示并返回原值
2. 值（val）等于 0 时输出 0 并返回 0
3. 值（val）为负数时输出负数字符串并返回原值

## 函数 追踪调试字符串（trace_dbg_str）

### 作用

输出字符串值并原样返回。与 追踪调试输出（trace_dbg）对应，用于字符串类型。

### 逻辑

函数 追踪调试字符串（trace_dbg_str）（名称（name）：字符串，值（val）：字符串）-> 字符串
    输出字符串（print）（值）
    返回 值

### 测试要点

1. 输出字符串值并返回原字符串
2. 空字符串：输出空内容并返回空字符串
