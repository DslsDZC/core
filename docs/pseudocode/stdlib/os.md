# os.cr 伪代码

> 源文件：src/stdlib/os.cr（104 行）
> 功能概要：操作系统接口标准库。提供进程工作目录查询、可执行文件路径解析、shell 命令执行、环境变量读取等操作系统级功能。纯 Core 实现，通过系统调用3（syscall3）内建函数直接使用操作系统系统调用（如获取当前目录 getcwd、读取符号链接 readlink、创建子进程 fork、执行程序 execve、等待子进程 wait4、退出进程 _exit）。

## 函数 获取当前目录（get_cwd）

### 作用

获取进程当前工作目录的绝对路径。通过获取当前目录系统调用（getcwd，系统调用号 79）将路径写入分配 4096 字节的缓冲区。返回时去除路径末尾的空终止符；若系统调用失败或返回长度小于等于 1（仅含终止符），则返回空字符串。

### 逻辑

函数 获取当前目录（get_cwd）（）-> 字符串
    令 路径缓冲区（buf）= 分配（alloc）（4096）
    令 系统调用返回值（n）= 系统调用3（syscall3）（79, 路径缓冲区, 4096, 0）
    // 系统调用号 79：获取当前工作目录（getcwd）写入缓冲区
    如果 系统调用返回值 小于等于 1，那么：
        返回 ""  // 系统调用失败或结果仅含空终止符
    返回 字符串切片（str_sub）（路径缓冲区, 0, 系统调用返回值 减 1）
    // 去除路径末尾的空终止符

### 测试要点

1. 正常执行：返回当前工作目录的绝对路径字符串
2. 获取当前目录系统调用失败（系统调用返回值 小于等于 0）：返回空字符串
3. 系统调用返回值等于 1（仅含空终止符）：返回空字符串

## 函数 获取可执行文件路径（get_exe_path）

### 作用

解析当前运行可执行文件的真实绝对路径，即使启动时命令行参数来自可执行文件搜索路径（PATH 环境变量）也能正确获取。通过读取符号链接系统调用（readlink，系统调用号 89）读取伪文件系统路径（"/proc/self/exe"）中的符号链接目标路径。

### 逻辑

函数 获取可执行文件路径（get_exe_path）（）-> 字符串
    令 路径缓冲区（buf）= 分配（alloc）（4096）
    令 系统调用返回值（n）= 系统调用3（syscall3）（89, "/proc/self/exe", 路径缓冲区, 4095）
    // 系统调用号 89：读取符号链接（readlink）的目标路径写入缓冲区，最多 4095 字节
    如果 系统调用返回值 小于等于 0，那么：
        返回 ""  // 读取符号链接失败（如伪文件系统（proc）不可用）
    返回 字符串切片（str_sub）（路径缓冲区, 0, 系统调用返回值）

### 测试要点

1. 在正常环境中运行：返回可执行文件的绝对路径
2. 伪文件系统（/proc）不可用（如容器受限环境）：返回空字符串
3. 读取符号链接系统调用失败：返回空字符串

## 函数 执行系统命令（system）

### 作用

在子进程中执行一条命令行解释器（shell）命令并等待其完成。流程为：（1） 调用创建子进程系统调用（fork，系统调用号 57）复制当前进程；（2） 父进程中等待子进程结束（wait4，系统调用号 61），然后从返回状态值的第 8 至 15 位提取子进程退出码；（3） 子进程中构建命令行参数数组，通过执行程序系统调用（execve，系统调用号 59）执行解释器程序及其参数（"/bin/sh -变量丙（c）" 外加命令字符串），若执行程序失败则通过退出进程系统调用（_exit，系统调用号 60）以状态码 127 退出。

### 逻辑

函数 执行系统命令（system）（命令字符串 cmd：字符串）-> 整数
    // 第一步：创建子进程
    令 子进程标识（pid）= 系统调用3（syscall3）（57, 0, 0, 0）
    // 系统调用号 57：创建子进程（fork），返回 0 给子进程、子进程号给父进程
    如果 子进程标识 小于 0，那么：
        返回 -1  // 创建子进程失败
    如果 子进程标识 大于 0，那么：
        // 当前为父进程：等待子进程结束
        令 状态缓冲区（status_buf）= 分配（alloc）（16）
        系统调用3（syscall3）（61, 子进程标识, 状态缓冲区, 0）
        // 系统调用号 61：等待指定子进程结束（wait4），将退出状态写入状态缓冲区
        // 正常退出码存储在状态值的第 8 至 15 位，即状态缓冲区偏移 1 字节处
        返回 读取字节（load8）（状态缓冲区, 1）取模（%） 256
        // 提取退出码（范围 0 至 255）
    // 否则为子进程（子进程标识 等于 0）
    // 第二步：构建执行程序的参数数组（32 字节，含 4 个 8 字节指针槽位）
    令 命令行参数数组（argv）= 分配（alloc）（32）
    存储字符串指针（store_str_ptr）（命令行参数数组, 0, "/bin/sh"）
    // 参数槽位 0：命令行解释器（shell）可执行文件路径
    存储字符串指针（store_str_ptr）（命令行参数数组, 8, "-变量丙（c）"）
    // 参数槽位 1：指示命令行解释器（shell）解析后续命令行字符串
    存储字符串指针（store_str_ptr）（命令行参数数组, 16, 命令字符串）
    // 参数槽位 2：待执行的命令字符串
    // 参数槽位 3（偏移 24 处）：写入空指针终止符（NULL，8 字节清零）
    令 清零索引（zi）= 0，可变（mut）
    循环（一直执行）：
        如果 清零索引 大于等于 8，那么：
            跳出循环
        写单字节（store8）（命令行参数数组, 24 加 清零索引, 0）
        清零索引 = 清零索引 加 1
    // 第三步：执行命令行解释器（shell）
    系统调用3（syscall3）（59, "/bin/sh", 命令行参数数组, 0）
    // 系统调用号 59：执行程序（execve），以命令行解释器（shell）执行命令字符串
    // 若执行程序成功则不会返回（当前进程映像被替换）
    系统调用3（syscall3）（60, 127, 0, 0）
    // 系统调用号 60：退出进程（_exit），以代码 127 退出（执行程序失败）
    返回 -1  // 此行为不可达，仅满足函数签名

### 测试要点

1. 命令正常执行（如 system（"true"））：返回退出码 0
2. 命令执行失败（如 system（"false"））：返回非零退出码（false 的退出码为 1）
3. 创建子进程系统调用失败：返回 -1
4. 子进程中执行程序系统调用失败（如 /bin/sh 不存在）：子进程以退出码 127 退出，父进程收到退出码 127
5. 传入空命令字符串：命令行解释器（shell）正常执行并返回

## 函数 获取环境变量（get_env）

### 作用

从伪文件路径（"/proc/self/environ"）读取当前进程的环境变量块，逐条目扫描查找指定名称的环境变量并返回其值。环境变量块由空字符分隔的"键（KEY）=值（VALUE）"条目组成，末尾由连续两个空字符终止。若环境变量不存在或不可读则返回空字符串。

### 逻辑

函数 获取环境变量（get_env）（查找名称 name：字符串）-> 字符串
    令 环境变量原始内容（env）= 读取文件（read_file）（"/proc/self/environ"）
    如果 字符串长度（str_len）（环境变量原始内容）等于 0，那么：
        返回 ""  // 读取伪文件失败或环境变量块为空
    令 环境变量内容长度（elen）= 字符串长度（str_len）（环境变量原始内容）
    令 主遍历索引（i）= 0，可变（mut）
    循环（一直执行）：
        如果 主遍历索引 大于等于 环境变量内容长度，那么：
            跳出循环
        // 第一步：在当前条目中找到等号字符（=，字符码 61）的位置
        令 等号位置（eq_pos）= -1，可变（mut）
        令 内层扫描索引（j）= 主遍历索引，可变（mut）
        循环（一直执行）：
            如果 内层扫描索引 大于等于 环境变量内容长度，那么：
                跳出循环
            令 当前字符（c）= 读取字节（load8）（环境变量原始内容, 内层扫描索引）
            如果 当前字符 等于 61，那么：
                // 字符码 61 为等号字符（=）
                令 等号位置 = 内层扫描索引
                跳出循环
            如果 当前字符 等于 0，那么：
                // 遇到空终止符，当前条目无等号（非键值对）
                跳出循环
            内层扫描索引 = 内层扫描索引 加 1
        // 第二步：若找到等号，比较等号之前的键名与查找名称
        如果 等号位置 大于等于 0，那么：
            令 键名长度（key_len）= 等号位置 减 主遍历索引
            令 查找名长度（nlen）= 字符串长度（str_len）（查找名称）
            如果 键名长度 等于 查找名长度，那么：
                // 长度相等，逐字节比较键名
                令 是否匹配（is_match）= 1，可变（mut）
                令 键比较索引（ki）= 0，可变（mut）
                循环（一直执行）：
                    如果 键比较索引 大于等于 键名长度，那么：
                        跳出循环
                    如果 读取字节（load8）（环境变量原始内容, 主遍历索引 加 键比较索引）不等于 读取字节（load8）（查找名称, 键比较索引），那么：
                        令 是否匹配 = 0
                        跳出循环
                    键比较索引 = 键比较索引 加 1
                如果 是否匹配 不等于 0，那么：
                    // 键名完全匹配：提取等号之后至下一个空终止符之间的值
                    令 值起始位置（val_start）= 等号位置 加 1
                    令 值结束位置（val_end）= 值起始位置，可变（mut）
                    循环（一直执行）：
                        如果 值结束位置 大于等于 环境变量内容长度，那么：
                            跳出循环
                        如果 读取字节（load8）（环境变量原始内容, 值结束位置）等于 0，那么：
                            跳出循环  // 遇到空终止符，值的结束
                        值结束位置 = 值结束位置 加 1
                    返回 字符串切片（str_sub）（环境变量原始内容, 值起始位置, 值结束位置 减 值起始位置）
        // 第三步：跳过当前条目（移动到下一个空终止符之后）
        循环（当 主遍历索引 小于 环境变量内容长度 且 读取字节（load8）（环境变量原始内容, 主遍历索引）不等于 0 时）：
            主遍历索引 = 主遍历索引 加 1
        主遍历索引 = 主遍历索引 加 1  // 跳过空终止符，进入下一个环境变量条目
    返回 ""  // 遍历完所有条目，未找到匹配名称的环境变量

### 测试要点

1. 目标环境变量存在：返回该变量的字符串值
2. 目标环境变量不存在：返回空字符串
3. 伪文件路径（"/proc/self/environ"）不可读：返回空字符串
4. 环境变量值为空（等号后直接跟空终止符）：值起始位置 等于 值结束位置，返回空字符串
5. 环境变量键名长度与查找名称不同：直接跳过该条目，继续搜索下一项
6. 环境变量名部分匹配但长度不同：不匹配，继续搜索
