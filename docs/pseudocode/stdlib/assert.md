## 全局状态

无全局变量。

## 函数 断言（assert）

### 作用

条件（cond）为假（等于 0）时触发带位置恐慌（panic_at）。

### 逻辑

如果 条件（cond）等于 0，那么：
    带位置恐慌（信息（msg）, "", 0, 0）

### 测试要点

1. 条件为真（非零）时不触发恐慌
2. 条件为假（等于 0）时触发带位置恐慌并终止
3. 恐慌信息不包含文件/行号（均为空或 0）

## 函数 断言假（assert_not）

### 作用

条件为真时触发带位置恐慌（panic_at）。与断言（assert）的条件逻辑相反（反向断言）。

### 逻辑

如果 条件（cond）不等于 0，那么：
    带位置恐慌（信息（msg）, "", 0, 0）

### 测试要点

1. 条件为假时不触发恐慌
2. 条件为真时触发恐慌

## 函数 断言相等（assert_eq）

### 作用

第一个值（a）不等于第二个值（b）时触发带位置恐慌（panic_at）。

### 逻辑

如果 第一个值（a）不等于 第二个值（b），那么：
    带位置恐慌（信息（msg）, "", 0, 0）

### 测试要点

1. 第一个值 等于 第二个值 时不触发恐慌
2. 第一个值 不等于 第二个值 时触发恐慌

### 作用

### 逻辑

## 函数 调试断言（debug_assert）

### 作用

调试模式断言——当前行为与普通断言相同（始终检查）。未来可由编译选项控制是否启用。

### 逻辑

如果 条件（cond）等于 0，那么：
    带位置恐慌（信息（msg）, "", 0, 0）

### 测试要点

1. 当前行为与断言（assert）完全一致
2. 条件为假时触发恐慌

## 函数 调试断言相等（debug_assert_eq）

### 作用

### 逻辑

### 测试要点

2. 第一个值 不等于 第二个值 时触发恐慌

## 函数 不可达（unreachable）

### 作用

标记代码中逻辑上不可达的位置。若执行到此立即触发带位置恐慌（panic_at）。

### 逻辑

带位置恐慌（"internal error: entered unreachable code", "", 0, 0）

### 测试要点

1. 调用即恐慌，输出 "内部错误：进入了不可达代码"
2. 无返回值

## 函数 不可达（可变）（unreachable_mut）

### 作用

有返回值的不可达标记——用于函数必须有返回值的场景（如匹配（match）完备分支的兜底）。返回 -1，但实际执行前已恐慌退出。

### 逻辑

带位置恐慌（"internal error: entered unreachable code", "", 0, 0）
返回 -1

### 测试要点

1. 调用即恐慌，执行不到返回语句
2. 返回类型为整数，适配需要返回值的上下文

### 作用

### 逻辑

### 测试要点

1. 调用即恐慌
2. 恐慌信息为 "尚未实现："

## 函数 检查边界（check_bounds）

### 作用

数组访问的运行时边界检查。检查索引（index）是否在 [0, 长度（len）） 范围内，超出则触发带位置恐慌（panic_at）。

### 逻辑

如果 索引（index）小于 0 或 索引 大于等于 长度（len），那么：
    带位置恐慌（信息（msg）, "", 0, 0）

### 测试要点

1. 索引 = 0，长度 = 10 通过检查
2. 索引 = 9，长度 = 10 通过检查
3. 索引 = -1 触发恐慌
4. 索引 = 10，长度 = 10 触发恐慌（等于长度）
5. 长度 = 0 时任何索引都触发恐慌

## 函数 检查范围（check_range）

### 作用

检查子范围 [起始（start）, 结束（end）） 是否在 [0, 长度（len）） 内。违反则触发带位置恐慌（panic_at）。

### 逻辑

如果 起始（start）小于 0 或 起始 大于 结束（end）或 结束 大于 长度（len），那么：
    带位置恐慌（信息（msg）, "", 0, 0）

### 测试要点

1. 起始 = 0，结束 = 5，长度 = 10 通过
2. 起始 = 5，结束 = 10，长度 = 10 通过（结束 等于 长度 通过）
3. 起始 = -1 触发恐慌
4. 起始 = 5，结束 = 3 触发恐慌（起始 大于 结束）
5. 结束 = 11，长度 = 10 触发恐慌（结束 大于 长度）
