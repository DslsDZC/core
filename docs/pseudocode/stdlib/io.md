## 函数 输出字符串（print）

### 作用

向标准输出（stdout，文件描述符 1）写入一个字符串。通过系统调用3（syscall3）内建函数调用操作系统的写入（write）系统调用（系统调用号 1）。

### 逻辑

函数 输出字符串（print）（待输出字符串 状态（s）：字符串）
    令 字符串长度（slen）= 字符串长度（str_len）（待输出字符串）
    令 系统调用返回值1（r1）= 系统调用3（syscall3）（1, 1, 待输出字符串, 字符串长度）
    // 系统调用号 1：将待输出字符串写入标准输出（文件描述符 1）
    返回

### 测试要点

1. 空字符串：字符串长度（slen）等于 0，系统调用3 写入 0 字节
2. 普通非空字符串：成功写入到标准输出

## 函数 输出行（println）

### 作用

向标准输出写入一个字符串，并在末尾自动追加换行符。分两次调用写入（write）系统调用：先写字符串，再写换行符。

### 逻辑

函数 输出行（println）（待输出字符串 状态（s）：字符串）
    令 字符串长度（slen）= 字符串长度（str_len）（待输出字符串）
    令 系统调用返回值1（r1）= 系统调用3（syscall3）（1, 1, 待输出字符串, 字符串长度）
    // 系统调用号 1：写入字符串内容
    令 系统调用返回值2（r2）= 系统调用3（syscall3）（1, 1, "\数量（n）", 1）
    // 系统调用号 1：写入换行符（\数量（n），长度 1）
    返回

### 测试要点

1. 空字符串输入：输出仅一个换行符
2. 非空字符串输入：输出字符串内容后跟一个换行符

## 函数 输出整数（print_i）

### 作用

先将整数转换为十进制字符串表示，再将结果输出到标准输出。等价于先调用整数转字符串（int_str），再调用输出字符串（print）。

### 逻辑

函数 输出整数（print_i）（待输出整数 数量（n）：整数）
    输出字符串（print）（整数转字符串（int_str）（待输出整数））

### 测试要点

1. 待输出整数等于 0：输出字符串 "0"
2. 待输出整数为负数：输出带负号的字符串
3. 语义上等价于依次调用整数转字符串和输出字符串

## 函数 输出整数行（println_i）

### 作用

先将整数转换为十进制字符串表示，再输出到标准输出并在末尾追加换行符。等价于先调用整数转字符串（int_str），再调用输出行（println）。

### 逻辑

函数 输出整数行（println_i）（待输出整数 数量（n）：整数）
    输出行（println）（整数转字符串（int_str）（待输出整数））

### 测试要点

1. 待输出整数等于 0：输出 "0" 后跟换行符
2. 语义上等价于依次调用整数转字符串和输出行

## 函数 读取文件（read_file）

### 作用

打开指定路径的文件，读取其全部内容并返回为字符串。使用操作系统的一组文件操作系统调用：以只读方式打开（打开系统调用，open，系统调用号 2）、定位文件指针（定位系统调用，文件定位（lseek），系统调用号 8）、读取数据（读取系统调用，read，系统调用号 0）、关闭文件（关闭系统调用，close，系统调用号 3）。若文件打开失败、定位失败或读取后内容为空，均返回空字符串。

### 逻辑

函数 读取文件（read_file）（路径 path：字符串）-> 字符串
    令 文件描述符（fd）= 系统调用3（syscall3）（2, 路径, 0, 0）
    // 系统调用号 2：以只读标志（O_RDONLY，值为 0）打开指定路径文件
    如果 文件描述符 小于 0，那么：
        返回 ""  // 打开文件失败
    令 文件大小（fsize）= 系统调用3（syscall3）（8, 文件描述符, 0, 2）
    // 系统调用号 8：定位到文件末尾（SEEK_END，偏移基准 2），返回文件总字节数
    如果 文件大小 小于 0，那么：
        令 系统调用返回值1（r1）= 系统调用3（syscall3）（3, 文件描述符, 0, 0）
        // 系统调用号 3：关闭文件描述符
        返回 ""  // 获取文件大小失败
    令 系统调用返回值1（r1）= 系统调用3（syscall3）（8, 文件描述符, 0, 0）
    // 系统调用号 8：将文件指针重置回文件开头（SEEK_SET，偏移基准 0）
    令 缓冲区（buf）= 分配（alloc）（文件大小 加 1）
    令 已读字节数（nread）= 系统调用3（syscall3）（0, 文件描述符, 缓冲区, 文件大小）
    // 系统调用号 0：从文件读取指定字节数到缓冲区
    令 系统调用返回值2（r2）= 系统调用3（syscall3）（3, 文件描述符, 0, 0）
    // 系统调用号 3：关闭文件描述符
    如果 已读字节数 大于 0，那么：
        写单字节（store8）（缓冲区, 已读字节数, 0）  // 在尾部写入空终止符（null byte）
    返回 缓冲区

### 测试要点

1. 文件存在且有内容：返回文件的全部字符内容
2. 文件不存在：打开系统调用返回负数，返回空字符串
3. 空文件：文件大小等于 0，分配 1 字节缓冲区，已读字节数等于 0，返回仅含空终止符的字符串
4. 定位到文件末尾失败：关闭文件描述符后返回空字符串

## 函数 写入文件（write_file）

### 作用

打开（若不存在则创建，若已存在则截断至零长度）指定路径的文件，将给定字符串内容写入，最后关闭文件。返回实际写入的字节数；若文件打开失败则返回 -1。文件打开标志组合：只写（O_WRONLY，值 1）、如不存在则创建（O_CREAT，值 64）、打开时截断（O_TRUNC，值 512），三者按位或合并为整数值 577；权限设为 0644（八进制，十进制值 420）。

### 逻辑

函数 写入文件（write_file）（路径 path：字符串, 写入内容 content：字符串）-> 整数
    令 文件描述符（fd）= 系统调用3（syscall3）（2, 路径, 577, 420）
    // 系统调用号 2：以只写且创建且截断模式打开文件（O_WRONLY | O_CREAT | O_TRUNC = 577），权限 0644
    如果 文件描述符 小于 0，那么：
        返回 -1  // 打开或创建文件失败
    令 内容长度（clen）= 字符串长度（str_len）（写入内容）
    令 已写字节数（nwritten）= 系统调用3（syscall3）（1, 文件描述符, 写入内容, 内容长度）
    // 系统调用号 1：将内容写入文件描述符
    令 系统调用返回值1（r1）= 系统调用3（syscall3）（3, 文件描述符, 0, 0）
    // 系统调用号 3：关闭文件描述符
    返回 已写字节数

### 测试要点

1. 正常写入文件：打开成功，写入成功，关闭成功，返回实际写入字节数
2. 目标路径不可写（权限不足或路径无效）：打开系统调用返回负数，返回 -1
3. 写入空字符串：内容长度等于 0，写入返回 0，关闭文件后返回 0
