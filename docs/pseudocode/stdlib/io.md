## 函数 输出字符串（print）

### 作用

向标准输出（文件描述符 1）写入字符串。通过系统调用（syscall3）直接调用 Linux write。

### 逻辑

令 字符串长度 = 字符串长度（s）
令 r1 = 系统调用3（1, 1, s, 字符串长度）  // write(1, s, len)，系统调用号 1
返回

### 测试要点

1. 空字符串：len = 0，write 调用写入 0 字节
2. 普通字符串输出到 stdout

## 函数 输出行（println）

### 作用

向标准输出写入字符串，末尾自动追加换行符。

### 逻辑

令 字符串长度 = 字符串长度（s）
令 r1 = 系统调用3（1, 1, s, 字符串长度）  // write 字符串
令 r2 = 系统调用3（1, 1, "\n", 1）        // write 换行符
返回

### 测试要点

1. 空字符串时输出一个换行符
2. 正常字符串时输出内容后跟换行符

## 函数 输出整数（print_i）

### 作用

将整数转换为字符串后输出到标准输出。

### 逻辑

输出字符串（整数转字符串（n））

### 测试要点

1. n = 0 时输出 "0"
2. n 为负数时输出带负号的字符串
3. 等价于 print(int_str(n))

## 函数 输出整数行（println_i）

### 作用

将整数转换为字符串后输出到标准输出，末尾换行。

### 逻辑

输出行（整数转字符串（n））

### 测试要点

1. n = 0 时输出 "0\n"
2. 等价于 println(int_str(n))

## 函数 读取文件（read_file）

### 作用

打开文件、读取全部内容，返回字符串。使用 Linux 系统调用 open/lseek/read/close。读取失败返回空字符串。

### 逻辑

令 文件描述符 = 系统调用3（2, 路径, 0, 0）  // open(path, O_RDONLY, 0)，系统调用号 2
如果 文件描述符 小于 0，那么：
    返回 ""
令 文件大小 = 系统调用3（8, 文件描述符, 0, 2）  // lseek(fd, 0, SEEK_END)，系统调用号 8
如果 文件大小 小于 0，那么：
    令 r1 = 系统调用3（3, 文件描述符, 0, 0）  // close(fd)，系统调用号 3
    返回 ""
令 r1 = 系统调用3（8, 文件描述符, 0, 0）  // lseek(fd, 0, SEEK_SET)
令 缓冲区 = 分配（文件大小 加 1）
令 已读字节数 = 系统调用3（0, 文件描述符, 缓冲区, 文件大小）  // read(fd, buf, size)，系统调用号 0
令 r2 = 系统调用3（3, 文件描述符, 0, 0）  // close(fd)
如果 已读字节数 大于 0，那么：
    写单字节（缓冲区, 已读字节数, 0）
返回 缓冲区

### 测试要点

1. 文件存在且有内容时返回文件全部内容
2. 文件不存在时 open 返回负值，返回空字符串
3. 空文件：fsize = 0，分配 1 字节缓冲区，nread = 0，返回仅含 null 终止符的字符串
4. lseek 失败时关闭文件描述符后返回空字符串

## 函数 写入文件（write_file）

### 作用

打开文件（若不存在则创建，若存在则截断），写入内容，返回写入的字节数。写入失败返回 -1。

### 逻辑

令 文件描述符 = 系统调用3（2, 路径, 577, 420）  // open O_WRONLY|O_CREAT|O_TRUNC, 0644
如果 文件描述符 小于 0，那么：
    返回 -1
令 内容长度 = 字符串长度（内容）
令 已写字节数 = 系统调用3（1, 文件描述符, 内容, 内容长度）  // write(fd, content, len)
令 r1 = 系统调用3（3, 文件描述符, 0, 0）  // close(fd)
返回 已写字节数

### 测试要点

1. 正常写入文件，返回写入的字节数
2. 目标路径不可写时 open 返回负值，返回 -1
3. 空内容：len = 0，write 返回 0，关闭文件后返回 0
