## 函数 内部：跳过空白（_skip_whitespace）

### 作用

从给定位置开始，跳过空格符和制表符，返回第一个非空白字符的位置。到达字符串末尾时返回字符串长度。

### 逻辑

函数 内部：跳过空白（_skip_whitespace）（配置内容（content）：字符串，起始位置（pos）：整数）-> 整数
    令 字符串总长度（slen）= 字符串长度（str_len）（配置内容）
    令 当前位置（p）= 起始位置
    循环（当 当前位置 小于 字符串总长度 时）：
        令 当前字符（ch）= 取字符串第 N 字符（get_char）（配置内容，当前位置）
        如果 当前字符 不等于 空格符 且 当前字符 不等于 制表符，那么：
            跳出循环
        令 当前位置 = 当前位置 加 1
    返回 当前位置

### 测试要点

1. 当前位置为空白时跳过所有连续空白
2. 当前位置非空白时直接返回原位置
3. 到达字符串末尾时返回 字符串总长度（slen）

## 函数 内部：判断行首位置（_is_at_line_start）

### 作用

判断给定位置是否为行首（位置为 0，或前一个字符是换行符）。

### 逻辑

函数 内部：判断行首位置（_is_at_line_start）（配置内容（content）：字符串，起始位置（pos）：整数）-> 布尔
    如果 起始位置 等于 0，那么：
        返回 真
    令 前一个字符（prev）= 取字符串第 N 字符（get_char）（配置内容，起始位置 减 1）
    返回 前一个字符 等于 换行符

### 测试要点

1. 起始位置（pos）等于 0 时返回真
2. 起始位置前一个字符是换行符时返回真
3. 起始位置前一个字符不是换行符时返回假

## 函数 内部：跳到下一行（_skip_to_next_line）

### 作用

从当前位置找到下一个换行符，返回换行符之后的位置（即下一行起始）。已到末尾则返回字符串长度。

### 逻辑

函数 内部：跳到下一行（_skip_to_next_line）（配置内容（content）：字符串，起始位置（pos）：整数）-> 整数
    令 字符串总长度（slen）= 字符串长度（str_len）（配置内容）
    令 当前位置（p）= 起始位置
    循环（当 当前位置 小于 字符串总长度 时）：
        如果 取字符串第 N 字符（get_char）（配置内容，当前位置）等于 换行符，那么：
            返回 当前位置 加 1
        令 当前位置 = 当前位置 加 1
    返回 字符串总长度

### 测试要点

1. 在行中间调用时返回下一行起始位置
2. 已在最后一行时返回字符串总长度

            返回 循环索引 加 1
        令 循环索引 = 循环索引 加 1

### 测试要点

## 函数 TOML：获取字符串（toml_get_str）

### 作用

从 配置格式（TOML）内容中提取指定键名的字符串值（格式：键名（key）= 某字符串值（value））。逐行扫描，仅在行首匹配键名（跳过前导空白后），找到等号（=）后读取双引号内的字符串。未找到或格式不匹配返回空字符串。

### 逻辑

函数 TOML：获取字符串（toml_get_str）（配置内容（content）：字符串，键名（key）：字符串）-> 字符串
    令 字符串总长度（slen）= 字符串长度（str_len）（配置内容）
    令 键名长度（klen）= 字符串长度（str_len）（键名）
    令 当前位置（pos）= 0
    循环（当 当前位置 小于 字符串总长度 时）：
        如果 非 内部：判断行首位置（配置内容，当前位置），那么：
            令 当前位置 = 内部：下一行起始位置（配置内容，当前位置）
            继续下一次循环
        令 行首位置（spos）= 内部：跳过空白（配置内容，当前位置）
        如果 行首位置 加 键名长度 小于等于 字符串总长度，那么：
            令 切片子串（sub）= 字符串切片（str_sub）（配置内容，行首位置，键名长度）
            如果 字符串相等比较（str_eq）（切片子串，键名）不等于 0，那么：
                令 等号位置（eq_pos）= 行首位置 加 键名长度
                令 等号位置 = 内部：跳过空白（配置内容，等号位置）
                如果 取字符串第 N 字符（get_char）（配置内容，等号位置）等于 等号符（=），那么：
                    令 值起始位置（val_pos）= 内部：跳过空白（配置内容，等号位置 加 1）
                    如果 取字符串第 N 字符（get_char）（配置内容，值起始位置）等于 双引号符，那么：
                        令 内容起始（start）= 值起始位置 加 1
                        令 内容结束（end）= 内容起始
                        循环（当 真 时）：
                            如果 内容结束 大于等于 字符串总长度，那么：返回 ""
                            如果 取字符串第 N 字符（get_char）（配置内容，内容结束）等于 双引号符，那么：
                                返回 字符串切片（str_sub）（配置内容，内容起始，内容结束 减 内容起始）
                            令 内容结束 = 内容结束 加 1
        令 当前位置 = 内部：下一行起始位置（配置内容，当前位置）
    返回 ""  // 遍历完毕，未找到匹配的键名

### 测试要点

1. 键名存在且值为字符串时返回字符串内容（不含引号）
2. 键名不存在时返回空字符串
3. 值为空字符串（两个连续双引号）时返回空字符串
4. 值未用双引号包裹时无法匹配，继续搜索下一行
5. 缺失闭合双引号时返回空字符串
6. 键名行前有空白字符时正确跳过（由 内部：跳过空白 处理）
7. 键名出现在非行首位置时不被识别（由 内部：判断行首位置 检查）

## 函数 TOML：获取整数（toml_get_int）

### 作用

从 配置格式（TOML）内容中提取指定键名的整数值（格式：键名（key）= 123 或 键名（key）= -123）。逐行扫描，仅在行首匹配键名，找到等号（=）后读取数字序列。支持负号前缀，遇到非数字字符停止解析。未找到或解析无效返回 0。

### 逻辑

函数 TOML：获取整数（toml_get_int）（配置内容（content）：字符串，键名（key）：字符串）-> 整数
    令 字符串总长度（slen）= 字符串长度（str_len）（配置内容）
    令 键名长度（klen）= 字符串长度（str_len）（键名）
    令 当前位置（pos）= 0
    循环（当 当前位置 小于 字符串总长度 时）：
        如果 非 内部：判断行首位置（配置内容，当前位置），那么：
            令 当前位置 = 内部：下一行起始位置（配置内容，当前位置）
            继续下一次循环
        令 行首位置（spos）= 内部：跳过空白（配置内容，当前位置）
        如果 行首位置 加 键名长度 小于等于 字符串总长度，那么：
            令 切片子串（sub）= 字符串切片（str_sub）（配置内容，行首位置，键名长度）
            如果 字符串相等比较（str_eq）（切片子串，键名）不等于 0，那么：
                令 等号位置（eq_pos）= 内部：跳过空白（配置内容，行首位置 加 键名长度）
                如果 取字符串第 N 字符（get_char）（配置内容，等号位置）等于 等号符（=），那么：
                    令 值起始位置（val_pos）= 内部：跳过空白（配置内容，等号位置 加 1）
                    令 整数值（val）= 0
                    令 数字读取位置（lp）= 值起始位置
                    令 负数标记（neg）= 0
                    如果 取字符串第 N 字符（get_char）（配置内容，数字读取位置）等于 负号符（-），那么：
                        令 负数标记 = 1
                        令 数字读取位置 = 数字读取位置 加 1
                    循环（当 数字读取位置 小于 字符串总长度 时）：
                        令 当前数字字符（c）= 按字节读取（load8）（配置内容，数字读取位置）
                        如果 当前数字字符 大于等于 48 且 当前数字字符 小于等于 57，那么：
                            令 整数值 = 整数值 乘以 10 加（当前数字字符 减 48）
                            令 数字读取位置 = 数字读取位置 加 1
                        否则：
                            跳出循环
                    如果 负数标记 等于 1，那么：
                        令 整数值 = 负 整数值
                    返回 整数值
        令 当前位置 = 内部：下一行起始位置（配置内容，当前位置）
    返回 0  // 遍历完毕，未找到匹配的键名

### 测试要点

1. 键存在且值为正整数时返回该整数
2. 键存在且值为负整数时返回带符号的整数
3. 键不存在时返回 0（注意与整数值（val）等于 0 的情况无法区分）
4. 等号后无有效数字时返回 0
5. 数字后跟非数字字符时停止解析，返回已解析部分
6. 行首空白跳过检查

## 函数 TOML：读取内存布局（toml_read_memlayout）

### 作用

从 配置格式（TOML）内容中读取四个内存布局配置键：栈大小（stack_size）、堆大小（heap_size）、代码段基址（text_base）、数据段基址（data_base），构造并返回 内存布局（MemLayout）结构体。未配置的键默认值为 0。

### 逻辑

函数 TOML：读取内存布局（toml_read_memlayout）（配置内容（content）：字符串）-> 内存布局（MemLayout）
    构造 内存布局（MemLayout）并返回，各字段赋值：
        内存布局（MemLayout）的 栈大小字段（stack_size）= TOML：获取整数（toml_get_int）（配置内容，栈大小键名（"stack_size"））
        内存布局（MemLayout）的 堆大小字段（heap_size）= TOML：获取整数（toml_get_int）（配置内容，堆大小键名（"heap_size"））
        内存布局（MemLayout）的 代码段基址字段（text_base）= TOML：获取整数（toml_get_int）（配置内容，代码段基址键名（"text_base"））
        内存布局（MemLayout）的 数据段基址字段（data_base）= TOML：获取整数（toml_get_int）（配置内容，数据段基址键名（"data_base"））

### 测试要点

1. 所有键都存在时返回完整的内存布局
2. 部分键缺失时对应字段为 0
3. 全部键缺失时返回全 0 的 内存布局（MemLayout）
