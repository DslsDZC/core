## 函数 发射单条指令（emit_instr）
### 作用
x86-64 后端的指令编码核心。读取单条 IR 指令的操作码，分发到各 分支（case） 分支，逐字节编码为机器码写入输出缓冲区，返回写入的字节数。本部分涵盖 空操作指令（IR_NOP） 到 调用指令（IR_CALL） 的分支逻辑。
### 签名
函数 发射单条指令（emit_instr）（指令索引（instr_idx）：整数, 缓冲区（buf）：字符串, 起始位置（pos）：整数）-> 整数
### 逻辑

—— 第一步：提取操作数字段
令 操作码（op）= IR 指令访问器：操作码（iri_op），传入 指令索引。
令 目标变量（d）= IR 指令访问器：目标（iri_dest），传入 指令索引。
令 源操作数 1（s1）= IR 指令访问器：操作数1（iri_s1），传入 指令索引。
令 源操作数 2（s2）= IR 指令访问器：操作数2（iri_s2），传入 指令索引。
令 源操作数 3（s3）= IR 指令访问器：操作数3（iri_s3），传入 指令索引。
令 类型信息（ti）= IR 指令访问器：类型类别（iri_tk），传入 指令索引。
令 当前指针（cp）= 0（从起始位置开始，累加已写入的字节数）。

#### 分支 空操作指令（IR_NOP）（空操作）
如果 操作码 等于 空操作操作码常量（IR_NOP），则返回 0（不生成任何机器码字节）。
##### 测试要点
1. 始终返回 0，不向缓冲区写入任何内容。

#### 分支 常量指令（IR_CONST）（常量加载）
如果 操作码 等于 常量加载操作码常量（IR_CONST）且 目标变量 大于等于 0，则执行以下操作：
    令 目标槽位（do2）= 全局变量槽位（g2_slot），传入 目标变量。
    如果 类型信息 等于 字符串类型常量（TI_STR），则执行以下操作：
        —— 字符串常量：走 .只读数据段（rodata） 引用路径
        令 只读数据偏移量（ro）= 全局变量字符串偏移（g2_str_off），传入 源操作数 1。（为字符串常量分配 .rodata 中的偏移量，若已分配则直接返回。）
        
        —— 记录 .只读数据段（rodata） 引用位置，供后续 Phase 3 中的后发射修补使用
        调用 扩展 .只读数据段（rodata） 引用数组（grow_rodataref），传入 原 x86 .只读数据段 引用计数 + 1。
        向 x86 .只读数据段（rodata） 引用位置数组（g_x86_rodataref_pos）的偏移量（x86 .rodata 引用计数 * 8）处写入 64 位值（起始位置 + 当前指针）—— 记录引用发生的缓冲区位置。
        向 x86 .只读数据段（rodata） 引用目标数组（g_x86_rodataref_ro）的偏移量（x86 .rodata 引用计数 * 8）处写入 64 位值 只读数据偏移量。
        将 x86 .只读数据段（rodata） 引用计数（g_x86_rodataref_count）增加 1。
        
        —— 发射 LEA 指令（占位符，后续修补）：lea r10, [rip+0]
        令 当前指针 = 当前指针 + 发射加载寄存器（e2_lr）的返回值，参数为：缓冲区、起始位置+当前指针、0（占位符 rel32 值）。
        
        —— 发射存储指令：将 r10 的值（字符串指针）存入栈帧目标槽位
        令 当前指针 = 当前指针 + 发射存储（e2_st）的返回值，参数为：缓冲区、起始位置+当前指针、10（r10 的寄存器编号）、目标槽位。
    否则执行以下操作：
        —— 整数常量：直接发射立即数存储
        令 当前指针 = 当前指针 + 发射加载立即数（e2_li）的返回值，参数为：缓冲区、起始位置+当前指针、目标槽位、源操作数 1。
    返回 当前指针。
##### 测试要点
1. 字符串常量：走 .只读数据段（rodata） 引用路径，lea r10 + 存储（st） r10 序列，约 11 字节。
2. 零值整数常量：走 发射加载立即数（e2_li） 的 32 位有符号路径。
3. 大整数常量（超出 32 位有符号范围）：走 发射加载立即数（e2_li） 的 64 位立即数路径。

#### 分支 二元运算指令（IR_BINARY）（二元运算）
如果 操作码 等于 二元运算操作码常量（IR_BINARY），则执行以下操作：
    令 目标槽位（do2）= 全局变量槽位（g2_slot），传入 目标变量。
    
    —— 加载两个操作数到 r10 和 r11
    令 当前指针 = 当前指针 + 发射加载变量（e2_load_var）的返回值，参数为：缓冲区、起始位置+当前指针、10（目标寄存器 r10）、源操作数 1。
    令 当前指针 = 当前指针 + 发射加载变量（e2_load_var）的返回值，参数为：缓冲区、起始位置+当前指针、11（目标寄存器 r11）、源操作数 2。
    
    —— 根据源操作数 3（运算符编码）分发到具体的 x86-64 编码序列

    如果 源操作数 3 等于 加法运算符常量（OP_ADD），则执行以下操作：
        令 当前指针 = 当前指针 + 发射 ALU 指令（e2_alu）的返回值，参数为：缓冲区、起始位置+当前指针、1（操作码 0x01，表示 加法指令（ADD） r/m, r 指令）。此指令效果为 r11 = r11 + r10。
    
    否则如果 源操作数 3 等于 减法运算符常量（OP_SUB），则执行以下操作：
        令 当前指针 = 当前指针 + 发射 ALU 指令（e2_alu）的返回值，参数为：缓冲区、起始位置+当前指针、41（操作码 0x29，表示 减法指令（SUB） r/m, r 指令）。此指令效果为 r11 = r11 - r10。
    
    否则如果 源操作数 3 等于 乘法运算符常量（OP_MUL），则执行以下操作：
        —— 发射 imul r10, r11 指令（双字节操作码 0x0F 0xAF，有符号乘法，结果存入 r10）
        令 当前指针 = 当前指针 + 发射 REX 前缀（emit_rex）的返回值，参数为：缓冲区、起始位置+当前指针、W=1、R=10/8、X=0、B=11/8。
        向缓冲区偏移量（起始位置+当前指针）处写入单字节值 15（第一字节 0x0F）。
        将 当前指针 增加 1。
        向缓冲区偏移量（起始位置+当前指针）处写入单字节值 175（第二字节 0xAF）。
        将 当前指针 增加 1。
        令 当前指针 = 当前指针 + 发射 ModRM（emit_modrm）的返回值，参数为：缓冲区、起始位置+当前指针、寻址模式=3、寄存器字段=10%8（r10 的低 3 位 = 2）、寄存器或内存字段=11%8（r11 的低 3 位 = 3）。
    
    否则如果 源操作数 3 等于 左移运算符常量（OP_SHL），则执行以下操作：
        —— 第一步：mov rcx, r11（将移位量从 r11 移至 rcx，因为 SHL 指令的移位量必须来自 CL 寄存器）
        令 当前指针 = 当前指针 + 发射 REX 前缀（emit_rex）的返回值，参数为：缓冲区、起始位置+当前指针、W=1、R=11/8、X=0、B=0（rcx 的 B=0）。
        向缓冲区偏移量（起始位置+当前指针）处写入单字节值 137（操作码 0x89，MOV r/m, r）。
        将 当前指针 增加 1。
        令 当前指针 = 当前指针 + 发射 ModRM（emit_modrm）的返回值，参数为：缓冲区、起始位置+当前指针、寻址模式=3、寄存器字段=11%8（即 3）、寄存器或内存字段=1（rcx 的寄存器编号为 1）。
        —— 第二步：shl r10, cl（操作码 0xD3，/4 扩展码）
        令 当前指针 = 当前指针 + 发射 REX 前缀（emit_rex）的返回值，参数为：缓冲区、起始位置+当前指针、W=1、R=0、X=0、B=10/8。
        向缓冲区偏移量（起始位置+当前指针）处写入单字节值 211（操作码 0xD3，SHIFT r/m, CL 指令）。
        将 当前指针 增加 1。
        令 当前指针 = 当前指针 + 发射 ModRM（emit_modrm）的返回值，参数为：缓冲区、起始位置+当前指针、寻址模式=3、寄存器字段=4（/4 扩展码表示 SHL）、寄存器或内存字段=10%8（即 2）。
    
    否则如果 源操作数 3 等于 算术右移运算符常量（OP_SHR），则执行以下操作：
        —— 第一步：mov rcx, r11（与 SHL 相同，移位量移至 CL 寄存器）
        令 当前指针 = 当前指针 + 发射 REX 前缀（emit_rex）的返回值，参数为：缓冲区、起始位置+当前指针、W=1、R=11/8、X=0、B=0。
        向缓冲区偏移量（起始位置+当前指针）处写入单字节值 137（操作码 0x89）。
        将 当前指针 增加 1。
        令 当前指针 = 当前指针 + 发射 ModRM（emit_modrm）的返回值，参数为：缓冲区、起始位置+当前指针、寻址模式=3、寄存器字段=11%8、寄存器或内存字段=1。
        —— 第二步：sar r10, cl（操作码 0xD3，/7 扩展码，算术右移）
        令 当前指针 = 当前指针 + 发射 REX 前缀（emit_rex）的返回值，参数为：缓冲区、起始位置+当前指针、W=1、R=0、X=0、B=10/8。
        向缓冲区偏移量（起始位置+当前指针）处写入单字节值 211（操作码 0xD3）。
        将 当前指针 增加 1。
        令 当前指针 = 当前指针 + 发射 ModRM（emit_modrm）的返回值，参数为：缓冲区、起始位置+当前指针、寻址模式=3、寄存器字段=5（/5 扩展码表示 SHR）、寄存器或内存字段=10%8。
    
    否则如果 源操作数 3 等于 指针加法运算符常量（OP_PTR_ADD），则执行以下操作：
        —— 效果：r10 = r10 + r11 * 8（将偏移量按元素大小 8 字节缩放后加到基指针上）
        —— 第一步：imul r11, 8, r11（三操作数 IMUL，立即数 8，REX.WB 置位 + 操作码 0x6B + ModRM 寄存器模式 + imm8）
        令 当前指针 = 当前指针 + 发射 REX 前缀（emit_rex）的返回值，参数为：缓冲区、起始位置+当前指针、W=1、R=11/8、X=0、B=11/8。
        向缓冲区偏移量（起始位置+当前指针）处写入单字节值 107（操作码 0x6B，IMUL r, r/m, imm8 指令）。
        将 当前指针 增加 1。
        令 当前指针 = 当前指针 + 发射 ModRM（emit_modrm）的返回值，参数为：缓冲区、起始位置+当前指针、寻址模式=3、寄存器字段=11%8、寄存器或内存字段=11%8。
        向缓冲区偏移量（起始位置+当前指针）处写入单字节值 8（imm8 立即数 8，即缩放因子）。
        将 当前指针 增加 1。
        —— 第二步：add r10, r11（基指针加缩放后的偏移量）
        令 当前指针 = 当前指针 + 发射 ALU 指令（e2_alu）的返回值，参数为：缓冲区、起始位置+当前指针、1（操作码 0x01）。
    
    否则如果 源操作数 3 等于 指针减法运算符常量（OP_PTR_SUB），则执行以下操作：
        —— 效果：r10 = r10 - r11 * 8（从基指针中减去按元素大小缩放的偏移量）
        —— 第一步：imul r11, 8, r11（与 指针加法（PTR_ADD） 相同）
        令 当前指针 = 当前指针 + 发射 REX 前缀（emit_rex）的返回值，参数为：缓冲区、起始位置+当前指针、W=1、R=11/8、X=0、B=11/8。
        向缓冲区偏移量（起始位置+当前指针）处写入单字节值 107（操作码 0x6B）。
        将 当前指针 增加 1。
        令 当前指针 = 当前指针 + 发射 ModRM（emit_modrm）的返回值，参数为：缓冲区、起始位置+当前指针、寻址模式=3、寄存器字段=11%8、寄存器或内存字段=11%8。
        向缓冲区偏移量（起始位置+当前指针）处写入单字节值 8。
        将 当前指针 增加 1。
        —— 第二步：sub r10, r11
        令 当前指针 = 当前指针 + 发射 ALU 指令（e2_alu）的返回值，参数为：缓冲区、起始位置+当前指针、41（操作码 0x29）。
    
    否则如果 源操作数 3 等于 指针差运算符常量（OP_PTR_DIFF），则执行以下操作：
        —— 效果：r10 = （r10 - r11） / 8（计算两指针间的字节差再除以元素大小得到元素个数）
        —— 第一步：sub r10, r11（先求字节差）
        令 当前指针 = 当前指针 + 发射 ALU 指令（e2_alu）的返回值，参数为：缓冲区、起始位置+当前指针、41（操作码 0x29）。
        —— 第二步：sar r10, 3（算术右移 3 位，即除以 8）
        令 当前指针 = 当前指针 + 发射 REX 前缀（emit_rex）的返回值，参数为：缓冲区、起始位置+当前指针、W=1、R=0、X=0、B=10/8。
        向缓冲区偏移量（起始位置+当前指针）处写入单字节值 193（操作码 0xC1，SHIFT r/m, imm8 指令）。
        将 当前指针 增加 1。
        令 当前指针 = 当前指针 + 发射 ModRM（emit_modrm）的返回值，参数为：缓冲区、起始位置+当前指针、寻址模式=3、寄存器字段=7（/7 扩展码表示 SAR）、寄存器或内存字段=10%8。
        向缓冲区偏移量（起始位置+当前指针）处写入单字节值 3（imm8 立即数 3，表示右移 3 位即除以 8）。
        将 当前指针 增加 1。
    
    否则如果 源操作数 3 等于 除法运算符常量（OP_DIV）或者 源操作数 3 等于 取模运算符常量（OP_MOD），则执行以下操作：
        —— 第一步：mov rax, r10（将被除数 r10 移至 rax，idiv 的隐式被除数寄存器）
        令 当前指针 = 当前指针 + 发射 MOV（e2_mov）的返回值，参数为：缓冲区、起始位置+当前指针、0（rax 的寄存器编号）、10。
        —— 第二步：cqo（将 rax 符号扩展至 rdx:rax，为 idiv 准备 128 位被除数）
        令 当前指针 = 当前指针 + 发射 REX 前缀（emit_rex）的返回值，参数为：缓冲区、起始位置+当前指针、W=1、R=0、X=0、B=0。
        向缓冲区偏移量（起始位置+当前指针）处写入单字节值 153（操作码 0x99，CQO 指令）。
        将 当前指针 增加 1。
        —— 第三步：idiv r11（有符号除法，rdx:rax / r11，商存入 rax，余数存入 rdx）
        令 当前指针 = 当前指针 + 发射 REX 前缀（emit_rex）的返回值，参数为：缓冲区、起始位置+当前指针、W=1、R=0、X=0、B=11/8。
        向缓冲区偏移量（起始位置+当前指针）处写入单字节值 247（操作码 0xF7，IDIV r/m 指令）。
        将 当前指针 增加 1。
        令 当前指针 = 当前指针 + 发射 ModRM（emit_modrm）的返回值，参数为：缓冲区、起始位置+当前指针、寻址模式=3、寄存器字段=7（/7 扩展码表示 IDIV）、寄存器或内存字段=11%8。
        —— 第四步：将结果（商或余数）移至 r10
        如果 源操作数 3 等于 除法运算符常量（OP_DIV），则执行以下操作：
            令 当前指针 = 当前指针 + 发射 MOV（e2_mov）的返回值，参数为：缓冲区、起始位置+当前指针、10（r10）、0（rax，除法结果的商在 rax 中）。
        否则（取模运算），执行以下操作：
            令 当前指针 = 当前指针 + 发射 MOV（e2_mov）的返回值，参数为：缓冲区、起始位置+当前指针、10（r10）、2（rdx，除法结果的余数在 rdx 中）。
    
    否则如果 源操作数 3 大于等于 相等比较运算符常量（OP_EQ）且 源操作数 3 小于等于 大于等于比较运算符常量（OP_GE），则执行以下操作：
        —— 比较操作通用序列：cmp r11, r10 → SETcc al → movzx r10, al
        —— 第一步：cmp r11, r10（比较，操作码 0x39/subrego=57）
        令 当前指针 = 当前指针 + 发射 ALU 指令（e2_alu）的返回值，参数为：缓冲区、起始位置+当前指针、57（操作码 0x39，CMP r/m, r 指令）。
        —— 第二步：SETcc al（根据比较结果和条件码设置 AL 寄存器为 0 或 1）
        令 条件码操作码（sop）= 148（默认对应 SETE / 相等时设置）。
        如果 源操作数 3 等于 不等运算符常量（OP_NE），则令 条件码操作码 = 149（SETNE）。
        否则如果 源操作数 3 等于 小于运算符常量（OP_LT），则令 条件码操作码 = 156（SETL）。
        否则如果 源操作数 3 等于 大于运算符常量（OP_GT），则令 条件码操作码 = 159（SETG）。
        否则如果 源操作数 3 等于 小于等于运算符常量（OP_LE），则令 条件码操作码 = 158（SETLE）。
        否则如果 源操作数 3 等于 大于等于运算符常量（OP_GE），则令 条件码操作码 = 157（SETGE）。
        向缓冲区偏移量（起始位置+当前指针）处写入单字节值 15（SETcc 双字节操作码的第一字节 0x0F）。
        将 当前指针 增加 1。
        向缓冲区偏移量（起始位置+当前指针）处写入单字节值为 条件码操作码（SETcc 的第二字节，根据具体条件而定）。
        将 当前指针 增加 1。
        令 当前指针 = 当前指针 + 发射 ModRM（emit_modrm）的返回值，参数为：缓冲区、起始位置+当前指针、寻址模式=3、寄存器字段=0、寄存器或内存字段=0（SETcc 指令的 ModRM 指向 AL/RAX 寄存器的低 8 位）。
        —— 第三步：movzx r10, al（将 AL 的 8 位结果零扩展至 64 位 r10）
        令 当前指针 = 当前指针 + 发射 REX 前缀（emit_rex）的返回值，参数为：缓冲区、起始位置+当前指针、W=0（MOVZX 为 32/64 位操作但 REX.W 为 0，REX.RB 根据寄存器高位设置）、R=10/8、X=0、B=0。
        向缓冲区偏移量（起始位置+当前指针）处写入单字节值 15（MOVZX 双字节操作码的第一字节 0x0F）。
        将 当前指针 增加 1。
        向缓冲区偏移量（起始位置+当前指针）处写入单字节值 182（MOVZX 双字节操作码的第二字节 0xB6，表示 MOVZX r, r/m8）。
        将 当前指针 增加 1。
        令 当前指针 = 当前指针 + 发射 ModRM（emit_modrm）的返回值，参数为：缓冲区、起始位置+当前指针、寻址模式=3、寄存器字段=10%8、寄存器或内存字段=0。
    
    否则如果 源操作数 3 等于 按位与运算符常量（OP_AND），则执行以下操作：
        令 当前指针 = 当前指针 + 发射 ALU 指令（e2_alu）的返回值，参数为：缓冲区、起始位置+当前指针、33（操作码 0x21，AND r/m, r 指令）。
    
    否则如果 源操作数 3 等于 按位或运算符常量（OP_OR），则执行以下操作：
        令 当前指针 = 当前指针 + 发射 ALU 指令（e2_alu）的返回值，参数为：缓冲区、起始位置+当前指针、9（操作码 0x09，OR r/m, r 指令）。
    
    —— 将运算结果（现在在 r10 中）存回栈帧目标槽位
    令 当前指针 = 当前指针 + 发射存储（e2_st）的返回值，参数为：缓冲区、起始位置+当前指针、10（r10）、目标槽位。
    返回 当前指针。
##### 测试要点
1. 加法（OP_ADD）：约 15 字节（load s1 4 + load s2 4 + alu 3 + store 4）。
2. 除法（OP_DIV）：约 20 字节（mov + cqo + idiv + mov + store）。
3. 比较（相等运算（OP_EQ） 等）：cmp + SETcc + movzx 序列，约 15 字节。
4. 指针运算（OP_PTR_ADD）：imul imm8 序列 + add，约 14 字节。
5. 操作数为全局变量时：发射加载变量（e2_load_var） 走 RIP 相对路径（每操作数 10 字节）。
6. 乘法（OP_MUL）：双字节操作码 imul r10,r11，约 13 字节。

#### 分支 一元运算指令（IR_UNARY）（一元运算）
如果 操作码 等于 一元运算操作码常量（IR_UNARY）且 目标变量 大于等于 0，则执行以下操作：
    令 目标槽位（do2）= 全局变量槽位（g2_slot），传入 目标变量。
    —— 加载操作数到 r10
    令 当前指针 = 当前指针 + 发射加载变量（e2_load_var）的返回值，参数为：缓冲区、起始位置+当前指针、10、源操作数 1。
    
    如果 源操作数 3 等于 一元取负运算符常量（UOP_NEG），则执行以下操作：
        —— 发射 neg r10 指令（操作码 0xF7，/3 扩展码）
        令 当前指针 = 当前指针 + 发射 REX 前缀（emit_rex）的返回值，参数为：缓冲区、起始位置+当前指针、W=1、R=0、X=0、B=10/8。
        向缓冲区偏移量（起始位置+当前指针）处写入单字节值 247（操作码 0xF7，NEG r/m 指令）。
        将 当前指针 增加 1。
        令 当前指针 = 当前指针 + 发射 ModRM（emit_modrm）的返回值，参数为：缓冲区、起始位置+当前指针、寻址模式=3、寄存器字段=3（/3 扩展码表示 NEG）、寄存器或内存字段=10%8。
    
    否则如果 源操作数 3 等于 一元逻辑非运算符常量（UOP_NOT），则执行以下操作：
        —— 逻辑非序列：test r10, r10 → sete al → movzx r10, al（效果：若 r10==0 则 r10=1，否则 r10=0）
        —— 第一步：test r10, r10（操作码 0x85）
        令 当前指针 = 当前指针 + 发射 REX 前缀（emit_rex）的返回值，参数为：缓冲区、起始位置+当前指针、W=1、R=10/8、X=0、B=10/8。
        向缓冲区偏移量（起始位置+当前指针）处写入单字节值 133（操作码 0x85，TEST r/m, r 指令）。
        将 当前指针 增加 1。
        令 当前指针 = 当前指针 + 发射 ModRM（emit_modrm）的返回值，参数为：缓冲区、起始位置+当前指针、寻址模式=3、寄存器字段=10%8、寄存器或内存字段=10%8。
        —— 第二步：sete al（双字节操作码 0x0F 0x94，若上一条指令结果为零则设置 AL=1）
        向缓冲区偏移量（起始位置+当前指针）处写入单字节值 15（第一字节 0x0F）。
        将 当前指针 增加 1。
        向缓冲区偏移量（起始位置+当前指针）处写入单字节值 148（第二字节 0x94，SETE 指令）。
        将 当前指针 增加 1。
        令 当前指针 = 当前指针 + 发射 ModRM（emit_modrm）的返回值，参数为：缓冲区、起始位置+当前指针、寻址模式=3、寄存器字段=0、寄存器或内存字段=0。
        —— 第三步：movzx r10, al（双字节操作码 0x0F 0xB6，将 8 位 AL 结果零扩展至 64 位）
        令 当前指针 = 当前指针 + 发射 REX 前缀（emit_rex）的返回值，参数为：缓冲区、起始位置+当前指针、W=0、R=10/8、X=0、B=0。
        向缓冲区偏移量（起始位置+当前指针）处写入单字节值 15（第一字节 0x0F）。
        将 当前指针 增加 1。
        向缓冲区偏移量（起始位置+当前指针）处写入单字节值 182（第二字节 0xB6）。
        将 当前指针 增加 1。
        令 当前指针 = 当前指针 + 发射 ModRM（emit_modrm）的返回值，参数为：缓冲区、起始位置+当前指针、寻址模式=3、寄存器字段=10%8、寄存器或内存字段=0。
    
    —— 将结果存回目标槽位
    令 当前指针 = 当前指针 + 发射存储（e2_st）的返回值，参数为：缓冲区、起始位置+当前指针、10、目标槽位。
    返回 当前指针。
##### 测试要点
1. 取负运算（UOP_NEG）：neg r10 指令共 3 字节，加上 加载（load） 和 存储（store） 约 11 字节。
2. 取非运算（UOP_NOT）：test + sete + movzx 序列共 9 字节，加上 加载（load） 和 存储（store） 约 17 字节。
3. 目标变量为全局变量时存储走 RIP 相对路径。

#### 分支 调用指令（IR_CALL）（函数调用）
如果 操作码 等于 函数调用操作码常量（IR_CALL），则执行以下操作：
    令 函数第一个参数索引（fa）= 源操作数 1（函数参数的起始变量索引）。
    令 参数个数（ac）= 源操作数 2。
    令 当前参数索引（ai）= 0。
    
    —— 阶段 1：将前 6 个参数加载到 System V AMD64 调用约定的寄存器中
    进入循环，每次迭代执行以下操作：
        如果 当前参数索引 大于等于 参数个数，则跳出循环。
        如果 当前参数索引 大于等于 6，则跳出循环（只处理前 6 个寄存器参数）。
        令 目标寄存器（r）= -1。
        如果 当前参数索引 等于 0，则令 目标寄存器 = 7（rdi，第一个整型参数寄存器）。
        如果 当前参数索引 等于 1，则令 目标寄存器 = 6（rsi，第二个整型参数寄存器）。
        如果 当前参数索引 等于 2，则令 目标寄存器 = 2（rdx，第三个整型参数寄存器）。
        如果 当前参数索引 等于 3，则令 目标寄存器 = 1（rcx，第四个整型参数寄存器）。
        如果 当前参数索引 等于 4，则令 目标寄存器 = 8（r8，第五个整型参数寄存器）。
        如果 当前参数索引 等于 5，则令 目标寄存器 = 9（r9，第六个整型参数寄存器）。
        如果 目标寄存器 大于等于 0，则执行以下操作：
            令 当前指针 = 当前指针 + 发射加载变量（e2_load_var）的返回值，参数为：缓冲区、起始位置+当前指针、目标寄存器、函数第一个参数索引 + 当前参数索引。
        将 当前参数索引 增加 1。
    循环结束。
    
    —— 阶段 2：将第 7 个及以后的参数通过栈传递（System V AMD64 规定从右到左压入栈，参数 7 最靠近返回地址）
    令 栈参数索引（stack_ai）为 参数个数 - 1，可修改。
    进入循环，每次迭代执行以下操作：
        如果 栈参数索引 小于 6，则跳出循环（参数 0-5 已由寄存器传递，不在此处理）。
        —— 加载参数值到 r10
        令 当前指针 = 当前指针 + 发射加载变量（e2_load_var）的返回值，参数为：缓冲区、起始位置+当前指针、10、函数第一个参数索引 + 栈参数索引。
        —— 发射 push r10 指令（操作码 0x41 0x52，0x41 是 REX.B 前缀，0x52 是 PUSH r10 的操作码）
        向缓冲区偏移量（起始位置+当前指针）处写入单字节值 65（REX.B 前缀，r10 的 B 位=1）。
        向缓冲区偏移量（起始位置+当前指针+1）处写入单字节值 82（操作码 0x52，PUSH r10 指令）。
        将 当前指针 增加 2。
        将 栈参数索引 减少 1。
    循环结束。
    
    —— 阶段 3：根据被调用函数的驻留字符串索引（源操作数 3）分派：匹配内建函数则内联生成机器码，匹配普通函数则生成 call 指令
    
    如果 源操作数 3 等于 内建函数 三参系统调用（syscall3） 的驻留字符串索引（g_ni_syscall3），则执行以下操作：
        —— 内建三参系统调用（__builtin_syscall3）（num, 参数1（arg1）, 参数2（arg2）, arg3）：重排参数寄存器
        —— 调用约定为：rdi=参数1（arg1）（原在rsi）, rsi=参数2（arg2）（原在rdx）, rdx=参数3（arg3）（原在rcx）, rax=数量（num）（原在rdi）
        令 当前指针 = 当前指针 + 发射 MOV（e2_mov）的返回值，参数为：缓冲区、起始位置+当前指针、0（rax）、7（rdi 中原存放 num，移至 rax）。
        令 当前指针 = 当前指针 + 发射 MOV（e2_mov）的返回值，参数为：缓冲区、起始位置+当前指针、7（rdi）、6（rsi 中原存放 参数1（arg1），移至 rdi）。
        令 当前指针 = 当前指针 + 发射 MOV（e2_mov）的返回值，参数为：缓冲区、起始位置+当前指针、6（rsi）、2（rdx 中原存放 arg2，移至 rsi）。
        令 当前指针 = 当前指针 + 发射 MOV（e2_mov）的返回值，参数为：缓冲区、起始位置+当前指针、2（rdx）、1（rcx 中原存放 arg3，移至 rdx）。
        —— 发射 syscall 指令（双字节操作码 0x0F 0x05）
        向缓冲区偏移量（起始位置+当前指针）处写入单字节值 15（第一字节 0x0F）。
        向缓冲区偏移量（起始位置+当前指针+1）处写入单字节值 5（第二字节 0x05）。
        将 当前指针 增加 2。
        —— 将 syscall 返回值从 rax 存回目标变量
        如果 目标变量 大于等于 0，则执行以下操作：
            令 当前指针 = 当前指针 + 发射存储（e2_st）的返回值，参数为：缓冲区、起始位置+当前指针、0（rax）、全局变量槽位（g2_slot），传入 目标变量。
    
    否则如果 源操作数 3 等于 内建函数 读取字节（load8） 的驻留字符串索引（g_ni_load8），则执行以下操作：
        —— 内建读取字节（__builtin_load8）（指针（ptr）, offset）：加载单字节，movzx rax, 字节（byte） [rdi+rsi]
        令 当前指针 = 当前指针 + 发射 REX 前缀（emit_rex）的返回值，参数为：缓冲区、起始位置+当前指针、W=1、R=0、X=0、B=0。
        向缓冲区偏移量（起始位置+当前指针）处写入单字节值 15（第一字节 0x0F）。
        将 当前指针 增加 1。
        向缓冲区偏移量（起始位置+当前指针）处写入单字节值 182（第二字节 0xB6，MOVZX r, r/m8 指令）。
        将 当前指针 增加 1。
        令 当前指针 = 当前指针 + 发射 ModRM（emit_modrm）的返回值，参数为：缓冲区、起始位置+当前指针、寻址模式=0、寄存器字段=0（rax 的低 3 位）、寄存器或内存字段=4（rm=4 表示 SIB 寻址）。
        令 当前指针 = 当前指针 + 发射 SIB（emit_sib）的返回值，参数为：缓冲区、起始位置+当前指针、比例因子=0、索引寄存器=6（rsi 的低 3 位）、基址寄存器=7（rdi 的低 3 位）。此 SIB 字节编码 [rdi+rsi] 寻址。
        如果 目标变量 大于等于 0，则执行以下操作：
            令 当前指针 = 当前指针 + 发射存储（e2_st）的返回值，参数为：缓冲区、起始位置+当前指针、0（rax）、全局变量槽位（g2_slot），传入 目标变量。
    
    否则如果 源操作数 3 等于 内建函数 写字节（store8） 的驻留字符串索引（g_ni_store8），则执行以下操作：
        —— 内建写字节（__builtin_store8）（指针（ptr）, offset, 值（val））：存储单字节，mov [rdi+rsi], dl（第三个参数在 rdx = 寄存器 2，取其低 8 位 dl）
        向缓冲区偏移量（起始位置+当前指针）处写入单字节值 136（操作码 0x88，MOV r/m8, r8 指令）。
        将 当前指针 增加 1。
        令 当前指针 = 当前指针 + 发射 ModRM（emit_modrm）的返回值，参数为：缓冲区、起始位置+当前指针、寻址模式=0、寄存器字段=2（rdx 的低 3 位，对应 dl）、寄存器或内存字段=4（SIB 寻址）。
        令 当前指针 = 当前指针 + 发射 SIB（emit_sib）的返回值，参数为：缓冲区、起始位置+当前指针、比例因子=0、索引寄存器=6（rsi）、基址寄存器=7（rdi）。
    
    否则如果 源操作数 3 等于 内建函数 读取 64 位（load64） 的驻留字符串索引（g_ni_load64），或者等于 内建函数 字符串指针加载（load_str_ptr） 的驻留字符串索引（g_ni_load_str_ptr），或者等于 内建函数 读 64 位（r64） 的驻留字符串索引（g_ni_r64），则执行以下操作：
        —— 三者均为 mov rax, [rdi+rsi] 指令（从给定地址+偏移量处加载 64 位值）
        令 当前指针 = 当前指针 + 发射 REX 前缀（emit_rex）的返回值，参数为：缓冲区、起始位置+当前指针、W=1、R=0、X=0、B=0。
        向缓冲区偏移量（起始位置+当前指针）处写入单字节值 139（操作码 0x8B，MOV r, r/m 指令）。
        将 当前指针 增加 1。
        令 当前指针 = 当前指针 + 发射 ModRM（emit_modrm）的返回值，参数为：缓冲区、起始位置+当前指针、寻址模式=0、寄存器字段=0（rax）、寄存器或内存字段=4（SIB 寻址）。
        令 当前指针 = 当前指针 + 发射 SIB（emit_sib）的返回值，参数为：缓冲区、起始位置+当前指针、比例因子=0、索引寄存器=6（rsi）、基址寄存器=7（rdi）。
        如果 目标变量 大于等于 0，则执行以下操作：
            令 当前指针 = 当前指针 + 发射存储（e2_st）的返回值，参数为：缓冲区、起始位置+当前指针、0、全局变量槽位（g2_slot），传入 目标变量。
    
    否则如果 源操作数 3 等于 内建函数 字符串指针存储（store_str_ptr） 的驻留字符串索引（g_ni_store_str_ptr），则执行以下操作：
        —— 内建字符串指针存储（__builtin_store_str_ptr）（指针（ptr）, offset, 值（val））：mov [rdi+rsi], rdx
        令 当前指针 = 当前指针 + 发射 REX 前缀（emit_rex）的返回值，参数为：缓冲区、起始位置+当前指针、W=1、R=0、X=0、B=0。
        向缓冲区偏移量（起始位置+当前指针）处写入单字节值 137（操作码 0x89，MOV r/m, r 指令）。
        将 当前指针 增加 1。
        令 当前指针 = 当前指针 + 发射 ModRM（emit_modrm）的返回值，参数为：缓冲区、起始位置+当前指针、寻址模式=0、寄存器字段=2（rdx）、寄存器或内存字段=4（SIB 寻址）。
        令 当前指针 = 当前指针 + 发射 SIB（emit_sib）的返回值，参数为：缓冲区、起始位置+当前指针、比例因子=0、索引寄存器=6（rsi）、基址寄存器=7（rdi）。
    
    否则如果 源操作数 3 等于 内建函数 获取参数（get_arg） 的驻留字符串索引（g_ni_get_arg）且 全局变量 argv 指针变量索引（gv_argv）大于等于 0，则执行以下操作：
        —— 内建获取参数（__builtin_get_arg）（n）：将 C 命令行参数 argv[参数序号（数量）] 转换为带隐藏长度头的 Core 字符串
        —— 注意：命令行参数指针索引（gv_argv） 必须 >= 0（g_rt_argv_ptr 已在全局变量注册表中注册）。
        —— 若 命令行参数指针索引（gv_argv） 为 -1，则回落至普通调用路径。
        
        —— 第 1 步：通过 RIP 相对寻址加载 argv 指针（g_rt_argv_ptr） 全局变量到 r10
        调用 扩展 RIP 修补数组（grow_rip_patch），传入 原 x86 RIP 修补计数 + 1。
        向 x86 RIP 修补位置数组（g_x86_rip_patch_pos）的偏移量（x86 RIP 修补计数 * 8）处写入 64 位值（起始位置 + 当前指针 + 3）—— LEA 指令的 disp32 字段位置。
        向 x86 RIP 全局变量修补数组（g_x86_rip_patch_globals）的偏移量（x86 RIP 修补计数 * 8）处写入 64 位值 命令行参数指针索引（gv_argv）。
        将 x86 RIP 修补计数 增加 1。
        令 当前指针 = 当前指针 + 发射加载寄存器（e2_lr）的返回值，参数为：缓冲区、起始位置+当前指针、0（占位符，待修补为正确的 RIP 相对偏移量）。此指令编码为 lea r10, [rip+0]。
        
        —— 第 2 步：解引用：mov r10, [r10]（加载 argv 数组的基址）
        令 当前指针 = 当前指针 + 发射 REX 前缀（emit_rex）的返回值，参数为：缓冲区、起始位置+当前指针、W=1、R=10/8、X=0、B=10/8（REX.W 且 R 和 B 均从 r10 的高位取）。
        向缓冲区偏移量（起始位置+当前指针）处写入单字节值 139（操作码 0x8B，MOV r, r/m 指令）。
        将 当前指针 增加 1。
        令 当前指针 = 当前指针 + 发射 ModRM（emit_modrm）的返回值，参数为：缓冲区、起始位置+当前指针、寻址模式=0、寄存器字段=10%8、寄存器或内存字段=10%8。
        
        —— 第 3 步：mov r10, [r10 + rdi*8]（加载 argv[数量（n）]，按 SIB 寻址：比例因子=3 即 *8，索引寄存器=rdi%8=7，基址寄存器=r10%8）
        令 当前指针 = 当前指针 + 发射 REX 前缀（emit_rex）的返回值，参数为：缓冲区、起始位置+当前指针、W=1、R=10/8、X=0、B=10/8。
        向缓冲区偏移量（起始位置+当前指针）处写入单字节值 139（操作码 0x8B）。
        将 当前指针 增加 1。
        令 当前指针 = 当前指针 + 发射 ModRM（emit_modrm）的返回值，参数为：缓冲区、起始位置+当前指针、寻址模式=0、寄存器字段=10%8、寄存器或内存字段=4（rm=4 表示 SIB 寻址）。
        令 当前指针 = 当前指针 + 发射 SIB（emit_sib）的返回值，参数为：缓冲区、起始位置+当前指针、比例因子=3（*8）、索引寄存器=7（rdi%8）、基址寄存器=10%8（r10 的低 3 位）。
        
        —— 第 4 步：空指针/空字符串检查：test r10, r10 → jne 有效标签（valid）（若 argv[数量（n）] 非空，跳转到字符串处理）
        令 当前指针 = 当前指针 + 发射 REX 前缀（emit_rex）的返回值，参数为：缓冲区、起始位置+当前指针、W=1、R=10/8、X=0、B=10/8。
        向缓冲区偏移量（起始位置+当前指针）处写入单字节值 133（操作码 0x85，TEST r/m, r 指令）。
        将 当前指针 增加 1。
        令 当前指针 = 当前指针 + 发射 ModRM（emit_modrm）的返回值，参数为：缓冲区、起始位置+当前指针、寻址模式=3、寄存器字段=10%8、寄存器或内存字段=10%8。
        向缓冲区偏移量（起始位置+当前指针）处写入单字节值 117（操作码 0x75，JNE rel8 指令）。
        向缓冲区偏移量（起始位置+当前指针+1）处写入单字节值 18（rel8 偏移量，跳过后续 NULL 分支的 18 字节到达 valid 标签处）。
        将 当前指针 增加 2。
        
        —— 第 5 步：空指针（NULL） 分支 —— 分配 1 字节空字符串并写入 '\0' 头
        向缓冲区偏移量（起始位置+当前指针）处写入单字节值 191（操作码 0xBF，MOV r32, imm32 指令，reg=7 表示 edi）。
        向缓冲区偏移量（起始位置+当前指针+1）处写入 32 位值 1（分配 1 字节用于空字符串）。
        将 当前指针 增加 5。
        —— 记录 分配修补位置（alloc_patch） 条目（对 分配函数（alloc） 函数的调用）
        调用 扩展分配修补数组（grow_alloc_patch），传入 原 x86 分配修补计数 + 1。
        向 x86 分配修补位置数组（g_x86_alloc_patch_pos）的偏移量（x86 分配修补计数 * 8）处写入 64 位值（起始位置 + 当前指针）。
        将 x86 分配修补计数 增加 1。
        向缓冲区偏移量（起始位置+当前指针）处写入单字节值 232（操作码 0xE8，CALL rel32 指令）。
        向缓冲区偏移量（起始位置+当前指针+1）处写入 32 位值 0（占位符，待 Phase 3 修补为 分配函数（alloc） 的实际偏移量）。
        将 当前指针 增加 5。
        —— 向分配的首字节写入 0（空字符串的 '\0' 终止符同时充当长度头）
        向缓冲区偏移量（起始位置+当前指针）处写入单字节值 198（操作码 0xC6，MOV r/m8, imm8 指令）。
        将 当前指针 增加 1。
        令 当前指针 = 当前指针 + 发射 ModRM（emit_modrm）的返回值，参数为：缓冲区、起始位置+当前指针、寻址模式=0、寄存器字段=0（/0 扩展码）、寄存器或内存字段=0（rax 的低 3 位）。
        向缓冲区偏移量（起始位置+当前指针）处写入单字节值 0（imm8 值 0，空字符）。
        将 当前指针 增加 1。
        —— 无条件跳转到 完成标签（done） 标签（跳过字符串长度计算和拷贝循环，已处于空字符串状态）
        令 当前指针 = 当前指针 + 发射 JMP 指令（e2_jmp）的返回值，参数为：缓冲区、起始位置+当前指针、43（rel32 偏移量，跳过 strlen + 分配函数（alloc） + copy 循环序列到达 done 标签处）。
        
        —— 第 6 步：有效标签（valid） 标签 —— 计算字符串长度（strlen 循环）
        —— 注意：第 5 步的 JNE 跳过了 空指针（NULL） 分支，直接到达此处（r10 指向 argv[数量（n）] 字符串的首字符）
        —— 初始化计数器：xor edi, edi（edi 用作字符串长度计数器，清零）
        向缓冲区偏移量（起始位置+当前指针）处写入单字节值 49（操作码 0x31，XOR r/m, r 指令）。
        向缓冲区偏移量（起始位置+当前指针+1）处写入单字节值 255（ModRM 字节，3*64 + 7*8 + 7 = 255，表示 XOR edi, edi）。
        将 当前指针 增加 2。
        —— 字符串长度（strlen） 循环体开始：
        —— 比较指令：cmp 字节（byte） [r10+rdi], 0（检查当前字节是否为零终止符）
        令 当前指针 = 当前指针 + 发射 REX 前缀（emit_rex）的返回值，参数为：缓冲区、起始位置+当前指针、W=0、R=0、X=0、B=10/8（REX.B 置位因为基址寄存器 r10>=8，需要通过 SIB 的 base 字段指定）。
        向缓冲区偏移量（起始位置+当前指针）处写入单字节值 128（操作码 0x80，CMP r/m8, imm8 指令，/7 扩展码）。
        将 当前指针 增加 1。
        令 当前指针 = 当前指针 + 发射 ModRM（emit_modrm）的返回值，参数为：缓冲区、起始位置+当前指针、寻址模式=0、寄存器字段=7（/7 扩展码表示 CMP）、寄存器或内存字段=4（rm=4 表示 SIB 寻址）。
        令 当前指针 = 当前指针 + 发射 SIB（emit_sib）的返回值，参数为：缓冲区、起始位置+当前指针、比例因子=0、索引寄存器=7（rdi%8，作为索引寄存器）、基址寄存器=10%8（r10 的低 3 位，作为基址寄存器）。此 SIB 编码 [r10+rdi] 寻址。
        向缓冲区偏移量（起始位置+当前指针）处写入单字节值 0（imm8 值 0，与 '\0' 终止符比较）。
        将 当前指针 增加 1。
        —— 条件跳转：je 长度完成标签（len_done）（若找到 '\0' 终止符，则字符串长度计数完成，跳转到 len_done）
        向缓冲区偏移量（起始位置+当前指针）处写入单字节值 116（操作码 0x74，JE rel8 指令）。
        向缓冲区偏移量（起始位置+当前指针+1）处写入单字节值 8（rel8 偏移量，跳过 inc rdi 和 jmp 回到循环体的两条指令共 8 字节）。
        将 当前指针 增加 2。
        —— 计数器递增：inc rdi（REX.W + 0xFF + /0 扩展码）
        令 当前指针 = 当前指针 + 发射 REX 前缀（emit_rex）的返回值，参数为：缓冲区、起始位置+当前指针、W=1、R=0、X=0、B=0。
        向缓冲区偏移量（起始位置+当前指针）处写入单字节值 255（操作码 0xFF，INC r/m 指令）。
        将 当前指针 增加 1。
        令 当前指针 = 当前指针 + 发射 ModRM（emit_modrm）的返回值，参数为：缓冲区、起始位置+当前指针、寻址模式=3、寄存器字段=0（/0 扩展码表示 INC）、寄存器或内存字段=7（rdi 的低 3 位）。
        —— 无条件跳回循环体开头
        令 当前指针 = 当前指针 + 发射 JMP 指令（e2_jmp）的返回值，参数为：缓冲区、起始位置+当前指针、-15（rel32 负值，跳回 cmp byte [r10+rdi],0 处）。
        
        —— 第 7 步：长度完成标签（len_done） 标签 —— 再递增一次以包含 '\0' 终止符，然后调用 分配函数（alloc） 分配 长度（len）+1 字节
        —— inc rdi（包含 null 终止符的额外计数）
        令 当前指针 = 当前指针 + 发射 REX 前缀（emit_rex）的返回值，参数为：缓冲区、起始位置+当前指针、W=1、R=0、X=0、B=0。
        向缓冲区偏移量（起始位置+当前指针）处写入单字节值 255（操作码 0xFF）。
        将 当前指针 增加 1。
        令 当前指针 = 当前指针 + 发射 ModRM（emit_modrm）的返回值，参数为：缓冲区、起始位置+当前指针、寻址模式=3、寄存器字段=0、寄存器或内存字段=7。
        —— 调用 分配函数（alloc）（edi） —— edi 中已经存放字符串长度（含 '\0' 终止符）
        调用 扩展分配修补数组（grow_alloc_patch），传入 原 x86 分配修补计数 + 1。
        向 x86 分配修补位置数组（g_x86_alloc_patch_pos）的偏移量（x86 分配修补计数 * 8）处写入 64 位值（起始位置 + 当前指针）。
        将 x86 分配修补计数 增加 1。
        向缓冲区偏移量（起始位置+当前指针）处写入单字节值 232（操作码 0xE8）。
        向缓冲区偏移量（起始位置+当前指针+1）处写入 32 位值 0（call 占位符）。
        将 当前指针 增加 5。
        
        —— 第 8 步：逐字节拷贝循环（将 C 字符串从 argv[数量（n）] 拷贝到新分配的 Core 字符串缓冲区）
        —— 初始化拷贝索引：xor r11d, r11d（清零 r11 的低 32 位，r11 用作拷贝循环中的索引计数器）
        令 当前指针 = 当前指针 + 发射 REX 前缀（emit_rex）的返回值，参数为：缓冲区、起始位置+当前指针、W=0、R=11/8、X=0、B=11/8（MOVZX 风格，但此处是 XOR 的 REX.RB 前置）。
        向缓冲区偏移量（起始位置+当前指针）处写入单字节值 49（操作码 0x31，XOR r/m, r 指令）。
        将 当前指针 增加 1。
        令 当前指针 = 当前指针 + 发射 ModRM（emit_modrm）的返回值，参数为：缓冲区、起始位置+当前指针、寻址模式=3、寄存器字段=11%8、寄存器或内存字段=11%8。
        —— 拷贝循环体开始：
        —— 加载单字节：mov dl, [r10+r11]（从源字符串加载一个字节到 dl，操作码 0x8A MOV r8, r/m8，REX.X=1 因为索引寄存器 r11>=8）
        令 当前指针 = 当前指针 + 发射 REX 前缀（emit_rex）的返回值，参数为：缓冲区、起始位置+当前指针、W=0、R=0、X=11/8（索引寄存器高位 bit，r11>=8 时置位）、B=10/8（基址寄存器高位）。
        向缓冲区偏移量（起始位置+当前指针）处写入单字节值 138（操作码 0x8A，MOV r8, r/m8 指令）。
        将 当前指针 增加 1。
        令 当前指针 = 当前指针 + 发射 ModRM（emit_modrm）的返回值，参数为：缓冲区、起始位置+当前指针、寻址模式=0、寄存器字段=2（rdx 的低 3 位，即 dl）、寄存器或内存字段=4（SIB 寻址）。
        令 当前指针 = 当前指针 + 发射 SIB（emit_sib）的返回值，参数为：缓冲区、起始位置+当前指针、比例因子=0、索引寄存器=11%8（r11 的低 3 位）、基址寄存器=10%8（r10 的低 3 位）。
        —— 存储单字节：mov [rax+r11], dl（将加载的字节存入目标缓冲区，操作码 0x88 MOV r/m8, r8）
        令 当前指针 = 当前指针 + 发射 REX 前缀（emit_rex）的返回值，参数为：缓冲区、起始位置+当前指针、W=0、R=0、X=11/8（索引寄存器高位）、B=0（基址寄存器 rax 没有高位需求）。
        向缓冲区偏移量（起始位置+当前指针）处写入单字节值 136（操作码 0x88，MOV r/m8, r8 指令）。
        将 当前指针 增加 1。
        令 当前指针 = 当前指针 + 发射 ModRM（emit_modrm）的返回值，参数为：缓冲区、起始位置+当前指针、寻址模式=0、寄存器字段=2（dl）、寄存器或内存字段=4（SIB 寻址）。
        令 当前指针 = 当前指针 + 发射 SIB（emit_sib）的返回值，参数为：缓冲区、起始位置+当前指针、比例因子=0、索引寄存器=11%8、基址寄存器=0（rax 的低 3 位）。

##### 测试要点
1. 无参数调用：仅 call + 存储（store） rax，约 9 字节。
2. 6 个寄存器参数：6 次 发射加载变量（e2_load_var） + call + 存储（store），约 33 字节。
3. 8 个参数（超 6 个）：额外两次 push r10 + add rsp，约额外 11 字节。
4. 三参系统调用（syscall3） 内建：4 次 mov 参数重排 + syscall 指令，约 15 字节。
5. 读取字节（load8）/写字节（store8）/读取 64 位（load64）/字符串指针存储（store_str_ptr）/写 64 位（w64） 内建：mov + SIB 编码，约 8-10 字节。
6. 获取参数（get_arg） 内建（最大内建分支）：RIP 加载 + 空指针检查 + 字符串长度（strlen） 循环 + 分配函数（alloc） + 拷贝循环，约 70+ 字节。
7. 动态拷贝内建（_dyncpy） 内建：xor ecx + cmp/jae + mov[rdi+rcx],al + mov[rdx+rcx],al + inc rcx + jmp 循环，约 20 字节。
8. 协程包装地址（goroutine_wrapper_addr）：movabs r10, imm64（10 字节）+ 存储（store），约 14 字节。
9. 函数在 函数偏移数组（func_offsets） 中找到：直接相对 call。
10. 函数未找到：发射 外部重定位（ext_rel） + call 占位符。
