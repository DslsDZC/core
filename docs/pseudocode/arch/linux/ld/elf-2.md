## 函数 发射堆扩展代码（emit_heap_expand）
### 作用
发射 扩展堆（heap_expand） 函数的机器码。通过 内存映射（mmap） 系统调用分配 1GiB 新区间，更新 堆指针全局（g_heap_ptr） 和 堆末尾全局（g_heap_end）。分配失败时返回 -1。
### 逻辑

令 当前指针（cp） = 0
令 函数虚拟地址（fva） = 代码段基址（TEXT_BASE） + 起始位置

—— 内存映射（mmap） 系统调用参数设置
—— 发射 xor edi, edi 指令（2 字节）：edi = 0（地址（addr） = NULL，让内核选择映射地址）
向缓冲区偏移量 起始位置+当前指针 处写入字节值 49（xor r/m32, r32 的 opcode，0x31）
向缓冲区偏移量 起始位置+当前指针+1 处写入字节值 255（ModRM 字节，mod×64+reg×8+rm = 3×64+7×8+7 = 192+56+7 = 255：mod=3 寄存器模式、reg=7 rdi、rm=7 rdi，即 xor edi, edi）
令 当前指针 = 当前指针 + 2
—— 发射 mov esi, 1073741824 指令（5 字节）：esi = 1 GiB（length = 0x40000000）
调用 发射写8位（e2_w8）向偏移量 起始位置+当前指针 处写入字节值 190（mov r32, imm32 的 opcode，0xBE，目标 esi）
调用 发射写32位（e2_w32）向偏移量 起始位置+当前指针+1 处写入 32 位立即数 1073741824（1 GiB = 0x40000000）
令 当前指针 = 当前指针 + 5
—— 发射 mov edx, 3 指令（5 字节）：edx = 3（prot = PROT_READ（1） | PROT_WRITE（2））
向缓冲区偏移量 起始位置+当前指针 处写入字节值 186（mov r32, imm32 的 opcode，0xBA，目标 edx）
调用 发射写32位（e2_w32）向偏移量 起始位置+当前指针+1 处写入 32 位立即数 3
令 当前指针 = 当前指针 + 5
—— 发射 mov r10d, 0x22 指令（6 字节）：r10d = 34（flags = MAP_PRIVATE（2） | MAP_ANONYMOUS（32） = 0x22）
向缓冲区偏移量 起始位置+当前指针 处写入字节值 65（REX.B 前缀，W=0、R=0、X=0、B=1 = 64+0+0+0+1 = 65，表示目标为 r10d）
向缓冲区偏移量 起始位置+当前指针+1 处写入字节值 186（mov r32, imm32 的 opcode，0xBA）
调用 发射写32位（e2_w32）向偏移量 起始位置+当前指针+2 处写入 32 位立即数 34（0x22）
令 当前指针 = 当前指针 + 6
—— 发射 mov r8d, -1 指令（6 字节）：r8d = -1（文件描述符（fd） = -1，MAP_ANONYMOUS 时忽略）
向缓冲区偏移量 起始位置+当前指针 处写入字节值 65（REX.B 前缀，W=0、B=1 = 65）
向缓冲区偏移量 起始位置+当前指针+1 处写入字节值 184（mov r32, imm32 的 opcode，0xB8，目标 r8d）
调用 发射写32位（e2_w32）向偏移量 起始位置+当前指针+2 处写入 32 位有符号立即数 -1（0xFFFFFFFF）
令 当前指针 = 当前指针 + 6
—— 发射 xor r9d, r9d 指令（3 字节）：r9d = 0（offset = 0）
向缓冲区偏移量 起始位置+当前指针 处写入字节值 69（REX.R+B 前缀，W=0、R=1、X=0、B=1 = 64+0+4+0+1 = 69，R=1 和 B=1 编码 r9d）
向缓冲区偏移量 起始位置+当前指针+1 处写入字节值 49（xor r/m32, r32 的 opcode，0x31）
向缓冲区偏移量 起始位置+当前指针+2 处写入字节值 201（ModRM 字节，mod×64+reg×8+rm = 3×64+1×8+1 = 192+8+1 = 201：mod=3、reg=1 r9（配 REX.R=1）、rm=1 r9（配 REX.B=1），即 xor r9d, r9d）
令 当前指针 = 当前指针 + 3
—— 发射 mov eax, 9 指令（5 字节）：eax = 9（sys_mmap 系统调用号）
向缓冲区偏移量 起始位置+当前指针 处写入字节值 184（mov r32, imm32 的 opcode，0xB8，目标 eax）
调用 发射写32位（e2_w32）向偏移量 起始位置+当前指针+1 处写入 32 位立即数 9
令 当前指针 = 当前指针 + 5
—— 发射 syscall 指令（2 字节）：执行 内存映射（mmap） 系统调用，返回值存入 rax
向缓冲区偏移量 起始位置+当前指针 处写入字节值 15（两字节 opcode 前缀 0F）
向缓冲区偏移量 起始位置+当前指针+1 处写入字节值 5（syscall 的第二 opcode 字节 05）
令 当前指针 = 当前指针 + 2

—— 检查 内存映射（mmap） 返回值
—— 发射 test rax, rax 指令（3 字节）：检查 rax 是否为负（mmap 失败时返回 -errno）
向缓冲区偏移量 起始位置+当前指针 处写入字节值 72（REX.W 前缀，W=1 = 72）
向缓冲区偏移量 起始位置+当前指针+1 处写入字节值 133（test r/m64, r64 的 opcode，0x85）
向缓冲区偏移量 起始位置+当前指针+2 处写入字节值 192（ModRM 字节，mod×64+reg×8+rm = 3×64+0×8+0 = 192：mod=3、reg=0 rax、rm=0 rax，即 test rax, rax）
令 当前指针 = 当前指针 + 3
—— 发射 js .堆链接标签（Lhf） 指令（2 字节）：若 rax 为负（符号位设置），跳转到失败路径
向缓冲区偏移量 起始位置+当前指针 处写入字节值 120（js rel8 的 opcode，符号位设置时短跳转）
向缓冲区偏移量 起始位置+当前指针+1 处写入字节值 24（rel8 偏移量，正值表示向前跳过 24 字节到达 .Lhf 标签）
令 当前指针 = 当前指针 + 2

—— 成功路径：更新 堆指针（heap_ptr） 和 堆末尾（heap_end）
—— 发射 mov [rip + 堆指针全局（g_heap_ptr）], rax 指令（7 字节）：将 内存映射（mmap） 返回的新基址存为 堆指针（heap_ptr）
如果 堆指针索引（gv_heap_ptr） 大于等于 0，那么：
    —— 使用 RIP 修补方式
    令 局部变量 堆 RIP 修补位置（rip_hp_ex） = 起始位置 + 当前指针 + 3
    向缓冲区偏移量 起始位置+当前指针 处写入字节值 72（REX.W 前缀，W=1 = 72）
    向缓冲区偏移量 起始位置+当前指针+1 处写入字节值 137（mov r/m64, r64 的 opcode，0x89）
    向缓冲区偏移量 起始位置+当前指针+2 处写入字节值 5（ModRM 字节，mod×64+reg×8+rm = 0×64+0×8+5 = 5：mod=0 RIP 相对寻址、reg=0 rax、rm=5，即 mov [rip+disp32], rax）
    调用 发射写32位（e2_w32）向偏移量 起始位置+当前指针+3 处写入占位符值 0
    令 当前指针 = 当前指针 + 7
    调用 扩展 RIP 修补数组（grow_rip_patch）（x86 RIP 修补计数（g_x86_rip_patch_count） + 1）
    调用 写64位（w64）向 x86 RIP 修补位置数组（g_x86_rip_patch_pos）偏移量 x86 RIP 修补计数 × 8 处写入 堆 RIP 修补位置（rip_hp_ex）
    调用 写64位（w64）向 x86 RIP 全局变量修补数组（g_x86_rip_patch_globals）偏移量 x86 RIP 修补计数 × 8 处写入 堆指针索引（gv_heap_ptr）
    令 x86 RIP 修补计数 = x86 RIP 修补计数 + 1
否则：
    —— 使用直接 BSS 偏移量
    令 局部变量 相对偏移量（rel_hp_s） = BSS 虚拟地址 - （函数虚拟地址 + 当前指针 + 7）
    向缓冲区偏移量 起始位置+当前指针 处写入字节值 72（REX.W 前缀）
    向缓冲区偏移量 起始位置+当前指针+1 处写入字节值 137（mov r/m64, r64 的 opcode）
    向缓冲区偏移量 起始位置+当前指针+2 处写入字节值 5（ModRM 字节，RIP 相对寻址模式）
    调用 写单字节有符号（w8_signed）向偏移量 起始位置+当前指针+3 处写入 相对偏移量（rel_hp_s）
    令 当前指针 = 当前指针 + 7

—— 发射 lea r11, [rax + 1073741824] 指令（7 字节）：r11 = 新基址 + 1 GiB = 新 堆末尾（heap_end） 值
向缓冲区偏移量 起始位置+当前指针 处写入字节值 76（REX.W+R 前缀，W=1、R=1、X=0、B=0 = 76，R=1 对应 r11 高位）
向缓冲区偏移量 起始位置+当前指针+1 处写入字节值 141（lea r64, [r/m] 的 opcode，0x8D）
向缓冲区偏移量 起始位置+当前指针+2 处写入字节值 152（ModRM 字节，mod×64+reg×8+rm = 2×64+3×8+0 = 128+24+0 = 152：mod=2 表示 [寄存器+disp32] 寻址、reg=3 r11（配 REX.R=1）、rm=0 rax）
调用 发射写32位（e2_w32）向偏移量 起始位置+当前指针+3 处写入 32 位有符号位移量 1073741824（1 GiB = 0x40000000）
令 当前指针 = 当前指针 + 7

—— 发射 mov [rip + 堆末尾全局（g_heap_end）], r11 指令（7 字节）：将新 堆末尾（heap_end） 值存回全局变量
如果 堆末尾索引（gv_heap_end） 大于等于 0，那么：
    —— 使用 RIP 修补方式
    令 局部变量 堆末尾 RIP 修补位置（rip_he_ex） = 起始位置 + 当前指针 + 3
    向缓冲区偏移量 起始位置+当前指针 处写入字节值 76（REX.W+R 前缀，R=1 对应 r11 高位）
    向缓冲区偏移量 起始位置+当前指针+1 处写入字节值 137（mov r/m64, r64 的 opcode，0x89）
    向缓冲区偏移量 起始位置+当前指针+2 处写入字节值 29（ModRM 字节，mod×64+reg×8+rm = 0×64+3×8+5 = 29：mod=0 RIP 相对、reg=3 r11（配 REX.R=1）、rm=5）
    调用 发射写32位（e2_w32）向偏移量 起始位置+当前指针+3 处写入占位符值 0
    令 当前指针 = 当前指针 + 7
    调用 扩展 RIP 修补数组（grow_rip_patch）（x86 RIP 修补计数 + 1）
    调用 写64位（w64）向 x86 RIP 修补位置数组 偏移量 x86 RIP 修补计数 × 8 处写入 堆末尾 RIP 修补位置（rip_he_ex）
    调用 写64位（w64）向 x86 RIP 全局变量修补数组 偏移量 x86 RIP 修补计数 × 8 处写入 堆末尾索引（gv_heap_end）
    令 x86 RIP 修补计数 = x86 RIP 修补计数 + 1
否则：
    —— 使用直接 BSS 偏移量（heap_end 位于 BSS 偏移量 8 处）
    令 局部变量 相对偏移量（rel_hp_e） = （BSS 虚拟地址 + 8） - （函数虚拟地址 + 当前指针 + 7）
    向缓冲区偏移量 起始位置+当前指针 处写入字节值 76（REX.W+R 前缀）
    向缓冲区偏移量 起始位置+当前指针+1 处写入字节值 137（mov r/m64, r64 的 opcode）
    向缓冲区偏移量 起始位置+当前指针+2 处写入字节值 29（ModRM 字节，RIP 相对寻址模式）
    调用 写单字节有符号（w8_signed）向偏移量 起始位置+当前指针+3 处写入 相对偏移量（rel_hp_e）
    令 当前指针 = 当前指针 + 7

—— 发射 xor eax, eax 指令（2 字节）：eax = 0（返回值表示成功）
向缓冲区偏移量 起始位置+当前指针 处写入字节值 49（xor r/m32, r32 的 opcode，0x31）
向缓冲区偏移量 起始位置+当前指针+1 处写入字节值 192（ModRM 字节，mod×64+reg×8+rm = 3×64+0×8+0 = 192：xor eax, eax）
令 当前指针 = 当前指针 + 2
—— 发射 返回（ret） 指令（1 字节）
向缓冲区偏移量 起始位置+当前指针 处写入字节值 195（返回（ret） 的 opcode，C3）
令 当前指针 = 当前指针 + 1

—— .堆链接标签（Lhf） 失败路径：内存映射（mmap） 返回了负值（-errno）
—— 发射 mov rax, -1 指令（7 字节）：rax = -1（返回 -1 表示分配失败）
向缓冲区偏移量 起始位置+当前指针 处写入字节值 72（REX.W 前缀，W=1 = 72）
向缓冲区偏移量 起始位置+当前指针+1 处写入字节值 199（mov r/m64, imm32 的 opcode，0xC7，使用 /0 操作码扩展）
向缓冲区偏移量 起始位置+当前指针+2 处写入字节值 192（ModRM 字节，mod×64+reg×8+rm = 3×64+0×8+0 = 192：mod=3、reg=0 rax（mov /0 扩展）、rm=0 rax，即 mov rax, imm32）

令 当前指针 = 当前指针 + 7

## 函数 写程序头（write_phdr）
### 作用
向 ELF 文件头后的程序头表中写入一条程序头条目。
### 逻辑

—— 计算本条目的基址偏移量：程序头表紧接 ELF 文件头之后
令 基址 = ELF 头大小（EHDR_SIZE，值为 64） + 索引 × 程序头大小（PHDR_SIZE，值为 56）（每条目 56 字节，索引从 0 开始）
—— 依次写入 8 个字段（每种字段的偏移量由全局常量 P_TYPE、P_FLAGS 等定义）
调用 写32位（w32）（缓冲区, 基址 + P_TYPE（偏移量 0）, 段类型）（p_type：段类型，4 字节，例如 PT_LOAD=1）
调用 写32位（w32）（缓冲区, 基址 + P_FLAGS（偏移量 4）, 段权限标志）（p_flags：段权限，4 字节，例如 PF_R|PF_X=5）
调用 写64位（w64）（缓冲区, 基址 + P_OFFSET（偏移量 8）, 段文件偏移量）（p_offset：段在文件中的起始偏移量，8 字节）
调用 写64位（w64）（缓冲区, 基址 + P_VADDR（偏移量 16）, 段虚拟地址）（p_vaddr：段在内存中的虚拟地址，8 字节）
调用 写64位（w64）（缓冲区, 基址 + P_PADDR（偏移量 24）, 段物理地址）（p_paddr：段物理地址，通常等于虚拟地址，8 字节）
调用 写64位（w64）（缓冲区, 基址 + P_FILESZ（偏移量 32）, 段文件内大小）（p_filesz：段在文件中的字节数，8 字节）
调用 写64位（w64）（缓冲区, 基址 + P_MEMSZ（偏移量 40）, 段内存内大小）（p_memsz：段在内存中的字节数，可大于 filesz 以预留 BSS，8 字节）
调用 写64位（w64）（缓冲区, 基址 + P_ALIGN（偏移量 48）, 段对齐）（p_align：对齐边界，通常为 4096，8 字节）

### 测试要点
1. PHDR[0] 写入在偏移量 64 （EHDR_SIZE） 处。
2. PHDR[1] 写入在偏移量 120 （64+56） 处。
3. 各字段按 ELF64 规范正确编码。

## 函数 ELF2 头写入（elf2_hdr）
### 作用
写入完整的 ELF64 文件头（含 e_ident、e_type、e_machine 等）和两个程序头：一个可读可执行代码段（PHDR[0]）、一个可读可写数据段（PHDR[1]），后者 memsz 设为 1 GiB 以容纳虚拟 蹦床式（bump） 堆。
### 逻辑

—— 初始化 ELF 头 + 2 个程序头区域为零
令 头大小 = ELF 头大小（EHDR_SIZE，64） + 2 × 程序头大小（PHDR_SIZE，56）（64 + 112 = 176 字节）
令 变量 循环索引（i） = 0
循环（当 索引（i） 小于 头大小 时）：
    调用 存储单字节（store8）（缓冲区, 索引（i）, 0）（将头区域全部清零）
    令 循环索引（i） = 循环索引 + 1
    如果 循环索引（i） 大于等于 头大小，那么：跳出循环

—— e_ident 字段（16 字节的 ELF 标识）
调用 写单字节（w8）向缓冲区偏移量 E_EHDR_MAGIC（值 0）处写入字节值 127（\x7f，ELF 魔数首字节）
调用 写单字节（w8）向缓冲区偏移量 E_EHDR_MAGIC+1 处写入字节值 69（'错误（E）'，ASCII 0x45）
调用 写单字节（w8）向缓冲区偏移量 E_EHDR_MAGIC+2 处写入字节值 76（'L'，ASCII 0x4C）
调用 写单字节（w8）向缓冲区偏移量 E_EHDR_MAGIC+3 处写入字节值 70（'F'，ASCII 0x46）
—— 写入 \x7fELF 魔数
调用 写单字节（w8）向缓冲区偏移量 E_CLASS（值 4）处写入字节值 2（ELF 类别字段（EI_CLASS） = ELFCLASS64，表示 64 位格式）
调用 写单字节（w8）向缓冲区偏移量 E_DATA（值 5）处写入字节值 1（ELF 数据编码字段（EI_DATA） = ELFDATA2LSB，表示小端字节序）
调用 写单字节（w8）向缓冲区偏移量 E_VER（值 6）处写入字节值 1（ELF 版本字段（EI_VERSION） = EV_CURRENT，表示当前 ELF 版本）

—— e_type、e_machine、e_version
调用 写16位（w16）向缓冲区偏移量 E_TYPE（值 16）处写入 16 位值 2（ET_EXEC，可执行文件）
调用 写16位（w16）向缓冲区偏移量 E_MACH（值 18）处写入 16 位值 62（EM_X86_64，x86-64 架构）
调用 写32位（w32）向缓冲区偏移量 E_VERSION（值 20）处写入 32 位值 1（EV_CURRENT）

—— 入口点：代码段基址（TEXT_BASE = 0x400000） + ELF 头 + 两个程序头 = 0x400000 + 176
调用 写64位（w64）向缓冲区偏移量 E_ENTRY（值 24）处写入 64 位值 0x400000 + ELF 头大小 + 2 × 程序头大小（即 0x400000 + 176 = 4194304 + 176 = 4194480）

—— 程序头偏移量：程序头表紧接 ELF 文件头之后
调用 写64位（w64）向缓冲区偏移量 E_PHOFF（值 32）处写入 64 位值 ELF 头大小（64）

—— 大小字段
调用 写16位（w16）向缓冲区偏移量 E_EHSIZE（值 52）处写入 16 位值 ELF 头大小（Elf64_Ehdr）
调用 写16位（w16）向缓冲区偏移量 E_PHENTSIZE（值 54）处写入 16 位值 程序头大小（Elf64_Phdr）
调用 写16位（w16）向缓冲区偏移量 E_PHNUM（值 56）处写入 16 位值 2（两个程序头：代码段 + 数据段）

—— PHDR[0]：代码段（RX，文件偏移量 0，虚拟地址 = TEXT_BASE）
调用 写程序头（write_phdr）（缓冲区, 索引=0, 段类型=1（PT_LOAD）, 段权限=5（PF_R|PF_X）, 文件偏移量=0, 虚拟地址=4194304（TEXT_BASE）, 物理地址=4194304, 文件内大小=code_end, 内存内大小=code_end, 对齐=4096）

—— PHDR[1]：只读数据段（rodata） + BSS 数据段（RW，从代码段后的页开始）
令 局部变量 只读数据段虚拟地址（rodata_va） = 4194304（TEXT_BASE） + 代码段结束偏移（code_end）（数据段起始虚拟地址，紧接代码段之后）
令 局部变量 数据段大小（data_sz） = 总大小（total_sz） - 代码段结束偏移（code_end）（数据段在文件中的大小）
调用 写程序头（write_phdr）（缓冲区, 索引=1, 段类型=1（PT_LOAD）, 段权限=6（PF_R|PF_W）, 文件偏移量=code_end, 虚拟地址=rodata_va, 物理地址=rodata_va, 文件内大小=data_sz, 内存内大小=1073741824（1 GiB 虚拟 bump 堆）, 对齐=4096）

### 测试要点
1. 代码段权限为 PF_R|PF_X=5（可读可执行）。
2. 数据段权限为 PF_R|PF_W=6（可读可写）。
3. 数据段 memsz 为 1GiB（虚拟 bump 堆）。
4. 段对齐为 4096（4KB 页）。
5. 入口点为 TEXT_BASE + 176（ELF 头 + 程序头之后）。
