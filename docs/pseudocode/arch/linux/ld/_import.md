# _import.cr 伪代码

> 源文件：src/arch/linux/ld/_import.cr（15 行）
> 功能概要：corearch 后端项目的共享引入文件。汇总该目录下所有模块所需的系统库引入语句，供各源文件通过 `_import.cr` 统一引用。

## 标识符对照表

| 中文名 | 原名 | 说明 |
|--------|------|------|
| 引入 | import | 模块引入关键字 |

## 全局状态

本文件仅包含引入语句，不声明全局变量。

## 功能说明

本文件为纯引入文件，依次引入以下模块：

1. 引入 `cli`（命令行参数解析）
2. 引入 `fmt`（字符串格式化）
3. 引入 `io`（输入输出）
4. 引入 `toml`（TOML 配置解析）
5. 引入 `ast`（AST 节点定义与 IR 操作码）
6. 引入 `globals`（全部全局变量声明）
7. 引入 `dyn_arr`（动态数组扩展函数）
8. 引入 `monomorph`（泛型单态化）
9. 引入 `ccr_io`（.ccr 二进制文件序列化/反序列化）
10. 引入 `sizes`（指令字节大小计算）
11. 引入 `instr`（x86-64 指令编码与发射）
12. 引入 `resolve`（标签解析与分支偏移量修补）
13. 引入 `elf`（ELF 二进制生成）
14. 引入 `ld`（动态链接器）

所有 `src/arch/linux/ld/` 目录下的源文件均通过引入 `_import` 获得这些依赖，避免重复书写引入语句。
