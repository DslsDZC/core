# _import.cr 伪代码

> 源文件：src/arch/linux/ld/_import.cr（15 行）
> 功能概要：corearch 后端项目的共享引入文件。汇总该目录下所有模块所需的系统库引入语句，供各源文件通过 `_import.cr` 统一引用。

## 标识符对照表

| 中文名 | 原名 | 说明 |
|--------|------|------|
| 引入 | import | 模块引入关键字 |

## 全局状态

本文件仅包含引入语句，不声明全局变量。

## 功能说明

本文件为纯引入文件，依次引入以下模块：

1. 引入 命令行参数模块（cli）
2. 引入 字符串格式化模块（fmt）
3. 引入 输入输出模块（io）
4. 引入 配置解析模块（TOML）（toml）
5. 引入 AST 节点与 IR 操作码模块（ast）
6. 引入 全局变量声明模块（globals）
7. 引入 动态数组扩展模块（dyn_arr）
8. 引入 泛型单态化模块（monomorph）
9. 引入 .线性指令流（ccr） 二进制序列化模块（ccr_io）
10. 引入 指令字节大小计算模块（sizes）
11. 引入 x86-64 指令编码与发射模块（instr）
12. 引入 标签解析与偏移量修补模块（resolve）
13. 引入 ELF 二进制生成模块（elf）
14. 引入 动态链接器模块（ld）

所有该目录下的源文件均通过引入本文件获得这些依赖，避免重复书写引入语句。
