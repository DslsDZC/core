# resolve.cr 伪代码

> 源文件：src/arch/linux/ld/resolve.cr（91 行）
> 功能概要：通用的标签到偏移量解析遍。使用真实编码器 发射单条指令（emit_instr） 测量每条指令的大小（无需重复维护尺寸逻辑），记录标签位置，然后将 IR_BRANCH 和 IR_JUMP 指令的源操作数替换为已解析的字节偏移量。解析后，IR_BRANCH 的 src2/src3 和 IR_JUMP 的 src1 直接填入目标偏移量，后端发射单条指令可直接使用，无需标签表查找。

## 函数 解析标签（res_labels）
### 作用
三遍扫描实现标签到字节偏移量的解析：
- 第一遍：使用真实编码器 发射单条指令 测量每条指令的大小，累加得到每个标签的字节偏移量。
- 第二遍：将分支指令（IR_BRANCH）的操作数2（真分支）和操作数3（假分支），以及跳转指令（IR_JUMP）的操作数1替换为已解析的绝对偏移量，并将类型类别标记为已解析（IR_RESOLVED）。
- 第三遍：将标签指令（IR_LABEL）的操作码改为空操作（IR_NOP），因为标签信息已编码到分支/跳转指令的操作数中。

之后 发射单条指令 可直接使用操作数中预计算的偏移量，无需再查标签表。

### 逻辑
输出调试信息：依次打印 "    （res_labels）: "、IR 函数个数（整数转字符串）、" （funcs）, "、IR 指令总数（整数转字符串）、" （instrs）"，然后换行。

令 当前函数索引（fi）= 0
循环（当 当前函数索引 小于 IR 函数个数 时）：
    令 指令起始（ist）= 读 64 位（IR 函数指令起始索引数组, 当前函数索引 乘以 8）
    令 指令计数（ic）= 读 64 位（IR 函数指令计数数组, 当前函数索引 乘以 8）
    令 变量起始（vs_r）= 读 64 位（IR 函数变量起始索引数组, 当前函数索引 乘以 8）
    令 变量计数（vc_r）= 读 64 位（IR 函数变量计数数组, 当前函数索引 乘以 8）
    令 参数计数（pc_r）= 读 64 位（IR 函数参数计数数组, 当前函数索引 乘以 8）

    —— 初始化槽位状态以获取准确的指令尺寸
    调用 全局变量初始化（）
    令 当前函数变量起始（g_current_func_var_start）= 变量起始

    令 变量槽索引（vi4）= 0
    循环（当 变量槽索引 小于 变量计数 时）：
        调用 全局变量槽位（变量起始 + 变量槽索引）
        令 变量槽索引 = 变量槽索引 + 1

    令 参数槽索引（pi4）= 0
    循环（当 参数槽索引 小于 参数计数 且 参数槽索引 小于 6 时）：
        调用 全局变量槽位（变量起始 + 参数槽索引）
        令 参数槽索引 = 参数槽索引 + 1

    —— 第一遍：通过 发射单条指令（真实编码器）测量指令大小
    令 标签计数（g_label_count）= 0
    令 当前偏移量（off）= 0
    令 指令索引（ii）= 0
    令 暂存缓冲区（scratch）= 分配内存（64）
    循环（当 指令索引 小于 指令计数 时）：
        令 指令编号（inst_idx）= 指令起始 + 指令索引
        如果 IR 指令访问器：操作码（指令编号） 等于 标签指令，那么：
            令 标签编号（ln）= IR 指令访问器：操作数1（指令编号）
            如果 标签编号 大于等于 0，那么：
                调用 扩展标签位置数组（标签编号 + 1）
                写 64 位（标签位置数组, 标签编号 乘以 8, 当前偏移量）
                如果 标签编号 + 1 大于 标签计数，那么：
                    令 标签计数 = 标签编号 + 1
        否则：
            —— 用真实编码器测量当前指令大小，累加到偏移量
            令 当前偏移量 = 当前偏移量 + 发射单条指令（指令编号, 暂存缓冲区, 0）
        令 指令索引 = 指令索引 + 1

    —— 保存本函数的代码大小，供 Phase 2 重用
    调用 扩展函数代码大小数组（当前函数索引 + 1）
    写 64 位（x86 函数代码大小数组, 当前函数索引 乘以 8, 当前偏移量）

    —— 第二遍：用已解析的偏移量修补分支和跳转指令
    令 指令索引 = 0
    循环（当 指令索引 小于 指令计数 时）：

            调用 IR 指令访问器：设置操作码（指令编号, 分支指令）
            调用 IR 指令访问器：设置操作数2（指令编号, 真分支偏移量）
            调用 IR 指令访问器：设置操作数3（指令编号, 假分支偏移量）
            调用 IR 指令访问器：设置类型类别（指令编号, 已解析）
        如果 IR 指令访问器：操作码（指令编号） 等于 跳转指令，那么：
            令 目标偏移量（tgt_off）= 读 64 位（标签位置数组, IR 指令访问器：操作数1（指令编号） 乘以 8）
            调用 IR 指令访问器：设置操作码（指令编号, 跳转指令）
            调用 IR 指令访问器：设置操作数1（指令编号, 目标偏移量）
            调用 IR 指令访问器：设置类型类别（指令编号, 已解析）
        令 指令索引 = 指令索引 + 1

    —— 第三遍：把标签改成空操作（发射时跳过空操作（NOP），返回 0 字节）
    令 指令索引 = 0
    循环（当 指令索引 小于 指令计数 时）：
        如果 IR 指令访问器：操作码（指令起始 + 指令索引） 等于 标签指令，那么：
            调用 IR 指令访问器：设置操作码（指令起始 + 指令索引, 空操作）
        令 指令索引 = 指令索引 + 1

    令 当前函数索引 = 当前函数索引 + 1

### 测试要点
1. 空函数（指令计数等于 0）：函数代码大小应为 0，不发生任何修补。
2. 仅含标签指令的函数：偏移量记录后标签转换为空操作，代码大小为 0（空操作不发射字节）。
3. 前向跳转：分支指令（BRANCH）/跳转指令（JUMP）的偏移量应正确指向目标标签位置。
4. 后向跳转：偏移量应为正确的绝对偏移值。
5. 多个分支指令跳转到同一标签：两条分支指令的各自目标偏移量应正确。
6. 标签编号为负数（IR 标签编号取操作数1）：不记录标签位置。
7. 同一函数内顺序标签：各标签偏移量应单调递增。

## 解析后的 IR 指令约定

- 分支指令（IR_BRANCH）：操作数2 = 真分支绝对偏移量，操作数3 = 假分支绝对偏移量，类型类别 = 已解析（IR_RESOLVED）
- 跳转指令（IR_JUMP）：操作数1 = 目标绝对偏移量，类型类别 = 已解析（IR_RESOLVED）
- 标签指令（IR_LABEL）：操作码变为空操作（IR_NOP），发射单条指令遇到空操作（NOP）返回 0 字节
