# resolve.cr 伪代码

> 源文件：src/arch/linux/ld/resolve.cr（91 行）
> 功能概要：通用的标签到偏移量解析遍。使用真实编码器 emit_instr 测量每条指令的大小（无需重复维护尺寸逻辑），记录标签位置，然后将 IR_BRANCH 和 IR_JUMP 指令的源操作数替换为已解析的字节偏移量。解析后，IR_BRANCH 的 src2/src3 和 IR_JUMP 的 src1 直接填入目标偏移量，后端 emit_instr 可直接使用，无需标签表查找。

## 函数 解析标签（res_labels）
### 作用
三遍扫描实现标签到字节偏移量的解析：
- 第一遍：使用真实编码器 emit_instr 测量每条指令的大小，累加得到每个标签的字节偏移量。
- 第二遍：将 IR_BRANCH（分支指令）的 src2（真分支）/src3（假分支）和 IR_JUMP（跳转指令）的 src1 替换为已解析的绝对偏移量，并将类型类别标记为 IR_RESOLVED。
- 第三遍：将 IR_LABEL（标签）指令改为 IR_NOP（空操作），因为标签信息已编码到分支/跳转指令的操作数中。

之后 emit_instr 可直接使用操作数中预计算的偏移量，无需再查标签表。
### 逻辑
输出调试信息："res_labels: [函数个数] funcs, [指令总数] instrs"

令 当前函数索引 = 0
循环（当 当前函数索引 小于 IR 函数个数 时）：
    令 指令起始 = 读 64 位（IR 函数指令起始索引数组, 当前函数索引 * 8）
    令 指令计数 = 读 64 位（IR 函数指令计数数组, 当前函数索引 * 8）
    令 变量起始 = 读 64 位（IR 函数变量起始索引数组, 当前函数索引 * 8）
    令 变量计数 = 读 64 位（IR 函数变量计数数组, 当前函数索引 * 8）
    令 参数计数 = 读 64 位（IR 函数参数计数数组, 当前函数索引 * 8）

    —— 初始化槽位状态以获取准确尺寸
    调用 全局变量初始化（）
    令 当前函数变量起始 = 变量起始
    令 变量索引 = 0；循环（当 变量索引 < 变量计数 时）：
        调用 全局变量槽位（变量起始 + 变量索引）
        变量索引 = 变量索引 + 1
    令 参数索引 = 0；循环（当 参数索引 < 参数计数 且 参数索引 < 6 时）：
        调用 全局变量槽位（变量起始 + 参数索引）
        参数索引 = 参数索引 + 1

    —— 第一遍：通过 emit_instr（真实编码器）测量指令大小
    令 标签计数 = 0
    令 当前偏移量 = 0
    令 指令索引 = 0
    令 暂存缓冲区 = 分配（64）
    循环（当 指令索引 < 指令计数 时）：
        令 指令编号 = 指令起始 + 指令索引
        如果 读取操作码（指令编号） 等于 IR_LABEL，那么：
            令 标签编号 = 读取操作数 1（指令编号）
            如果 标签编号 不小于 0，那么：
                调用 扩展标签位置数组（标签编号 + 1）
                写入 64 位（标签位置数组, 标签编号 * 8, 当前偏移量）
                如果 标签编号 + 1 大于 标签计数，那么：令 标签计数 = 标签编号 + 1
        否则：
            令 当前偏移量 = 当前偏移量 + 发射单条指令（指令编号, 暂存缓冲区, 0）
        指令索引 = 指令索引 + 1

    —— 保存每个函数的代码大小，供第二阶段重用
    调用 扩展函数代码大小数组（当前函数索引 + 1）
    写入 64 位（x86 函数代码大小数组, 当前函数索引 * 8, 当前偏移量）

    —— 第二遍：用已解析的偏移量修补 BRANCH/JUMP
    令 指令索引 = 0
    循环（当 指令索引 < 指令计数 时）：
        令 指令编号 = 指令起始 + 指令索引
        如果 读取操作码（指令编号） 等于 IR_BRANCH，那么：
            令 真分支偏移量 = 读 64 位（标签位置数组, 读取操作数 2（指令编号）* 8）
            令 假分支偏移量 = 读 64 位（标签位置数组, 读取操作数 3（指令编号）* 8）
            调用 设置操作码（指令编号, IR_BRANCH）
            调用 设置操作数 2（指令编号, 真分支偏移量）
            调用 设置操作数 3（指令编号, 假分支偏移量）
            调用 设置类型类别（指令编号, IR_RESOLVED）
        如果 读取操作码（指令编号） 等于 IR_JUMP，那么：
            令 目标偏移量 = 读 64 位（标签位置数组, 读取操作数 1（指令编号）* 8）
            调用 设置操作码（指令编号, IR_JUMP）
            调用 设置操作数 1（指令编号, 目标偏移量）
            调用 设置类型类别（指令编号, IR_RESOLVED）
        指令索引 = 指令索引 + 1

    —— 第三遍：把 LABEL 改成 NOP（发射时跳过 NOP）
    令 指令索引 = 0
    循环（当 指令索引 < 指令计数 时）：
        如果 读取操作码（指令起始 + 指令索引） 等于 IR_LABEL，那么：
            调用 设置操作码（指令起始 + 指令索引, IR_NOP）
        指令索引 = 指令索引 + 1

    当前函数索引 = 当前函数索引 + 1

### 测试要点
1. 空函数（指令计数 = 0）：函数代码大小应为 0，不发生任何修补。
2. 仅含 LABEL 指令的函数：偏移量记录后标签转换为 NOP，代码大小为 0（NOP 不发射字节）。
3. 前向跳转：BRANCH/JUMP 的偏移量应正确指向目标标签位置。
4. 后向跳转：偏移量应为负数相对值（或发射时转换为负相对值）。
5. 多个 BRANCH 跳转到同一标签：两条分支指令的 src2/src3 应各有各自的偏移量。
6. 标签编号不存在（未定义）：操作数保持原值，留待后端处理。
7. 同一函数内嵌套标签：各标签偏移量应单调递增。

## 解析后的 IR 指令约定

- IR_BRANCH：src2 = 真分支绝对偏移量，src3 = 假分支绝对偏移量，type_kind = IR_RESOLVED
- IR_JUMP：src1 = 目标绝对偏移量，type_kind = IR_RESOLVED
- IR_LABEL：操作码变为 IR_NOP（emit_instr 遇到 NOP 返回 0 字节）
