### 逻辑

令 x86 栈大小（g_x86_stack_size）= 0
令 x86 当前函数索引（g_x86_func_idx）= 0

令 x86 栈映射数组（g_stack_map）= ""（空字符串，零长度字节缓冲区）
### 测试要点
1. 所有计数器和容量置零。
2. 栈映射数组初始化为空字符串。

## 函数 拆分链接参数（split_links）
### 作用
按逗号（ASCII 44）分割链接参数字符串，将每个分割出的 .so 文件路径通过 链接上下文：添加 .so 注册到链接上下文。

参数：链接参数字符串（值（val）：字符串）

### 逻辑
令 源字符串长度（sl）= 字符串长度（链接参数字符串）
令 起始位置（start）= 0
令 当前索引（i）= 0
循环（当 当前索引 小于等于 源字符串长度 时）：
    —— 逗号的字符码为 44，到达字符串末尾或遇到逗号时分割
    如果 当前索引 等于 源字符串长度 或 按字节读取（链接参数字符串, 当前索引）等于 44，那么：
        如果 当前索引 大于 起始位置，那么：
            —— 分割出一个非空子串
            令 子串（p）= 字符串切片（链接参数字符串, 起始位置, 当前索引 - 起始位置）
            调用 链接上下文：添加 .so（子串）
        令 起始位置 = 当前索引 + 1
    令 当前索引 = 当前索引 + 1
### 测试要点
1. 空字符串：不注册任何 .so。
2. 单个路径（如 "变量甲（a）.so"）：注册 1 个 .so。
3. 多个路径（如 "变量甲（a）.so,变量乙（b）.so"）：注册 2 个 .so。
4. 末尾逗号：不产生空名称注册。
5. 连续逗号（如 "变量甲（a）.so,,变量乙（b）.so"）：中间空项被跳过。

## 函数 后端主入口（corearch_main）
### 作用
后端程序（corearch）的主入口。解析命令行参数，加载 .线性指令流（ccr） 文件，根据 共享库标志（--shared）、静态链接标志（--static）、链接标志（--link）选项协调 ELF 生成流水线（静态直写、动态链接、共享库模式），输出最终 ELF 文件。

返回值：整数（0 成功，1 失败）

调用 CLI：获取布尔标志（"shared", "", "Output shared library （.so）"）
调用 CLI：获取布尔标志（"static", "", "Static linking （embed runtime）"）
调用 CLI：添加标志（"link", "l", "Comma-sep .so files, or 'auto' 遍历（for） ~/.核心（core）/lib/"）
调用 CLI：添加标志（"output", "o", "Output path"）
调用 CLI：添加标志（"opt-level", "O", "Optimization level （0-3, default=0）"）

### 测试要点
1. 无参数启动：应输出帮助信息并返回 1。
2. 无效 .线性指令流（ccr） 文件路径：应输出错误并返回 1。
3. 损坏的 .线性指令流（ccr） 文件：加载 .线性指令流 文件返回非零值，应输出错误。
4. 共享库模式（--shared）：输出文件类型应为 共享对象类型常量（共享对象类型（ET_DYN），值 3），文件扩展名为 .so。
5. 静态链接（--static）链接参数（--link）为 自动（auto）：应找到 运行时库（core_rt）.so 并调用 链接上下文：发射静态链接。
6. 链接自动模式（--link auto，无静态链接）：应走到 链接上下文：发射动态链接 动态链接路径。
7. 指定链接文件（--link 变量甲（a）.so,变量乙（b）.so）：拆分链接参数 解析两个路径并各自注册。
8. 输出标志（-o）指定输出路径：应使用用户指定的路径而非 默认输出（变量甲（a）.out）。
9. 优化级别标志（--opt-level）超出范围：应钳制到 0 到 3 之间。
10. 空代码段（代码大小小于等于 0）：应输出 错误消息（"error: empty code"）并返回 1。
11. 链接失败（输出大小小于等于 0）：应输出 错误消息（"error: linking failed"）并返回 1。
