# ld.cr 伪代码

> 源文件：src/arch/linux/ld/ld.cr（477 行）
> 功能概要：Core 动态 ELF 链接器。采用 mold 风格的块架构，支持动态链接（生成依赖 .so 的 ELF）、共享库（--shared）和静态链接（嵌入 .so 代码段）三种模式。管线：初始化上下文 → 添加 .so → 添加 PLT 条目 → 设置用户代码 → 布局 → 修补重定位 → 发射。

## 函数 扩展 .so 数组（dyn_grow_so）

### 作用
按需扩展 .so 路径数组的容量。每个 .so 路径条目占 8 字节（一个字符串指针）。初始容量为 0，首次扩展后至少为 4。

### 逻辑
    如果 所需容量（needed）小于 .so 容量（g_so_cap），那么：返回
    令 新容量（nc） = .so 容量 * 2
    如果 新容量 小于 4，那么：令 新容量 = 4
    如果 新容量 小于 所需容量，那么：令 新容量 = 所需容量 + 4
    令 新缓冲区（nb） = 分配内存（新容量 * 8）
    调用 内部：动态拷贝（源地址 = .so 路径数组，拷贝字节数 = .so 容量 * 8，目标地址 = 新缓冲区）
    令 .so 路径数组 = 新缓冲区
    令 .so 容量 = 新容量

### 测试要点
1. 初始容量 0 时第一次扩展：新容量大于等于 4。
2. 扩展后原路径数据不丢失。
3. 所需容量小于当前容量时直接返回，不做任何操作。

## 函数 扩展 PLT 数组（dyn_grow_plts）

### 作用
按需扩展 PLT 条目数组的容量。每个 PLT 条目占 16 字节（名称指针 8 字节 + .so 索引 8 字节）。最小容量为 16。

### 逻辑
    如果 所需容量（needed）小于 PLT 容量（g_plt_cap），那么：返回
    令 新容量（nc） = PLT 容量 * 2
    如果 新容量 小于 16，那么：令 新容量 = 16
    如果 新容量 小于 所需容量，那么：令 新容量 = 所需容量 + 16
    令 新缓冲区（nb） = 分配内存（新容量 * 16）
    调用 内部：动态拷贝（源地址 = PLT 条目数组，拷贝字节数 = PLT 容量 * 16，目标地址 = 新缓冲区）
    令 PLT 条目数组 = 新缓冲区
    令 PLT 容量 = 新容量

### 测试要点
1. 初始扩展：最小容量 16。
2. 条目扩容后原有 PLT 数据保留。
3. 所需容量小于当前容量时直接返回。

## 函数 扩展块数组（grow_chunks）

### 作用
同时扩展四个块属性数组（块类型数组、块虚拟地址数组、块文件偏移数组、块大小数组）到所需容量。四个数组保持同步：索引相同的条目属于同一个块。每个新数组先清零再拷贝旧数据，确保新增槽位初始值为 0。

### 逻辑
    令 新容量（nc） = 块类型容量（g_ch_kind_cap） * 2
    如果 新容量 小于 8，那么：令 新容量 = 8
    如果 新容量 小于 所需容量（needed），那么：令 新容量 = 所需容量 + 8
    —— 扩展块类型数组
    令 新类型缓冲区（nb） = 分配内存（新容量 * 8）
    令 清零索引（zi） = 0
    循环（当 清零索引 小于 新容量 * 8 时）：
        在 新类型缓冲区 偏移 清零索引 处写入单字节 0
        令 清零索引 = 清零索引 + 1
    调用 内部：动态拷贝（源地址 = 块类型数组，拷贝字节数 = 块类型容量 * 8，目标地址 = 新类型缓冲区）
    令 块类型数组 = 新类型缓冲区
    令 块类型容量 = 新容量
    —— 扩展块虚拟地址数组
    令 新虚拟地址缓冲区（nb2） = 分配内存（新容量 * 8）
    令 清零索引 = 0
    循环（当 清零索引 小于 新容量 * 8 时）：
        在 新虚拟地址缓冲区 偏移 清零索引 处写入单字节 0
        令 清零索引 = 清零索引 + 1
    调用 内部：动态拷贝（源地址 = 块虚拟地址数组，拷贝字节数 = 块虚拟地址容量 * 8，目标地址 = 新虚拟地址缓冲区）
    令 块虚拟地址数组 = 新虚拟地址缓冲区
    令 块虚拟地址容量 = 新容量
    —— 扩展块文件偏移数组
    令 新文件偏移缓冲区（nb3） = 分配内存（新容量 * 8）
    令 清零索引 = 0
    循环（当 清零索引 小于 新容量 * 8 时）：
        在 新文件偏移缓冲区 偏移 清零索引 处写入单字节 0
        令 清零索引 = 清零索引 + 1
    调用 内部：动态拷贝（源地址 = 块文件偏移数组，拷贝字节数 = 块文件偏移容量 * 8，目标地址 = 新文件偏移缓冲区）
    令 块文件偏移数组 = 新文件偏移缓冲区
    令 块文件偏移容量 = 新容量
    —— 扩展块大小数组
    令 新大小缓冲区（nb4） = 分配内存（新容量 * 8）
    令 清零索引 = 0
    循环（当 清零索引 小于 新容量 * 8 时）：
        在 新大小缓冲区 偏移 清零索引 处写入单字节 0
        令 清零索引 = 清零索引 + 1
    调用 内部：动态拷贝（源地址 = 块大小数组，拷贝字节数 = 块大小容量 * 8，目标地址 = 新大小缓冲区）
    令 块大小数组 = 新大小缓冲区
    令 块大小容量 = 新容量

### 测试要点
1. 初始首次扩展容量至少为 8。
2. 四个数组同步扩展，扩展后同一索引对应同一块的四个属性。
3. 新增槽位（超出旧容量的部分）全部清零。
4. 旧数据完整保留。

## 函数 新增通道（cnew）

### 作用
创建一个新块，写入类型编号，其余三个字段（虚拟地址、文件偏移、大小）初值为 0，块计数加 1。

### 逻辑
    调用 扩展块数组（所需容量 = 块计数（g_ch_count） + 1）
    写入 64 位值（目标数组 = 块类型数组，偏移量 = 块计数 * 8，值 = 块类型（k））
    写入 64 位值（目标数组 = 块虚拟地址数组，偏移量 = 块计数 * 8，值 = 0）
    写入 64 位值（目标数组 = 块文件偏移数组，偏移量 = 块计数 * 8，值 = 0）
    写入 64 位值（目标数组 = 块大小数组，偏移量 = 块计数 * 8，值 = 0）
    令 块计数 = 块计数 + 1

### 测试要点
1. 新块的虚拟地址、文件偏移、大小均为 0。
2. 块类型写入正确的类型编号。
3. 块计数正确递增。

## 函数 按种类查找通道（cby）

### 作用
按类型编号查找第一个匹配的块，返回其索引（从 0 开始）。未找到返回 -1。调用方需自行检查返回值。

### 逻辑
    令 索引（i） = 0
    循环（当 索引 小于 块计数（g_ch_count） 时）：
        从 块类型数组 偏移量 索引*8 处读取 64 位值
        如果 读出的值 等于 目标类型（k），那么：返回 索引
        令 索引 = 索引 + 1
    返回 -1

### 测试要点
1. 找到目标类型时返回正确的块索引（第一个匹配的）。
2. 搜索不存在的类型返回 -1。
3. 块计数为 0 时直接返回 -1。

## 函数 查找 .so 符号（so_find）

### 作用
在 .so 文件的 ELF 结构内按名称查找符号，返回其值（符号地址）。仅匹配同时满足三个条件的符号：全局绑定（全局绑定常量（STB_GLOBAL），即符号信息字节除以 16 等于 1）、函数类型（函数类型常量（STT_FUNC），即符号信息字节对 16 取模等于 2）、所属节索引非零。先扫描节头表定位 动态符号节（动态符号节（.dynsym））和动态字符串节（动态字符串节（.dynstr）），再遍历符号表逐条比对名称。

### 逻辑
    如果 字符串长度（buf） 小于 64，那么：返回 -1
    从 缓冲区 偏移 16 处读取 16 位值
    如果 读出的值 不等于 3（共享对象文件类型），那么：返回 -1
    从 缓冲区 偏移 40 处读取 64 位值，记为 ELF 节头偏移（e_shoff）
    从 缓冲区 偏移 60 处读取 16 位值，记为 ELF 节数量（e_shnum）
    令 动态符号偏移（do） = 0
    令 动态符号大小（ds） = 0
    令 字符串表偏移（so） = 0
    令 字符串表大小（ss） = 0
    令 节索引（i） = 0
    循环（当 节索引 小于 ELF 节数量 时）：
        从 缓冲区 偏移 ELF 节头偏移 + 节索引*64 + 4 处读取 32 位值，记为 节类型（t）
        从 缓冲区 偏移 ELF 节头偏移 + 节索引*64 + 16 处读取 64 位值，记为 节地址（a）
        从 缓冲区 偏移 ELF 节头偏移 + 节索引*64 + 24 处读取 64 位值，记为 节偏移（o）
        从 缓冲区 偏移 ELF 节头偏移 + 节索引*64 + 32 处读取 64 位值，记为 节大小（s）
        如果 节类型 等于 11（动态符号节类型 SHT_DYNSYM），那么：
            令 动态符号偏移 = 节偏移
            令 动态符号大小 = 节大小
        如果 节类型 等于 3（字符串表节类型 SHT_STRTAB） 且 节地址 不等于 0，那么：
            令 字符串表偏移 = 节偏移
            令 字符串表大小 = 节大小
        令 节索引 = 节索引 + 1
    如果 动态符号大小 等于 0 或 字符串表大小 等于 0，那么：返回 -1
    令 符号个数（sc） = 动态符号大小 / 24
    令 符号索引（i） = 0
    循环（当 符号索引 小于 符号个数 时）：
        从 缓冲区 偏移 动态符号偏移 + 符号索引*24 处读取 32 位值，记为 符号名称偏移（sn）
        从 缓冲区 偏移 动态符号偏移 + 符号索引*24 + 8 处读取 64 位值，记为 符号值（sv）
        读取 缓冲区 偏移 动态符号偏移 + 符号索引*24 + 4 处的单字节，记为 符号信息字节（si_val）
        从 缓冲区 偏移 动态符号偏移 + 符号索引*24 + 6 处读取 16 位值，记为 符号节索引（sx）
        如果 符号信息字节/16 等于 1 且 符号信息字节%16 等于 2 且 符号节索引 不等于 0，那么：
            令 读取的名称（nm） = 空字符串
            令 字符串位置（k） = 符号名称偏移
            循环（当 字符串位置 小于 字符串表大小 时）：
                读取 缓冲区 偏移 字符串表偏移 + 字符串位置 处的单字节，记为 当前字符（c）
                如果 当前字符 等于 0，那么：跳出循环
                调用 取字符串第 总个数（N） 字符（" ", 0）获取单字符缓冲区（sc2）
                在 单字符缓冲区 偏移 0 处写入 当前字符
                令 读取的名称 = 读取的名称 + 单字符缓冲区
                令 字符串位置 = 字符串位置 + 1
            如果 字符串长度（读取的名称） 大于 0 且 字符串相等比较（name） 不等于 0，那么：返回 符号值
        令 符号索引 = 符号索引 + 1
    返回 -1

### 测试要点
1. 有效 .so 文件：找到 打印函数（printf） 返回对应地址。
2. 无效 .so（小于 64 字节）：返回 -1。
3. 非 共享对象文件类型（ET_DYN） 文件（文件类型字段（e_type） 不等于 3）：返回 -1。
4. 符号表中无匹配名称：返回 -1。
5. 名称匹配但符号信息字节不满足 全局绑定常量（STB_GLOBAL）加 函数类型常量（STT_FUNC）：被过滤，返回 -1。
6. 动态符号大小为 0 或字符串表大小为 0：返回 -1。

## 函数 查找任意 .so 符号（so_find_any）

### 作用
遍历所有已注册 .so 文件，逐个调用 查找 .so 符号 查找目标符号地址，找到即返回。任一 .so 中找到即停止。

### 逻辑
    令 .so 索引（si） = 0
    循环（当 .so 索引 小于 .so 计数（g_so_count） 时）：
        从 .so 路径数组 偏移 .so 索引*8 处读取 64 位值（路径指针）
        如果 驻留字符串长度（上述路径指针） 大于 0，那么：
            令 文件缓冲区（b） = 读取文件（上述路径指针）
            如果 字符串长度（文件缓冲区） 大于 0，那么：
                令 符号地址（a） = 查找 .so 符号（name）
                如果 符号地址 大于等于 0，那么：返回 符号地址
        令 .so 索引 = .so 索引 + 1
    返回 -1

### 测试要点
1. 符号在第一个 .so 中找到：立即返回，不扫描后续 .so。
2. 符号在所有 .so 中都不存在：返回 -1。
3. .so 文件不存在或读取失败：跳过，继续下一个。
4. .so 路径为空字符串：跳过。

## 函数 布局（layout）

### 作用
遍历所有块，按类型计算每个块的大小，按顺序分配虚拟地址和文件偏移。块按创建顺序排列，每个块的虚拟地址为前一块的虚拟地址加上前一块的大小，文件偏移等于虚拟地址减去代码段基址（即相对于代码段起点的偏移）。

### 逻辑
    令 当前虚拟地址（va） = 代码段基址（g_text_base）
    令 块索引（i） = 0
    循环（当 块索引 小于 块计数（g_ch_count） 时）：
        令 块大小（sz） = 0
        从 块类型数组 偏移 块索引*8 处读取 64 位值，记为 块类型（k）
        如果 块类型 等于 0（ELF 头块 EhdrChunk），那么：令 块大小 = 344
        如果 块类型 等于 1（解释器路径块 InterpChunk），那么：令 块大小 = 29
        如果 块类型 等于 2（用户代码块 UserChunk），那么：令 块大小 = 用户代码大小（g_user_size）
        如果 块类型 等于 3（PLT 块 PltChunk），那么：令 块大小 = 32 + PLT 条目计数（g_plt_count） * 16
        如果 块类型 等于 4（GOT.PLT 块 GotPltChunk），那么：令 块大小 = （3 + PLT 条目计数） * 8
        如果 块类型 等于 5（动态段块 DynChunk），那么：令 块大小 = 10 * 16
        如果 块类型 等于 6（DynsymChunk），那么：令 块大小 = （1 + PLT 条目计数） * 24
        如果 块类型 等于 7（动态字符串表块 动态字符串块类型（DynstrChunk）），那么：
            令 块大小 = 1 + 字符串长度（"运行时库文件（core_rt.so）"） + 1
            令 遍历索引（j） = 0
            循环（当 遍历索引 小于 PLT 条目计数 时）：
                从 PLT 条目数组 偏移 遍历索引*16 处读取 64 位值（名称指针）
                令 块大小 = 块大小 + 驻留字符串长度（上述名称指针） + 1
                令 遍历索引 = 遍历索引 + 1
        如果 块类型 等于 8（重定位表块 RelaChunk），那么：令 块大小 = PLT 条目计数 * 24
        写入 64 位值（目标数组 = 块虚拟地址数组，偏移量 = 块索引*8，值 = 当前虚拟地址）
        写入 64 位值（目标数组 = 块文件偏移数组，偏移量 = 块索引*8，值 = 当前虚拟地址 - 代码段基址）
        写入 64 位值（目标数组 = 块大小数组，偏移量 = 块索引*8，值 = 块大小）
        令 当前虚拟地址 = 当前虚拟地址 + 块大小
        令 块索引 = 块索引 + 1

### 测试要点
1. 无 PLT 条目时 PLT 块大小 = 32（仅头部）。
2. 有 3 个 PLT 条目时 PLT 块大小 = 32 + 48 = 80。
3. 各块的虚拟地址按创建顺序递增，无重叠。
4. 文件偏移 = 虚拟地址 - 代码段基址（即从 0 开始的连续布局）。
5. 动态字符串表块大小随 PLT 名称数量正确增长。

## 函数 写 32 位有符号（w32s）

### 作用
将 32 位有符号值写入缓冲区指定偏移。实际调用 写 32 位 完成写入——有符号值的补码表示与无符号值相同，因此直接委托即可。

### 逻辑
    调用 写 32 位（目标数组 = 输出缓冲区（buf），偏移量 = 位置（pos），值 = 有符号值（v））

### 测试要点
1. 负数值的补码被正确写入（如 -5 写入为 0xFFFFFFFB）。
2. 与 写 32 位 行为一致。

## 函数 发射指令（emit）

### 作用
遍历块数组，按类型将每个块的数据写入输出缓冲区。这是链接器最核心的函数，负责生成完整的 ELF 文件内容：ELF 头和程序头（块类型 0）、解释器路径节（.interp） 解释器路径（块类型 1）、用户代码拷贝（块类型 2）、PLT 过程链接表（块类型 3）、GOT.PLT 全局偏移表（块类型 4）、动态链接信息节（.dynamic） 动态段及 动态字符串节（.dynstr） 动态字符串表（块类型 5）、动态符号节（.dynsym） 动态符号表（块类型 6）、重定位表节（.rela.plt） 重定位表（块类型 8）。注意块类型 7（DynstrChunk）的数据由块类型 5 的 情况分支负责写入，类型 7 自身无独立发射（emit）分支。

### 逻辑

    令 清零索引（zi） = 0
    循环（当 清零索引 小于 总大小（total） 时）：
        在 输出缓冲区（buf） 偏移 清零索引 处写入单字节 0
        令 清零索引 = 清零索引 + 1
    令 代码段基址局部副本（tb） = 代码段基址（g_text_base）
    令 块索引（i） = 0
    循环（当 块索引 小于 块计数（g_ch_count） 时）：
        从 块文件偏移数组 偏移 块索引*8 处读取 64 位值，记为 当前块文件偏移（p）
        从 块类型数组 偏移 块索引*8 处读取 64 位值，记为 当前块类型（k）

        —— 块类型 0：ELF 头 + 程序头（EhdrChunk）
        如果 当前块类型 等于 0，那么：
            在 输出缓冲区 偏移 0 处写入单字节 127（0x7F）
            在 输出缓冲区 偏移 1 处写入单字节 69（'错误（E）'）
            在 输出缓冲区 偏移 2 处写入单字节 76（'L'）
            在 输出缓冲区 偏移 3 处写入单字节 70（'F'）

            在 输出缓冲区 偏移 5 处写入单字节 1（ELF 数据编码字段（EI_DATA）：小端）
            在 输出缓冲区 偏移 6 处写入单字节 1（EI_VERSION）
            令 ELF 类型（etype） = 2（可执行文件类型常量 可执行文件类型常量（ET_EXEC））
            如果 是否为 .so 标记（is_so） 不等于 0，那么：令 ELF 类型 = 3（共享对象文件类型）
            在 输出缓冲区 偏移 16 处写入 16 位值（文件类型字段（e_type） = ELF 类型）
            在 输出缓冲区 偏移 18 处写入 16 位值（e_machine = 62，x86-64）
            在 输出缓冲区 偏移 20 处写入 32 位值（e_version = 1）
            令 用户代码块索引（uv） = 按种类查找通道（类型编号 = 2）
            从 块虚拟地址数组 偏移 用户代码块索引*8 处读取 64 位值，记为 入口虚拟地址（ev）
            在 输出缓冲区 偏移 24 处写入 64 位值（e_entry = 入口虚拟地址）

            在 输出缓冲区 偏移 54 处写入 16 位值（e_phentsize = 56）
            在 输出缓冲区 偏移 56 处写入 16 位值（e_phnum = 5）
            在 输出缓冲区 偏移 58 处写入 16 位值（e_shentsize = 64）

            写入 输出缓冲区 偏移 328（p_memsz，同上值）

        —— 块类型 1：解释器路径节（.interp） 解释器路径（InterpChunk）

        —— 块类型 4：GOT.PLT（GotPltChunk）

            令 PLT 条目索引 = 0
            循环（当 PLT 条目索引 小于 PLT 条目计数 时）：

            从 块虚拟地址数组 偏移 动态字符串块索引*8 处读取 64 位值，记为 动态字符串表虚拟地址（dv2）

            在 输出缓冲区 偏移 当前块文件偏移 + 16 处写入 64 位值（st_size = 0）

                在 输出缓冲区 偏移 符号条目偏移 + 8 处写入 64 位值（st_value = 0）

                在 输出缓冲区 偏移 重定位条目偏移 + 16 处写入 64 位值（r_addend = 0）

        令 块索引 = 块索引 + 1

2. PLT 条目数量为 0 时 GOT 仍有 3 个保留槽。
3. 动态链接信息节（.dynamic） 段以 动态段终止标签（DT_NULL）（tag=0）终止。
4. 所有 PLT 条目的 push 立即数为对应条目索引（0, 1, 2, ...）。
5. 动态字符串表以空字节起始，依次包含 "运行时库文件（core_rt.so）\0" 和各 PLT 名称。
6. 动态符号节（.dynsym） 符号 0 为全零的空条目，后续符号的 符号信息字段（st_info） 为 18（全局绑定常量（STB_GLOBAL） | 函数类型常量（STT_FUNC））。

## 函数 修补重定位（patch_relocs）

### 作用
遍历外部重定位列表，将用户代码中 call 指令的 32位相对偏移量（rel32） 占位符替换为指向对应 PLT 条目地址的实际相对偏移量。仅在 x86 外部重定位计数 大于 0 时执行。调用位置通过绝对位置减 176（ELF 头大小）转换为用户代码内偏移，边界检查确保偏移在用户代码范围内。PLT 表通过名称匹配查找对应条目。

### 逻辑
    如果 x86 外部重定位计数（g_x86_ext_rel_count） 等于 0，那么：返回
    令 用户代码块索引（uc） = 按种类查找通道（类型编号 = 2）
    从 块虚拟地址数组 偏移 用户代码块索引*8 处读取 64 位值，记为 用户代码虚拟地址（uv）
    从 块虚拟地址数组 偏移（按种类查找通道（类型编号 = 3）*8）处读取 64 位值，记为 PLT 块虚拟地址（pv）
    令 重定位索引（ri） = 0
    循环（当 重定位索引 小于 x86 外部重定位计数 时）：
        从 x86 外部重定位位置数组（g_x86_ext_rel_pos）偏移 重定位索引*8 处读取 64 位值，记为 绝对位置（abs_pos）
        令 代码偏移量（code_off） = 绝对位置 - 176
        如果 代码偏移量 小于 0 或 代码偏移量 大于等于 用户代码大小（g_user_size），那么：
            令 重定位索引 = 重定位索引 + 1
            继续下一次循环
        从 x86 外部重定位名称数组（g_x86_ext_rel_name）偏移 重定位索引*8 处读取 64 位值，记为 函数名称索引（fn_name_ni）
        令 函数名称（fn_name） = 空字符串
        如果 函数名称索引 大于等于 0，那么：令 函数名称 = 驻留字符串获取（函数名称索引）
        令 PLT 索引（plt_idx） = -1
        令 搜索索引（si） = 0
        循环（当 搜索索引 小于 PLT 条目计数（g_plt_count） 时）：
            从 PLT 条目数组 偏移 搜索索引*16 处读取 64 位值（名称指针）
            如果 字符串相等比较（上述名称指针, 函数名称） 不等于 0，那么：
                令 PLT 索引 = 搜索索引
                跳出循环
            令 搜索索引 = 搜索索引 + 1
        如果 PLT 索引 大于等于 0，那么：
            令 调用虚拟地址（call_va） = 用户代码虚拟地址 + 代码偏移量
            令 PLT 条目虚拟地址（plt_va2） = PLT 块虚拟地址 + 16 + PLT 索引 * 16
            令 相对偏移量（rel） = PLT 条目虚拟地址 - 调用虚拟地址 - 5
            调用 写 32 位有符号（用户代码指针（g_user_code）, 代码偏移量, 相对偏移量）
        令 重定位索引 = 重定位索引 + 1

### 测试要点
1. 无外部重定位时直接返回。
2. PLT 条目找到时正确写入 call 指令的 32位相对偏移量（rel32） 相对偏移量。
3. 代码偏移量超出用户代码范围时跳过该条目。
4. PLT 表中无匹配名称时跳过（调用位置保持占位符不变）。
5. 绝对位置减 176 后得到用户代码内偏移。

## 函数 初始化链接上下文（ctx_init）

### 作用
清零所有链接器状态：块计数、.so 计数、PLT 计数、各容量和缓冲区、代码段基址恢复为默认值 十六进制 400000 号地址。

### 逻辑
    令 块计数（g_ch_count） = 0
    令 .so 计数（g_so_count） = 0
    令 PLT 条目计数（g_plt_count） = 0
    令 .so 容量（g_so_cap） = 0
    令 PLT 容量（g_plt_cap） = 0
    令 代码段基址（g_text_base） = 4194304
    令 用户代码指针（g_user_code） = 空字符串
    令 用户代码大小（g_user_size） = 0

### 测试要点
1. 所有计数器和容量归零。
2. 代码段基址恢复为默认值 十六进制 400000 号地址。
3. 用户代码指针和大小清零。

## 函数 链接上下文：添加 .so（ctx_add_so）

### 作用
注册一个 .so 文件路径到全局 .so 路径数组中。

### 逻辑
    调用 扩展 .so 数组（所需容量 = .so 计数（g_so_count） + 1）
    写入 64 位值（目标数组 = .so 路径数组（g_so_paths），偏移量 = .so 计数 * 8，值 = 路径（path））
    令 .so 计数 = .so 计数 + 1

### 测试要点
1. 自动扩容保证写入成功。
2. .so 计数正确递增。

## 函数 链接上下文：添加 PLT 条目（ctx_add_plt）

### 作用
注册一个 PLT 条目，包含函数名称和所属 .so 文件索引。每条目占 16 字节（名称指针 8 字节 + .so 索引 8 字节）。

### 逻辑

    写入 64 位值（目标数组 = PLT 条目数组（g_plts），偏移量 = PLT 条目计数 * 16，值 = 名称（name））
    写入 64 位值（目标数组 = PLT 条目数组，偏移量 = PLT 条目计数 * 16 + 8，值 = .so 索引（so_idx））
    令 PLT 条目计数 = PLT 条目计数 + 1

### 测试要点
1. 条目存储后 PLT 计数正确递增。
2. 名称指针和 .so 索引写入正确的数组位置。

## 函数 链接上下文：发射动态链接（ctx_emit_dyn）

### 作用
生成完整的动态链接 ELF 可执行文件。创建全部 9 个块（类型 0 到 8），依次执行布局计算、修补重定位、发射指令，最后写入磁盘文件。

### 逻辑
    调用 新增通道（类型编号 = 0）—— ELF 头块
    调用 新增通道（类型编号 = 1）—— 解释器路径块
    调用 新增通道（类型编号 = 2）—— 用户代码块
    调用 新增通道（类型编号 = 3）—— PLT 块
    调用 新增通道（类型编号 = 4）—— GOT.PLT 块
    调用 新增通道（类型编号 = 5）—— 动态段块
    调用 新增通道（类型编号 = 6）—— 动态符号表块
    调用 新增通道（类型编号 = 7）—— 动态字符串表块
    调用 新增通道（类型编号 = 8）—— 重定位表块
    调用 布局（）
    调用 修补重定位（）
    从 块虚拟地址数组 偏移（块计数 - 1）*8 处读取 64 位值，加上从 块大小数组 偏移（块计数 - 1）*8 处读取的 64 位值，减去 代码段基址，记为 总大小（total）
    调用 输出行（整数转字符串（总大小））
    调用 发射指令（输出缓冲区（buf）, 总大小, 0）
    令 文件描述符（fd） = 系统调用 3（系统调用号 = 2, 路径（path）, 标志 = 577, 模式 = 420）
    如果 文件描述符 小于 0，那么：返回 -1
    令 已写入字节数（nw） = 系统调用 3（系统调用号 = 1, 文件描述符, 输出缓冲区, 总大小）
    系统调用 3（系统调用号 = 3, 文件描述符, 0, 0）
    返回 总大小

### 测试要点
1. 生成的文件为包含 解释器路径节（.interp） 和 动态链接信息节（.dynamic） 段的动态链接 ELF。
2. 所有 PLT 条目正确编码。
3. 写入失败时（文件描述符小于 0）返回 -1。
4. 总大小为最后一个块的虚拟地址 + 大小 - 代码段基址。

## 函数 链接上下文：发射 .so（ctx_emit_so）

### 作用
生成共享库 .so 文件（仅含 ELF 头块和用户代码块两个块）。设置 是否为共享库标记（is_so）=1 使得发射（emit）函数将 ELF 类型设为 共享对象文件类型（ET_DYN）（3）。仅包含单个可加载段（由 emit 函数处理）。

### 逻辑
    调用 新增通道（类型编号 = 0）—— ELF 头块
    调用 新增通道（类型编号 = 2）—— 用户代码块
    令 块计数（g_ch_count） = 2
    调用 布局（）
    从 块虚拟地址数组 偏移（块计数 - 1）*8 处读取 64 位值，加上从 块大小数组 偏移（块计数 - 1）*8 处读取的 64 位值，减去 代码段基址，记为 总大小（total）
    调用 发射指令（输出缓冲区（buf）, 总大小, 1）
    令 文件描述符（fd） = 系统调用 3（系统调用号 = 2, 路径（path）, 标志 = 577, 模式 = 420）
    如果 文件描述符 小于 0，那么：返回 -1
    令 已写入字节数（nw） = 系统调用 3（系统调用号 = 1, 文件描述符, 输出缓冲区, 总大小）
    系统调用 3（系统调用号 = 3, 文件描述符, 0, 0）
    返回 总大小

### 测试要点
1. 输出文件类型为 共享对象文件类型（ET_DYN）（3）。
2. 仅两个块（类型 0 和类型 2），无 PLT/GOT/动态链接信息节（.dynamic）。
3. 块计数显式设为 2（覆盖之前可能残留的值）。

## 函数 解析 .so 文本段（so_parse_text）

### 作用
在 .so 文件中查找可执行代码段——筛选条件：节类型为 程序数据节类型常量（SHT_PROGBITS）（1）、节标志为 分配标志常量（SHF_ALLOC）|可执行标志常量（SHF_EXECINSTR）（即 2|4 = 6）、节大小大于 0。找到后记录其文件偏移、大小和加载地址到全局变量中，供静态链接时拷贝。

### 逻辑
    如果 字符串长度（buf） 小于 64，那么：返回 -1
    从 缓冲区 偏移 40 处读取 64 位值，记为 ELF 节头偏移（e_shoff）
    从 缓冲区 偏移 60 处读取 16 位值，记为 ELF 节数量（e_shnum）
    令 节索引（i） = 0
    循环（当 节索引 小于 ELF 节数量 时）：
        从 缓冲区 偏移 ELF 节头偏移 + 节索引*64 + 4 处读取 32 位值，记为 节类型（t）
        从 缓冲区 偏移 ELF 节头偏移 + 节索引*64 + 8 处读取 64 位值，记为 节标志（fl）
        从 缓冲区 偏移 ELF 节头偏移 + 节索引*64 + 16 处读取 64 位值，记为 节地址（a）
        从 缓冲区 偏移 ELF 节头偏移 + 节索引*64 + 24 处读取 64 位值，记为 节偏移（o）
        从 缓冲区 偏移 ELF 节头偏移 + 节索引*64 + 32 处读取 64 位值，记为 节大小（s）
        如果 节类型 等于 1 且 节标志 等于 6 且 节大小 大于 0，那么：
            令 .so 文件偏移（g_so_off） = 节偏移
            令 .so 节大小（g_so_sz） = 节大小
            令 .so 节加载地址（g_so_addr） = 节地址
            返回 0
        令 节索引 = 节索引 + 1
    返回 -1

### 测试要点
1. 典型的 .so 文件应有至少一个 代码段 段被找到。
2. 非 ELF 文件（长度小于 64）返回 -1。
3. 存在 代码段 段但大小为零：不匹配，继续搜索。
4. 节标志必须恰好为 6（分配标志常量（SHF_ALLOC）=2 | 可执行标志常量（SHF_EXECINSTR）=4）。

## 函数 链接上下文：发射静态链接（ctx_emit_static）

### 作用
将所有已注册 .so 中第一个有效文件的代码段嵌入输出 ELF，解析用户代码中的外部符号引用，修补为直接相对调用。输出为单个可加载段（PT_LOAD）的静态 ELF，入口点指向用户代码的 入口点（_start）。

### 逻辑
    令 .so 文件缓冲区（so_buf） = 空字符串
    令 .so 遍历索引（si） = 0
    循环（当 .so 遍历索引 小于 .so 计数（g_so_count） 时）：
        从 .so 路径数组（g_so_paths）偏移 .so 遍历索引*8 处读取 64 位值，记为 .so 路径指针（sp）
        如果 字符串长度（.so 路径指针） 大于 0，那么：
            令 文件缓冲区（b） = 读取文件（.so 路径指针）
            如果 字符串长度（文件缓冲区） 大于 0 且 解析 .so 文本段（文件缓冲区） 等于 0，那么：
                令 .so 文件缓冲区 = 文件缓冲区
                跳出循环
        令 .so 遍历索引 = .so 遍历索引 + 1
    如果 字符串长度（.so 文件缓冲区） 等于 0，那么：返回 -1
    如果 .so 节大小（g_so_sz） 小于等于 0，那么：返回 -1

    —— 布局计算
    令 头部大小（hdr_sz） = 176
    令 .so 输出偏移（so_out） = 头部大小
    令 用户代码输出偏移（user_out） = .so 输出偏移 + .so 节大小
    令 总大小（total） = 用户代码输出偏移 + 用户代码大小（g_user_size）

    —— 清零输出缓冲区
    令 清零索引（zi） = 0
    循环（当 清零索引 小于 总大小 时）：
        在 输出缓冲区（buf） 偏移 清零索引 处写入单字节 0
        令 清零索引 = 清零索引 + 1

    —— 拷贝 .so 代码段
    令 拷贝索引 1（ci） = 0
    循环（当 拷贝索引 1 小于 .so 节大小 时）：
        读取 .so 文件缓冲区 偏移 .so 文件偏移（g_so_off） + 拷贝索引 1 处的单字节，写入 输出缓冲区 偏移 .so 输出偏移 + 拷贝索引 1 处
        令 拷贝索引 1 = 拷贝索引 1 + 1

    —— 拷贝用户代码
    令 拷贝索引 2（cj） = 0
    循环（当 拷贝索引 2 小于 用户代码大小 时）：
        读取 用户代码指针（g_user_code）偏移 拷贝索引 2 处的单字节，写入 输出缓冲区 偏移 用户代码输出偏移 + 拷贝索引 2 处
        令 拷贝索引 2 = 拷贝索引 2 + 1

    —— 修补外部重定位：用户代码中的 call 指令 → .so 函数
    令 重定位修补索引（rpi） = 0
    循环（当 重定位修补索引 小于 x86 外部重定位计数（g_x86_ext_rel_count） 时）：
        从 x86 外部重定位位置数组 偏移 重定位修补索引*8 处读取 64 位值，记为 绝对位置（abs_pos）
        从 x86 外部重定位名称数组 偏移 重定位修补索引*8 处读取 64 位值，记为 函数名称索引（fn_ni）
        令 函数名称（fn_name） = 驻留字符串获取（函数名称索引）
        如果 字符串长度（函数名称） 大于 0，那么：
            令 符号地址（sym_addr） = 查找 .so 符号（.so 文件缓冲区, 函数名称）
            如果 符号地址 大于等于 .so 节加载地址 且 符号地址 小于 .so 节加载地址 + .so 节大小，那么：
                令 函数在 .so 内的偏移（func_off） = 符号地址 - .so 节加载地址
                令 调用指令在输出缓冲区的位置（call_pos） = 用户代码输出偏移 + 绝对位置
                令 目标虚拟地址（target_va） = 十六进制 400000 号地址 + .so 输出偏移 + 函数在 .so 内的偏移
                令 相对偏移量（rel） = 目标虚拟地址 - （调用指令在输出缓冲区的位置 + 5）
                在 输出缓冲区 偏移 调用指令在输出缓冲区的位置 + 1 处写入 32 位值（相对偏移量，覆盖 call 指令的 32位相对偏移量（rel32） 操作数）
        令 重定位修补索引 = 重定位修补索引 + 1

    —— 写入 ELF 头（PT_LOAD）
    在 输出缓冲区 偏移 0 处写入单字节 127（0x7F）
    在 输出缓冲区 偏移 1 处写入单字节 69（'错误（E）'）
    在 输出缓冲区 偏移 2 处写入单字节 76（'L'）
    在 输出缓冲区 偏移 3 处写入单字节 70（'F'）
    在 输出缓冲区 偏移 4 处写入单字节 2（ELF 类别字段（EI_CLASS）：64 位）
    在 输出缓冲区 偏移 5 处写入单字节 1（ELF 数据编码字段（EI_DATA）：小端）
    在 输出缓冲区 偏移 6 处写入单字节 1（EI_VERSION）
    在 输出缓冲区 偏移 16 处写入 16 位值（文件类型字段（e_type） = 2，可执行文件类型常量（ET_EXEC））
    在 输出缓冲区 偏移 18 处写入 16 位值（e_machine = 62，x86-64）
    在 输出缓冲区 偏移 20 处写入 32 位值（e_version = 1）
    在 输出缓冲区 偏移 24 处写入 64 位值（e_entry = 十六进制 400000 号地址 + 用户代码输出偏移）
    在 输出缓冲区 偏移 32 处写入 64 位值（e_phoff = 64）
    在 输出缓冲区 偏移 40 处写入 64 位值（e_shoff = 0）
    在 输出缓冲区 偏移 52 处写入 16 位值（e_ehsize = 64）
    在 输出缓冲区 偏移 54 处写入 16 位值（e_phentsize = 56）
    在 输出缓冲区 偏移 56 处写入 16 位值（e_phnum = 1）
    在 输出缓冲区 偏移 58 处写入 16 位值（e_shentsize = 64）
    —— 单个可加载段（PT_LOAD） 程序头（偏移 64）
    在 输出缓冲区 偏移 64 处写入 32 位值（p_type = 1，PT_LOAD）
    在 输出缓冲区 偏移 68 处写入 32 位值（p_flags = 5，读+执行）
    在 输出缓冲区 偏移 72 处写入 64 位值（p_offset = 0）
    在 输出缓冲区 偏移 80 处写入 64 位值（p_vaddr = 十六进制 400000 号地址）
    在 输出缓冲区 偏移 88 处写入 64 位值（p_paddr = 十六进制 400000 号地址）
    在 输出缓冲区 偏移 96 处写入 64 位值（p_filesz = 总大小）
    在 输出缓冲区 偏移 104 处写入 64 位值（p_memsz = 总大小）
    在 输出缓冲区 偏移 112 处写入 64 位值（p_align = 4096）

    —— 写入文件
    令 文件描述符（fd） = 系统调用 3（系统调用号 = 2, 路径（path）, 标志 = 577, 模式 = 420）
    如果 文件描述符 小于 0，那么：返回 -1
    令 已写入字节数（nw） = 系统调用 3（系统调用号 = 1, 文件描述符, 输出缓冲区, 总大小）
    系统调用 3（系统调用号 = 3, 文件描述符, 0, 0）
    返回 总大小

### 测试要点
1. 无有效 .so 文件时返回 -1。
2. .so 节大小小于等于 0 时返回 -1。
3. 外部符号在 .so 中找到且在 代码段 范围内：call 指令的 32位相对偏移量（rel32） 正确修补。
4. 外部符号不在 .so 中或在 代码段 范围外：跳过，保持占位符。
5. 输出为单个可加载段覆盖全部内容（包含 .so 代码 + 用户代码）的静态 ELF。
6. 入口点指向用户代码中 入口点（_start） 的位置（十六进制 400000 号地址 + 头部大小 + .so 代码大小）。
