## 函数 发射单条指令（emit_instr）续

### 分支 外部调用指令（IR_CALL_EXTERN）（外部函数调用）
如果 操作码 等于 外部调用操作码常量（IR_CALL_EXTERN），那么：
    令 目标槽位（do2）= 全局变量槽位（g2_slot），传入 目标变量。
    令 函数名驻留索引（name_ni）= 源操作数 1。
    —— 记录外部重定位（供链接器/ld.cr 在 Phase 3 修补时使用）
    调用 扩展外部重定位数组（grow_ext_rel），传入 原 x86 外部重定位计数 + 1。
    向 x86 外部重定位位置数组（g_x86_ext_rel_pos）的偏移量（x86 外部重定位计数 * 8）处写入 64 位值（起始位置 + 当前指针）。
    向 x86 外部重定位名称数组（g_x86_ext_rel_name）的偏移量（x86 外部重定位计数 * 8）处写入 64 位值 函数名驻留索引。
    将 x86 外部重定位计数（g_x86_ext_rel_count）增加 1。
    —— 发射 call 占位符（操作码 0xE8 + rel32=0，5 字节，后续由链接器修补为实际偏移量）
    向缓冲区偏移量（起始位置+当前指针）处写入单字节值 232（操作码 0xE8，CALL rel32）。
    向缓冲区偏移量（起始位置+当前指针+1）处写入 32 位值 0（占位符）。
    将 当前指针 增加 5。
    —— 将返回值从 rax 存回目标槽位
    令 当前指针 = 当前指针 + 发射存储（e2_st）的返回值，参数为：缓冲区、起始位置+当前指针、0（rax）、目标槽位。
    返回 当前指针。
##### 测试要点
1. 固定 9 字节（call 5 + store 4）。
2. 外部重定位条目数量正确递增。
3. 若目标变量 < 0 则略过 存储（store）（call 5 字节 + 返回）。

### 分支 热补丁路由指令（IR_HOTPATCH_ROUTE）（热补丁路由）
如果 操作码 等于 热补丁路由操作码常量（IR_HOTPATCH_ROUTE），那么：
    令 目标槽位（do2）= 全局变量槽位（g2_slot），传入 目标变量。
    令 函数名驻留索引（name_ni）= 源操作数 1。
    —— 记录 调用修补位置（call_patch）（走调用修补路径而非外部重定位路径）
    调用 扩展调用修补数组（grow_call_patch），传入 原 x86 调用修补计数 + 1。
    向 x86 调用修补位置数组（g_x86_call_patch_pos）的偏移量（x86 调用修补计数 * 8）处写入 64 位值（起始位置 + 当前指针）。
    向 x86 调用修补名称数组（g_x86_call_patch_name）的偏移量（x86 调用修补计数 * 8）处写入 64 位值 函数名驻留索引。
    将 x86 调用修补计数 增加 1。
    —— 发射 call 占位符（5 字节）+ 存储（store）（4 字节）
    向缓冲区偏移量（起始位置+当前指针）处写入单字节值 232（0xE8）。
    向缓冲区偏移量（起始位置+当前指针+1）处写入 32 位值 0。
    将 当前指针 增加 5。
    令 当前指针 = 当前指针 + 发射存储（e2_st）的返回值，参数为：缓冲区、起始位置+当前指针、0、目标槽位。
    返回 当前指针。
##### 测试要点
1. 与 外部调用指令（IR_CALL_EXTERN） 编码相同（call 5 + store 4 = 9 字节），但走 调用修补位置（call_patch） 而非 外部重定位（ext_rel） 修补路径。
2. 调用修补位置（call_patch） 条目名称记录为驻留字符串索引。

### 分支 生成协程指令（IR_SPAWN）（协程启动）
如果 操作码 等于 协程启动操作码常量（IR_SPAWN），那么：
    令 目标槽位（do2）= 全局变量槽位（g2_slot），传入 目标变量。
    令 函数名驻留索引（name_ni）= 源操作数 1。
    —— 在当前单线程模式下，生成协程（spawn） 编码与普通函数调用相同：call + 存储（store） 返回值
    调用 扩展调用修补数组（grow_call_patch），传入 原 x86 调用修补计数 + 1。
    向 x86 调用修补位置数组的偏移量（x86 调用修补计数 * 8）处写入 64 位值（起始位置 + 当前指针）。
    向 x86 调用修补名称数组的偏移量（x86 调用修补计数 * 8）处写入 64 位值 函数名驻留索引。
    将 x86 调用修补计数 增加 1。
    向缓冲区偏移量（起始位置+当前指针）处写入单字节值 232（0xE8）。
    向缓冲区偏移量（起始位置+当前指针+1）处写入 32 位值 0。
    将 当前指针 增加 5。
    令 当前指针 = 当前指针 + 发射存储（e2_st）的返回值，参数为：缓冲区、起始位置+当前指针、0、目标槽位。
    返回 当前指针。
##### 测试要点
1. 当前为单线程模式，编码与普通调用相同（9 字节）。

### 分支 函数地址指令（IR_FNADDR）（获取函数地址）
如果 操作码 等于 函数地址操作码常量（IR_FNADDR），那么：
    令 目标槽位（do2）= 全局变量槽位（g2_slot），传入 目标变量。
    令 函数名驻留索引（name_ni）= 源操作数 1。
    —— 记录 函数地址修补位置（fnaddr_patch）（供 Phase 3 用函数的绝对虚拟地址 TEXT_BASE + 缓冲区位置 修补）
    调用 扩展函数地址修补数组（grow_fnaddr_patch），传入 原 x86 函数地址修补计数 + 1。
    向 x86 函数地址修补位置数组（g_x86_fnaddr_patch_pos）的偏移量（x86 函数地址修补计数 * 8）处写入 64 位值（起始位置 + 当前指针）。
    向 x86 函数地址修补名称数组（g_x86_fnaddr_patch_name）的偏移量（x86 函数地址修补计数 * 8）处写入 64 位值 函数名驻留索引。
    将 x86 函数地址修补计数 增加 1。
    —— 发射 movabs r10, imm64 指令
    —— REX.W+B = 0x49（B 位置位因为 r10>=8），操作码 0xBA（0xB8 + 寄存器编码 2 表示 r10）
    向缓冲区偏移量（起始位置+当前指针）处写入单字节值 73（REX.W+B=0x49）。
    向缓冲区偏移量（起始位置+当前指针+1）处写入单字节值 186（MOV r64, imm64 的操作码，目标寄存器=r10）。
    向缓冲区偏移量（起始位置+当前指针+2）处写入 64 位值 0（占位符，待 Phase 3 修补为函数的绝对虚拟地址）。
    将 当前指针 增加 10（REX 1 + opcode 1 + imm64 8）。
    —— 将函数地址从 r10 存入目标槽位
    令 当前指针 = 当前指针 + 发射存储（e2_st）的返回值，参数为：缓冲区、起始位置+当前指针、10、目标槽位。
    返回 当前指针。
##### 测试要点
1. 固定 14 字节（movabs 10 + store 4）。
2. movabs 的 8 字节立即数在 Phase 3 才修补为实际绝对地址。

### 分支 返回指令（IR_RETURN）（返回）
如果 操作码 等于 返回操作码常量（IR_RETURN），那么：
    如果 源操作数 1 大于等于 0（有返回值），那么：
        如果从 x86 变量是否全局标记数组（g_x86_is_global）的偏移量（源操作数 1 * 8）处读取的 64 位值不等于 0，那么：
            —— 返回值是全局变量：通过 RIP 相对寻址加载到 rax
            调用 扩展 RIP 修补数组（grow_rip_patch），传入 原 x86 RIP 修补计数 + 1。
            向 x86 RIP 修补位置数组的偏移量（x86 RIP 修补计数 * 8）处写入 64 位值（起始位置 + 当前指针 + 3）。
            向 x86 RIP 全局变量修补数组的偏移量（x86 RIP 修补计数 * 8）处写入 64 位值 源操作数 1。
            将 x86 RIP 修补计数 增加 1。
            令 当前指针 = 当前指针 + 发射加载寄存器（e2_lr）的返回值，参数为：缓冲区、起始位置+当前指针、0（占位符）。此指令编码为 lea r10, [rip+0]。
            —— mov rax, [r10]（从 r10 指向的全局变量内存处加载到 rax）
            令 当前指针 = 当前指针 + 发射 REX 前缀（emit_rex）的返回值，参数为：缓冲区、起始位置+当前指针、W=1、R=0（rax）、X=0、B=10/8（r10 的 B 位）。
            向缓冲区偏移量（起始位置+当前指针）处写入单字节值 139（操作码 0x8B，MOV r, r/m）。
            将 当前指针 增加 1。
            令 当前指针 = 当前指针 + 发射 ModRM（emit_modrm）的返回值，参数为：缓冲区、起始位置+当前指针、寻址模式=0（[r10] 无位移量）、寄存器字段=0（rax%8）、寄存器或内存字段=10%8（r10 的低 3 位）。
        否则执行以下操作：
            —— 返回值是局部变量：直接从栈帧槽位加载到 rax
            令 当前指针 = 当前指针 + 发射加载双字（e2_ld）的返回值，参数为：缓冲区、起始位置+当前指针、0（rax）、全局变量槽位（g2_slot），传入 源操作数 1。
    —— 记录 返回修补位置（ret_patch）（供调用者在 Phase 3 修补 jmp 跳转到函数尾声）
    调用 扩展返回修补数组（grow_ret_patch），传入 原 x86 RET 修补计数 + 1。
    向 x86 RET 修补位置数组（g_x86_ret_patch_pos）的偏移量（x86 RET 修补计数 * 8）处写入 64 位值（起始位置 + 当前指针）。
    将 x86 RET 修补计数 增加 1。
    —— 发射 jmp 到尾声的占位符跳转（待 Phase 3 修补为相对偏移量）
    令 当前指针 = 当前指针 + 发射 JMP 指令（e2_jmp）的返回值，参数为：缓冲区、起始位置+当前指针、0（占位符）。
    返回 当前指针。
##### 测试要点
1. 无返回值（s1 < 0）：仅 jmp 占位符（5 字节）+ 返回修补位置（ret_patch） 记录。
2. 局部变量返回：mov rax,[rbp+偏移量（off）]（4/7 字节） + jmp（5 字节）。
3. 全局变量返回：lea r10,[rip+0]（7 字节） + mov rax,[r10]（3 字节） + jmp（5 字节）= 15 字节。
4. 每个 返回（return） 产生一个 返回修补位置（ret_patch） 条目。

### 分支 分配指令（IR_ALLOC）（堆分配）
如果 操作码 等于 堆分配操作码常量（IR_ALLOC），则返回 0。（堆分配调用由 alloc_patch 在 Phase 3 统一处理，此处不发射任何指令。）
##### 测试要点
1. 始终返回 0。

### 分支 分配结构指令（IR_ALLOC_STRUCT）（结构体分配）
如果 操作码 等于 结构体分配操作码常量（IR_ALLOC_STRUCT），那么：
    令 目标槽位（do2）= 全局变量槽位（g2_slot），传入 目标变量。
    令 结构体名驻留索引（name_ni）= 源操作数 3。
    如果 结构体名驻留索引 大于等于 0，那么：
        —— 在 结构数组（g_structs） 全局结构体注册表中查找该结构体
        令 结构体索引（si）= -1。
        令 查找索引（sfi）= 0。
        进入循环，每次迭代执行以下操作：
            如果 查找索引 大于等于 结构体计数（g_struct_count），那么：跳出循环。
            如果 结构体信息访问器：名称（si_name），传入 查找索引，的结果 等于 结构体名驻留索引，那么：
                令 结构体索引 = 查找索引。
                跳出循环。
            将 查找索引 增加 1。
        循环结束。
        如果 结构体索引 大于等于 0，那么：
            令 字段计数（fc）= 结构体信息访问器：字段计数（si_field_count），传入 结构体索引。
            如果 字段计数 大于 0，那么：
                —— 发射 mov edi, （字段计数 * 8） 指令（分配大小 = 字段计数 * 8 字节）
                向缓冲区偏移量（起始位置+当前指针）处写入单字节值 191（操作码 0xBF，MOV r32, imm32，reg=7 表示 edi）。
                向缓冲区偏移量（起始位置+当前指针+1）处写入 32 位值（字段计数 * 8）。
                将 当前指针 增加 5。
                —— 记录 分配修补位置（alloc_patch）
                调用 扩展分配修补数组（grow_alloc_patch），传入 原 x86 分配修补计数 + 1。
                向 x86 分配修补位置数组的偏移量（x86 分配修补计数 * 8）处写入 64 位值（起始位置 + 当前指针）。
                将 x86 分配修补计数 增加 1。
                —— 发射 call 分配函数（alloc） 占位符
                向缓冲区偏移量（起始位置+当前指针）处写入单字节值 232（0xE8）。
                向缓冲区偏移量（起始位置+当前指针+1）处写入 32 位值 0。
                将 当前指针 增加 5。
                —— 将分配结果（rax）存入目标槽位
                令 当前指针 = 当前指针 + 发射存储（e2_st）的返回值，参数为：缓冲区、起始位置+当前指针、0、目标槽位。
    返回 当前指针。
##### 测试要点
1. 字段计数为 0：不发射任何代码，返回 0。
2. 字段计数 > 0：mov edi, 大小（size）（5 字节）+ call 分配函数（alloc）（5 字节）+ 存储（store） rax（4 字节）= 14 字节。
3. 结构体名不在 结构数组（g_structs） 中：不发射代码。

### 分支 分配数组指令（IR_ALLOC_ARRAY）（数组分配）
如果 操作码 等于 数组分配操作码常量（IR_ALLOC_ARRAY），那么：
    令 目标槽位（do2）= 全局变量槽位（g2_slot），传入 目标变量。
    令 分配大小（sz）= 源操作数 1 * 8（数组元素个数 * 每个元素 8 字节）。
    如果 分配大小 大于 0，那么：
        向缓冲区偏移量（起始位置+当前指针）处写入单字节值 191（0xBF，mov edi, imm32）。
        向缓冲区偏移量（起始位置+当前指针+1）处写入 32 位值 分配大小。
        将 当前指针 增加 5。
        调用 扩展分配修补数组（grow_alloc_patch），传入 原 x86 分配修补计数 + 1。
        向 x86 分配修补位置数组的偏移量（x86 分配修补计数 * 8）处写入 64 位值（起始位置 + 当前指针）。
        将 x86 分配修补计数 增加 1。
        向缓冲区偏移量（起始位置+当前指针）处写入单字节值 232（0xE8）。
        向缓冲区偏移量（起始位置+当前指针+1）处写入 32 位值 0。
        将 当前指针 增加 5。
        令 当前指针 = 当前指针 + 发射存储（e2_st）的返回值，参数为：缓冲区、起始位置+当前指针、0、目标槽位。
    返回 当前指针。
##### 测试要点
1. 分配大小为 0：不发射代码，返回 0。
2. 与 分配结构指令（ALLOC_STRUCT） 编码结构相同。

### 分支 竞技场新建指令（IR_ARENA_NEW）（新建竞技场）
如果 操作码 等于 新建竞技场操作码常量（IR_ARENA_NEW），那么：
    令 目标槽位（do2）= 全局变量槽位（g2_slot），传入 目标变量。
    如果 源操作数 1 大于 0，那么：
        —— 该作用域确实有分配发生：通过 竞技场新建（arena_new）（） 调用创建新的竞技场
        令 竞技场新建驻留索引（ni_arena_new）= 字符串驻留（str_intern），传入 "竞技场新建（arena_new）"。
        调用 扩展调用修补数组（grow_call_patch），传入 原 x86 调用修补计数 + 1。
        向 x86 调用修补位置数组的偏移量（x86 调用修补计数 * 8）处写入 64 位值（起始位置 + 当前指针）。
        向 x86 调用修补名称数组的偏移量（x86 调用修补计数 * 8）处写入 64 位值 竞技场新建驻留索引。
        将 x86 调用修补计数 增加 1。
        向缓冲区偏移量（起始位置+当前指针）处写入单字节值 232（0xE8）。
        向缓冲区偏移量（起始位置+当前指针+1）处写入 32 位值 0。
        将 当前指针 增加 5。
        —— 将 竞技场新建（arena_new） 的返回值（rax 中的竞技场标识符）存入目标槽位
        令 当前指针 = 当前指针 + 发射存储（e2_st）的返回值，参数为：缓冲区、起始位置+当前指针、0、目标槽位。
    否则执行以下操作：
        —— 该作用域无分配：不创建竞技场，目标 = -1（表示无竞技场）
        —— 这样避免了从竞技场基础设施自身（arena_new/arena_reset/_grow_arena_meta）中调用 竞技场新建（arena_new），
        —— 从而防止递归。竞技场重置指令（IR_ARENA_RESET） 对 索引（id） < 0 的情况安全地跳过调用。
        向缓冲区偏移量（起始位置+当前指针）处写入单字节值 72（REX.W 前缀 0x48）。
        向缓冲区偏移量（起始位置+当前指针+1）处写入单字节值 199（操作码 0xC7，MOV r/m, imm32）。
        向缓冲区偏移量（起始位置+当前指针+2）处写入单字节值 192（ModRM 字节：3*64 + 0*8 + 0 = 192，/0 扩展码=MOV，rm=0=rax）。
        向缓冲区偏移量（起始位置+当前指针+3）处写入 32 位值 -1（有符号立即数 -1）。
        将 当前指针 增加 7。
        令 当前指针 = 当前指针 + 发射存储（e2_st）的返回值，参数为：缓冲区、起始位置+当前指针、0、目标槽位。
    返回 当前指针。
##### 测试要点
1. 源1（s1） > 0：call 竞技场新建（arena_new）（5 字节） + 存储（store） rax（4 字节）= 9 字节。
2. 源1（s1） <= 0：mov rax, -1（7 字节） + 存储（store） rax（4 字节）= 11 字节，避免竞技场基础设施递归。

### 分支 竞技场重置指令（IR_ARENA_RESET）（重置竞技场）
如果 操作码 等于 重置竞技场操作码常量（IR_ARENA_RESET），那么：
    —— 第一步：加载竞技场标识符到 edi（寄存器 7 = rdi 作为第一参数）
    令 当前指针 = 当前指针 + 发射加载变量（e2_load_var）的返回值，参数为：缓冲区、起始位置+当前指针、7（rdi）、源操作数 1。
    —— 第二步：空竞技场检查 —— test rdi, rdi，若是负值（无竞技场）则跳过 call
    —— 这样做是为了防止 竞技场重置（arena_reset） 自身对 -1 的调用引发无限递归
    向缓冲区偏移量（起始位置+当前指针）处写入单字节值 72（REX.W 前缀 0x48）。
    向缓冲区偏移量（起始位置+当前指针+1）处写入单字节值 133（操作码 0x85，TEST r/m, r）。
    向缓冲区偏移量（起始位置+当前指针+2）处写入单字节值 255（ModRM 字节：3*64 + 7*8 + 7 = 255，TEST rdi, rdi）。
    将 当前指针 增加 3。
    —— jl +5（若 rdi < 0 即有符号小于零，跳过紧随其后 5 字节的 call 指令）
    向缓冲区偏移量（起始位置+当前指针）处写入单字节值 124（操作码 0x7C，JL rel8）。
    向缓冲区偏移量（起始位置+当前指针+1）处写入单字节值 5（rel8 偏移量，跳过 5 字节）。
    将 当前指针 增加 2。
    —— 第三步：调用 竞技场重置（arena_reset）（edi 中已存放竞技场标识符）
    令 竞技场重置驻留索引（ni_arena_reset）= 字符串驻留（str_intern），传入 "竞技场重置（arena_reset）"。
    调用 扩展调用修补数组（grow_call_patch），传入 原 x86 调用修补计数 + 1。
    向 x86 调用修补位置数组的偏移量（x86 调用修补计数 * 8）处写入 64 位值（起始位置 + 当前指针）。
    向 x86 调用修补名称数组的偏移量（x86 调用修补计数 * 8）处写入 64 位值 竞技场重置驻留索引。
    将 x86 调用修补计数 增加 1。
    向缓冲区偏移量（起始位置+当前指针）处写入单字节值 232（0xE8）。
    向缓冲区偏移量（起始位置+当前指针+1）处写入 32 位值 0。
    将 当前指针 增加 5。
    返回 当前指针。
##### 测试要点
1. 竞技场索引（arena_id） < 0：跳过 call（仅 load_var 4 字节 + test 3 字节 + jl 2 字节 = 9 字节）。
2. 竞技场索引（arena_id） >= 0：执行额外 call 竞技场重置（arena_reset）（5 字节），总约 14 字节。

### 分支 加载指令（IR_LOAD）（加载）
如果 操作码 等于 加载操作码常量（IR_LOAD）且 目标变量 大于等于 0，那么：
    令 目标槽位（do2）= 全局变量槽位（g2_slot），传入 目标变量。
    如果 源操作数 1 大于等于 0，那么：
        令 是否全局变量（isg）= 从 x86 变量是否全局标记数组（g_x86_is_global）的偏移量（源操作数 1 * 8）处读取的 64 位值，可修改。
        如果 是否全局变量 不等于 0，那么：
            —— 加载全局变量：RIP 相对寻址
            调用 扩展 RIP 修补数组（grow_rip_patch），传入 原 x86 RIP 修补计数 + 1。
            向 x86 RIP 修补位置数组的偏移量（x86 RIP 修补计数 * 8）处写入 64 位值（起始位置 + 当前指针 + 3）。
            向 x86 RIP 全局变量修补数组的偏移量（x86 RIP 修补计数 * 8）处写入 64 位值 源操作数 1。
            将 x86 RIP 修补计数 增加 1。
            令 当前指针 = 当前指针 + 发射加载寄存器（e2_lr）的返回值，参数为：缓冲区、起始位置+当前指针、0（占位符，lea r10, [rip+0]）。
            —— mov r10, [r10]（解引用全局变量指针）
            令 当前指针 = 当前指针 + 发射 REX 前缀（emit_rex）的返回值，参数为：缓冲区、起始位置+当前指针、W=1、R=10/8、X=0、B=10/8。
            向缓冲区偏移量（起始位置+当前指针）处写入单字节值 139（0x8B）。
            将 当前指针 增加 1。
            令 当前指针 = 当前指针 + 发射 ModRM（emit_modrm）的返回值，参数为：缓冲区、起始位置+当前指针、寻址模式=0、寄存器字段=10%8、寄存器或内存字段=10%8。
            —— 存储到目标槽位
            令 当前指针 = 当前指针 + 发射存储（e2_st）的返回值，参数为：缓冲区、起始位置+当前指针、10、目标槽位。
        否则执行以下操作：
            —— 加载局部变量
            令 当前指针 = 当前指针 + 发射加载变量（e2_load_var）的返回值，参数为：缓冲区、起始位置+当前指针、10、源操作数 1。
            令 当前指针 = 当前指针 + 发射存储（e2_st）的返回值，参数为：缓冲区、起始位置+当前指针、10、目标槽位。
    否则执行以下操作（源操作数 1 < 0，变量索引为负，如常量或临时变量）：
        令 当前指针 = 当前指针 + 发射加载变量（e2_load_var）的返回值，参数为：缓冲区、起始位置+当前指针、10、源操作数 1。
        令 当前指针 = 当前指针 + 发射存储（e2_st）的返回值，参数为：缓冲区、起始位置+当前指针、10、目标槽位。
    返回 当前指针。
##### 测试要点
1. 局部变量：加载变量（load_var） + 存储（store） 约 8 字节。
2. 全局变量：lea + mov r10,[r10] + 存储（store） 约 14 字节。
3. 变量索引为负（s1 < 0）：与局部变量路径相同。

### 分支 存储指令（IR_STORE）（存储）
如果 操作码 等于 存储操作码常量（IR_STORE），那么：
    令 源偏移量（o1）= 全局变量槽位（g2_slot），传入 源操作数 1（目标地址的变量槽位）。
    如果 源操作数 1 大于等于 0，那么：
        如果从 x86 变量是否全局标记数组的偏移量（源操作数 1 * 8）处读取的 64 位值不等于 0，那么：
            —— 目标是全局变量：通过 RIP 相对寻址找到目标地址，然后将源操作数 2 的值写入
            令 当前指针 = 当前指针 + 发射加载变量（e2_load_var）的返回值，参数为：缓冲区、起始位置+当前指针、10、源操作数 2。（加载值到 r10。）
            调用 扩展 RIP 修补数组（grow_rip_patch），传入 原 x86 RIP 修补计数 + 1。
            向 x86 RIP 修补位置数组的偏移量（x86 RIP 修补计数 * 8）处写入 64 位值（起始位置 + 当前指针 + 3）。
            向 x86 RIP 全局变量修补数组的偏移量（x86 RIP 修补计数 * 8）处写入 64 位值 源操作数 1。
            将 x86 RIP 修补计数 增加 1。
            令 当前指针 = 当前指针 + 发射加载寄存器字节（e2_lrb）的返回值，参数为：缓冲区、起始位置+当前指针、0（占位符，lea r11, [rip+0]）。
            —— mov [r11], r10（将值写入全局变量地址）
            令 当前指针 = 当前指针 + 发射 REX 前缀（emit_rex）的返回值，参数为：缓冲区、起始位置+当前指针、W=1、R=10/8、X=0、B=11/8。
            向缓冲区偏移量（起始位置+当前指针）处写入单字节值 137（0x89，MOV r/m, r）。
            将 当前指针 增加 1。
            令 当前指针 = 当前指针 + 发射 ModRM（emit_modrm）的返回值，参数为：缓冲区、起始位置+当前指针、寻址模式=0、寄存器字段=10%8、寄存器或内存字段=11%8。
        否则执行以下操作：
            —— 目标是局部变量
            令 当前指针 = 当前指针 + 发射加载变量（e2_load_var）的返回值，参数为：缓冲区、起始位置+当前指针、10、源操作数 2。
            令 当前指针 = 当前指针 + 发射存储（e2_st）的返回值，参数为：缓冲区、起始位置+当前指针、10、源偏移量。
    否则执行以下操作（源操作数 1 < 0）：
        令 当前指针 = 当前指针 + 发射加载变量（e2_load_var）的返回值，参数为：缓冲区、起始位置+当前指针、10、源操作数 2。
        令 当前指针 = 当前指针 + 发射存储（e2_st）的返回值，参数为：缓冲区、起始位置+当前指针、10、源偏移量。
    返回 当前指针。
##### 测试要点
1. 局部变量目标：加载变量（load_var）（4） + 存储（store）（4） = 8 字节。
2. 全局变量目标：加载变量（load_var）（4） + lea r11,[rip+0]（7） + mov [r11],r10（3） = 14 字节。

### 分支 加载字段指令（IR_LOAD_FIELD）（加载结构体字段）
如果 操作码 等于 加载结构体字段操作码常量（IR_LOAD_FIELD）且 目标变量 大于等于 0，那么：
    令 结构体变量槽位（o1）= 全局变量槽位（g2_slot），传入 源操作数 1。
    令 目标槽位（do2）= 全局变量槽位（g2_slot），传入 目标变量。
    令 字段偏移字节数（fo）= 源操作数 3（字段索引）* 8，可修改。
    —— 第一步：mov r10, [rbp+结构体变量槽位]（加载结构体指针到 r10）
    令 当前指针 = 当前指针 + 发射加载双字（e2_ld）的返回值，参数为：缓冲区、起始位置+当前指针、10、结构体变量槽位。
    —— 第二步：mov r10, [r10 + 字段偏移字节数]（从结构体中加载指定字段的值）
    令 当前指针 = 当前指针 + 发射 REX 前缀（emit_rex）的返回值，参数为：缓冲区、起始位置+当前指针、W=1、R=10/8、X=0、B=10/8。
    向缓冲区偏移量（起始位置+当前指针）处写入单字节值 139（0x8B）。
    将 当前指针 增加 1。
    令 当前指针 = 当前指针 + 发射 ModRM（emit_modrm）的返回值，参数为：缓冲区、起始位置+当前指针、寻址模式=2（disp32）、寄存器字段=10%8、寄存器或内存字段=10%8。
    令 当前指针 = 当前指针 + 发射写 32 位（e2_w32）的返回值，参数为：缓冲区、起始位置+当前指针、字段偏移字节数（disp32 位移量）。
    —— 第三步：存储（store） r10 到目标槽位
    令 当前指针 = 当前指针 + 发射存储（e2_st）的返回值，参数为：缓冲区、起始位置+当前指针、10、目标槽位。
    返回 当前指针。
##### 测试要点
1. 第 0 字段：字段偏移字节数 = 0，mov r10, [r10+0]。
2. 第 3 字段：字段偏移字节数 = 24，mov r10, [r10+24]。
3. 约 14 字节（ld 4-7 + mov [r10+disp32] 7 + st 4）。

### 分支 存储字段指令（IR_STORE_FIELD）（存储到结构体字段）
如果 操作码 等于 存储结构体字段操作码常量（IR_STORE_FIELD），那么：
    令 结构体变量槽位（o1）= 全局变量槽位（g2_slot），传入 源操作数 1。
    令 源值变量槽位（o2）= 全局变量槽位（g2_slot），传入 源操作数 2。
    令 字段偏移字节数（fo）= 源操作数 3 * 8，可修改。
    —— 第一步：mov r10, [rbp+结构体变量槽位]（加载结构体指针）
    令 当前指针 = 当前指针 + 发射加载双字（e2_ld）的返回值，参数为：缓冲区、起始位置+当前指针、10、结构体变量槽位。
    —— 第二步：mov r11, [rbp+源值变量槽位]（加载要存储的值）
    令 当前指针 = 当前指针 + 发射加载双字（e2_ld）的返回值，参数为：缓冲区、起始位置+当前指针、11、源值变量槽位。
    —— 第三步：mov [r10 + 字段偏移字节数], r11（将值存入结构体的指定字段）
    令 当前指针 = 当前指针 + 发射 REX 前缀（emit_rex）的返回值，参数为：缓冲区、起始位置+当前指针、W=1、R=11/8（源寄存器 r11 高位）、X=0、B=10/8（基址寄存器 r10 高位）。
    向缓冲区偏移量（起始位置+当前指针）处写入单字节值 137（0x89）。
    将 当前指针 增加 1。

### 分支 解引用指令（IR_DEREF）（解引用）
如果 操作码 等于 解引用操作码常量（IR_DEREF）且 目标变量 大于等于 0，那么：
    令 目标槽位（do2）= 全局变量槽位（g2_slot），传入 目标变量。
    —— 源操作数 3 编码了来源验证（ProvenanceVerify）产生的边界信息：
    —— 若 源3（s3） == 0：无需检查（来源已知，可直接安全解引用）
    —— 若 源3（s3） != 0：需要进行边界检查（值编码了 alloc_size）
    
    —— 第一步：加载指针到 r10（处理局部和全局两种来源）
    令 当前指针 = 当前指针 + 发射加载变量（e2_load_var）的返回值，参数为：缓冲区、起始位置+当前指针、10、源操作数 1。
    
    —— 第二步：可选的边界检查序列（仅当 s3 != 0 时执行）
    如果 源操作数 3 不等于 0，那么：
        令 分配大小（alloc_sz）= 源操作数 3（来源验证中编码的分配字节数）。
        —— 第 甲（a）步：复制指针到 r11 用于偏移量计算：mov r11, r10
        令 当前指针 = 当前指针 + 发射 REX 前缀（emit_rex）的返回值，参数为：缓冲区、起始位置+当前指针、W=1、R=11/8、X=0、B=10/8。
        向缓冲区偏移量（起始位置+当前指针）处写入单字节值 137（0x89，MOV r/m, r）。
        将 当前指针 增加 1。
        令 当前指针 = 当前指针 + 发射 ModRM（emit_modrm）的返回值，参数为：缓冲区、起始位置+当前指针、寻址模式=3、寄存器字段=10%8、寄存器或内存字段=11%8。
        —— 第 乙（b）步：and r11, 0xFFF（提取页面内偏移量，即指针的低 12 位）
        令 当前指针 = 当前指针 + 发射 REX 前缀（emit_rex）的返回值，参数为：缓冲区、起始位置+当前指针、W=1、R=0、X=0、B=11/8。
        向缓冲区偏移量（起始位置+当前指针）处写入单字节值 129（操作码 0x81，AND r/m, imm32，/4 扩展码）。
        将 当前指针 增加 1。
        令 当前指针 = 当前指针 + 发射 ModRM（emit_modrm）的返回值，参数为：缓冲区、起始位置+当前指针、寻址模式=3、寄存器字段=4（/4 扩展码=AND）、寄存器或内存字段=11%8。
        向缓冲区偏移量（起始位置+当前指针）处写入 32 位值 4095（0xFFF 掩码）。
        将 当前指针 增加 4。
        —— 第 丙（c）步：cmp r11, 分配大小（比较页面内偏移量与分配大小）
        令 当前指针 = 当前指针 + 发射 REX 前缀（emit_rex）的返回值，参数为：缓冲区、起始位置+当前指针、W=1、R=0、X=0、B=11/8。
        向缓冲区偏移量（起始位置+当前指针）处写入单字节值 129（操作码 0x81，CMP r/m, imm32，/7 扩展码）。
        将 当前指针 增加 1。
        令 当前指针 = 当前指针 + 发射 ModRM（emit_modrm）的返回值，参数为：缓冲区、起始位置+当前指针、寻址模式=3、寄存器字段=7（/7 扩展码=CMP）、寄存器或内存字段=11%8。
        向缓冲区偏移量（起始位置+当前指针）处写入 32 位值 分配大小。
        将 当前指针 增加 4。
        —— 第 丁（d）步：jae 崩溃标签（.crash）（若页面内偏移量 >= 分配大小，则跳转到崩溃处理，双字节近跳转 0x0F 0x83）
        令 崩溃跳转位置（crash_jmp_pos）= 起始位置 + 当前指针。（记录 jae 的位置供后续修补。）
        令 当前指针 = 当前指针 + 发射 JAE 指令（e2_jae）的返回值，参数为：缓冲区、起始位置+当前指针、0（占位符，后面立即修补）。
        —— 第 戊（e）步：空指针检查 —— test r10, r10（操作码 0x85）
        令 当前指针 = 当前指针 + 发射 REX 前缀（emit_rex）的返回值，参数为：缓冲区、起始位置+当前指针、W=1、R=10/8、X=0、B=10/8。
        向缓冲区偏移量（起始位置+当前指针）处写入单字节值 133（操作码 0x85，TEST r/m, r）。
        将 当前指针 增加 1。
        令 当前指针 = 当前指针 + 发射 ModRM（emit_modrm）的返回值，参数为：缓冲区、起始位置+当前指针、寻址模式=3、寄存器字段=10%8、寄存器或内存字段=10%8。
        —— 第 己（f）步：jne 安全标签（.safe）（若 r10 不为零，即非空指针，则安全，跳过 ud2 崩溃指令）
        令 安全跳转位置（safe_jmp_pos）= 起始位置 + 当前指针。（记录 jne 的位置供后续修补。）
        向缓冲区偏移量（起始位置+当前指针）处写入单字节值 117（操作码 0x75，JNE rel8）。
        向缓冲区偏移量（起始位置+当前指针+1）处写入单字节值 0（占位符偏移量，后面立即修补）。
        将 当前指针 增加 2。
        —— 第 庚（g）步：崩溃标签（.crash） 标签 —— 发射 ud2（未定义指令，触发 非法指令信号（SIGILL） 信号）
        写 8 位（w8），向缓冲区偏移量（当前指针）处写入单字节值 15（ud2 第一字节 0x0F）。
        写 8 位（w8），向缓冲区偏移量（当前指针+1）处写入单字节值 11（ud2 第二字节 0x0B）。
        将 当前指针 增加 2。
        —— 修补 jae 偏移量：使 jae 指令跳转到此处（崩溃标签（.crash） 标签即 ud2 指令）
        向缓冲区偏移量（崩溃跳转位置 + 2）处写入 32 位值（起始位置 + 当前指针）-（崩溃跳转位置 + 6）。（crash_jmp_pos+2 是 jae 指令的 rel32 字段位置，crash_jmp_pos+6 是 jae 指令后的下一条指令位置。）
        —— 修补 jne 偏移量：使 jne 指令跳过 ud2 到达 安全标签（.safe） 标签
        写 8 位（w8），向缓冲区偏移量（安全跳转位置 + 1）处写入单字节值（起始位置 + 当前指针）-（安全跳转位置 + 2）+ 2。（安全跳转位置（safe_jmp_pos）+1 是 jne 指令的 rel8 偏移量字段位置。注意：当前指针已指向 ud2 之后的位置。+2 是因为 ud2 本身占 2 字节，所以 safe 标签位于当前指针位置 + 2。）
        
        —— 注意：源代码中的 写单字节（w8） 修补逻辑为：
        —— 写单字节（w8）（缓冲区（buf）, 安全跳转位置（safe_jmp_pos） + 1, （位置（pos）+cp） - （安全跳转位置（safe_jmp_pos） + 2） + 2）；
        —— 解读：安全跳转位置（safe_jmp_pos）+1 是 jne 的 rel8 字节位置；位置（pos）+当前指针（cp） 此时指向 ud2 的末尾（即 safe 标签处）。由于 jne 跳转的目标是 安全标签（safe） 而非 崩溃标签（crash），而 位置+当前指针 已经指向 崩溃标签 标签的末尾处（即 ud2 之后），而 安全标签 标签是从 崩溃标签 标签继续向后的，所以计算结果为 （位置+cp） - （安全跳转位置（safe_jmp_pos）+2） + 2。实际上 位置+当前指针 在 ud2 之后，而 安全标签 标签就在 崩溃标签 标签之后（两个标签重叠于 ud2 之后的位置），因此实际偏移量为正数 2 字节（跳过 ud2 的 2 字节）。
    
    —— 第三步：安全解引用 —— mov r10, [r10]（从指针地址加载 64 位值）
    令 当前指针 = 当前指针 + 发射 REX 前缀（emit_rex）的返回值，参数为：缓冲区、起始位置+当前指针、W=1、R=10/8、X=0、B=10/8。
    向缓冲区偏移量（起始位置+当前指针）处写入单字节值 139（0x8B）。
    将 当前指针 增加 1。
    令 当前指针 = 当前指针 + 发射 ModRM（emit_modrm）的返回值，参数为：缓冲区、起始位置+当前指针、寻址模式=0、寄存器字段=10%8、寄存器或内存字段=10%8。
    —— 第四步：将解引用结果存入目标槽位
    令 当前指针 = 当前指针 + 发射存储（e2_st）的返回值，参数为：缓冲区、起始位置+当前指针、10、目标槽位。
    返回 当前指针。
##### 测试要点
1. 源3（s3） == 0（无需检查）：加载变量（load_var） + mov r10,[r10] + 存储（store），约 11 字节。
2. 源3（s3） != 0（需检查）：额外边界检查序列约 35+ 字节（mov+and+cmp+jae+test+jne+ud2+修补）。
3. 空指针解引用（r10 == 0）：test 后 jne 不触发，执行 ud2 → 非法指令信号（SIGILL）。
4. 越界解引用（页面内偏移 >= 分配大小）：jae 跳转到 ud2 → 非法指令信号（SIGILL）。
5. 三处跳转修补（jae→crash, jne→safe, 位置（pos）+cp 到 ud2 末尾）均正确计算为相对偏移量。

### 分支 分支指令（IR_BRANCH）（条件分支）
如果 操作码 等于 条件分支操作码常量（IR_BRANCH），那么：
    —— 第一步：加载条件值到 r10
    令 当前指针 = 当前指针 + 发射加载变量（e2_load_var）的返回值，参数为：缓冲区、起始位置+当前指针、10、源操作数 1。
    —— 第二步：test r10, r10（操作码 0x85）
    令 当前指针 = 当前指针 + 发射 REX 前缀（emit_rex）的返回值，参数为：缓冲区、起始位置+当前指针、W=1、R=10/8、X=0、B=10/8。
    向缓冲区偏移量（起始位置+当前指针）处写入单字节值 133（0x85，TEST r/m, r）。
    将 当前指针 增加 1。
    令 当前指针 = 当前指针 + 发射 ModRM（emit_modrm）的返回值，参数为：缓冲区、起始位置+当前指针、寻址模式=3、寄存器字段=10%8、寄存器或内存字段=10%8。
    —— 第三步：发射条件跳转（je → false_label（s3），jmp → true_label（s2））
    —— 单遍回溯修补策略：若标签目标位置已知则立即发射正确的偏移量；若未知（前向跳转）则记录到 待处理（pending） 数组。
    
    —— 处理 假标签（false_label）（s3）的条件跳转：
    令 JE 相对偏移位置（je_rel_pos）= 起始位置 + 当前指针 + 2（je 指令中 rel32 字段的位置）。
    令 当前指针 = 当前指针 + 发射 JE 指令（e2_je）的返回值，参数为：缓冲区、起始位置+当前指针、0（占位符）。
    如果 源操作数 3 大于等于 0 且从标签位置数组（g_label_poses）的偏移量（源操作数 3 * 8）处读取的 64 位值大于等于 0（标签已知），那么：
        令 目标位置 = 从标签位置数组的偏移量（源操作数 3 * 8）处读取的 64 位值。
        向缓冲区偏移量 JE 相对偏移位置 处写入 32 位值（目标位置 - （JE 相对偏移位置 + 4））。（计算从 je 指令末尾到目标标签的相对偏移量。）
    否则如果 源操作数 3 大于等于 0（标签未知），那么：
        —— 将前向跳转记录到 待处理（pending） 数组
        调用 扩展待处理数组（grow_pending），传入 原待处理计数 + 1。
        向待处理位置数组（g_pending_pos）的偏移量（待处理计数 * 8）处写入 64 位值 JE 相对偏移位置。
        向待处理标签数组（g_pending_label）的偏移量（待处理计数 * 8）处写入 64 位值 源操作数 3。
        将待处理计数（g_pending_count）增加 1。
    
    —— 处理 真标签（true_label）（s2）的无条件跳转：
    令 JMP 相对偏移位置（jmp_rel_pos）= 起始位置 + 当前指针 + 1（jmp 指令中 rel32 字段的位置）。
    令 当前指针 = 当前指针 + 发射 JMP 指令（e2_jmp）的返回值，参数为：缓冲区、起始位置+当前指针、0（占位符）。
    如果 源操作数 2 大于等于 0 且从标签位置数组的偏移量（源操作数 2 * 8）处读取的 64 位值大于等于 0（标签已知），那么：
        令 目标位置 = 从标签位置数组的偏移量（源操作数 2 * 8）处读取的 64 位值。
        向缓冲区偏移量 JMP 相对偏移位置 处写入 32 位值（目标位置 - （JMP 相对偏移位置 + 4））。
    否则如果 源操作数 2 大于等于 0（标签未知），那么：
        调用 扩展待处理数组（grow_pending），传入 原待处理计数 + 1。
        向待处理位置数组的偏移量（待处理计数 * 8）处写入 64 位值 JMP 相对偏移位置。
        向待处理标签数组的偏移量（待处理计数 * 8）处写入 64 位值 源操作数 2。
        将待处理计数 增加 1。
    返回 当前指针。
##### 测试要点
1. 后向跳转（标签已知）：je 和 jmp 立即正确修补。
2. 前向跳转（标签未知）：记录到 待处理（pending） 数组。
3. 两个分支（true/false）独立处理，各自有独立的相对偏移位置和 待处理（pending） 记录。

### 分支 跳转指令（IR_JUMP）（无条件跳转）
如果 操作码 等于 无条件跳转操作码常量（IR_JUMP），那么：
    令 JMP 相对偏移位置（jmp_rel_pos）= 起始位置 + 当前指针 + 1。
    令 当前指针 = 当前指针 + 发射 JMP 指令（e2_jmp）的返回值，参数为：缓冲区、起始位置+当前指针、0（占位符）。
    如果 源操作数 1 大于等于 0 且从标签位置数组的偏移量（源操作数 1 * 8）处读取的 64 位值大于等于 0，那么：
        令 目标位置 = 从标签位置数组的偏移量（源操作数 1 * 8）处读取的 64 位值。
        向缓冲区偏移量 JMP 相对偏移位置 处写入 32 位值（目标位置 - （JMP 相对偏移位置 + 4））。
    否则如果 源操作数 1 大于等于 0，那么：
        调用 扩展待处理数组（grow_pending），传入 原待处理计数 + 1。
        向待处理位置数组的偏移量（待处理计数 * 8）处写入 64 位值 JMP 相对偏移位置。
        向待处理标签数组的偏移量（待处理计数 * 8）处写入 64 位值 源操作数 1。
        将待处理计数 增加 1。
    返回 当前指针。
##### 测试要点
1. 同 分支指令（IR_BRANCH） 的跳转修补逻辑，但仅一个目标（s1）。

### 分支 标签指令（IR_LABEL）（标签定义）
如果 操作码 等于 标签操作码常量（IR_LABEL），那么：
    令 标签索引（li）= IR 指令访问器：操作数1（iri_s1），传入 指令索引。
    如果 标签索引 大于等于 0，那么：
        —— 第一步：记录当前缓冲区位置为该标签的目标位置
        调用 扩展标签位置数组（grow_label_poses），传入 标签索引 + 1。
        向标签位置数组（g_label_poses）的偏移量（标签索引 * 8）处写入 64 位值 起始位置（pos）。
        如果 标签索引 + 1 大于 标签计数（g_label_count），则将 标签计数 赋值为 标签索引 + 1。
        —— 第二步：遍历 待处理（pending） 数组，修补所有指向该标签的前向跳转
        令 待处理索引（pi）= 0，可修改。
        进入循环，每次迭代执行以下操作：
            如果 待处理索引 大于等于 待处理计数（g_pending_count），那么：跳出循环。
            如果从待处理标签数组（g_pending_label）的偏移量（待处理索引 * 8）处读取的 64 位值等于 标签索引，那么：
                令 记录位置（rp）= 从待处理位置数组（g_pending_pos）的偏移量（待处理索引 * 8）处读取的 64 位值。
                —— 修补跳转指令的 rel32 偏移量字段
                向缓冲区偏移量 记录位置 处写入 32 位值（起始位置 - （记录位置 + 4））。（计算从跳转指令末尾到当前标签位置的相对偏移量。）
                —— 标记该 待处理（pending） 条目为已修补
                向待处理标签数组的偏移量（待处理索引 * 8）处写入 64 位值 -1。
            将 待处理索引 增加 1。
        循环结束。
    返回 0（标签本身不产生任何机器码字节——它是元信息，不是指令）。
##### 测试要点
1. 标签记录当前位置（pos）。
2. 所有指向该标签的前向跳转正确修补为原始负的相对偏移量。
3. 同一标签被多个前向跳转引用时全部修补（遍历整个 pending 数组）。
4. 标签索引超出标签计数时，标签计数自动扩展。

### 分支 构造枚举指令（IR_MAKE_ENUM）（创建枚举值）

### 分支 边界检查指令（IR_BOUNDS_CHECK）（边界检查）
如果 操作码 等于 边界检查操作码常量（IR_BOUNDS_CHECK）且 源操作数 2 大于等于 0，那么：
    —— 源操作数 1 = 索引变量，源操作数 2 = 最大长度字面量
    —— 若索引 < 0 或索引 >= 最大长度，则触发 ud2（SIGILL）
    —— 第一步：mov r10, [源操作数 1 的槽位]（加载索引到 r10）
    令 当前指针 = 当前指针 + 发射加载变量（e2_load_var）的返回值，参数为：缓冲区、起始位置+当前指针、10、源操作数 1。

    令 当前指针 = 当前指针 + 发射加载变量（e2_load_var）的返回值，参数为：缓冲区、起始位置+当前指针、11、源操作数 2。
    —— 第三步：cmp r10, r11（操作码 0x39，e2_alu opcode=57）
    令 当前指针 = 当前指针 + 发射 ALU 指令（e2_alu）的返回值，参数为：缓冲区、起始位置+当前指针、57。
    —— 第四步：jb +2（若索引无符号小于最大长度，跳过 ud2。操作码 0x72，JB rel8）
    向缓冲区偏移量（起始位置+当前指针）处写入单字节值 114（操作码 0x72，JB rel8）。
    向缓冲区偏移量（起始位置+当前指针+1）处写入单字节值 2（rel8 偏移量，跳过 2 字节即 ud2 指令）。

    写 8 位（w8），向缓冲区偏移量（当前指针+1）处写入单字节值 11（0x0B）。
    将 当前指针 增加 2。
    返回 当前指针。
##### 测试要点
1. 索引在 [0, 最大长度（max_len）） 范围内：不触发 ud2。
2. 索引 >= 最大长度（max_len）：ud2 → 非法指令信号（SIGILL）。
3. 负索引（视为大无符号数）：无符号比较触发 ud2。
4. 约 13 字节（ld+ld+cmp+jb+ud2）。

    令 跳转到完成的位置（jmp_done_off）= 当前指针。
    向缓冲区偏移量（起始位置+当前指针）处写入单字节值 235（操作码 0xEB，JMP rel8）。
    向缓冲区偏移量（起始位置+当前指针+1）处写入单字节值 0（占位符偏移量）。
    将 当前指针 增加 2。
    
    —— 第 5 步：.完成标签（done） 标签 —— 将提取的值存入目标变量
    令 完成位置（done_pos）= 当前指针。
    如果 目标变量 大于等于 0，那么：
        令 当前指针 = 当前指针 + 发射存储（e2_st）的返回值，参数为：缓冲区、起始位置+当前指针、10、目标槽位。
    
    —— 第 6 步：修补所有前向跳转偏移量（rel8）
    —— 修补 je 跳转到 公共分支（case_common） 的三处偏移量
    向缓冲区偏移量（跳转 1 偏移量位置 + 1）处写入单字节值（公共案例位置 - （跳转 1 偏移量位置 + 2））。（j1_off+1 是 je 的 rel8 字段，j1_off+2 是 je 指令后的下一条指令位置。）
    向缓冲区偏移量（跳转 2 偏移量位置 + 1）处写入单字节值（公共案例位置 - （跳转 2 偏移量位置 + 2））。
    向缓冲区偏移量（跳转 3 偏移量位置 + 1）处写入单字节值（公共案例位置 - （跳转 3 偏移量位置 + 2））。
    —— 修补 jmp 跳转到 完成标签（done） 的偏移量
    向缓冲区偏移量（跳转到完成的位置 + 1）处写入单字节值（完成位置 - （跳转到完成的位置 + 2））。
    返回 当前指针。
##### 测试要点
1. 标签值匹配 类型信息：整数（TI_INT）（0）：je 跳转到 公共分支（case_common），提取值后存回目标。
2. 标签值匹配 类型信息：布尔（TI_BOOL）（2）：同上。
3. 标签值匹配 类型信息：字符串（TI_STR）（3）：同上。
4. 标签值不匹配任何已知类型：顺次落入 类型错误（type_error），执行 xor eax,eax； 返回（ret）。
5. 全部跳转为短 rel8（2 字节 je + 1 字节偏移量）。
6. 六处 rel8 偏移量修补（3 个 je + 1 个 jmp 跳到 done + 额外？实际上是 4 处修补：3 个 je 的偏移量和 1 个 jmp 的偏移量），均在发射完成后用绝对位置计算。

### 末尾兜底
如果以上所有分支均不匹配（未识别的操作码），则返回 0。
