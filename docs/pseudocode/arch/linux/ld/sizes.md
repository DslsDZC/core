# sizes.cr 伪代码

> 源文件：src/arch/linux/ld/sizes.cr（75 行）
> 功能概要：x86-64 指令字节大小的唯一真相源。所有后端指令尺寸计算均通过本文件提供的函数完成，确保 Phase 1（序言/尾声）、Phase 2（布局估算）和 Phase 3（实际发射）的尺寸计算完全一致。严禁在 elf.cr、instr.cr、resolve.cr 中硬编码字节数。

## 函数 基本编码尺寸（各函数）

### 函数 mov 指令大小（sz_mov）
#### 作用
返回寄存器到寄存器 mov 指令的固定字节数。
#### 逻辑
返回 3。
#### 测试要点
1. 调用 mov 指令大小始终返回 3，与源/目标寄存器无关。

### 函数 加载双字大小（sz_ld）
#### 作用
根据目标偏移量（offset）所在的编码区间返回 mov 指令（[rbp+偏移量] 形式）或寄存器间拷贝的字节数。

参数：偏移量（o：整数）-> 整数

#### 逻辑
如果 偏移量 大于等于 寄存器槽基址常量（E2_REG_SLOT_BASE），那么：
    —— 寄存器到寄存器拷贝（ModRM 中 mod 字段等于 3）
    返回 3
如果 偏移量 大于等于 -128 且 偏移量 小于等于 127，那么：
    —— 采用 [rbp+disp8] 寻址模式（REX + opcode + ModRM + disp8），共 4 字节
    返回 4
否则：
    —— 采用 [rbp+disp32] 寻址模式（REX + opcode + ModRM + SIB + disp32），共 7 字节
    返回 7
#### 测试要点
1. 寄存器槽情况（偏移量大于等于 寄存器槽基址常量）：返回 3。
2. disp8 情况：返回 4。
3. disp32 情况：返回 7。
4. 边界值 -128 和 127 应走 disp8 分支。

    —— 寄存器到寄存器拷贝（ModRM 中 mod 字段等于 3）
    返回 3
如果 偏移量 大于等于 -128 且 偏移量 小于等于 127，那么：
    —— 采用 [rbp+disp8] 寻址模式，共 4 字节
    返回 4
否则：
    —— 采用 [rbp+disp32] 寻址模式，共 7 字节

#### 测试要点
1. 同加载双字大小的三个区间验证。

### 函数 加载立即数大小（sz_li）
#### 作用
返回 mov 指令（[rbp+位移量（disp）], 立即数（imm）形式）的字节数，区分 32 位有符号立即数和 64 位立即数两条路径。

参数：偏移量（o：整数）、立即数值（值（v）：整数）-> 整数

#### 逻辑
如果 立即数值 小于 -2147483648 或 立即数值 大于 2147483647，那么：
    —— 64 位立即数路径：先执行 mov rax, 64位立即数（imm64）（10 字节），再执行 mov 指令（[rbp+位移量], rax 形式）
    如果 偏移量 大于等于 -128 且 偏移量 小于等于 127，那么：
        —— 寄存器存储用 disp8 寻址（4 字节），合计 10 + 4 = 14 字节
        返回 14
    否则：
        —— 寄存器存储用 disp32 寻址（7 字节），合计 10 + 7 = 17 字节
        返回 17
否则：
    —— 32 位有符号扩展立即数路径：mov 指令（[rbp+位移量], 32位立即数（imm32）形式）
    如果 偏移量 大于等于 -128 且 偏移量 小于等于 127，那么：
        —— 采用 disp8 寻址，共 8 字节（REX + opcode（2） + ModRM（1） + SIB（1） + disp8（1） + imm32（4） 中除去 SIB 的为 REX + opcode（1） + ModRM（1） + disp8（1） + imm32（4） = 8，或含 SIB 时为 8/11）
        返回 8
    否则：
        —— 采用 disp32 寻址，共 11 字节
        返回 11
#### 测试要点
1. 小立即数 + disp8：返回 8。
2. 小立即数 + disp32：返回 11。
3. 64 位立即数 + disp8：返回 14。
4. 64 位立即数 + disp32：返回 17。
5. 边界值 -2147483648 和 2147483647 应走 32 位立即数路径。
6. 边界值 -2147483649 和 2147483648 应走 64 位立即数路径。

### 函数 sub rsp 大小（sz_sub_rsp）
#### 作用
根据栈帧大小返回 sub rsp 指令（立即数形式）的字节数。

参数：栈帧大小（ss：整数）-> 整数

#### 逻辑
如果 栈帧大小 小于等于 0，那么：
    —— 无需分配栈空间，不发射任何字节
    返回 0
如果 栈帧大小 大于 127，那么：
    —— 采用 disp32 编码：sub rsp, 32位立即数（REX + opcode + ModRM + imm32），共 7 字节
    返回 7
否则：
    —— 采用 disp8 编码：sub rsp, 8位立即数（imm8）（REX + opcode + ModRM + imm8），共 4 字节
    返回 4
#### 测试要点
1. 栈帧大小为 0：返回 0。
2. 栈帧大小为 128：返回 7（触发 disp32 分支）。
3. 栈帧大小为 127：返回 4（disp8 分支上限）。
4. 栈帧大小为负数：返回 0。

## 函数 指令大小（instr_size）
### 作用
按 IR 操作码返回各指令的估计字节数。用于 Phase 2 布局阶段快速估算函数体大小，无需实际调用发射函数。

参数：操作码（op：整数）-> 整数

### 逻辑
如果 操作码 等于 内联提示操作码（IR_INLINE），那么：返回 0（编译提示，无运行时代码）
如果 操作码 等于 无边界检查操作码（IR_NO_BOUNDS_CHECK），那么：返回 0（编译提示，无运行时代码）
如果 操作码 等于 快速路径操作码（IR_FAST），那么：返回 0（编译提示，无运行时代码）
如果 操作码 等于 循环展开操作码（IR_UNROLL），那么：返回 0（编译提示，无运行时代码）
如果 操作码 等于 段标记操作码（IR_SECTION），那么：返回 0（编译提示，无运行时代码）
如果 操作码 等于 延迟求值桩操作码（IR_LAZY_THUNK），那么：返回 11
如果 操作码 等于 延迟求值强制操作码（IR_LAZY_FORCE），那么：返回 11
如果 操作码 等于 协程派生操作码（IR_SPAWN），那么：返回 9（调用指令 5 字节 + 存储指令 4 字节）
如果 操作码 等于 协程让出操作码（IR_YIELD），那么：返回 0（当前为空操作）
如果 操作码 等于 外部调用操作码（IR_CALL_EXTERN），那么：返回 9（调用指令 5 字节 + 存储指令 4 字节）
如果 操作码 等于 热补丁路由操作码（IR_HOTPATCH_ROUTE），那么：返回 9（调用指令 5 字节 + 存储指令 4 字节）
如果 操作码 等于 函数地址操作码（IR_FNADDR），那么：返回 14（movabs 10 字节 + 存储指令 4 字节）
如果 操作码 等于 动态打包操作码（IR_DYN_PACK），那么：返回 16（加载变量 + 存储指令 + 加载立即数：值+标签打包）
如果 操作码 等于 动态标签操作码（IR_DYN_TAG），那么：返回 8（从偏移+8 加载 + 存储）
如果 操作码 等于 动态值操作码（IR_DYN_VAL），那么：返回 8（从偏移+0 加载 + 存储）
如果 操作码 等于 动态分发操作码（IR_DYN_DISPATCH），那么：返回 40（标签加载 + cmp/je 链，常见情况约 35 到 44 字节）
—— 未知 / 非注解类操作码：返回 0，由调用者按默认启发式（指令计数乘以 5）估算
返回 0
### 测试要点
1. 编译提示类操作码（IR_INLINE、IR_NO_BOUNDS_CHECK、IR_FAST、IR_UNROLL、IR_SECTION）返回 0。
2. 调用类操作码（生成协程指令（IR_SPAWN）、外部调用指令（IR_CALL_EXTERN）、热补丁路由指令（IR_HOTPATCH_ROUTE））均返回 9。
3. 动态类型操作码各自返回对应的估计值。
4. 未识别操作码返回 0（由调用者处理）。
