# sizes.cr 伪代码

> 源文件：src/arch/linux/ld/sizes.cr（75 行）
> 功能概要：x86-64 指令字节大小的唯一真相源。所有后端指令尺寸计算均通过本文件提供的函数完成，确保 Phase 1（序言/尾声）、Phase 2（布局估算）和 Phase 3（实际发射）的尺寸计算完全一致。严禁在 elf.cr、instr.cr、resolve.cr 中硬编码字节数。

## 函数 基本编码尺寸（各函数）

### 函数 sz_mov（MOV 指令大小）
#### 作用
返回 `mov r64, r64`（寄存器到寄存器）指令的固定字节数。
#### 逻辑
返回 3（REX 字节 + opcode 0x89 + ModRM 字节）。
#### 测试要点
1. 调用 sz_mov 始终返回 3，与源/目标寄存器无关。

### 函数 sz_ld（加载双字大小）
#### 作用
根据目标偏移量所在的编码区间返回 `mov r64, [rbp+offset]` 或寄存器间拷贝的字节数。
#### 逻辑
如果 偏移量 不小于 寄存器槽基址常量，那么：
    —— 寄存器到寄存器拷贝（mod=3）
    返回 3
如果 偏移量 在 [-128, 127] 范围内，那么：
    —— [rbp+disp8] 寻址模式
    返回 4
否则：
    —— [rbp+disp32] 寻址模式
    返回 7
#### 测试要点
1. 寄存器槽情况（偏移量 >= 寄存器槽基址常量）返回 3。
2. disp8 情况返回 4。
3. disp32 情况返回 7。
4. 边界值 -128 和 127 应走 disp8 分支。

### 函数 sz_st（存储指令大小）
#### 作用
根据目标偏移量返回 `mov [rbp+offset], r64` 的字节数。与 sz_ld 逻辑完全相同。
#### 逻辑
与 sz_ld 相同：寄存器槽返回 3，disp8 返回 4，disp32 返回 7。
#### 测试要点
1. 同 sz_ld 的三个区间验证。

### 函数 sz_li（加载立即数大小）
#### 作用
返回 `mov [rbp+disp], imm` 指令的字节数，区分 32 位有符号立即数和 64 位立即数两条路径。
#### 逻辑
如果 立即数值 小于 -2^31 或 大于 2^31-1，那么：
    —— 64 位立即数路径：mov rax, imm64 然后 mov [rbp+disp], rax
    如果 偏移量 在 disp8 范围，那么：返回 14
    否则：返回 17
否则：
    —— 32 位有符号扩展立即数路径：mov [rbp+disp], imm32
    如果 偏移量 在 disp8 范围，那么：返回 8
    否则：返回 11
#### 测试要点
1. 小立即数 + disp8：返回 8。
2. 小立即数 + disp32：返回 11。
3. 64 位立即数 + disp8：返回 14。
4. 64 位立即数 + disp32：返回 17。
5. 边界值 -2^31-1 和 2^31 应走 64 位立即数路径。

### 函数 sz_sub_rsp（sub rsp 大小）
#### 作用
根据栈帧大小返回 `sub rsp, imm` 指令字节数。
#### 逻辑
如果 栈帧大小 不大于 0，那么：返回 0（无需分配栈空间）

否则：返回 4（disp8 编码）
#### 测试要点
1. 栈帧大小为 0 返回 0。
2. 栈帧大小为 128 返回 7。
3. 栈帧大小为 127 返回 4。

## 函数 _start 尺寸

### 函数 sz_start_body（_start 函数体大小）
#### 作用
返回 `_start` 函数体（不含 argc/argv 全局变量保存）的字节数。
#### 逻辑
返回 4 + 5 + 调用指令大小（）+ 2 + 5 + 系统调用大小（）
= 4 + 5 + 5 + 2 + 5 + 2 = 23
其中：mov rdi,[rsp](4) + lea rsi,[rsp+8](5) + call main(5) + mov edi,eax(2) + mov eax,60(5) + syscall(2)
#### 测试要点
1. 始终返回 23。

### 函数 sz_start_argv_save（_start argv 保存大小）
#### 作用
返回保存 argc 或 argv 全局变量所需的额外字节数（每个全局变量保存块的大小）。
#### 逻辑
返回 加载寄存器大小（）+ 3 = 7 + 3 = 10
其中：lea r10,[rip+0](7) + mov [r10],rdi(3)
#### 测试要点
1. 始终返回 10。

## 函数 instr_size（指令大小）
### 作用
按 IR 操作码返回各指令的估计字节数。用于 Phase 2 布局阶段快速估算函数体大小，无需实际调用发射函数。
### 逻辑
如果 操作码 等于 IR_INLINE，那么：返回 0（编译提示，无运行时代码）
如果 操作码 等于 IR_NO_BOUNDS_CHECK，那么：返回 0
如果 操作码 等于 IR_FAST，那么：返回 0
如果 操作码 等于 IR_UNROLL，那么：返回 0
如果 操作码 等于 IR_SECTION，那么：返回 0
如果 操作码 等于 IR_LAZY_THUNK，那么：返回 11
如果 操作码 等于 IR_LAZY_FORCE，那么：返回 11
如果 操作码 等于 IR_SPAWN，那么：返回 9（调用 5 字节 + 保存 4 字节）
如果 操作码 等于 IR_YIELD，那么：返回 0
如果 操作码 等于 IR_CALL_EXTERN，那么：返回 9（调用 5 字节 + 保存 4 字节）
如果 操作码 等于 IR_HOTPATCH_ROUTE，那么：返回 9
如果 操作码 等于 IR_FNADDR，那么：返回 14（movabs(10) + 保存(4)）
如果 操作码 等于 IR_DYN_PACK，那么：返回 16（加载变量 + 存储 + 立即数存储）
如果 操作码 等于 IR_DYN_TAG，那么：返回 8（从偏移+8 加载 + 存储）
如果 操作码 等于 IR_DYN_VAL，那么：返回 8（从偏移+0 加载 + 存储）
如果 操作码 等于 IR_DYN_DISPATCH，那么：返回 40
其余未知操作码：返回 0（由调用者用默认启发式估算）
### 测试要点
1. IR_NOP 类操作码返回 0。
2. 调用类操作码（IR_SPAWN, IR_CALL_EXTERN, IR_HOTPATCH_ROUTE）均返回 9。
3. 动态类型操作码各自返回对应的估计值。
4. 未识别操作码返回 0（由调用者处理）。
