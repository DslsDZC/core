# rt.cr 伪代码
> 源文件：src/runtime/rt.cr（14 行）
> 功能概要：定义 Core 运行时所需的全部底层全局变量，供汇编运行时（s）和 ELF 后端使用。包括命令行参数传递、堆分配器边界（bump allocator）及热补丁运行时状态。

## 全局状态

本文件仅含全局变量声明，无函数定义。逐行翻译如下：

引入 竞技场全局变量模块（arena_globals）。

| 全局变量 | 类型 | 可变 | 初始值 | 说明 |
|---------|------|------|--------|------|
| 命令行参数个数（g_rt_argc） | 整数（int） | 可变（mut） | 未初始化（由 _start 写入） | 程序启动时由 ELF 入口 _start 从栈上读取并写入本变量。记录传入 main 的命令行参数数量。 |
| argv 指针（g_rt_argv_ptr） | 字符串（string） | 可变（mut） | 未初始化（由 _start 写入） | 指向命令行参数字符串数组的起始地址。由 _start 在进程启动阶段从栈上提取并写入。 |
| 堆指针（g_heap_ptr） | 字符串（string） | 可变（mut） | 未初始化（运行时初始化） | 堆（bump allocator）的当前分配指针。每次分配内存时向前移动。必须是 Core 全局变量，以便 ELF 后端的 RIP 相对寻址修补（rip_patch）机制正确解析其在 BSS 段中的地址。 |
| 堆末尾（g_heap_end） | 字符串（string） | 可变（mut） | 未初始化（运行时初始化） | 堆内存区域的末尾边界地址。分配器在 g_heap_ptr 到达或超过 g_heap_end 时触发堆扩展。同样必须是 Core 全局变量以保证 BSS 地址解析正确。 |
| 热补丁配置（g_hp_config） | 字符串（string） | 可变（mut） | 未初始化（热补丁初始化时写入） | 指向热补丁配置数据的指针，由热补丁子系统在加载配置时填充。 |
| 热补丁进行中计数（g_hp_inflight） | 字符串（string） | 可变（mut） | 未初始化（热补丁初始化时写入） | 记录当前正在进行的热补丁操作计数，用于并发控制与安全状态跟踪。 |
