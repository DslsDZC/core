# region_check.cr 伪代码
> 源文件：src/compiler/region_check.cr（156 行）
> 功能概要：区域检查（Region Check）pass。在指针分析之后运行，验证解引用（IR_DEREF）的目标分配点所在的子图（subgraph）是否仍然存活（未退出）。实现 希伯特风格（Siebert）的区域逃逸检查：检测悬垂指针（分配点所在的子图已退出但仍被解引用）、返回指针逃逸（返回指向已退出子图的指针）、Store 逃逸（将指向已退出子图分配的指针存储到更长寿的指针中）。

## 全局状态

本文件读取以下全局状态（由指针分析和数据流图填充）：

- 数据流节点数组（g_df_nodes）：数据流图指令。
- 数据流节点计数（g_df_node_count）：数据流节点总数。
- 数据流节点所属 region（g_df_node_region）：每个数据流节点归属的子图序号（由 数据流图：创建节点（df_create_node） 写入的 常时（1）显式映射）。
- 指针集数组（g_pts）：每个变量的指针集位图。
- 结构图数组（g_sgs）：region 结构图，含 类别（OFF_SG_KIND）、节点起始（OFF_SG_NSTART）、节点计数（OFF_SG_NCOUNT）、出口节点序号（OFF_SG_EXIT）等字段。
- 结构图计数（g_sg_count）：结构图总数。
- IR 函数个数（g_ir_func_count）、数据流图各函数节点起始索引（g_df_func_node_start）、数据流图各函数节点计数（g_df_func_node_count）。

领域专名保留：数据流节点条目大小（ESZ_DFNODE）、操作码字段偏移（OFF_DF_OPCODE）/ 目标字段偏移（OFF_DF_DEST）/ 操作数1字段偏移（OFF_DF_S1）/ 操作数2字段偏移（OFF_DF_S2）、不安全区域（SG_UNSAFE）/ 函数区域（SG_FUNC）、类别字段偏移（OFF_SG_KIND）/ 节点起始字段偏移（OFF_SG_NSTART）/ 节点计数字段偏移（OFF_SG_NCOUNT）/ 出口字段偏移（OFF_SG_EXIT）、解引用（IR_DEREF）/ 返回（IR_RETURN）/ 指针存储（IR_STORE_PTR）、生命周期错误（EC_B_LIFETIME）。

## 函数 包含节点的子图（subgraph_containing）

### 作用
通过 常时（1）显式映射（g_df_node_region）查询给定数据流节点序号所属的子图序号。若节点序号无效则返回 -1。

### 逻辑

    函数 包含节点的子图（节点序号 node_seq：整数）-> 整数：
        // 显式映射：常时（1）归属查询（数据流节点所属 region 由 数据流图：创建节点（df_create_node） 写入）
        如果 节点序号 大于等于 0 且 节点序号 小于 数据流节点计数，那么：
            返回 读 64 位（r64）（源 = 数据流节点所属 region，偏移 = 节点序号 * 8）
        返回 -1

### 测试要点
1. 有效节点序号：返回其所属子图序号。
2. 节点序号为负：返回 -1。
3. 节点序号超出范围：返回 -1。
4. 节点未分配子图时 数据流节点所属 region 存储的值决定返回结果。

## 函数 判断 不安全块内（is_in_unsafe）

### 作用
判断给定数据流节点是否位于 不安全区域（SG_UNSAFE）内。不安全块内的节点跳过区域检查。

### 逻辑

    函数 判断 不安全块内（节点序号 node_seq：整数）-> 整数：
        令 结构图索引（si） = 0（可变）
        循环：
            如果 结构图索引 大于等于 结构图计数，那么：
                跳出循环
            令 结构图类别（kind） = 读 64 位（r64）（源 = 结构图数组，偏移 = 结构图索引 * 结构图条目大小 + 类别字段偏移）
            如果 结构图类别 等于 不安全区域（SG_UNSAFE），那么：
                令 结构图节点起始（nstart） = 读 64 位（r64）（源 = 结构图数组，偏移 = 结构图索引 * 结构图条目大小 + 节点起始字段偏移）
                令 结构图节点计数（ncount） = 读 64 位（r64）（源 = 结构图数组，偏移 = 结构图索引 * 结构图条目大小 + 节点计数字段偏移）
                如果 节点序号 大于等于 结构图节点起始 且 节点序号 小于 结构图节点起始 + 结构图节点计数，那么：
                    返回 1
            令 结构图索引 = 结构图索引 + 1
        返回 0

### 测试要点
1. 不安全区域内返回 1；否则返回 0。
2. 与 指针分析：判断 不安全块内（pa_in_unsafe） 逻辑相同。

### 作用
将分配节点的数据流序号映射到其所属的子图序号。委托给 包含节点的子图（subgraph_containing）。

### 逻辑

    函数 分配序列映射到 SG（分配节点序号 alloc_seq：整数）-> 整数：
        // 将 标量分配 节点的数据流序号映射到其所属的子图
        返回 包含节点的子图（subgraph_containing）（分配节点序号）

### 测试要点
1. 与 包含节点的子图 行为一致（直接委托）。

## 函数 区域检查：点集是否逃逸（rc_pts_has_escaped）

### 作用
检查指针集位图中的任何分配目标是否逃逸了其父级子图。逃逸条件：分配所在子图的出口节点序号（OFF_SG_EXIT）为有效值，且当前解引用节点序号大于该出口序号（表示子图已退出）。

### 逻辑

    函数 区域检查：点集是否逃逸（指针集位图 pts：整数，当前节点序号 ni：整数，函数节点起始 nstart：整数）-> 整数：
        // 检查指针集中是否有任何分配目标逃逸了其父级子图
        令 位掩码（mask） = 1（可变）
        令 位序号（bi） = 0（可变）
        循环：
            如果 位序号 大于等于 64，那么：
                跳出循环
            如果 （指针集位图 / 位掩码） % 2 等于 1，那么：
                令 分配节点序号（alloc_seq） = 位序号 + 函数节点起始
                令 分配子图（alloc_sg） = 分配序列映射到 SG（alloc_seq_to_sg）（分配节点序号）
                令 解引用子图（deref_sg） = 包含节点的子图（subgraph_containing）（当前节点序号）
                如果 分配子图 大于等于 0 且 解引用子图 大于等于 0，那么：
                    令 分配子图出口（alloc_exit） = 读 64 位（r64）（源 = 结构图数组，偏移 = 分配子图 * 结构图条目大小 + 出口字段偏移（OFF_SG_EXIT））
                    如果 分配子图出口 大于等于 0 且 当前节点序号 大于 分配子图出口，那么：
                        返回 1  // 逃逸 — 分配所在子图已退出
            令 位掩码 = 位掩码 * 2
            令 位序号 = 位序号 + 1
        返回 0

### 测试要点
1. 指针集为空（0）：遍历无命中，返回 0。
2. 分配点在当前子图内且子图未退出：分配子图出口 无效或 当前节点序号 小于等于 分配子图出口，返回 0。
3. 分配点所在子图已退出（当前节点序号 > 分配子图出口）：返回 1。
4. 分配子图或解引用子图无效（负数）：返回 0（保守，不做错误报告，交由其他 pass）。

## 函数 区域检查：返回逃逸（rc_return_escape）

### 作用
希伯特风格（Siebert）检查：判断返回指令的返回值（若为指针）是否指向已退出子图的分配。函数级别的分配（SG_FUNC）允许返回，其他子图（循环（loop） body、如果（if）-那么（then） 等）的分配若在返回点之前已退出则报错。

### 逻辑

    函数 区域检查：返回逃逸（当前节点序号 ni：整数，返回变量 s1：整数，函数节点起始 nstart：整数）：
        // 希伯特规则（Siebert）：检查返回的指针是否逃逸其区域
        如果 返回变量 小于 0，那么：返回
        令 指针集位图（pts） = 读 64 位（r64）（源 = 指针集数组，偏移 = 返回变量 * 8）
        如果 指针集位图 等于 0，那么：返回
        令 当前子图（cur_sg） = 包含节点的子图（subgraph_containing）（当前节点序号）
        如果 当前子图 小于 0，那么：返回
        // 检查是否有目标分配在调用者使用返回值之前就已退出的子图中
        令 位掩码（mask） = 1（可变）
        令 位序号（bi） = 0（可变）
        循环：
            如果 位序号 大于等于 64，那么：
                跳出循环
            如果 （指针集位图 / 位掩码） % 2 等于 1，那么：
                令 分配节点序号（alloc_seq） = 位序号 + 函数节点起始
                令 分配子图（alloc_sg） = 分配序列映射到 SG（alloc_seq_to_sg）（分配节点序号）
                如果 分配子图 大于等于 0，那么：
                    令 分配子图类别（alloc_sg_kind） = 读 64 位（r64）（源 = 结构图数组，偏移 = 分配子图 * 结构图条目大小 + 类别字段偏移）
                    如果 分配子图类别 等于 函数区域（SG_FUNC），那么：
                        // 函数级别的分配 = 允许返回
                        令 位序号 = 位序号 + 1
                        令 位掩码 = 位掩码 * 2
                        继续下一次循环
                    令 分配子图出口（alloc_exit） = 读 64 位（r64）（源 = 结构图数组，偏移 = 分配子图 * 结构图条目大小 + 出口字段偏移）
                    如果 分配子图出口 大于等于 0 且 当前节点序号 大于 分配子图出口，那么：
                        检查错误（check_error）（错误码：生命周期错误（EC_B_LIFETIME），
                            消息 = "region escape: returning pointer to exited subgraph allocation",
                            行号 = 0，列号 = 0）
            令 位掩码 = 位掩码 * 2
            令 位序号 = 位序号 + 1

### 测试要点
1. 返回变量为负：直接返回。
2. 返回变量指针集为空：直接返回。
3. 返回 函数区域 级别的分配：允许返回，不报错。
4. 返回已退出子图（如循环体）中的分配：报错 生命周期错误。
5. 返回未退出子图中的分配：不报错（子图仍在活跃范围内）。

## 函数 区域检查：存储逃逸（rc_store_escape）

### 作用
希伯特风格（Siebert）检查：检测 指针存储（*指针（ptr）=值（val））时 值变量（值） 的目标分配是否可能逃逸 — 即 值变量 指向的分配的生存期是否大于等于 指针变量（指针） 指向的分配的生存期。当前实现为简化版本（调用 区域检查：点集是否逃逸 做基础检查）。

### 逻辑

    函数 区域检查：存储逃逸（当前节点序号 ni：整数，指针变量 ptr_var：整数，值变量 val_var：整数）：
        // 希伯特规则（Siebert）：检查存储指针是否产生悬垂引用
        // 指针存储 — 值变量 的目标分配的生存期必须大于等于 指针变量 的生存期
        如果 值变量 小于 0，那么：返回
        令 值指针集（val_pts） = 读 64 位（r64）（源 = 指针集数组，偏移 = 值变量 * 8）
        如果 值指针集 等于 0，那么：返回
        区域检查：点集是否逃逸（rc_pts_has_escaped）（值指针集，当前节点序号，0）  // 简化检查

### 测试要点
1. 值变量为负时直接返回。
2. 值指针集为空时直接返回。
3. 有逃逸分配点时调用 区域检查：点集是否逃逸 检查（简化版；完整 Siebert 需要更精确的分配点生存期比较）。

## 函数 区域检查函数（region_check_func）

### 作用
对单个函数执行区域检查。遍历所有数据流节点：
1. 对 解引用（IR_DEREF）指令：检查指针的每个目标分配所在子图的退出序号是否小于当前节点序号，若小于则报悬垂指针错误（EC_B_LIFETIME）。
2. 对 返回（IR_RETURN）指令：调用 区域检查：返回逃逸。
3. 对 指针存储（IR_STORE_PTR）指令：调用 区域检查：存储逃逸。
不安全块内的所有指令跳过检查。

### 逻辑

    函数 区域检查函数（节点起始 nstart：整数，节点计数 ncount：整数）：
        令 当前节点序号（ni） = 节点起始（可变）
        循环：
            如果 当前节点序号 大于等于 节点起始 + 节点计数，那么：
                跳出循环
            令 操作码（op） = 读 64 位（r64）（源 = 数据流节点数组，偏移 = 当前节点序号 * 数据流节点条目大小 + 操作码字段偏移）
            令 目标变量（d_dest） = 读 64 位（r64）（源 = 数据流节点数组，偏移 = 当前节点序号 * 数据流节点条目大小 + 目标字段偏移）
            令 操作数1（s1） = 读 64 位（r64）（源 = 数据流节点数组，偏移 = 当前节点序号 * 数据流节点条目大小 + 操作数1字段偏移）
            令 操作数2（s2） = 读 64 位（r64）（源 = 数据流节点数组，偏移 = 当前节点序号 * 数据流节点条目大小 + 操作数2字段偏移）

            // 不安全块内跳过所有检查
            如果 判断 不安全块内（is_in_unsafe）（当前节点序号） 不等于 0，那么：
                令 当前节点序号 = 当前节点序号 + 1
                继续下一次循环

            // ── 解引用检查 ──
            如果 操作码 等于 解引用（IR_DEREF） 且 目标变量 大于等于 0 且 操作数1 大于等于 0，那么：
                令 指针集位图（pts） = 读 64 位（r64）（源 = 指针集数组，偏移 = 操作数1 * 8）
                如果 指针集位图 不等于 0，那么：
                    令 位掩码（mask） = 1（可变）
                    令 位序号（bi） = 0（可变）
                    循环：
                        如果 位序号 大于等于 64，那么：
                            跳出循环
                        如果 （指针集位图 / 位掩码） % 2 等于 1，那么：
                            令 分配节点序号（alloc_seq） = 位序号 + 节点起始
                            令 分配子图（alloc_sg） = 分配序列映射到 SG（alloc_seq_to_sg）（分配节点序号）
                            令 解引用子图（deref_sg） = 包含节点的子图（subgraph_containing）（当前节点序号）
                            如果 分配子图 大于等于 0 且 解引用子图 大于等于 0，那么：
                                令 分配子图出口（alloc_exit） = 读 64 位（r64）（源 = 结构图数组，偏移 = 分配子图 * 结构图条目大小 + 出口字段偏移）
                                如果 分配子图出口 大于等于 0 且 当前节点序号 大于 分配子图出口，那么：
                                    检查错误（check_error）（错误码：生命周期错误（EC_B_LIFETIME），
                                        消息 = "dangling pointer: allocation subgraph exited before deref",
                                        行号 = 0，列号 = 0）
                        令 位掩码 = 位掩码 * 2
                        令 位序号 = 位序号 + 1

            // ── 希伯特规则（Siebert）：过程间返回逃逸检查 ──
            如果 操作码 等于 返回（IR_RETURN） 且 操作数1 大于等于 0，那么：
                区域检查：返回逃逸（rc_return_escape）（当前节点序号，操作数1，节点起始）

            // ── 希伯特规则（Siebert）：过程间存储逃逸检查 ──
            如果 操作码 等于 指针存储（IR_STORE_PTR），那么：
                区域检查：存储逃逸（rc_store_escape）（当前节点序号，操作数1，操作数2）

            令 当前节点序号 = 当前节点序号 + 1

### 测试要点
1. 空函数（ncount = 0）：循环不执行。
2. 解引用指令的目标分配在活跃子图内：不报错。
3. 解引用指令的目标分配所在子图已退出（当前节点序号 > 分配子图出口）：报错 生命周期错误。
4. 解引用的指针集为空：跳过检查。
5. 返回指令的操作数为指针且指向已退出子图分配：报错 生命周期错误。
6. 返回 函数区域 级别的分配：不报错（允许返回）。
7. 不安全块内的所有指令均跳过检查。
8. 非 解引用/返回/指针存储 指令直接跳过。

## 函数 区域检查全部（region_check_all）

### 作用
对所有 IR 函数逐一调用 区域检查函数（region_check_func）。

### 逻辑

    函数 区域检查全部：
        // 安全检查通行证 — 始终运行
        令 函数序号（fi） = 0（可变）
        循环：
            如果 函数序号 大于等于 IR 函数个数，那么：
                跳出循环
            令 节点起始（nstart） = 读 64 位（r64）（源 = 数据流图各函数节点起始索引，偏移 = 函数序号 * 8）
            令 节点计数（ncount） = 读 64 位（r64）（源 = 数据流图各函数节点计数，偏移 = 函数序号 * 8）
            区域检查函数（region_check_func）（节点起始，节点计数）
            令 函数序号 = 函数序号 + 1

### 测试要点
1. 无 IR 函数时循环不执行。
2. 每个函数独立执行区域检查。
3. 始终运行（不检查优化级别等标志）。
