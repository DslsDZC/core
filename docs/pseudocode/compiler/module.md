## 函数 注册文件 ID（reg_fileid）
### 作用
将文件 ID 字符串和路径注册到文件数组（g_files）中。若文件 ID 已存在则直接返回其驻留索引（去重）。每个文件条目占 16 字节：[文件 ID 驻留索引（8） + 路径指针（8）]。

### 逻辑
函数 注册文件 ID（reg_fileid）（文件标识字符串（fileid_str）：字符串，路径（path）：字符串）-> 整数：
    令 文件驻留索引（fni） = 字符串驻留（文件标识字符串）
    // 去重：检查是否已注册过
    令 文件索引（fi） = 0
    循环（当 文件索引 小于 文件计数 时）：
        如果 读 64 位（文件数组，文件索引 * 16）等于 文件驻留索引，那么：
            返回 文件驻留索引    // 已注册，直接返回
        令 文件索引 = 文件索引 + 1

    // 新注册
    扩展文件数组（文件计数 + 1）
    写 64 位（文件数组，文件计数 * 16，文件驻留索引）
    存储字符串指针（store_str_ptr）（文件数组，文件计数 * 16 + 8，路径）
    令 文件计数 = 文件计数 + 1
    返回 文件驻留索引

### 测试要点
1. 新文件 ID 被注册，文件计数递增
2. 重复文件 ID 直接返回已有驻留索引
3. 驻留索引和路径正确写入

## 函数 解析引入（res_imports）
### 作用
多遍导入解析器：扫描词法单元流中的 （import） 语句，加载对应源文件，执行重分词（re-tokenize）（引入）导入文件中的 （引入）。支持项目引用（@project）、子目录路径（:: 分隔符）、别名（: alias）、.so 扩展索引加载。实现去重和段管理。

                        // 按优先级搜索 .（cr） 文件：源码目录 -> （src）/（stdlib）/ -> （src）/（runtime）/ -> （src）/（compiler）/ -> 当前目录
                        令 文件路径 = 源码目录 + 文件系统路径 + ".（cr）"

                            令 文件路径 = "（src）/（runtime）/" + 文件系统路径 + ".（cr）"

                            令 文件内容 = 读取文件（文件路径）

                            令 文件路径 = 文件系统路径 + ".（cr）"

                            跳出循环
                        令 模块扫描索引 = 模块扫描索引 + 1

                        令 词法单元索引 = 解析位置
                        继续下一次循环

                    输出（"  -> "）
                    输出行（文件路径）

                    令 段字节偏移（seg_byte） = 主文件源码长度 + 总累积字节数 + 本轮累积字节数 + 1
                    扩展段数组（段计数 + 1）

                继续下一次循环    // 跳到下一个词法单元

            跳出循环    // 没有新 （import），导入解析完成

        // 有新导入：将新发现文件的源码追加到总源码末尾，重分词

            令 当前源码字符串 = 当前源码字符串 + 本轮累积源码
            分词（当前源码字符串）
            令 总累积字节数 = 总累积字节数 + 本轮累积字节数

    // 导入解析已全部完成，移除预置的 （_import.cr） 内容以防止被当作代码解析
    // （否则类型检查器会报虚假错误，IR 生成可能崩溃）
    如果 字符串长度（引入累积）大于 0，那么：
        令 跳过字节数（skip） = 字符串长度（引入累积）+ 1    //（n）+1 是预置时的 "\（数量）" 分隔符

        分词（当前源码字符串）

    构建行号到文件映射（）
