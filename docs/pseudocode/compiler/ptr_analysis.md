# ptr_analysis.cr 伪代码
> 源文件：源指针集（src）/compiler/ptr_analysis.cr（283 行）
> 功能概要：指针分析（Pointer Analysis）pass。基于 安德森风格（Andersen）的包含约束（inclusion constraints）在数据流图上执行过程间指针分析（points-to analysis）。实现规则：Addr（分配/引用 → 自指）、Copy（加载/存储沿定义-使用链传播指针集）、Store（指针变量→值变量（v） → 将 值变量 的指针集合并到 p 指向的每个分配的 分配指针集）、Load（结果→指针变量（r=*p） → 将 指针变量 指向的每个分配的 分配指针集 合并到 r）、PHI（合并两个前驱的指针集）、Call（保守处理）。采用不动点迭代至收敛（上限 10 次）。

## 函数 指针分析：判断 不安全块内（pa_in_unsafe）

### 作用
判断给定数据流节点序号是否位于 不安全区域（SG_UNSAFE）内。在 不安全块内时抑制指针跟踪。

### 逻辑

    函数 指针分析：判断 不安全块内（节点序号 node_seq：整数）-> 整数：
        令 结构图索引（si） = 0（可变）
        循环：
            如果 结构图索引 大于等于 结构图计数，那么：
                跳出循环
            令 结构图类别（kind） = 读 64 位（r64）（源 = 结构图数组，偏移 = 结构图索引 * 结构图条目大小 + 类别字段偏移）
            如果 结构图类别 等于 不安全区域（SG_UNSAFE），那么：
                令 结构图节点起始（nstart） = 读 64 位（r64）（源 = 结构图数组，偏移 = 结构图索引 * 结构图条目大小 + 节点起始字段偏移）
                令 结构图节点计数（ncount） = 读 64 位（r64）（源 = 结构图数组，偏移 = 结构图索引 * 结构图条目大小 + 节点计数字段偏移）
                如果 节点序号 大于等于 结构图节点起始 且 节点序号 小于 结构图节点起始 + 结构图节点计数，那么：
                    返回 1
            令 结构图索引 = 结构图索引 + 1
        返回 0

### 测试要点
1. 节点在 不安全区域范围内返回 1；否则返回 0。
2. 无任何 SG 区域时返回 0。
3. 与 来源验证：判断 不安全块内（pv_is_in_unsafe） 逻辑相同。

## 函数 扩展分配指针集数组（grow_alloc_pts）

### 作用
确保分配指针集数组容量大于等于 需要容量。初始最小容量为 16。

### 逻辑

    函数 扩展分配指针集数组（需要容量（n）：整数）：
        令 目标容量（nc） = 分配指针集容量
        如果 目标容量 等于 0，那么：令 目标容量 = 16
        循环：
            如果 目标容量 大于 需要容量，那么：跳出循环
            令 目标容量 = 目标容量 * 2
        令 新缓冲区（nb） = 分配内存（目标容量 * 8）
        如果 分配指针集容量 大于 0，那么：
            内部：动态拷贝（_dyncpy）（源 = 分配指针集，大小 = 分配指针集容量 * 8，目标 = 新缓冲区）
        令 分配指针集 = 新缓冲区
        令 分配指针集容量 = 目标容量

### 测试要点
1. 首次调用时初始容量 16。
2. 需要容量 小于容量时不扩展。
3. 扩展后旧数据保留。

## 函数 指针分析：位置位（pa_set_bit）

### 作用
在位图中设置指定位置的位（0-63）。通过乘法构造掩码然后加法置位（模拟位或运算）。返回置位后的位图值。

### 逻辑

    函数 指针分析：位置位（位图（bitmap）：整数，位位置（bitpos）：整数）-> 整数：
        // 位位置：要设置的位（0-63）
        // 通过乘法构造掩码：2^位位置 = 1 << 位位置
        令 位掩码（mask） = 1（可变）
        令 位计数（bi） = 0（可变）
        循环：
            如果 位计数 大于等于 位位置，那么：
                跳出循环
            令 位掩码 = 位掩码 * 2
            令 位计数 = 位计数 + 1
        返回 位图 + 位掩码  // 通过加法完成置位（等效于 OR）

### 测试要点
1. 位位置 = 0 → 位掩码 = 1，返回 位图+1（设置第 0 位）。
2. 位位置 = 3 → 位掩码 = 8，返回 位图+8（设置第 3 位）。
3. 若该位已置位，加法可能溢出该位向高位传播（这是该实现的已知局限，假设每位最多被设置一次）。

## 函数 指针分析：位测试（pa_has_bit）

### 作用
检查位图指定位是否已设置。

### 逻辑

    函数 指针分析：位测试（位图（bitmap）：整数，位位置（bitpos）：整数）-> 整数：
        令 位掩码（mask） = 1（可变）
        令 位计数（bi） = 0（可变）
        循环：
            如果 位计数 大于等于 位位置，那么：
                跳出循环
            令 位掩码 = 位掩码 * 2
            令 位计数 = 位计数 + 1
        返回 （位图 / 位掩码） % 2

### 测试要点
1. 位未设置时 （位图/位掩码）%2 = 0。
2. 位已设置时 （位图/位掩码）%2 = 1。
3. 位位置 = 0 测试最低位，位位置 = 63 测试最高位。

## 函数 指针分析：合并点集（pa_merge_pts）

### 作用
将源变量的指针集位图合并到目标变量的指针集位图中（位或操作）。若目标变量指针集发生变化则写回并返回 1，否则返回 0。

### 逻辑

    函数 指针分析：合并点集（目标变量 dst_var：整数，源变量 src_var：整数）-> 整数：
        如果 目标变量 小于 0 或 源变量 小于 0，那么：
            返回 0
        如果 指针集容量 小于等于 目标变量，那么：扩展指针集数组（grow_pts）（目标变量 + 1）
        如果 指针集容量 小于等于 源变量，那么：扩展指针集数组（源变量 + 1）
        令 目标指针集（dst） = 读 64 位（r64）（源 = 指针集数组，偏移 = 目标变量 * 8）
        令 源指针集（src） = 读 64 位（r64）（源 = 指针集数组，偏移 = 源变量 * 8）
        如果 源指针集 等于 0，那么：返回 0
        // 位或操作：从目标出发，将源中置位但目标未置位的位逐一添加
        令 输出值（out_val） = 目标指针集（可变）
        令 变化标记（changed） = 0（可变）
        令 位掩码（mask） = 1（可变）
        令 位计数（bi） = 0（可变）
        循环：
            如果 位计数 大于等于 64，那么：
                跳出循环
            如果 （源指针集 / 位掩码） % 2 等于 1 且 （输出值 / 位掩码） % 2 等于 0，那么：
                令 输出值 = 输出值 + 位掩码
                令 变化标记 = 1
            令 位掩码 = 位掩码 * 2
            令 位计数 = 位计数 + 1
        如果 变化标记 不等于 0，那么：
            写 64 位（w64）（目标 = 指针集数组，偏移 = 目标变量 * 8，值 = 输出值）
        返回 变化标记

### 测试要点
1. 两个变量的指针集相同时返回 0（无变化）。
2. 源指针集为空（0）时返回 0。
3. 目标指针集全 0 且源有值：目标变为源的副本，返回 1。
4. 目标已有部分位，源有额外位：合并后返回 1。
5. 目标变量或源变量为负时返回 0。

## 函数 指针分析：合并分配点集（pa_merge_alloc_pts）

### 作用
将分配点 分配序号（alloc_seq） 的分配指针集（g_alloc_pts）合并到变量 目标变量（dst_var） 的指针集中。用于 安德森加载规则（Andersen Load） 规则（*p 读取时从分配内容传播指针集）。

### 逻辑

    函数 指针分析：合并分配点集（目标变量 dst_var：整数，分配序号 alloc_seq：整数）-> 整数：
        如果 目标变量 小于 0 或 分配序号 小于 0，那么：
            返回 0
        如果 指针集容量 小于等于 目标变量，那么：扩展指针集数组（目标变量 + 1）
        如果 分配指针集容量 小于等于 分配序号，那么：扩展分配指针集数组（分配序号 + 1）
        令 源指针集（src） = 读 64 位（r64）（源 = 分配指针集，偏移 = 分配序号 * 8）
        如果 源指针集 等于 0，那么：返回 0
        令 前值（prev） = 读 64 位（r64）（源 = 指针集数组，偏移 = 目标变量 * 8）
        令 变化标记（changed） = 0（可变）
        令 位掩码（mask） = 1（可变）
        令 位计数（bi） = 0（可变）
        循环：
            如果 位计数 大于等于 64，那么：
                跳出循环
            如果 （源指针集 / 位掩码） % 2 等于 1 且 （前值 / 位掩码） % 2 等于 0，那么：
                令 前值 = 指针分析：位置位（pa_set_bit）（前值，位计数）
                令 变化标记 = 1
            令 位掩码 = 位掩码 * 2
            令 位计数 = 位计数 + 1
        如果 变化标记 不等于 0，那么：
            写 64 位（w64）（目标 = 指针集数组，偏移 = 目标变量 * 8，值 = 前值）
        返回 变化标记

### 测试要点
1. 分配序号对应的分配指针集为空时返回 0。
2. 正常合并后目标变量指针集增加分配指针集中的位。
3. 目标变量或分配序号为负时返回 0。

## 函数 指针分析：存储到分配（pa_store_to_alloc）

### 作用
将源变量的指针集写入分配点的分配指针集中。实现 安德森存储规则（Andersen Store） 规则：指针变量 → 值变量 时，值变量（v） 的指针集合并到 指针变量（p） 指向的每个分配的 分配指针集。

### 逻辑

    函数 指针分析：存储到分配（分配序号 alloc_seq：整数，源变量 src_var：整数）-> 整数：
        令 源指针集（src） = 读 64 位（r64）（源 = 指针集数组，偏移 = 源变量 * 8）
        如果 源指针集 等于 0，那么：返回 0
        扩展分配指针集数组（分配序号 + 1）
        令 前值（prev） = 读 64 位（r64）（源 = 分配指针集，偏移 = 分配序号 * 8）
        令 变化标记（changed） = 0（可变）
        令 位掩码（mask） = 1（可变）
        令 位计数（bi） = 0（可变）
        循环：
            如果 位计数 大于等于 64，那么：
                跳出循环
            如果 （源指针集 / 位掩码） % 2 等于 1 且 （前值 / 位掩码） % 2 等于 0，那么：
                令 前值 = 指针分析：位置位（pa_set_bit）（前值，位计数）
                令 变化标记 = 1
            令 位掩码 = 位掩码 * 2
            令 位计数 = 位计数 + 1
        如果 变化标记 不等于 0，那么：
            写 64 位（w64）（目标 = 分配指针集，偏移 = 分配序号 * 8，值 = 前值）
        返回 变化标记

### 测试要点
1. 源变量指针集为空时返回 0。
2. 正常合并后分配指针集增加源变量指针集的位。
3. 重复存储相同指针不改变状态（changed = 0）。

## 函数 指针分析：加载（pa_load）

### 作用
实现 安德森加载规则（Andersen Load） 规则：结果 → 指针变量。对指针集位图（pts_ptr）中每个置位的分配点，将其 分配指针集 合并到目标变量的指针集中。

### 逻辑

    函数 指针分析：加载（解引用节点 deref_node：整数，目标变量 dst_var：整数，指针变量 ptr_var：整数）-> 整数：
        令 变化标记（changed） = 0（可变）
        令 指针集位图（pts_ptr） = 读 64 位（r64）（源 = 指针集数组，偏移 = 指针变量 * 8）
        令 位掩码（mask） = 1（可变）
        令 位计数（bi） = 0（可变）
        循环：
            如果 位计数 大于等于 64，那么：
                跳出循环
            如果 （指针集位图 / 位掩码） % 2 等于 1，那么：
                如果 指针分析：合并分配点集（pa_merge_alloc_pts）（目标变量，位计数） 不等于 0，那么：
                    令 变化标记 = 1
            令 位掩码 = 位掩码 * 2
            令 位计数 = 位计数 + 1
        返回 变化标记

### 测试要点
1. 指针变量的指针集为空（0）：不执行任何合并，返回 0。
2. 指针变量指向单个分配，该分配有 分配指针集 内容：合并后返回 1。
3. 指针变量指向多个分配：逐一合并每个分配的 分配指针集。
4. 解引用节点（deref_node） 参数仅用于记录（当前实现未使用其值）。

## 函数 指针分析函数（ptr_analysis_func）

### 作用
对单个函数执行 安德森风格（Andersen）指针分析。采用不动点迭代（最多 10 次）直至指针集不再变化。在一个迭代中遍历所有数据流节点，根据操作码应用对应规则：
- 地址规则（Addr）：标量分配（ALLOC）/结构体分配（ALLOC_STRUCT）/数组分配（ALLOC_ARRAY） → 自指针（位 0 置位），偏移量清零。
- 拷贝规则（Copy）：引用（REF）/索引地址（ADDR_INDEX） → 传播指针集和偏移量；加载（LOAD）/存储（STORE） → 沿定义-使用链传播。
- 指针加法/指针减法 → 传播指针集并计算常量偏移（来源验证增强（Prov-GC） 增强）。
- 合并节点（PHI） → 合并两个前驱的指针集，近似偏移量为 0。
- 调用（CALL） → 保守处理（指针集保持不变）。
- 存储规则（Store）（IR_STORE_PTR）：指针变量→值变量（*指针（ptr）=值（val）） → 分配指针集 合并。
- 加载规则（Load）（IR_DEREF）：结果 → 指针变量 → 合并 指针变量 指针集 + 合并 分配指针集 内容。

### 逻辑

    函数 指针分析函数（节点起始 nstart：整数，节点计数 ncount：整数，变量起始 vstart：整数，变量计数 vcount：整数）：
        // ── 初始化该函数各变量的指针集和偏移量 ──
        令 变量索引（vi） = 0（可变）
        循环：
            如果 变量索引 大于等于 变量计数，那么：
                跳出循环
            令 变量索引（var_idx） = 变量起始 + 变量索引
            扩展指针集数组（变量索引 + 1）
            写 64 位（w64）（目标 = 指针集数组，偏移 = 变量索引 * 8，值 = 0）
            扩展偏移量数组（grow_offsets）（变量索引 + 1）
            写 64 位（w64）（目标 = 偏移量数组，偏移 = 变量索引 * 8，值 = 0）
            令 变量索引 = 变量索引 + 1

        // ── 不动点迭代 ──
        令 变化标记（changed） = 1（可变）
        令 迭代计数（iter） = 0（可变）
        循环：
            如果 变化标记 等于 0，那么：跳出循环
            如果 迭代计数 大于等于 10，那么：跳出循环  // 安全上限
            令 变化标记 = 0
            令 迭代计数 = 迭代计数 + 1

            令 当前节点序号（ni） = 节点起始（可变）
            循环：
                如果 当前节点序号 大于等于 节点起始 + 节点计数，那么：跳出循环

                令 操作码（op） = 读 64 位（r64）（源 = 数据流节点数组，偏移 = 当前节点序号 * 数据流节点条目大小 + 操作码字段偏移）
                令 目标变量（d_dest） = 读 64 位（r64）（源 = 数据流节点数组，偏移 = 当前节点序号 * 数据流节点条目大小 + 目标字段偏移）
                令 操作数1（s1） = 读 64 位（r64）（源 = 数据流节点数组，偏移 = 当前节点序号 * 数据流节点条目大小 + 操作数1字段偏移）
                令 操作数2（s2） = 读 64 位（r64）（源 = 数据流节点数组，偏移 = 当前节点序号 * 数据流节点条目大小 + 操作数2字段偏移）
                令 操作数3（s3） = 读 64 位（r64）（源 = 数据流节点数组，偏移 = 当前节点序号 * 数据流节点条目大小 + 操作数3字段偏移）

                // 在 不安全块内：抑制指针跟踪
                如果 指针分析：判断 不安全块内（pa_in_unsafe）（当前节点序号） 不等于 0，那么：
                    令 当前节点序号 = 当前节点序号 + 1
                    继续下一次循环

                如果 目标变量 大于等于 0，那么：
                    // ── 地址规则（Addr）：标量分配/引用/索引地址 → 自指针 ──
                    如果 操作码 等于 标量分配（IR_ALLOC） 或 操作码 等于 结构体分配（IR_ALLOC_STRUCT） 或 操作码 等于 数组分配（IR_ALLOC_ARRAY），那么：
                        如果 读 64 位（r64）（源 = 指针集数组，偏移 = 目标变量 * 8） 等于 0，那么：
                            写 64 位（w64）（目标 = 指针集数组，偏移 = 目标变量 * 8，值 = 1）
                            令 变化标记 = 1
                        写 64 位（w64）（目标 = 偏移量数组，偏移 = 目标变量 * 8，值 = 0）

                    如果 操作码 等于 引用（IR_REF） 且 操作数1 大于等于 0，那么：
                        如果 指针分析：合并点集（pa_merge_pts）（目标变量，操作数1） 不等于 0，那么：令 变化标记 = 1
                        // 偏移量传播
                        写 64 位（w64）（目标 = 偏移量数组，偏移 = 目标变量 * 8，值 = 读 64 位（r64）（源 = 偏移量数组，偏移 = 操作数1 * 8））

                    如果 操作码 等于 索引地址（IR_ADDR_INDEX） 且 操作数1 大于等于 0，那么：
                        如果 指针分析：合并点集（目标变量，操作数1） 不等于 0，那么：令 变化标记 = 1
                        写 64 位（w64）（目标 = 偏移量数组，偏移 = 目标变量 * 8，值 = 读 64 位（r64）（源 = 偏移量数组，偏移 = 操作数1 * 8））

                    // ── 指针算术：传播指针集并计算偏移量 ──
                    如果 操作码 等于 二元运算（IR_BINARY） 且 （操作数3 等于 指针加法（OP_PTR_ADD） 或 操作数3 等于 指针减法（OP_PTR_SUB）） 且 操作数1 大于等于 0，那么：
                        如果 指针分析：合并点集（目标变量，操作数1） 不等于 0，那么：令 变化标记 = 1
                        // 来源验证增强（Prov-GC）：精确计算常量偏移
                        令 基础偏移量（base_off） = 读 64 位（r64）（源 = 偏移量数组，偏移 = 操作数1 * 8）
                        令 偏移值（off_val） = 0（可变）
                        // 检查操作数2 是否来自一个常量指令
                        如果 操作数2 大于等于 0，那么：
                            令 生产者节点（prod） = 读 64 位（r64）（源 = 变量生产者节点映射，偏移 = 操作数2 * 8）
                            如果 生产者节点 大于等于 0，那么：
                                令 生产者操作码（prod_op） = 读 64 位（r64）（源 = 数据流节点数组，偏移 = 生产者节点 * 数据流节点条目大小 + 操作码字段偏移）
                                如果 生产者操作码 等于 常量（IR_CONST），那么：
                                    令 偏移值 = 读 64 位（r64）（源 = 数据流节点数组，偏移 = 生产者节点 * 数据流节点条目大小 + 操作数1字段偏移）
                        如果 操作数3 等于 指针加法，那么：
                            写 64 位（w64）（目标 = 偏移量数组，偏移 = 目标变量 * 8，值 = 基础偏移量 + 偏移值 * 8）
                        否则：
                            写 64 位（w64）（目标 = 偏移量数组，偏移 = 目标变量 * 8，值 = 基础偏移量 - 偏移值 * 8）

                    // ── 拷贝规则（Copy）：加载/存储 沿定义-使用链传播 ──
                    如果 （操作码 等于 加载（IR_LOAD） 或 操作码 等于 存储（IR_STORE）） 且 操作数1 大于等于 0，那么：
                        如果 指针分析：合并点集（目标变量，操作数1） 不等于 0，那么：令 变化标记 = 1
                        写 64 位（w64）（目标 = 偏移量数组，偏移 = 目标变量 * 8，值 = 读 64 位（r64）（源 = 偏移量数组，偏移 = 操作数1 * 8））

                    // ── 合并节点（PHI）：合并两个前驱的指针集 ──
                    如果 操作码 等于 合并节点（IR_PHI），那么：
                        如果 操作数1 大于等于 0 且 指针分析：合并点集（目标变量，操作数1） 不等于 0，那么：令 变化标记 = 1
                        如果 操作数2 大于等于 0 且 指针分析：合并点集（目标变量，操作数2） 不等于 0，那么：令 变化标记 = 1
                        写 64 位（w64）（目标 = 偏移量数组，偏移 = 目标变量 * 8，值 = 0）  // 合并后近似偏移

                    // ── 调用（CALL）：保守处理 ──
                    如果 操作码 等于 调用（IR_CALL），那么：
                        写 64 位（w64）（目标 = 偏移量数组，偏移 = 目标变量 * 8，值 = 0）

                // ── 存储规则（Store）：指针变量 → 值变量（Andersen） — 操作数1 = 指针, 操作数2 = 值 ──
                如果 操作码 等于 指针存储（IR_STORE_PTR） 且 操作数1 大于等于 0 且 操作数2 大于等于 0，那么：
                    如果 指针分析：存储（pa_store）（操作数1，操作数2） 不等于 0，那么：令 变化标记 = 1

                // ── 加载规则（Load）：结果 → 指针变量（Andersen） — 目标变量 = 目标, 操作数1 = 指针 ──
                如果 操作码 等于 解引用（IR_DEREF） 且 目标变量 大于等于 0 且 操作数1 大于等于 0，那么：
                    // 同时传播指针集的保守基
                    如果 指针分析：合并点集（目标变量，操作数1） 不等于 0，那么：令 变化标记 = 1
                    // 合并每个指向对象的分配内容
                    如果 指针分析：加载（pa_load）（当前节点序号，目标变量，操作数1） 不等于 0，那么：令 变化标记 = 1

                令 当前节点序号 = 当前节点序号 + 1

### 测试要点
1. 空函数（ncount = 0）：初始化变量后直接结束迭代（变化标记 = 1 但内层循环不执行，下一轮变化标记 = 0 跳出）。
2. 单 标量分配 指令：目标变量 指针集 置 1（自指针），偏移量 0，第一轮 变化标记 = 1，第二轮 变化标记 = 0。
3. 引用链：标量分配 → 引用 → 引用：指针集沿链传播，至少需 2 次迭代收敛（步长传播）。
4. 存储-加载对：指针存储 + 解引用，存储写入 分配指针集，加载从 分配指针集 读出。
5. 常量指针算术：常量（5） + 二元运算（指针加法） → 偏移量 = 基础偏移量 + 5*8。
6. 变量指针算术：操作数2 来自非 常量 指令时偏移值 = 0。
7. 不安全块内的节点跳过所有指针跟踪逻辑。
8. 迭代次数安全上限为 10（防止无限循环）。
9. 合并节点 合并两个前驱后偏移量归零（保守近似）。

## 函数 指针分析全部（ptr_analysis_all）

### 作用
对所有 IR 函数逐一调用 指针分析函数（ptr_analysis_func）。

### 逻辑

    函数 指针分析全部：
        令 函数序号（fi） = 0（可变）
        循环：
            如果 函数序号 大于等于 IR 函数个数，那么：
                跳出循环
            令 节点起始（nstart） = 读 64 位（r64）（源 = 数据流图各函数节点起始索引，偏移 = 函数序号 * 8）
            令 节点计数（ncount） = 读 64 位（r64）（源 = 数据流图各函数节点计数，偏移 = 函数序号 * 8）
            令 变量起始（vstart） = 读 64 位（r64）（源 = IR 函数变量起始索引数组，偏移 = 函数序号 * 8）
            令 变量计数（vcount） = 读 64 位（r64）（源 = IR 函数变量计数数组，偏移 = 函数序号 * 8）
            指针分析函数（ptr_analysis_func）（节点起始，节点计数，变量起始，变量计数）
            令 函数序号 = 函数序号 + 1

### 测试要点
1. 无 IR 函数时循环不执行。
2. 每个函数独立分析，各自的变量索引范围和节点范围不重叠。
3. 分配指针集 在函数间不重置（支持跨函数指针传播的累积效果）。
