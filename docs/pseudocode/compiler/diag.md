## 函数 读取源码行（read_source_line）
### 作用
从当前源码字符串（g_source）中按行号（从 1 开始）提取指定行的文本内容。用于诊断输出时显示出错行的源码。

### 逻辑
函数 读取源码行（read_source_line）（行号（line）：整数）-> 字符串：
    令 源码长度（slen） = 字符串长度（当前源码字符串）
    令 当前行号计数器（cur） = 1
    令 行起始位置（start） = 0
    令 扫描索引（i） = 0

    循环（当 扫描索引 小于 源码长度 时）：
        如果 当前行号计数器 等于 行号，那么：
            令 行尾扫描索引（j） = 扫描索引
            循环（当 行尾扫描索引 小于 源码长度 时）：
                令 当前字符（c） = 取字符串第（N）字符（当前源码字符串，行尾扫描索引）
                如果 当前字符 等于（换行符 "\数量（n）"），那么：跳出循环
                令 行尾扫描索引 = 行尾扫描索引 + 1
            返回 字符串切片（当前源码字符串，扫描索引，行尾扫描索引 - 扫描索引）
        如果 读字节（load8）（当前源码字符串，扫描索引）等于 10，那么：    // 换行符
            令 当前行号计数器 = 当前行号计数器 + 1
            令 行起始位置 = 扫描索引 + 1
        令 扫描索引 = 扫描索引 + 1
    返回 ""

### 测试要点
1. 请求第 1 行时返回源文件首行内容
2. 请求超出总行数的行号时返回空字符串
3. 空源文件请求任意行号返回空字符串
4. 行内容不含换行符时返回该行全部内容

## 函数 源码行数（source_line_count）
### 作用
统计当前源码字符串（g_source）的总行数（从 1 开始计数）。用于诊断输出时判断行号是否有效。

### 逻辑
函数 源码行数（source_line_count）（） -> 整数：
    令 计数 = 1
    令 扫描索引（i） = 0
    令 源码长度（slen） = 字符串长度（当前源码字符串）
    循环（当 扫描索引 小于 源码长度 时）：
        如果 读字节（load8）（当前源码字符串，扫描索引）等于 10，那么：    // 换行符
            令 计数 = 计数 + 1
        令 扫描索引 = 扫描索引 + 1
    返回 计数

### 测试要点
1. 空源文件返回 1（至少一行）
2. 单行无换行符返回 1
3. 含（N）个换行符的源文件返回（次数）+1

## 函数 打印源码行（print_source_line）
### 作用
输出指定行的源码内容，并在指定列下方打印 "^" 标注和注解信息（截断至 48 字符或首个 （em dash）全角破折号 之前）。若行号小于等于 0 或源码行为空则直接返回。

### 逻辑
函数 打印源码行（print_source_line）（行号（line）：整数，列号（col）：整数，注解（annotation）：字符串）：
    如果 行号 小于等于 0，那么：
        返回

    令 行文本（ltxt） = 读取源码行（行号）
    如果 字符串长度（行文本）等于 0，那么：
        返回

    // 格式化输出行号（右对齐两位）
    令 行号字符串（ln_str） = 整数转字符串（行号）
    如果 行号 小于 10，那么：
        令 行号字符串 = " " + 行号字符串

    输出（行号字符串）
    输出（" | "）
    输出行（行文本）

    // 输出下划线（空格 + "^"）
    输出（"   | "）
    令 列偏移（ci） = 0
    循环（当 列偏移 小于 列号 - 1 时）：
        输出（" "）
        令 列偏移 = 列偏移 + 1
    输出（"^"）

    // 输出注解（截断处理）
    如果 字符串长度（注解）大于 0，那么：
        输出（" "）
        令 注解长度（alen） = 字符串长度（注解）
        令 截断位置（cutoff） = 注解长度

        // 找到首个 （em dash）全角破折号（U+2014，UTF-8 编码为 3 字节：E2 80 94）的位置作为截断点
        令 注解扫描索引（ci2） = 0
        循环（当 注解扫描索引 + 3 小于等于 注解长度 时）：
            如果 读字节（load8）（注解，注解扫描索引）等于 226，那么：    // （em dash）全角破折号 起始字节
                令 截断位置 = 注解扫描索引
                跳出循环
            令 注解扫描索引 = 注解扫描索引 + 1

        // 最多 48 字符
        如果 截断位置 大于 48，那么：
            令 截断位置 = 48

        输出（字符串切片（注解，0，截断位置））

    输出行（""）

### 测试要点
1. 行号小于等于 0 时直接返回，不输出任何内容
2. 源码行为空字符串时直接返回，不输出
3. 列号为 1 时 "^" 在行首位置
4. 注解含 （em dash）全角破折号（U+2014）时在 （em dash）全角破折号 前截断
5. 注解超过 48 字符时截断至 48 字符
6. 行号小于 10 时行号前缀补空格实现右对齐

## 函数 错误类别前缀（error_cat_prefix）
### 作用
将错误类别整数编码映射为缩写字母前缀字符串，用于诊断输出中的错误编号格式化（如（"P"）代表解析错误，（"TB"）代表类型借用错误，（"ICE"）代表内部编译器错误）。

### 逻辑
函数 错误类别前缀（error_cat_prefix）（类别（cat）：整数）-> 字符串：
    如果 类别 等于 1，那么：返回（"P"）
    如果 类别 等于 2，那么：返回（"次数（N）"）
    如果 类别 等于 3，那么：返回（"I"）
    如果 类别 等于 4，那么：返回（"TA"）
    如果 类别 等于 5，那么：返回（"TF"）
    如果 类别 等于 6，那么：返回（"TB"）
    如果 类别 等于 7，那么：返回（"TU"）
    如果 类别 等于 8，那么：返回（"TC"）
    如果 类别 等于 9，那么：返回（"TM"）
    如果 类别 等于 10，那么：返回（"TK"）
    如果 类别 等于 11，那么：返回（"TS"）
    如果 类别 等于 12，那么：返回（"TG"）
    如果 类别 等于 13，那么：返回（"B"）
    如果 类别 等于 14，那么：返回（"R"）
    如果 类别 等于 15，那么：返回（"错误（E）"）
    如果 类别 等于 16，那么：返回（"ICE"）
    返回（"错误（E）"）

### 测试要点
1. 类别 1 返回（"P"）（解析错误）
2. 类别 4 返回（"TA"）（类型参数错误）
3. 类别 6 返回（"TB"）（类型借用错误）
4. 类别 16 返回（"ICE"）（内部编译器错误）
5. 未定义的类别值（如 0、99）返回（"错误（E）"）

## 函数 诊断编号填充（pad_diag_num）
### 作用
将诊断编号格式化为至少两位数的字符串（不足两位前面补 "0"）。

### 逻辑
函数 诊断编号填充（pad_diag_num）（编号（num）：整数）-> 字符串：
    令 编号字符串 = 整数转字符串（编号）
    如果 编号 小于 10，那么：
        令 编号字符串 = "0" + 编号字符串
    返回 编号字符串

### 测试要点
1. 编号 0 返回 "00"
2. 编号 9 返回 "09"
3. 编号 10 返回 "10"
4. 编号 99 返回 "99"

## 函数 打印诊断信息（print_diagnostics）
### 作用
遍历诊断数组（g_diags），按（Rust）风格格式化输出所有类型检查/语义诊断信息：包括错误编号（类别前缀 + 填充编号）、错误消息、源码位置以及带下划线标注的源码行。

### 逻辑
函数 打印诊断信息（print_diagnostics）（）：
    如果 诊断计数 等于 0，那么：
        返回

    令 总行数 = 源码行数（）
    令 诊断索引（di） = 0

    循环（当 诊断索引 小于 诊断计数 时）：
        // 每条诊断占 32 字节：[错误码（8）] [消息指针（8）] [行号（8）] [列号（8）]
        令 错误码（ec） = 读 64 位（诊断数组，诊断索引 * 32）
        令 消息（msg） = 加载字符串指针（load_str_ptr）（诊断数组，诊断索引 * 32 + 8）
        令 行号（ln） = 读 64 位（诊断数组，诊断索引 * 32 + 16）
        令 列号（cl） = 读 64 位（诊断数组，诊断索引 * 32 + 24）
        令 类别（cat） = 错误码 / 1000
        令 编号（num） = 错误码 取余 1000

        输出（（错误前缀 "error["））
        输出（错误类别前缀（类别））
        输出（诊断编号填充（编号））
        输出（"]: "）
        输出行（消息）

        输出（" --> "）
        输出（整数转字符串（行号））
        输出（":"）
        输出行（整数转字符串（列号））

        如果 行号 大于 0 且 行号 小于等于 总行数，那么：
            输出行（"   |"）
            打印源码行（行号，列号，消息）

        输出行（""）
        令 诊断索引 = 诊断索引 + 1

### 测试要点
1. 诊断计数为 0 时直接返回，不输出任何内容
2. 单条诊断正确显示（"error["）加类别前缀编号加（"]: "）加消息格式
3. 行号超出源码总行数时跳过源码行展示，不崩溃
4. 行号小于等于 0 时跳过源码行展示
5. 多条诊断按序输出，每条之间有空行分隔

## 函数 打印解析错误（print_parse_errors）
### 作用
遍历解析错误数组（g_errors），逐条输出解析阶段的错误消息。错误消息通过驻留字符串获取（istr_get）解码。

### 逻辑
函数 打印解析错误（print_parse_errors）（）：
    如果 错误计数 等于 0，那么：
        返回

    令 错误索引（ei2） = 0
    循环（当 错误索引 小于 错误计数 时）：
        输出行（（错误前缀 "error: "）+ 驻留字符串获取（读 64 位（错误数组，错误索引 * 8）））
        令 错误索引 = 错误索引 + 1

### 测试要点
1. 错误计数为 0 时直接返回，不输出任何内容
2. 单条错误正确输出（"error: "）加（消息）格式
3. 多条错误按序输出
