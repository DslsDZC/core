## 函数 扩展插件标签数组（grow_plugin_tags）
### 作用
当插件标签数组容量不足时，分配更大的缓冲区并拷贝现有数据。扩容策略：容量翻倍，最小 8，最小满足（需求量 + 8）。每项 24 字节。

### 逻辑
函数 扩展插件标签数组（grow_plugin_tags）（需求量（needed）：整数）：
    如果 需求量 小于 插件标签容量，那么：
        返回

    令 新容量（ncap） = 插件标签容量 * 2
    如果 新容量 小于 8，那么：令 新容量 = 8
    如果 新容量 小于 需求量，那么：令 新容量 = 需求量 + 8

    令 新缓冲（nb） = 分配内存（新容量 * 24）
    内部：动态拷贝（_dyncpy）（插件标签数组，插件标签容量 * 24，新缓冲）
    令 插件标签数组 = 新缓冲
    令 插件标签容量 = 新容量

### 测试要点
1. 需求量小于当前容量时直接返回，不分配
2. 首次扩容时容量至少为 8
3. 需求量超过翻倍容量时，新容量为需求量 + 8
4. 旧数据被完整拷贝到新缓冲区

## 函数 查找插件入口（find_plugin_entry）
### 作用
在插件注册表中线性扫描，查找匹配（命名空间名, 名称名）对的条目索引。如果命名空间名为 -1（未限定命名空间），则只要名称名匹配且条目命名空间名也小于 0 即可匹配。返回索引（大于等于 0）或 -1（未找到）。

### 逻辑
函数 查找插件入口（find_plugin_entry）（注册表（table）：字符串，统计个数（count）：整数，名称驻留索引（name_ni）：整数，命名空间驻留索引（ns_ni）：整数）-> 整数：
    如果 统计个数 小于等于 0，那么：
        返回 -1

    令 搜索索引（i） = 0
    循环（当 搜索索引 小于 统计个数 时）：
        // 每项占 24 字节：[命名空间驻留索引（8）] [名称驻留索引（8）] [数据（8）]

        如果 读 64 位（注册表，搜索索引 * 24 + 8）等于 名称驻留索引 且 读 64 位（注册表，搜索索引 * 24）等于 命名空间驻留索引，那么：
            // 精确匹配：命名空间和名称同时匹配
            返回 搜索索引

        如果 读 64 位（注册表，搜索索引 * 24 + 8）等于 名称驻留索引 且 命名空间驻留索引 小于 0 且 读 64 位（注册表，搜索索引 * 24）小于 0，那么：
            // 宽松匹配：未限定命名空间时，匹配到同样无命名空间的条目
            返回 搜索索引

        令 搜索索引 = 搜索索引 + 1

    返回 -1

### 测试要点
1. 条目数为 0 时返回 -1
2. 精确匹配（命名空间名 + 名称名 都匹配）返回对应索引
3. 传入命名空间名 = -1 时，匹配到命名空间名 < 0 的条目也返回索引
4. 未匹配时返回 -1

## 函数 注册插件标签（register_plugin_tag）
### 作用
向插件标签数组中注册一个新标签。防止重复注册：同一（命名空间名, 名称名）若已存在返回 -2；有命名空间的条目不能遮蔽无命名空间条目返回 -3。成功返回 0。

### 逻辑
函数 注册插件标签（register_plugin_tag）（命名空间驻留索引（ns_ni）：整数，名称驻留索引（name_ni）：整数，数据（data）：整数）-> 整数：
    // 冲突检查：同一（命名空间, 名称）对不能重复注册
    如果 查找插件入口（插件标签数组，插件标签计数，名称驻留索引，命名空间驻留索引）大于等于 0，那么：
        返回 -2

    // 遮蔽检查：有命名空间的条目不能遮蔽已有的无命名空间条目
    如果 命名空间驻留索引 大于等于 0 且 查找插件入口（插件标签数组，插件标签计数，名称驻留索引，-1）大于等于 0，那么：
        返回 -3

    // 扩容并写入
    扩展插件标签数组（插件标签计数 + 1）
    写 64 位（插件标签数组，插件标签计数 * 24，命名空间驻留索引）
    写 64 位（插件标签数组，插件标签计数 * 24 + 8，名称驻留索引）
    写 64 位（插件标签数组，插件标签计数 * 24 + 16，数据）
    令 插件标签计数 = 插件标签计数 + 1

    返回 0

### 测试要点
1. 重复注册相同（命名空间名, 名称名）返回 -2
2. 有命名空间的条目尝试遮蔽无命名空间同名条目返回 -3
3. 成功注册后插件标签计数递增 1
4. 数据正确写入表的三字段
