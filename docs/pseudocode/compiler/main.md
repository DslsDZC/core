## 函数 判断 .（cr） 文件（is_cr_file）
### 作用
判断文件路径是否以 ".cr" 扩展名结尾。用于区分单文件模式与项目目录模式。

### 逻辑
函数 判断 .（cr） 文件（is_cr_file）（路径（path）：字符串）-> 整数：
    令 路径长度（slen） = 字符串长度（路径）
    如果 路径长度 小于 3，那么：返回 0
    令 扩展名（ext） = 字符串切片（路径，路径长度 - 3，3）
    如果 字符串相等比较（扩展名，".cr"）不等于 0，那么：返回 1
    返回 0

### 测试要点
1. 路径以 ".cr" 结尾返回 1
2. 路径不以 ".cr" 结尾（如目录名）返回 0
3. 路径长度小于 3 返回 0

## 函数 判断声明语句（is_decl_stmt）
### 作用
判断一个字符串是否是一条声明语句（含 ": " 模式，如 "变量甲（x）: 整数（int） = 1"）。跳（run）空白后，检查前导标识符后面是否跟着冒号。用于 （run） 子命令中判断最后一条表达式是声明还是表达式。

### 逻辑
函数 判断声明语句（is_decl_stmt）（输入字符串（s）：字符串）-> 整数：
    令 输入长度（slen） = 字符串长度（输入字符串）
    令 扫描索引（i） = 0

    // 跳过前导空白字符
    循环：
        如果 扫描索引 大于等于 输入长度，那么：返回 0
        令 当前字节（cb） = 读字节（load8）（输入字符串，扫描索引）
        如果 当前字节 等于 32 或 等于 9 或 等于 10 或 等于 13，那么：    // 空格、制表符、换行、回车
            令 扫描索引 = 扫描索引 + 1
        否则：
            跳出循环

    // 检查首个非空白字符是否为标识符起始字符
    如果 扫描索引 小于 输入长度，那么：
        令 当前字节（cb） = 读字节（load8）（输入字符串，扫描索引）
        如果（当前字节 大于等于 97 且 当前字节 小于等于 122）或    // 'a'-'z'
           （当前字节 大于等于 65 且 当前字节 小于等于 90）或     // 'A'-'Z'
            当前字节 等于 95，那么：    // '（_）'
            // 首个字符是标识符起始，扫描标识符后续字符
            令 标识符扫描索引（j） = 扫描索引 + 1
            循环：
                如果 标识符扫描索引 大于等于 输入长度，那么：返回 0
                令 后续字节（c2b） = 读字节（load8）（输入字符串，标识符扫描索引）
                如果 后续字节 等于 32 或 等于 9 或 等于 10 或 等于 13，那么：    // 空白
                    令 标识符扫描索引 = 标识符扫描索引 + 1
                否则如果 后续字节 等于 58，那么：    // ':'
                    返回 1
                否则如果（后续字节 大于等于 97 且 后续字节 小于等于 122）或
                        （后续字节 大于等于 65 且 后续字节 小于等于 90）或
                        （后续字节 大于等于 48 且 后续字节 小于等于 57）或    // '0'-'9'
                         后续字节 等于 95，那么：    // 标识符续字符
                    令 标识符扫描索引 = 标识符扫描索引 + 1
                否则：
                    返回 0    // 非法字符
    返回 0

### 测试要点
1. "（x）: （int） = 1" 返回 1（是声明）
2. "（x） = 1" 返回 0（不是声明，无冒号）
3. "fn main()" 返回 0（函数定义不是声明语句）
4. 纯空白字符串返回 0
5. 以数字开头的字符串返回 0（不是有效标识符）
