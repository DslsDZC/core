## 函数 压入循环标签列表（looplabels）（push_loop_labels）

### 作用
记录当前循环的头部标签和出口标签，压入循环标签列表（looplabels）栈，用于 跳出循环（break）和 继续下一次循环（continue）指令生成。同时递增IR 循环嵌套深度。

### 逻辑
接收 头部标签（header）：整数，出口标签（exit）：整数
扩展 IR 循环栈数组（grow_ir_loop_stacks）（IR 循环嵌套深度（g_ir_loop_depth） + 1）
在 IR 循环头标签栈（g_ir_loop_header）偏移（IR 循环嵌套深度 * 8）处写入 64 位值：头部标签
在 IR 循环出口标签栈（g_ir_loop_exit）偏移（IR 循环嵌套深度 * 8）处写入 64 位值：出口标签
令 IR 循环嵌套深度 = IR 循环嵌套深度 + 1

### 测试要点
1. 记录头部和出口标签到当前深度
2. IR 循环嵌套深度递增
3. 嵌套循环时，跳出（break）/继续（continue） 总是引用最近压入的循环标签

---

## 函数 弹出循环标签列表（looplabels）（pop_loop_labels）

### 作用
退出当前循环时调用，递减IR 循环嵌套深度。

### 逻辑
令 IR 循环嵌套深度（g_ir_loop_depth） = IR 循环嵌套深度 - 1

### 测试要点
1. 退出循环后 跳出（break）/继续（continue） 引用上一级循环的标签
2. 深度不能减至负数

## 函数 获取变体名索引（get_variant_name_idx）

### 作用
从完全限定名（如 "Color.Red"）中提取最后一个点号（"."）后的变体名称部分，返回其驻留字符串索引。用于 匹配（match） 枚举模式匹配的标签比较。

### 逻辑
接收 限定名索引（qualified_ni）：整数
令 限定名字符串 = 驻留字符串获取（istr_get）（限定名索引）
令 字符串字节长度 = 字符串长度（str_len）（限定名字符串）
令 点号位置 = -1
令 扫描位置 = 0
循环：
    如果 扫描位置 大于等于 字符串字节长度，那么：
        跳出循环
    令 当前字符 = 取字符串第 序号（N） 字符（get_char）（限定名字符串, 扫描位置）
    如果 字符串相等比较（str_eq）（当前字符, "."） 不等于 0，那么：
        令 点号位置 = 扫描位置
    令 扫描位置 = 扫描位置 + 1

如果 点号位置 大于等于 0，那么：
    令 变体名字符串 = 字符串切片（str_sub）（限定名字符串, 点号位置 + 1, 字符串字节长度 - 点号位置 - 1）
    返回 字符串驻留（str_intern）（变体名字符串）
返回 限定名索引（qualified_ni）

### 测试要点
1. 无点号时返回完整限定名
2. 多个点号时取最后一个点号后的部分
3. 返回的变体名经过 字符串驻留（str_intern） 转为索引

## 函数 类型信息：从类型表达式创建（ti_from_type_expr）

### 作用
将类型表达式 AST 节点解析为 IR 类型索引（类型信息：整数（TI_INT）/类型信息：浮点（TI_FLOAT） 等）。处理三类输入：解析类型（parse_type） 产生的类型节点（ast_kind 等于 0）、基本类型名标识符（EXPR_IDENT）、以及复杂类型表达式（委托给 类型检查器（checker） 的 解析类型节点（res_type_node））。

### 逻辑
接收 节点（node）：整数（类型表达式 AST 节点索引）
如果 节点 小于 0，那么：
    返回 类型信息：单元（TI_UNIT）

（情况一：类型节点——由 parse_type 产生，ast_kind 等于 0，ast_type_val 存 TY_*）
如果 AST 访问器：类别（ast_kind）（节点） 等于 0，那么：
    令 类型值 = AST 访问器：类型值（ast_type_val）（节点）
    如果 类型值 等于 整数类型（TY_INT），那么：返回 类型信息：整数（TI_INT）
    如果 类型值 等于 浮点类型（TY_FLOAT），那么：返回 类型信息：浮点（TI_FLOAT）
    如果 类型值 等于 布尔类型（TY_BOOL），那么：返回 类型信息：布尔（TI_BOOL）
    如果 类型值 等于 字符串类型（TY_STRING），那么：返回 类型信息：字符串（TI_STR）
    如果 类型值 等于 字符类型（TY_CHAR），那么：返回 类型信息：字符（TI_CHAR）
    如果 类型值 等于 单元类型（TY_UNIT），那么：返回 类型信息：单元（TI_UNIT）
    返回 类型信息：单元（TI_UNIT）

（情况二：标识符表达式（EXPR_IDENT）——基本类型名标识符）
如果 AST 访问器：类别（ast_kind）（节点） 等于 标识符表达式（EXPR_IDENT），那么：
    令 名字索引 = AST 访问器：整数值（ast_int_val）（节点）
    令 名字字符串 = 驻留字符串获取（istr_get）（名字索引）
    如果 字符串相等比较（str_eq）（名字字符串, "int"） 不等于 0，那么：返回 类型信息：整数（TI_INT）
    如果 字符串相等比较（str_eq）（名字字符串, "float"） 不等于 0，那么：返回 类型信息：浮点（TI_FLOAT）
    如果 字符串相等比较（str_eq）（名字字符串, "bool"） 不等于 0，那么：返回 类型信息：布尔（TI_BOOL）
    如果 字符串相等比较（str_eq）（名字字符串, "string"） 不等于 0，那么：返回 类型信息：字符串（TI_STR）
    如果 字符串相等比较（str_eq）（名字字符串, "char"） 不等于 0，那么：返回 类型信息：字符（TI_CHAR）
    如果 字符串相等比较（str_eq）（名字字符串, "unit"） 不等于 0，那么：返回 类型信息：单元（TI_UNIT）
    （命名类型——查符号表）
    令 符号索引 = 查找全局符号（find_gsym）（名字索引）
    如果 符号索引 大于等于 0 且 符号类别（sym_kind）（符号索引） 等于 符号：类型（SYM_TYPE），那么：
        返回 符号类型（sym_type）（符号索引）

（情况三：复杂类型表达式——委托 类型检查器（checker） 解析）
返回 解析类型节点（res_type_node）（节点）

### 测试要点
1. 无效节点（小于 0）返回 类型信息：单元（TI_UNIT）
2. 基本类型名（整数（int）/浮点（float）/布尔（bool）/字符串（string）/字符（char）/单元类型（unit））正确映射
3. 用户定义类型通过符号表查找返回
4. 复杂泛型/数组/指针类型委托给 解析类型节点（res_type_node）

## 函数 类型大小（type_size）

### 作用
根据 IR 类型索引（TI_*）返回该类型在内存中的字节大小。覆盖基本类型、数组（元素大小乘以元素数）、指针/引用（8 字节）、切片（16 字节）、命名类型（64 字节固定）。

### 逻辑
接收 类型索引（ti）：整数
如果 类型索引 等于 类型信息：字符（TI_CHAR），那么：
    返回 4（不在类型表中，特判）
如果 类型索引 小于 0 或 类型索引 大于等于 类型总数（g_type_count），那么：
    返回 8（默认）
令 类型类别 = 获取类型类别（get_type_kind）（类型索引）
如果 类型类别 等于 基础类型（TYP_BASE），那么：
    令 类型基础数据 = 获取类型数据（get_type_data）（类型索引）
    如果 类型基础数据 等于 整数类型（TY_INT），那么：返回 8
    如果 类型基础数据 等于 浮点类型（TY_FLOAT），那么：返回 8
    如果 类型基础数据 等于 布尔类型（TY_BOOL），那么：返回 1
    如果 类型基础数据 等于 字符串类型（TY_STRING），那么：返回 8
    如果 类型基础数据 等于 单元类型（TY_UNIT），那么：返回 0
    如果 类型基础数据 等于 字符类型（TY_CHAR），那么：返回 4
    返回 8
如果 类型类别 等于 数组类型（TYP_ARRAY），那么：
    令 元素类型 = 获取类型数据（get_type_data）（类型索引）
    令 元素数量 = 获取类型额外（get_type_extra）（类型索引）
    返回 类型大小（type_size）（元素类型） * 元素数量
如果 类型类别 等于 指针类型（TYP_PTR） 或 等于 引用类型（TYP_REF），那么：返回 8
如果 类型类别 等于 切片类型（TYP_SLICE），那么：返回 16
如果 类型类别 等于 具名类型（TYP_NAMED），那么：返回 64
返回 8

### 测试要点
1. 类型信息：字符（TI_CHAR） 返回 4（不在类型表中独立处理）
2. 基本类型正确映射：整数（int）/浮点（float）=8, 布尔（bool）=1, 字符串（string）=8, 单元类型（unit）=0, 字符（char）=4
3. 数组大小递归计算：元素大小乘以元素数
4. 指针/引用固定 8 字节，切片固定 16 字节
5. 未知类型索引返回默认值 8

## 函数 类型对齐（type_align）

### 作用
返回类型的字节对齐要求。逻辑与 类型大小（type_size） 类似，但数组对齐等于元素对齐（而非数组总大小）。

### 逻辑
接收 类型索引（ti）：整数
如果 类型索引 等于 类型信息：字符（TI_CHAR），那么：返回 4
如果 类型索引 小于 0 或 类型索引 大于等于 类型总数（g_type_count），那么：返回 8
令 类型类别 = 获取类型类别（get_type_kind）（类型索引）
如果 类型类别 等于 基础类型（TYP_BASE），那么：
    令 类型基础数据 = 获取类型数据（get_type_data）（类型索引）
    如果 类型基础数据 等于 整数类型（TY_INT），那么：返回 8
    如果 类型基础数据 等于 浮点类型（TY_FLOAT），那么：返回 8
    如果 类型基础数据 等于 布尔类型（TY_BOOL），那么：返回 1
    如果 类型基础数据 等于 字符串类型（TY_STRING），那么：返回 8
    如果 类型基础数据 等于 字符类型（TY_CHAR），那么：返回 4
    返回 8
如果 类型类别 等于 数组类型（TYP_ARRAY），那么：
    返回 类型对齐（type_align）（获取类型数据（get_type_data）（类型索引））
如果 类型类别 等于 指针类型（TYP_PTR） 或 等于 引用类型（TYP_REF），那么：返回 8
如果 类型类别 等于 切片类型（TYP_SLICE），那么：返回 8
如果 类型类别 等于 具名类型（TYP_NAMED），那么：返回 8
返回 8

### 测试要点
1. 数组对齐等于元素对齐（而非数组总大小）
2. 基本类型对齐与自身大小一致（除 布尔（bool） 为 1）
3. 未知类型默认 8 字节对齐

## 函数 类型信息：解析结构体（ti_resolve_struct）

### 作用
根据 IR 类型索引查找对应的结构体信息索引。仅 具名类型（TYP_NAMED）（命名类型）可解析为结构体，遍历结构体表按名称匹配。

### 逻辑
接收 类型索引（ti）：整数
如果 类型索引 小于 0 或 类型索引 大于等于 类型总数（g_type_count），那么：
    返回 -1
令 类型类别 = 获取类型类别（get_type_kind）（类型索引）
如果 类型类别 不等于 具名类型（TYP_NAMED），那么：
    返回 -1
令 类型名索引 = 获取类型数据（get_type_data）（类型索引）
如果 类型名索引 小于 0，那么：
    返回 -1
令 类型名字符串 = 驻留字符串获取（istr_get）（类型名索引）
令 扫描位置 = 0
循环：
    如果 扫描位置 大于等于 结构体总数（g_struct_count），那么：
        跳出循环
    令 结构体名索引 = 结构体信息访问器：名称（si_name）（扫描位置）
    令 结构体名字符串 = 驻留字符串获取（istr_get）（结构体名索引）
    如果 字符串相等比较（str_eq）（结构体名字符串, 类型名字符串） 不等于 0，那么：
        返回 扫描位置
    令 扫描位置 = 扫描位置 + 1
返回 -1

### 测试要点
1. 非 具名类型（TYP_NAMED） 类型直接返回 -1
2. 名称匹配时返回结构体信息索引
3. 无匹配结构体时返回 -1

## 函数 类型信息：是否有字段（ti_has_field）

### 作用
判断某个结构体类型是否包含指定名称的字段。

### 逻辑
接收 类型索引（ti）：整数，字段名（name）：字符串
令 结构体索引 = 类型信息：解析结构体（ti_resolve_struct）（类型索引）
如果 结构体索引 小于 0，那么：
    返回 0
令 字段总数 = 结构体信息访问器：字段计数（si_field_count）（结构体索引）
令 扫描位置 = 0
循环：
    如果 扫描位置 大于等于 字段总数，那么：
        跳出循环
    令 字段名索引 = 结构体信息访问器：字段名称（si_field_name）（结构体索引, 扫描位置）
    令 字段名字符串 = 驻留字符串获取（istr_get）（字段名索引）
    如果 字符串相等比较（str_eq）（字段名字符串, 字段名） 不等于 0，那么：
        返回 1
    令 扫描位置 = 扫描位置 + 1
返回 0

### 测试要点
1. 非结构体类型返回 0
2. 名称匹配时返回 1，遍历所有字段
3. 字段名比较由 字符串相等比较（str_eq） 的语义决定

## 函数 类型信息：字段偏移（ti_field_offset）

### 作用
返回结构体中指定字段的字节偏移量。当前实现中每个字段固定 8 字节，因此偏移量为 字段索引 * 8。

### 逻辑
接收 类型索引（ti）：整数，字段名（name）：字符串
令 结构体索引 = 类型信息：解析结构体（ti_resolve_struct）（类型索引）
如果 结构体索引 小于 0，那么：
    返回 -1
令 字段总数 = 结构体信息访问器：字段计数（si_field_count）（结构体索引）
令 扫描位置 = 0
循环：
    如果 扫描位置 大于等于 字段总数，那么：
        跳出循环
    令 字段名索引 = 结构体信息访问器：字段名称（si_field_name）（结构体索引, 扫描位置）
    令 字段名字符串 = 驻留字符串获取（istr_get）（字段名索引）
    如果 字符串相等比较（str_eq）（字段名字符串, 字段名） 不等于 0，那么：
        返回 扫描位置 * 8
    令 扫描位置 = 扫描位置 + 1
返回 -1

### 测试要点
1. 字段偏移量 = 字段索引 * 8（固定字段大小设计）
2. 未找到字段时返回 -1
3. 非结构体类型返回 -1

## 函数 强制 如果（if）-那么（then） 块（force_if_thunk）

### 作用
检查变量的生产者指令是否为 惰性求值指令（IR_LAZY_THUNK）（惰性求值包装）。如果是，则发射 惰性强制求值指令（IR_LAZY_FORCE） 指令将惰性值强制求值为实际值，返回新的强制求值后变量；否则直接返回原变量。

### 逻辑
接收 变量索引（var_idx）：整数
如果 变量索引 小于 0，那么：
    返回 变量索引（不做任何操作）
令 生产者节点索引 = 从 数据流变量生产者表（g_df_var_producer）偏移（变量索引 * 8）处读取 64 位
如果 生产者节点索引 大于等于 0，那么：
    令 生产者操作码 = 从 数据流节点表（g_df_nodes）偏移（生产者节点索引 * ESZ_DFNODE + OFF_DF_OPCODE）处读取 64 位
    如果 生产者操作码 等于 惰性求值指令（IR_LAZY_THUNK），那么：
        令 强制后变量 = 新建 IR 变量（new_ir_var）（"_forced", IR 变量访问器：类型（irv_type）（变量索引））
        发射指令（emit）（惰性强制求值指令（IR_LAZY_FORCE）, 强制后变量, 变量索引, 0, 0, 0）
        返回 强制后变量
返回 变量索引

### 测试要点
1. 无生产者或生产者不是 惰性求值指令（IR_LAZY_THUNK） 时返回原变量
2. 惰性求值指令（IR_LAZY_THUNK） 被 惰性强制求值指令（IR_LAZY_FORCE） 替换，新变量类型与原变量一致
3. 无效变量（小于 0）直接返回

### 测试要点
1. 无效节点（小于 0）返回 -1
2. 空值表达式（EXPR_NONE） 包装节点正确转发到内部表达式，且排除自引用循环（变量甲（a） 不等于 节点（node））
3. 整数/浮点/布尔/字符串/字符字面量生成 常量指令（IR_CONST） 指令
4. 标识符按 局部变量 → 编译时常量 → 全局变量 → 占位变量 的优先级查找
5. 赋值操作对 类型信息：动态（TI_DYN） 类型的变量使用 动态打包指令（IR_DYN_PACK） 打包
6. 与运算（OP_AND） 条件下左值为假时跳到短路标签（结果 0），跳过右值求值
7. 或运算（OP_OR） 条件下左值为真时跳到短路标签（结果 1），跳过右值求值
8. 字符串 相等/不相等 比较调用 字符串相等比较（str_eq） 函数而非直接指针比较
9. 字符串 + 调用 字符串拼接（concat） 函数
10. 指针变量的 加法指令（ADD）/减法指令（SUB） 自动转换为 指针加法（PTR_ADD）/指针减法（PTR_SUB）
11. 两个指针变量相减转换为 指针差（PTR_DIFF），用以计算元素偏移量
12. 字节缓冲变量（分配函数（alloc） 产物）的加减保持原始 加法指令（ADD）/减法指令（SUB），不缩放
13. 动态类型操作数在二元运算前通过 动态值指令（IR_DYN_VAL） 解包
