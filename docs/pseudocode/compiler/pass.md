## 函数 数组访问前处理（pass_before_array_access）
### 作用
在每次 IR_LOAD/STORE_INDEX 指令生成之前调用，允许已注册插件拦截数组访问操作。返回 0 表示正常执行访问，返回 1 表示跳过此次访问。
### 逻辑
    令 arr_var = 参数 0（数组变量索引）
    令 idx_var = 参数 1（索引变量索引）
    令 idx_lit = 参数 2（字面量索引值）
    令 arr_len_lit = 参数 3（数组长度字面量）
    返回 扩展：分发数组访问（arr_var, idx_var, idx_lit, arr_len_lit）
### 测试要点
1. 当无任何插件注册时，返回 0（正常执行访问）
2. 当有插件返回 1 时，该次数组访问被跳过

## 函数 二元运算后处理（pass_after_binary）
### 作用
在每次二元运算 IR 指令生成之后调用，允许插件进行溢出检查等后处理。返回 int 值，语义由插件定义。
### 逻辑
    令 op = 参数 0（运算符操作码）
    令 lv = 参数 1（左操作数变量索引）
    令 rv = 参数 2（右操作数变量索引）
    令 result_var = 参数 3（结果变量索引）
    返回 扩展：分发二元运算（op, lv, rv, result_var）
### 测试要点
1. 无插件注册时返回默认值（0）
2. 溢出检查插件可在此拦截并添加诊断信息

## 函数 分发调用（dispatch_call）
### 作用
为 .so 动态库或 stdlib 插件提供调用分发机制。当前为桩实现，始终返回 -1 表示未处理。
### 逻辑
    令 fn_ni = 参数 0（函数名称索引）
    令 ac = 参数 1（参数个数）
    令 arg_vars = 参数 2（参数变量数组，类型：字符串）
    返回 -1
### 测试要点
1. 始终返回 -1，表示未找到处理者
2. 调用方应根据返回值 -1 回退到默认调用路径
