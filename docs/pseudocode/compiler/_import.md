# _import.cr 伪代码
> 源文件：src/compiler/_import.cr（35 行）
> 功能概要：编译器模块共享引入文件。src/compiler/ 目录下所有 .cr 文件自动引入本文件中的全部模块，实现跨文件符号可见性。

## 标识符对照表
本文件为纯引入文件，不含函数定义。

## 全局状态
本文件不声明全局变量，仅包含引入语句。

## 说明
本文件是 src/compiler/ 目录的「共享引入」文件，列出了编译器各模块所需的全部外部依赖。引入的模块包括：

- **cli**：命令行参数解析
- **ast**：AST/IR 节点定义与全局常量
- **globals**：全部全局变量声明
- **dyn_arr**：动态数组读写与增长工具
- **lexer**：词法分析器（分词）
- **parser**：递归下降语法分析器（解析全部）
- **checker**：类型检查器与借用检查器（检查全部）
- **diag**：编译器诊断信息输出（打印诊断信息）
- **ir_gen**：AST 到 IR 指令生成（IR 生成全部）
- **dataflow**：数据流图构建（DFNode/DFEdge/region）
- **ccr_io**：.ccr 二进制序列化/反序列化
- **module**：导入解析与文件 ID 管理（解析引入）
- **toml**：TOML 配置文件解析
- **project**：项目级配置加载（加载项目）
- **os**：操作系统接口（获取环境变量、获取可执行文件路径）
- **fmt**：字符串格式化（整数转字符串、字符串相等比较）
- **io**：输入输出（输出、输出行、读取文件、写入文件）
- **interp**：IR 解释器（IR 解释执行）
- **dump**：调试转储工具（CIR 文本转储）
- **monomorph**：泛型单态化
- **cir_cache**：CIR 增量编译缓存
- **ext_mgr**：扩展管理器（插件注册与分发）
- **ext_safety**：扩展安全检查
- **pass**：AST 级优化遍（常量折叠）
- **opt**：IR 级优化（公共子表达式消除、分配寄存器、栈共享优化）
- **ptr_analysis**：指针分析（指针分析全部）
- **region_check**：区域检查（区域检查全部）
- **provenance_verify**：来源验证
- **rt**：运行时全局变量
- **main**：编译器主入口与管线编排
- **entry**：程序入口点

本文件无函数定义，不建函数节。
