# elf.cr 伪代码
> 源文件：src/compiler/elf.cr（566 行）
> 功能概要：直接 ELF 可执行文件输出（无需 类型转换（as）/ld 外部工具）。两遍汇编器：第一遍定位标签并测量指令大小，第二遍编码为机器码字节。包含 ELF 头部写入、程序头生成、_start 入口发射、全固定模式 x86-64 指令编码。

## 函数 ELF 写头（elf_write_header）
### 作用
向 ELF 缓冲区写入 ELF 头部（64 字节）和两个程序头（各 56 字节）：代码段（RX）和数据段（（RW）/（BS）（text_base）段（data_base）内存布（heap_size）（t_base）、（data_base） 和 （heap_size），未配置则用默认值（text_base = 0x400000，heap_size = 256MB）。

### 逻辑
函数 ELF 写头（elf_write_header）（上下文（ctx）：ELF 上下文，布局（layout）：内存布局，代码大小（code_size）：整数）：
    令 头部写入偏移（hoff） = 0

    // ---- ELF 标识（magic）：0x7f + "ELF" ----
    写 32 位（上下文.缓冲区，头部写入偏移，1179403647）    // 0x7f 'E' 'L' 'F'
    令 头部写入偏移 = 头部写入偏移 + 4

    // ELF 类别字段（EI_CLASS） = 2（64 位），ELF 数据编码字段（EI_DATA） = 1（小端），ELF 版本字段（EI_VERSION） = 1，ELF 操作系统 ABI 字段（EI_OSABI） = 0
    写单字节（上下文.缓冲区，头部写入偏移，2）
    令 头部写入偏移 = 头部写入偏移 + 1
    写单字节（上下文.缓冲区，头部写入偏移，1）
    令 头部写入偏移 = 头部写入偏移 + 1
    写单字节（上下文.缓冲区，头部写入偏移，1）
    令 头部写入偏移 = 头部写入偏移 + 1
    写单字节（上下文.缓冲区，头部写入偏移，0）
    令 头部写入偏移 = 头部写入偏移 + 1

    // 8 字节填充零 + 4 字节填充零 + 填充字节
    写 64 位（上下文.缓冲区，头部写入偏移，0）
    令 头部写入偏移 = 头部写入偏移 + 8
    写 32 位（上下文.缓冲区，头部写入偏移，0）
    令 头部写入偏移 = 头部写入偏移 + 4
    写单字节（上下文.缓冲区，头部写入偏移，0）
    令 头部写入偏移 = 头部写入偏移 + 1

    // 跳转到 （e_type） 位置（偏移 16）
    令 头部写入偏移 = 16

    // ---- 确定段基址 ----
    令 代码段基址（text_base） = 布局.代码段基址
    令 数据段基址（data_base） = 布局.数据段基址
    如果 代码段基址 等于 0，那么：令 代码段基址 = 4194304    // 默认 0（x400000）
    如果 数据段基址 等于 0，那么：
        令 数据段基址 = 代码段基址 + 向上对齐（代码大小，4096）

    令 堆大小（heap_size） = 布局.堆大小
    如果 堆大小 等于 0，那么：令 堆大小 = 268435456    // 默认 256（MB）

    // ---- ELF 头部剩余字段 ----
    写 16 位（上下文.缓冲（e_type）偏移，2）    // （e_type） = ET_EXEC
    令 头部写入偏移 = 头部写入偏移 + 2
    写 16 位（上下文.缓冲（e_machine）62）    // （e_machine） = EM_X86_64
    令 头部写入偏移 = 头部写入偏移 + 2
    写 32 位（上下文.缓冲（e_version）1）    // （e_version）
    令 头部写入偏移 = 头部写入偏移 + 4
    写 64 位（上下文.缓冲（e_entry）移，代码段基址 + 上下文.代码起始）    // （e_entry）
    令 头部写入偏移 = 头部写入偏移 + 8
    写 64 位（上下文.缓冲（e_phoff）移，64）    // （e_phoff）（程序头表偏移）
    令 头部写入偏移 = 头部写入偏移 + 8
    写 64 位（上下文.缓冲（e_shoff）移，0）    // （e_shoff）（节头表偏移，无）
    令 头部写入偏移 = 头部写入偏移 + 8
    写 32 位（上下文.缓冲（e_flags）移，0）    // （e_flags）
    令 头部写入偏移 = 头部写入偏移 + 4
    写 16 位（上下文.缓冲（e_ehsize），64）    // （e_ehsize）
    令 头部写入偏移 = 头部写入偏移 + 2
    写 16 位（e_phentsize）    // （e_phentsize）
    令 头部写入偏移 = 头部写入偏移 + 2
    写 16 位（上下文.缓冲（e_phnum）移，2）    // （e_phnum） = 2
    令 头部写入偏移 = 头部写入偏移 + 2
    写 16 位（上下文.缓冲（e_shentsize）    // （e_shentsize）
    令 头部写入偏移 = 头部写入偏移 + 2
    写 16 位（上下文.缓冲（e_shnum）移，0）    // （e_shnum）
    令 头部写入偏移 = 头部写入偏移 + 2
    写 16 位（e_shstrndx）    // （e_shstrndx）

    // ===== 程序头 1：代码段（RX） =====
    令 程序头偏移（phoff） = 64
    写 32 位（上下文.缓冲（p_type）移，1）    // （p_type） = PT_LOAD
    令 程序头偏移 = 程序头偏移 + 4
    写 32 位（上下文.缓冲（p_flags），5）    // （p_flags） = PF_R | PF_X
    令 程序头偏移 = 程序头偏移 + 4
    写 64 位（上下文.缓冲（p_offset）0）    // （p_offset）（文件内偏移）
    令 程序头偏移 = 程序头偏移 + 8
    写 64 位（上下文.缓冲（p_vaddr），代码段基址）    // （p_vaddr）
    令 程序头偏移 = 程序头偏移 + 8
    写 64 位（上下文.缓冲（p_paddr），代码段基址）    // （p_paddr）
    令 程序头偏移 = 程序头偏移 + 8
    写 64 位（上下文.缓冲（p_filesz）代码大小）    // （p_filesz）
    令 程序头偏移 = 程序头偏移 + 8
    写 64 位（上下文.缓冲（p_memsz），代码大小）    // （p_memsz）
    令 程序头偏移 = 程序头偏移 + 8
    写 64 位（上下文.缓冲（p_align），4096）    // （p_align）

    // ===== 程序头 2：数据段 BSS（RW） =====
    写 32 位（上下文.缓冲（p_type）移，1）    // （p_type） = PT_LOAD
    令 程序头偏移 = 程序头偏移 + 4
    写 32 位（上下文.缓冲（p_flags），6）    // （p_flags） = PF_R | PF_W
    令 程序头偏移 = 程序头偏移 + 4
    写 64 位（上下文.缓冲（p_offset）0）    // （p_offset）
    令 程序头偏移 = 程序头偏移 + 8
    写 64 位（上下文.缓冲（p_vaddr），数据段基址）    // （p_vaddr）
    令 程序头偏移 = 程序头偏移 + 8
    写 64 位（上下文.缓冲（p_paddr），数据段基址）    // （p_paddr）
    令 程序头偏移 = 程序头偏移 + 8
    写 64 位（上下文.缓冲（p_filesz）0）    // （p_filesz）（BSS 不占用文件空间）
    令 程序头偏移 = 程序头偏移 + 8
    写 64 位（上下文.缓冲（p_memsz），堆大小）    // （p_memsz）
    令 程序头偏移 = 程序头偏移 + 8
    写 64 位（上下文.缓冲（p_align），4096）    // （p_align）

    // 写入完毕后，将上下文位置重置到代码段起始处
    令 上下文.位置 = 上下文.代码起始

## 函数 ELF 写代码段（elf_write_code）
### 作用
将生成的机器码字节拷贝到 ELF 缓冲区的代码段位置。从上下文当前位置开始逐字节写入，写入量与汇编代码大小（g_asm_code_size）一致。写入后更新上下文位置指针。

### 逻辑
函数 ELF 写代码段（elf_write_code）（上下文（ctx）：ELF 上下文，代码数据（code）：字符串）：
    令 拷贝索引（i） = 0
    循环（当 拷贝索引 小于 汇编代码大小 时）：
        写字节（store8）（上下文.缓冲区，上下文.位置 + 拷贝索引，读字节（load8）（代码数据，拷贝索引））
        令 拷贝索引 = 拷贝索引 + 1
    令 上下文.位置 = 上下文.位置 + 汇编代码大小

### 测试要点
1. 代码字节按序拷贝到缓冲区
2. 上下文位置指针正确前进

## 函数 ELF 结束（elf_finish）
### 作用
将 ELF 缓冲区内容写入文件系统：打开（（O_WRONL）（total_size）O_TRUNC，权限 0644）指定路径，写入 （total_size） 字节，关闭文件描述符。返回写入的字节数或 -1（失败）。

### 逻辑
函数 ELF 结束（elf_finish）（上下文（ctx）：ELF 上下文，输出路径（path）：字符串，总大小（total_size）：整数）-> 整数：
    令 文件描述符（fd） = 系统调用3（2，（open），577，420）    // （open）（O_WRONLY|O_CREAT|O_TRUNC, 0644）
    如果 文件描述符 小于 0，那么：返回 -1
    令 写入字节数（nw） = 系统调用3（1，（write），上下文.缓冲区，总大小）    // （写入）
    系统调用3（close）    // （close）
    返回 写入字节数

### 测试要点
1. 成功写入返回写入字节数
2. 无法打开文件时返回 -1
3. 写入后文件描述符被关闭

## 函数 测量指令大小（measure_instr）
### 作用
第一遍汇编：根据汇编文本行确定对应机器指令的字节大小。通过固定模式字符串匹配识别所有支持的 x86-64 指令。未知指令默认为 1 字节（NOP）。

### 逻辑
函数 测量指令大小（measure_instr）（行文本（line）：字符串）-> 整数：
    // ---- 固定大小指令（精确全行匹配） ----
    如果 字符串相等比较（行文本，"    push rbp"）不等于 0，那么：返回 1
    如果 字符串相等比较（行文本，"    pop rbp"）不等于 0，那么：返回 1

## 函数 汇编转字节码（asm_to_bytes）
### 作用
两遍汇编器主函数：第一遍扫描汇编文本定位所有标签（.Lxxx:）并测量每条指令的字节大小，累加计算总代码大小；第二遍逐指令编码为机器码字节。最后在结果（_start）置 （_start） 入口代码（14 字节：call main + mov edi, eax + mov eax, 60 + syscall）。

### 逻辑
函数 汇编转字节码（asm_to_bytes）（汇编文本（asm_text）：字符串）-> 字符串：
    令 汇编文本总长度（tal） = 字符串长度（汇编文本）

    // ===== 第一遍：定位标签并测量每条指令大小 =====
    令 累计总大小（total_size） = 0
    令 标签计数 = 0
    令 行扫描索引（li） = 0

    循环（当 行扫描索引 小于 汇编文本总长度 时）：
        // 提取一行文本（从当前位置到下一个换行符）
        令 行起始（lstart） = 行扫描索引
        循环（当 行扫描索引 小于 汇编文本总长度 时）：
            如果 取字符串第（N）字符（汇（n）文本，行扫描索引）等于 "\（数量）"，那么：跳出循环
            令 行扫描索引 = 行扫描索引 + 1
        如果 行扫描索引 大于等于 汇编文本总长度 且 行起始 小于 汇编文本总长度，那么：
            令 行扫描索引 = 汇编文本总长度    // 最后一行没有换行符

        令 行文本（line） = 字符串切片（汇编文本，行起始，行扫描索引 - 行起始）

        如果 判断标签行（行文本）不等于 0，那么：
            // ---- 处理标签行：提取标签号并记录位置 ----
            令 行长度（llen） = 字符串长度（行文本）
            如果 行长度 大于 3，那么：
                // 从 ":" 前反向扫描数字
                令 数字起始（digit_start） = 行长度 - 2    // ":" 前面的位置
                循环（当 数字起始 大于等于 2 时）：
                    如果 取字符串第（N）字符（行文本，数字起始 - 1）大于等于 "0" 且 取字符串第（次数）字符（行文本，数字起始 - 1）小于等于 "9"，那么：
                        令 数字起始 = 数字起始 - 1
                    否则：跳出循环

                令 标签号字符串（num_str） = 字符串切片（行文本，数字起始，行长度 - 1 - 数字起始）
                令 标签编号（label_num） = 字符串转整数（标签号字符串）

                如果 标签编号 大于等于 0，那么：
                    扩展标签位置数组（标签编号 + 1）
                    写 64 位（标签位置数组，标签编号 * 8，累计总大小）
                    如果 标签编号 + 1 大于 标签计数，那么：令 标签计数 = 标签编号 + 1
        否则：
            // 非标签行：如果不是伪指令行，累加指令大小
            如果 跳过指令（行文本）等于 0，那么：
                令 累计总大小 = 累计总大小 + 测量指令大小（行文本）

    令 清零索引（zi） = 0
    循环（当 清零索引 小于 缓冲区大小 时）：
        写字节（store8）（代码缓冲区，清零索引，0）
        令 清零索引 = 清零索引 + 1

    // ===== 第二遍：逐行编码为机器码 =====
    令 代码写入位置（cpos） = 0
    令 行扫描索引 = 0

            令 行扫描索引 = 汇编文本总长度

        如果 判断标签行（行文本）等于 0，那么：

    //   （B8） 3（C） 00 00 00       mov eax, 60（sys_exit 系统调用号）
    //   0（F） 05                syscall
    写字节（store8）（结果缓冲区，0，232）
    写字节（store8）（结果缓冲区，1，9）
