# opt.cr 伪代码
> 源文件：状态（s）已分配变量计数（rc）/compiler/opt.cr（525 行）
> 功能概要：编译优化遍 —— 在类型检查后、IR 生成前运行。包含 AST 层常量折叠（二元运算表达式（EXPR_BINARY） 运算符两操作数均为常量时在编译器期求值并原地替换为 整数字面量表达式（EXPR_INT））、AST 树递归遍历优化（对 20 种表达式节点类型递归优化子节点）、线性扫描寄存器分配（为 IR 变量分配被调用者保存寄存器）、栈槽共享（活跃区间不相交的变量共享同一栈槽）、公共子表达式消除（CSE，识别重复的纯计算表达式）。优化全部（optimize_all）为总入口：始终执行指针分析、区域检查和来源验证；优化级别大于等于 1 时加 AST 优化；级别大于等于 2 时加 公共子表达式消除（CSE）、寄存器分配和栈共享。

## 函数 AST 判断常量整数（ast_is_const_int）
签名：`函数 AST 判断常量整数（ast_is_const_int）（节点索引（node）：整数）-> 整数`
### 作用
检查给定的 AST 节点是否为整数常量（EXPR_INT）。负数的节点索引直接返回 0（假）。
### 逻辑
    如果 节点索引 小于 0，那么：返回 0
    如果 AST 访问器：类别（ast_kind）（node）等于 表达式：整数常量（EXPR_INT），那么：返回 1
    返回 0
### 测试要点
1. 节点索引 小于 0 返回 0
2. 表达式：整数常量（EXPR_INT） 节点返回 1
3. 非 表达式：整数常量（EXPR_INT） 节点（如 表达式：二元运算（EXPR_BINARY）、表达式：代码块（EXPR_BLOCK） 等）返回 0

### 作用
获取 AST 节点的整数值字段。假定调用方已验证节点是 表达式：整数常量（EXPR_INT） 常量。
### 逻辑
    返回 AST 访问器：整数值（ast_int_val）（node）
### 测试要点
1. 对 表达式：整数常量（EXPR_INT） 节点返回其存储的常量值
2. 对非 表达式：整数常量（EXPR_INT） 节点同样返回其 整数值字段（int_val） 字段（但语义由调用方保证）

## 函数 AST 布尔转整数（ast_bool_as_int）
签名：`函数 AST 布尔转整数（ast_bool_as_int）（值（value）：布尔）-> 整数`
### 作用
将布尔值转为整数：真返回 1，假返回 0。用于常量折叠中比较运算和逻辑运算的结果归一化。
### 逻辑
    如果 值 为真，那么：返回 1
    返回 0
### 测试要点
1. 真转换为 1
2. 假转换为 0

## 函数 AST 折叠二元运算（ast_fold_binary）
签名：`函数 AST 折叠二元运算（ast_fold_binary）（节点索引（node）：整数）-> 整数`
### 作用
尝试将二元运算节点（EXPR_BINARY）在编译器期求值折叠为常量（EXPR_INT）。当左右操作数均为常量整数时，根据操作码执行求值：算术（加减乘除模）、比较（等于/不等于/小于/大于/小于等于/大于等于）、逻辑（与/或）。除零（除法或取模的右操作数为 0）时返回 0 不折叠。未知操作码同样不折叠。折叠成功时原地将节点类别改为 整数字面量表达式（EXPR_INT），清零 第一/第二/第三子节点 字段，写入结果值和类型（TY_INT）。返回 1 表示已折叠，0 表示无法折叠或未折叠。
### 逻辑
    令 左操作数节点（left）= AST 访问器：第一子节点（ast_a）（node）
    令 右操作数节点（right）= AST 访问器：第二子节点（ast_b）（node）
    令 操作码（opc）= AST 访问器：第三子节点（ast_c）（node）

    如果 非（AST 判断常量整数（ast_is_const_int）（左操作数节点））或 非（AST 判断常量整数（右操作数节点）），那么：返回 0

    令 左常量值（v1）= AST 获取常量值（ast_const_val）（左操作数节点）
    令 右常量值（v2）= AST 获取常量值（右操作数节点）
    令 结果值（rv）= 0（可变）
    令 已知标记（known）= 1（可变，0 表示遇到未知操作码无法折叠）

    如果 操作码 等于 操作码：加法（OP_ADD），那么：令 结果值 = 左常量值 + 右常量值
    否则如果 操作码 等于 操作码：减法（OP_SUB），那么：令 结果值 = 左常量值 - 右常量值
    否则如果 操作码 等于 操作码：乘法（OP_MUL），那么：令 结果值 = 左常量值 * 右常量值
    否则如果 操作码 等于 操作码：除法（OP_DIV），那么：
        如果 右常量值 等于 0，那么：返回 0（除零，不折叠）
        令 结果值 = 左常量值 / 右常量值
    否则如果 操作码 等于 操作码：取模（OP_MOD），那么：
        如果 右常量值 等于 0，那么：返回 0（取模零，不折叠）
        令 结果值 = 左常量值 % 右常量值
    否则如果 操作码 等于 操作码：等于（OP_EQ），那么：令 结果值 = AST 布尔转整数（ast_bool_as_int）（左常量值 等于 右常量值）
    否则如果 操作码 等于 操作码：不等于（OP_NE），那么：令 结果值 = AST 布尔转整数（ast_bool_as_int）（左常量值 不等于 右常量值）
    否则如果 操作码 等于 操作码：小于（OP_LT），那么：令 结果值 = AST 布尔转整数（ast_bool_as_int）（左常量值 小于 右常量值）
    否则如果 操作码 等于 操作码：大于（OP_GT），那么：令 结果值 = AST 布尔转整数（ast_bool_as_int）（左常量值 大于 右常量值）
    否则如果 操作码 等于 操作码：小于等于（OP_LE），那么：令 结果值 = AST 布尔转整数（ast_bool_as_int）（左常量值 小于等于 右常量值）
    否则如果 操作码 等于 操作码：大于等于（OP_GE），那么：令 结果值 = AST 布尔转整数（ast_bool_as_int）（左常量值 大于等于 右常量值）
    否则如果 操作码 等于 操作码：逻辑与（OP_AND），那么：令 结果值 = AST 布尔转整数（ast_bool_as_int）（左常量值 不等于 0 且 右常量值 不等于 0）
    否则如果 操作码 等于 操作码：逻辑或（OP_OR），那么：令 结果值 = AST 布尔转整数（ast_bool_as_int）（左常量值 不等于 0 或 右常量值 不等于 0）
    否则：令 已知标记 = 0

    如果 已知标记 等于 0，那么：返回 0

    （折叠：原地将 表达式：二元运算（EXPR_BINARY） 替换为 表达式：整数常量（EXPR_INT），使用 设置类访问器（ast_set_*） 系列写函数直接修改节点字段）
    AST 访问器：设置类别（ast_set_kind）（节点（node）, 整数字面量表达式（EXPR_INT））
    AST 访问器：设置第一子节点（ast_set_a）（节点（node）, 0）
    AST 访问器：设置第二子节点（ast_set_b）（节点（node）, 0）
    AST 访问器：设置第三子节点（ast_set_c）（节点（node）, 0）
    AST 访问器：设置整数值（ast_set_int_val）（节点（node）, 结果值）
    AST 访问器：设置类型值（ast_set_type_val）（节点（node）, 整数类型（TY_INT））
    返回 1
### 测试要点
1. 两个操作数均为常量（EXPR_INT）时折叠成功返回 1
2. 任一操作数非常量时返回 0，不修改节点
3. 除零（操作码：除法（OP_DIV）或 操作码：取模（OP_MOD） 且 右常量值（v2） == 0）返回 0，不折叠
4. 未知操作码设置 已知标记（known） = 0 返回 0
5. 折叠后节点类别变为 表达式：整数常量（EXPR_INT），第一/第二/第三子节点 字段清零，整数值字段（int_val） 写入结果
6. 比较运算和逻辑运算结果正确归一化为 0 或 1

## 函数 AST 优化函数体（ast_optimize_body）
签名：`函数 AST 优化函数体（ast_optimize_body）（表达式节点索引（body）：整数）`
### 作用
递归遍历 AST 树，对每种表达式节点类型执行对应的优化动作：表达式：代码块（EXPR_BLOCK） 递归优化每条语句；表达式：返回（EXPR_RETURN） 优化返回值表达式；表达式：条件（EXPR_IF） 优化条件、真分支、假分支（若条件为常量则在 IR 生成阶段可跳过死分支）；表达式：二元运算（EXPR_BINARY） 递归优化左右子节点后尝试常量折叠；表达式：一元运算（EXPR_UNARY）/表达式：调用（EXPR_CALL）/表达式：结构体（EXPR_STRUCT）/表达式：数组（EXPR_ARRAY）/表达式：元组（EXPR_TUPLE）/表达式：声明（EXPR_LET）/表达式：协程（EXPR_GO）/表达式：让出（EXPR_YIELD）/表达式：循环（EXPR_LOOP）/表达式：当循环（EXPR_WHILE）/表达式：遍历循环（EXPR_FOR）/表达式：匹配（EXPR_MATCH）/表达式：语句（EXPR_STMT）/表达式：类型转换（EXPR_AS） 等各自递归优化关联子节点。对未列出的节点类型（EXPR_INDEX）不做任何操作。
### 逻辑
    如果 表达式节点索引 小于 0，那么：返回

    令 节点类别（bk）= AST 访问器：类别（ast_kind）（body）

    （代码块表达式（EXPR_BLOCK）：代码块，递归优化每条语句）
    如果 节点类别 等于 表达式：代码块（EXPR_BLOCK），那么：
        令 语句起始索引（ss）= AST 访问器：第一子节点（ast_a）（body）
        令 语句条数（sc）= AST 访问器：第二子节点（ast_b）（body）
        令 语句遍历索引（i）= 0
        循环（当 语句遍历索引 小于 语句条数 时）：
            令 当前语句节点（sn）= 读 64 位（r64）（代码块语句数组（g_block_stmts）, （语句起始索引 + 语句遍历索引） * 8）

        返回

    （返回表达式（EXPR_RETURN）：返回表达式，优化返回值子表达式）
    如果 节点类别 等于 表达式：返回（EXPR_RETURN），那么：
        如果 AST 访问器：第一子节点（body）大于等于 0，那么：AST 优化函数体（AST 访问器：第一子节点（body））
        返回

        AST 优化函数体（AST 访问器：第一子节点（body））（优化条件表达式）
        AST 优化函数体（AST 访问器：第二子节点（body））（优化真分支）
        如果 AST 访问器：第三子节点（ast_c）（body）大于等于 0，那么：AST 优化函数体（AST 访问器：第三子节点（body））（优化假分支，若存在）
        （检查条件是否为常量：若是，则可在 IR 生成阶段跳过死分支）
        令 条件节点（cond）= AST 访问器：第一子节点（body）
        如果 AST 判断常量整数（ast_is_const_int）（条件节点），那么：

## 函数 分配寄存器（alloc_registers）
签名：`函数 分配寄存器（alloc_registers）（）`
### 作用
为每个函数的 IR 变量分配物理寄存器。仅在优化级别大于等于 1 时执行。使用被调用者保存寄存器（callee-saved）：rbx（3）、r12（12）、r13（13）、r14（14）、r15（15），共 5 个——这些寄存器在函数调用过程中由被调用方负责保存/恢复，不会被调用破坏。算法分为三步：（1） 构建活跃区间——扫描每条指令，记录每个变量的首次引用位置和末次引用位置；（2） 线性扫描分配——逐条指令处理，先释放已结束变量的寄存器，再为目标变量分配空闲寄存器；（3） 将分配结果写入 优化元数据数组（g_opt_meta），格式为：键（4 字节） + 数据长度（4 字节） + 计数（4 字节） + [变量索引（4 字节）, 寄存器物理编号（4 字节）] 重复多次，均以小端字节序逐字节存储。

## 函数 优化全部（optimize_all）
签名：`函数 优化全部（optimize_all）（）`
### 作用
编译优化的总入口函数，在类型检查完成后、IR 生成前被调用。执行顺序：（1） 始终运行指针分析（ptr_analysis_all）、区域检查（region_check_all）和来源验证（provenance_verify_all），即使优化级别为 0；（2） 若优化级别大于等于 1，对每个函数的函数体 AST 执行 AST 优化函数体（ast_optimize_body）；（3） 若优化级别大于等于 2，额外执行 公共子表达式消除（CSE）、寄存器分配和栈共享优化。注意：公共子表达式消除（pass_cse） 在自编译二进制中已知会导致 一般保护故障（GPF），仅在优化级别大于等于 2 时启用。
### 逻辑
    （无条件执行的安全分析 pass——即使优化级别为 0 也需要运行）
    指针分析全部（ptr_analysis_all）（）
    区域检查全部（region_check_all）（）（验证解引用目标在活跃子图内）
    来源验证全部（provenance_verify_all）（）（检查解引用偏移与分配大小）

    如果 优化级别（g_opt_level）小于 1，那么：返回

    （AST 层优化：遍历所有已注册函数，对函数体执行常量折叠等优化）
    令 函数索引（fi）= 0
    循环（当 函数索引 小于 函数计数（g_func_count）时）：
        令 函数 AST 节点（fn_node）= 函数信息访问器：AST节点（fi_ast_node）（函数索引）
        令 函数体节点（body）= AST 访问器：数据（ast_data）（函数 AST 节点）
        AST 优化函数体（ast_optimize_body）（函数体节点）
        令 函数索引 = 函数索引 + 1

    （激进优化遍——仅在 优化级别二（O2） 时启用，公共子表达式消除（pass_cse） 已知在自编译时有问题）
    如果 优化级别（g_opt_level） 大于等于 2，那么：
        公共子表达式消除（pass_cse）（）
        分配寄存器（alloc_registers）（）
        栈共享优化（pass_stack_share）（）
### 测试要点
1. 指针分析、区域检查、来源验证始终执行（即使 优化级别（opt_level） 为 0）
2. 优化级别（opt_level） 小于 1 时在三个安全分析后直接返回，跳过 AST 和 IR 优化
3. 优化级别（opt_level） 大于等于 1 时执行 AST 优化遍历所有函数体
4. 优化级别（opt_level） 大于等于 2 时依次执行 公共子表达式消除（CSE）、寄存器分配、栈共享
5. 公共子表达式消除（pass_cse） 在自编译二进制中已知导致 一般保护故障（GPF）（注释标注，仅在 优化级别二（O2） 启用）
6. 执行顺序：安全分析 → AST 优化 → IR 优化（CSE → 寄存器分配 → 栈共享）
