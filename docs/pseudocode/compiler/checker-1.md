## 函数 分配类型（alloc_type）
函数 分配类型（alloc_type）（类别 种类（kind）：整数，数据 数据（data）：整数，额外 extra：整数）-> 整数

### 作用
在全局类型表（g_types 扁平字节缓冲）中分配一条新的类型条目。类型条目固定 24 字节（3 个 64 位整数：类别、数据、额外）。调用者传入类别（TYP_*）、数据字段和额外字段值，返回新条目的索引。

### 逻辑
`
令 局部索引（idx） = 类型计数（g_type_count）
调用 扩展类型数组（grow_types），参数为 局部索引 + 1
调用 写 64 位（w64），参数为 类型数组（g_types）、局部索引 * 24、类别（kind）
调用 写 64 位（w64），参数为 类型数组（g_types）、局部索引 * 24 + 8、数据（data）
调用 写 64 位（w64），参数为 类型数组（g_types）、局部索引 * 24 + 16、额外（extra）
令 类型计数 = 局部索引 + 1
返回 局部索引
`

### 测试要点
1. 首次调用：类型计数（g_type_count）为 0，返回 0，类型计数（g_type_count）更新为 1
2. 连续分配 次数（N） 次：返回 0 到 次数-1，类型计数（g_type_count）等于 次数
3. 传入任意 64 位整数值作为类别/数据/额外，写入后通过 读 64 位（r64）可读取原值
4. 当类型计数（g_type_count）超过当前容量时，扩展类型数组（grow_types）扩展缓冲区，已有数据被内部：动态拷贝（_dyncpy）保留

## 函数 初始化类型列表（types）（init_types）
函数 初始化类型列表（types）（init_types）（）

### 作用
将类型计数（g_type_count）重置为 0，并预分配编译器所需的 8 个基础类型索引（类型信息：整数（TI_INT）=0 到 类型信息：动态（TI_DYN）=7）。这些固定索引使后续代码可以通过常量直接引用常用类型。

### 逻辑
`
令 类型计数（g_type_count） = 0
调用 分配类型（alloc_type），参数为 类型条目类别：基础（TYP_BASE）、整数（TY_INT）、0（类型信息：整数（TI_INT） = 0）
调用 分配类型（alloc_type），参数为 类型条目类别：基础（TYP_BASE）、浮点数（TY_FLOAT）、0（类型信息：浮点（TI_FLOAT） = 1）
调用 分配类型（alloc_type），参数为 类型条目类别：基础（TYP_BASE）、布尔（TY_BOOL）、0（类型信息：布尔（TI_BOOL） = 2）
调用 分配类型（alloc_type），参数为 类型条目类别：基础（TYP_BASE）、字符串（TY_STRING）、0（类型信息：字符串（TI_STR） = 3）
调用 分配类型（alloc_type），参数为 类型条目类别：基础（TYP_BASE）、单元（TY_UNIT）、0（类型信息：单元（TI_UNIT） = 4）
调用 分配类型（alloc_type），参数为 类型条目类别：基础（TYP_BASE）、永无（TY_NEVER）、0（TI_NEVER = 5）
调用 分配类型（alloc_type），参数为 类型条目类别：基础（TYP_BASE）、字符（TY_CHAR）、0（类型信息：字符（TI_CHAR） = 6）
调用 分配类型（alloc_type），参数为 类型条目类别：动态（TYP_DYN）、0、0（类型信息：动态（TI_DYN） = 7）
`

### 测试要点
1. 调用后类型计数（g_type_count）== 8，且 类型表预分配：整数（TI_INT）（类型信息：整数）=0、类型表预分配：字符串（TI_STR）（类型信息：字符串）=3、类型表预分配：动态（TI_DYN）（类型信息：动态）=7 等常量值与索引一一对应
2. 每个预分配条目的类别字段正确（基础类型（TYP_BASE） 或 TYP_DYN）
3. 重复调用 初始化类型列表（types） 会重新创建类型表（所有旧引用失效）

## 函数 二元信息（bi）加上（bi_add）
函数 二元信息（bi）加上（bi_add）（名称 name：字符串，返回类型表索引 ret_ti：整数）

### 作用
向运行时内建函数表中追加一条记录（名称驻留索引 + 返回类型表索引）。在内部自动管理数组容量（按需扩展 2 倍 + 16，最小 16）。

### 逻辑
`
令 名称索引（ni） = 字符串驻留（str_intern），参数为 名称（name）

如果 运行时内建函数计数（g_rt_builtin_count） * 8 + 8 大于 字符串长度（str_len），参数为 运行时内建函数名数组（g_rt_builtin_names），那么：
    令 新容量（nc） = 运行时内建函数计数 * 2 + 16
    令 新缓冲（nb） = 分配内存（alloc），大小为 新容量 * 8 字节
    调用 内部：动态拷贝（_dyncpy），参数为 运行时内建函数名数组、运行时内建函数计数 * 8、新缓冲
    令 运行时内建函数名数组 = 新缓冲

如果 运行时内建函数计数 * 8 + 8 大于 字符串长度（str_len），参数为 运行时内建函数返回类型数组（g_rt_builtin_ret_types），那么：
    令 新容量（nc） = 运行时内建函数计数 * 2 + 16
    令 新缓冲（nb） = 分配内存（alloc），大小为 新容量 * 8 字节
    调用 内部：动态拷贝（_dyncpy），参数为 运行时内建函数返回类型数组、运行时内建函数计数 * 8、新缓冲
    令 运行时内建函数返回类型数组 = 新缓冲

调用 写 64 位（w64），参数为 运行时内建函数名数组、运行时内建函数计数 * 8、名称索引
调用 写 64 位（w64），参数为 运行时内建函数返回类型数组、运行时内建函数计数 * 8、返回类型表索引（ret_ti）
令 运行时内建函数计数 = 运行时内建函数计数 + 1
`

### 测试要点
1. 首次调用：容量不足触发扩展，新缓冲分配，数据拷贝，正确写入
2. 连续多次调用后数组对齐检查：第 次数（N） 条记录的偏移为 次数 * 8 字节
3. 容量触发扩展后原有数据不丢失

### 逻辑
`

`

### 测试要点
1. 对 类型表预分配：整数（TI_INT）（类型信息：整数）（= 0）调用返回 类型条目类别：基础（TYP_BASE）（基础类型）（= 0）
2. 对 类型表预分配：动态（TI_DYN）（类型信息：动态）（= 7）调用返回 类型条目类别：动态（TYP_DYN）（TYP_DYN）（= 11）
3. 类型表索引（ti）为 -1 或超出范围时返回 -1

## 函数 类型相等（equal）（type_equal）
函数 类型相等（equal）（type_equal）（类型1 t1：整数，类型2 t2：整数）-> 布尔

### 作用
判断两个类型表索引是否代表相同类型。对基础类型直接按整数比较；对复合类型（命名/数组/引用/指针/切片/泛型应用/泛型参数/元组）递归比较其子结构。

### 逻辑
`
如果 类型1（t1） 等于 类型2（t2），那么：返回 真

如果 类型1 大于等于 0 且 类型2 大于等于 0 且 类型1 小于 类型计数（g_type_count）且 类型2 小于 类型计数，那么：
    令 类别1（k1） = 获取类型类别（get_type_kind），参数为 类型1
    令 类别2（k2） = 获取类型类别（get_type_kind），参数为 类型2

    如果 类别1 等于 类型条目类别：命名（TYP_NAMED）且 类别2 等于 类型条目类别：命名（具名类型），那么：
        返回 获取类型数据（get_type_data），参数为 类型1 等于 获取类型数据，参数为 类型2

    如果 类别1 等于 类型条目类别：数组（TYP_ARRAY）且 类别2 等于 类型条目类别：数组（数组类型），那么：
        如果 类型相等（equal）（获取类型数据，参数为 类型1，获取类型数据，参数为 类型2）为真，那么：
            如果 获取类型额外（get_type_extra），参数为 类型1 等于 获取类型额外（get_type_extra），参数为 类型2，那么：
                返回 真
        返回 假

    如果 类别1 等于 类型条目类别：元组（TYP_TUPLE）且 类别2 等于 类型条目类别：元组（TYP_TUPLE），那么：
        如果 获取类型数据，参数为 类型1 不等于 获取类型数据，参数为 类型2，那么：返回 假
        令 起始1（start1） = 获取类型额外，参数为 类型1
        令 起始2（start2） = 获取类型额外，参数为 类型2
        令 个数（cnt） = 获取类型数据，参数为 类型1
        令 索引（i） = 0（可变）
        循环：
            如果 索引 大于等于 个数，那么：跳出循环
            如果 非 类型相等（equal）（读 64 位（r64），参数为 泛型应用数据数组（g_gen_apply_data）、（起始1 + 索引） * 8，读 64 位，参数为 泛型应用数据数组、（起始2 + 索引） * 8）为真，那么：返回 假
            令 索引 = 索引 + 1
        返回 真

    如果 类别1 等于 类型条目类别：引用（TYP_REF）且 类别2 等于 类型条目类别：引用（引用类型），那么：
        返回 获取类型额外，参数为 类型1 等于 获取类型额外，参数为 类型2 且 类型相等（equal）（获取类型数据，参数为 类型1，获取类型数据，参数为 类型2）为真

    如果 类别1 等于 类型条目类别：指针（TYP_PTR）且 类别2 等于 类型条目类别：指针（指针类型），那么：
        返回 类型相等（equal）（获取类型数据，参数为 类型1，获取类型数据，参数为 类型2）

    如果 类别1 等于 类型条目类别：切片（TYP_SLICE）且 类别2 等于 类型条目类别：切片（切片类型），那么：
        返回 类型相等（equal）（获取类型数据，参数为 类型1，获取类型数据，参数为 类型2）

    如果 类别1 等于 类型条目类别：泛型应用（TYP_GENERIC_APPLY）且 类别2 等于 类型条目类别：泛型应用（泛型应用类型），那么：
        如果 获取类型数据，参数为 类型1 不等于 获取类型数据，参数为 类型2，那么：返回 假
        令 起始1（start1） = 获取类型额外，参数为 类型1
        令 起始2（start2） = 获取类型额外，参数为 类型2
        令 计数1（count1） = 读 64 位，参数为 泛型应用数据数组（g_gen_apply_data）、起始1 * 8
        令 计数2（count2） = 读 64 位，参数为 泛型应用数据数组、起始2 * 8
        如果 计数1 不等于 计数2，那么：返回 假
        令 参数索引（ai） = 0（可变）
        循环：

            如果 非 类型相等（equal）（读 64 位，参数为 泛型应用数据数组、（起始1 + 1 + 参数索引） * 8，读 64 位，参数为 泛型应用数据数组、（起始2 + 1 + 参数索引） * 8）为真，那么：返回 假
            令 参数索引 = 参数索引 + 1
        返回 真

    如果 类别1 等于 类型条目类别：泛型参数（TYP_GENERIC_PARAM）且 类别2 等于 类型条目类别：泛型参数（泛型参数类型），那么：
        返回 获取类型数据，参数为 类型1 等于 获取类型数据，参数为 类型2

返回 假
`

### 测试要点
1. 相同基础类型：类型相等（equal）（类型信息：整数（TI_INT），类型信息：整数）返回 真
2. 不同基础类型：类型相等（equal）（类型信息：整数（TI_INT），类型信息：布尔（TI_BOOL））返回 假

4. 递归相等性：两个相同结构的嵌套泛型应用（如 向量类型（Vec）[整数（int）] 和 向量类型[整数]）返回 真；向量类型（向量类型）[整数（整数）] 和 向量类型[浮点（float）] 返回 假

## 函数 扫描让出（scan_for_yield）
函数 扫描让出（scan_for_yield）（节点 节点（node）：整数）-> 整数

### 作用
在 AST 子树中递归搜索是否存在 让出表达式（EXPR_YIELD）。返回 1 表示找到了 让出（yield） 节点，返回 0 表示没有。用于判断函数是否包含 让出（从而确定函数是否为 流程（flow） 函数）。

### 逻辑
`
如果 节点（node） 小于 0，那么：返回 0

令 节点类别（k） = AST 访问器：类别（ast_kind），参数为 节点

如果 节点类别 等于 让出表达式（EXPR_YIELD），那么：返回 1

如果 节点类别 等于 代码块表达式（EXPR_BLOCK），那么：
    令 语句起始（ss） = AST 访问器：变量甲（a）（ast_a），参数为 节点
    令 语句计数（sc） = AST 访问器：变量乙（b）（ast_b），参数为 节点
    令 索引（i） = 0（可变）
    循环：
        如果 索引 大于等于 语句计数，那么：跳出循环
        令 语句节点（sn） = 读 64 位（r64），参数为 代码块语句数组（g_block_stmts）、（语句起始 + 索引） * 8
        如果 扫描让出（scan_for_yield），参数为 语句节点 不等于 0，那么：返回 1
        令 索引 = 索引 + 1
    返回 0

如果 节点类别 等于 循环表达式（EXPR_LOOP）或 当循环表达式（EXPR_WHILE），那么：
    返回 扫描让出（第一子节点访问器，参数为 节点）

如果 节点类别 等于 如果表达式（EXPR_IF），那么：
    如果 扫描让出（第一子节点访问器，参数为 节点）不等于 0，那么：返回 1
    如果 扫描让出（第二子节点访问器，参数为 节点）不等于 0，那么：返回 1
    如果 AST 访问器：变量丙（c）（ast_c），参数为 节点 大于等于 0 且 扫描让出（第三子节点访问器，参数为 节点）不等于 0，那么：返回 1
    返回 0

如果 节点类别 等于 遍历表达式（EXPR_FOR），那么：
    返回 扫描让出（第三子节点访问器，参数为 节点）

返回 0
`

### 测试要点
1. 节点（node）为 -1（空节点）：返回 0
2. 节点本身就是 让出表达式（EXPR_YIELD）：返回 1
3. 代码块中包含嵌套 让出（yield）（深度任意）：正确递归返回 1
4. 如果（if） 表达式所有分支（那么（then）/否则（else））都被扫描
5. 遍历（for） 循环体内有 让出（yield）：返回 1

## 函数 检查错误（check_error）
函数 检查错误（check_error）（错误码 code：整数，消息 msg：字符串，行号 line：整数，列号 col：整数）

### 作用
向全局诊断数组（g_diags）追加一条结构化诊断条目。每条诊断 32 字节（错误码 + 消息字符串指针 + 行号 + 列号）。用于编译器中所有语义错误的报告。

### 逻辑
`
调用 扩展诊断数组（grow_diags），参数为 诊断计数（g_diag_count） + 1
调用 写 64 位（w64），参数为 诊断数组（g_diags）、诊断计数 * 32、错误码（code）
调用 存储字符串指针（store_str_ptr），参数为 诊断数组、诊断计数 * 32 + 8、消息（msg）
调用 写 64 位，参数为 诊断数组、诊断计数 * 32 + 16、行号（line）
调用 写 64 位，参数为 诊断数组、诊断计数 * 32 + 24、列号（col）
令 诊断计数 = 诊断计数 + 1
`

### 测试要点
1. 首次调用后诊断计数（g_diag_count）== 1
2. 每条诊断条目占 32 字节，可通过 读 64 位（r64）验证各字段
3. 错误码、行号、列号、消息字符串均正确保存
4. 多次调用导致容量不足时诊断数组自动扩展
