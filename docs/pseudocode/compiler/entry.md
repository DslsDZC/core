# entry.cr 伪代码
> 源文件：src/compiler/entry.cr（3 行）
> 功能概要：项目模式入口点，将程序入口委托给编译器主入口（compiler_main）函数。本文件是 corec 二进制的真正 main 函数定义，仅作转发。

## 标识符对照表
| 中文名 | 原名 | 首次出现函数 |
|--------|------|-------------|
| 主入口 | main | 主入口 |
| 编译器主入口 | compiler_main | 主入口 |

## 全局状态
本文件不涉及全局变量声明。

## 函数 主入口（main）
### 作用
项目模式入口点，Core 程序的 main 函数。直接调用编译器主入口（compiler_main）并返回其结果。本文件极简，所有实际逻辑均在 main.cr 的编译器主入口（corec_main）中。
### 逻辑
令 主入口 函数，返回整数：
    返回 调用 编译器主入口() 的结果

### 测试要点
1. 调用 main() 应返回与 compiler_main() 相同的整数值
2. 函数体仅一行，无任何副作用或条件分支
