## 函数 解析泛型参数（parse_generics）
### 作用
解析泛型参数列表 `[T1, T2, ...]` 或 `<T1, T2, ...>`。仅返回泛型参数个数（gc），不存储名称。用于 结构（struct）/枚举（enum） 声明中了解泛型个数而不需要名字的场景。
### 逻辑
    函数 解析泛型参数（parse_generics）-> 整数
        令 开启词法单元类别（open_tok）= 0（可变）
        令 关闭词法单元类别（close_tok）= 0（可变）
        如果 检查（check）（T_LBRACKET），那么：开启词法单元类别 = 左方括号（左方括号）； 关闭词法单元类别 = 右方括号（T_RBRACKET）
        否则如果 检查（T_LT），那么：开启词法单元类别 = 小于号（小于号）； 关闭词法单元类别 = 大于号（T_GT）
        如果 开启词法单元类别 大于 0，那么：
            前进词法单元（advance_tok）（）  -- 跳过 [ 或 <
            令 泛型计数（gc）= 0（可变）
            循环（当 真 时）：
                如果 检查（关闭词法单元类别），那么：跳出循环
                如果 泛型计数 大于等于 最大泛型参数数（MAX_GENERICS），那么：跳出循环
                前进词法单元（）  -- 消费泛型名称词法单元
                泛型计数 = 泛型计数 + 1
                如果 非 检查（T_COMMA），那么：跳出循环
                前进词法单元（）  -- 跳过逗号
            前进词法单元（）  -- 跳过 ] 或 >
            返回 泛型计数
        返回 0
### 测试要点
1. "[泛型参数 泛型参数（T）（泛型参数 T）]" 返回 1；"[泛型参数 泛型参数, U, V]" 返回 3
2. 超过 最大泛型参数数（MAX_GENERICS）（4）时截断返回 4
3. 无泛型括号时返回 0

## 函数 解析泛型参数到容器（parse_generics_into）

解析泛型参数列表并将名称和约束分别写入提供的缓冲区 名称列表（names） 和 约束列表（constrs）。格式同 解析泛型参数（parse_generics），但额外处理 `泛型参数 泛型参数（T）（泛型参数 T）: InterfaceName` 约束语法。约束列表 数组未指定约束的位置初始化为 -1。
### 逻辑
    函数 解析泛型参数到容器（parse_generics_into）（名称缓冲区（names）: 字符串（string）, 约束缓冲区（constrs）: 字符串） -> 整数
        令 约束索引（ci）= 0（可变）
        循环（当 真 时）：
            如果 约束索引 大于等于 4，那么：跳出循环
            写64位（w64）（约束缓冲区, 约束索引 * 8, -1）
            约束索引 = 约束索引 + 1
        令 开启词法单元类别（open_tok）= 0（可变）
        令 关闭词法单元类别（close_tok）= 0（可变）
        如果 检查（check）（T_LBRACKET），那么：开启词法单元类别 = 左方括号（左方括号）； 关闭词法单元类别 = 右方括号（T_RBRACKET）
        否则如果 检查（T_LT），那么：开启词法单元类别 = 小于号（小于号）； 关闭词法单元类别 = 大于号（T_GT）
        如果 开启词法单元类别 大于 0，那么：
            前进词法单元（advance_tok）（）  -- 跳过 [ 或 <
            令 泛型计数（gc）= 0（可变）
            循环（当 真 时）：
                如果 检查（关闭词法单元类别），那么：跳出循环
                如果 泛型计数 大于等于 最大泛型参数数（MAX_GENERICS），那么：跳出循环
                令 泛型词法单元（gt）= 前进词法单元（）  -- 消费泛型名称词法单元
                写64位（名称缓冲区, 泛型计数 * 8, 词法单元词素索引（tok_lx）（泛型词法单元））
                写64位（约束缓冲区, 泛型计数 * 8, -1）  -- 默认无约束
                如果 检查（T_COLON），那么：
                    前进词法单元（）  -- 跳过 :
                    令 约束词法单元（ct）= 前进词法单元（）  -- 消费约束类型名称
                    写64位（约束缓冲区, 泛型计数 * 8, 字符串驻留（str_intern）（词法单元词素索引（约束词法单元）））
                泛型计数 = 泛型计数 + 1
                如果 非 检查（T_COMMA），那么：跳出循环
                前进词法单元（）  -- 跳过逗号
            前进词法单元（）  -- 跳过 ] 或 >
            返回 泛型计数
        返回 0
### 测试要点
1. "[泛型参数 泛型参数（T）（泛型参数 T）: 显示特质（Show）, U]" 产生 名称列表（names）=["泛型参数 泛型参数","U"], 约束列表（constrs）=[显示特质,-1]
2. 约束仅对紧跟 `:` 的泛型参数生效

## 函数 提取热补丁版本号（extract_hotpatch_ver）
### 作用
从注解参数链（参数表达式（EXPR_ARG） 链表）中查找 `ver = 次数（N）` 的赋值，提取整数值作为热补丁版本号。若未找到返回 -1。
### 逻辑
    函数 提取热补丁版本号（extract_hotpatch_ver）（参数节点（args_node）: 整数（int）） -> 整数
        如果 参数节点 小于 0，那么：返回 -1
        令 当前参数（arg）= 参数节点
        循环（当 真 时）：
            如果 当前参数 小于 0，那么：跳出循环
            令 参数表达式（expr）= AST访问器：变量甲（a）（ast_a）（当前参数）
            令 表达式类别（k）= AST访问器：类别（ast_kind）（参数表达式）
            如果 表达式类别 等于 赋值表达式（EXPR_ASSIGN），那么：
                令 名称索引（name_ni）= AST访问器：变量甲（a）（参数表达式）
                令 名称（name）= 驻留字符串获取（istr_get）（名称索引）
