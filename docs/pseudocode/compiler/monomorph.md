# monomorph.cr 伪代码
> 源文件：src/compiler/monomorph.cr（438 行）
> 功能概要：泛型单态化引擎。通过实例缓存 + AST 深度克隆 + 类型参数替换，为每个泛型函数的具体类型组合生成特化副本并注册到函数数组（g_funcs）中。核心机制：替换映射构建、去重克隆、缓存查找或创建。

## 全局状态

- 泛型实例表（g_gen_instances）：字节缓冲区，可变。实例缓存，每条目 24 字节：[原始函数索引（8B）, 类型参数驻留名索引（8B）, 特化函数索引（8B）]。
- 泛型实例表计数（g_gen_instance_count）：整数，可变。已缓存的实例数。
- 泛型实例表容量（g_gen_instance_cap）：整数，可变。实例表当前容量（条目数上限）。
- 泛型替换旧值数组（g_gen_subst_old）：字节缓冲区，可变。当前单态化时的临时替换映射——泛型参数名驻留索引（旧值端）。
- 泛型替换新值数组（g_gen_subst_new）：字节缓冲区，可变。临时替换映射——具体类型名驻留索引（新值端）。
- 泛型替代表计数（g_gen_subst_count）：整数，可变。当前替换映射条目数。
- 泛型替代表容量（g_gen_subst_cap）：整数，可变。替换映射数组容量。
- 泛型去重旧值数组（g_gen_dedup_old）：字节缓冲区，可变。克隆期间的去重映射——原始 AST 节点索引（旧值端）。
- 泛型去重新值数组（g_gen_dedup_new）：字节缓冲区，可变。去重映射——克隆后 AST 节点索引（新值端）。
- 泛型去重表计数（g_gen_dedup_count）：整数，可变。去重表条目数。
- 泛型去重表容量（g_gen_dedup_cap）：整数，可变。去重表数组容量。

## 函数 扩展泛型实例表（grow_gen_instances）

### 作用
确保实例缓存数组容量大于等于 增长所需条数。容量不足时分配新缓冲区（24 字节/条目）并拷贝旧数据。初始最小容量为 64。

### 逻辑

    函数 扩展泛型实例表（增长所需条数（needed）：整数）：
        如果 增长所需条数 小于 泛型实例表容量，那么：
            返回
        令 新容量（nc） = 泛型实例表容量 * 2（可变）
        如果 新容量 小于 64，那么：
            令 新容量 = 64
        如果 新容量 小于 增长所需条数，那么：
            令 新容量 = 增长所需条数 + 64
        令 新缓冲区（nb） = 分配内存（新容量 * 24）
        内部：动态拷贝（_dyncpy）（源 = 泛型实例表，大小 = 泛型实例表容量 * 24，目标 = 新缓冲区）
        令 泛型实例表 = 新缓冲区
        令 泛型实例表容量 = 新容量

### 测试要点
1. 首次扩展（容量 0）时 新容量 取 64（max（0,64））。分配 64*24 字节。
2. 增长所需条数 小于当前容量时直接返回。
3. 扩展后旧数据的 24 字节条目完整保留。

## 函数 泛型实例化：构建替换（gen_build_subst）

### 作用
解析逗号分隔的类型参数字符串（如 "整数,字符串"），构建从泛型参数名到具体类型名的替换映射。将结果存入 泛型替换旧值数组 / 泛型替换新值数组 并行数组中。

### 逻辑

    函数 泛型实例化：构建替换（函数索引 函数原生内建索引（func_ni）：整数，类型参数字符串 type_args：字符串）：
        令 泛型替代表计数 = 0
        令 泛型替代表容量 = 0
        令 泛型个数（gc） = 函数信息访问器：泛型计数（fi_generic_count）（函数索引）
        如果 泛型个数 小于等于 0，那么：
            返回  // 非泛型函数，无需构建替换
        令 解析位置（pos） = 0（可变）
        令 泛型参数序号（gi） = 0（可变）
        循环：
            如果 泛型参数序号 大于等于 泛型个数，那么：
                跳出循环
            如果 按字节读取（load8）（类型参数字符串，解析位置） 等于 0，那么：
                跳出循环  // 字符串提前结束
            令 类型名起始位置（start） = 解析位置
            循环：
                令 当前字符（c） = 按字节读取（load8）（类型参数字符串，解析位置）
                如果 当前字符 等于 0 或 当前字符 等于 44，那么：  // 空字符或逗号 ','
                    跳出循环
                令 解析位置 = 解析位置 + 1
            令 类型名字符串（type_name） = 字符串切片（str_sub）（类型参数字符串，类型名起始位置，解析位置 - 类型名起始位置）
            如果 按字节读取（load8）（类型参数字符串，解析位置） 等于 44，那么：
                令 解析位置 = 解析位置 + 1  // 跳过逗号
            令 泛型参数名索引（gen_param_ni） = 函数信息访问器：泛型名称（fi_generic_name）（函数索引，泛型参数序号）
            令 具体类型名索引（concrete_ni） = 字符串驻留（str_intern）（类型名字符串）
            扩展泛型替代表（泛型替代表计数 + 1）
            写 64 位（w64）（目标 = 泛型替换旧值数组，偏移 = 泛型替代表计数 * 8，值 = 泛型参数名索引）
            写 64 位（w64）（目标 = 泛型替换新值数组，偏移 = 泛型替代表计数 * 8，值 = 具体类型名索引）
            令 泛型替代表计数 = 泛型替代表计数 + 1
            令 泛型参数序号 = 泛型参数序号 + 1

### 测试要点
1. 非泛型函数（泛型计数 <= 0）：直接返回，不修改任何状态。
2. 单类型参数 "整数"：构建 1 条替换映射，泛型替代表计数 = 1。
3. 多类型参数 "整数,字符串"：按逗号拆分构建 2 条映射。
4. 类型参数字符串含空格时：解析只识别空字符和逗号作为分隔符，空格可能被包含在类型名中（依赖上层保证输入格式正确）。
5. 泛型参数个数与类型参数个数不一致时：按较早结束的那边停止。
6. 类型参数字符串为空字符串：循环不执行（load8 返回 0），替代表计数保持 0。

## 函数 泛型实例化：查询替换（gen_lookup_subst）

### 作用
在替换映射中查找给定泛型参数名对应的具体类型名。若找到返回具体类型名的驻留索引，否则返回 -1（表示该名称不是泛型参数）。

### 逻辑

    函数 泛型实例化：查询替换（名称驻留索引 name_ni：整数）-> 整数：
        令 映射索引（mi） = 0（可变）
        循环：
            如果 映射索引 大于等于 泛型替代表计数，那么：
                跳出循环
            如果 读 64 位（r64）（源 = 泛型替换旧值数组，偏移 = 映射索引 * 8） 等于 名称驻留索引，那么：
                返回 读 64 位（r64）（源 = 泛型替换新值数组，偏移 = 映射索引 * 8）
            令 映射索引 = 映射索引 + 1
        返回 -1

### 测试要点
1. 名称在替换映射中存在时返回对应的具体类型名索引。
2. 名称不在替换映射中时返回 -1。
3. 替代表为空时直接返回 -1。

## 函数 泛型实例化：基础类型变量（gen_base_type_tv）

### 作用
检查给定名称是否是基础类型（整数（int）、浮点（float）、布尔（bool） 等），若是则返回对应的类型类别常量，否则返回 -1。

### 逻辑

    函数 泛型实例化：基础类型变量（名称驻留索引 name_ni：整数）-> 整数：
        令 驻留字符串（s） = 驻留字符串获取（istr_get）（名称驻留索引）
        如果 驻留字符串 等于 "整数"，那么：返回 类型类别：整数（TY_INT）
        如果 驻留字符串 等于 "浮点"，那么：返回 类型类别：浮点（TY_FLOAT）
        如果 驻留字符串 等于 "布尔"，那么：返回 类型类别：布尔（TY_BOOL）
        如果 驻留字符串 等于 "字符串"，那么：返回 类型类别：字符串（TY_STRING）
        如果 驻留字符串 等于 "字符"，那么：返回 类型类别：字符（TY_CHAR）
        如果 驻留字符串 等于 "单元"，那么：返回 类型类别：单元（TY_UNIT）
        如果 驻留字符串 等于 "空"，那么：返回 类型类别：空（TY_NEVER）
        返回 -1

### 测试要点
1. "整数" → 类型类别：整数，"浮点" → 类型类别：浮点，每个基础类型映射正确。
2. 非基础类型名（如 "我的结构体（MyStruct）"）返回 -1。
3. 空字符串返回 -1。

## 函数 泛型去重：查找（gen_dedup_find）

### 作用
在去重表中查找给定旧 AST 节点是否已有克隆副本。若有返回新节点索引，否则返回 -1。用于避免 AST 深克隆时的重复工作。

### 逻辑

    函数 泛型去重：查找（旧节点索引 old_node：整数）-> 整数：
        令 映射索引（mi） = 0（可变）
        循环：
            如果 映射索引 大于等于 泛型去重表计数，那么：
                跳出循环
            如果 读 64 位（r64）（源 = 泛型去重旧值数组，偏移 = 映射索引 * 8） 等于 旧节点索引，那么：
                返回 读 64 位（r64）（源 = 泛型去重新值数组，偏移 = 映射索引 * 8）
            令 映射索引 = 映射索引 + 1
        返回 -1

### 测试要点
1. 已克隆过的节点：返回对应的新节点索引。
2. 未克隆的节点：返回 -1。
3. 去重表为空：返回 -1。

## 函数 泛型实例化：克隆代码块（gen_clone_block）

### 作用
批量克隆代码块语句数组（g_block_stmts）中连续的一批语句。对每个语句 AST 节点调用 泛型实例化：克隆树（gen_clone_tree） 进行深克隆并把结果写入新位置。

### 逻辑

    函数 泛型实例化：克隆代码块（起始索引 开始（start）：整数，数量 count：整数）-> 整数：
        如果 数量 小于等于 0，那么：
            返回 -1
        令 新起始索引（new_start） = 代码块语句计数（g_block_stmt_count）
        扩展代码块语句数组（grow_block_stmts）（新起始索引 + 数量）
        令 当前序号（i） = 0（可变）
        循环：
            如果 当前序号 大于等于 数量，那么：
                跳出循环
            令 旧语句（old_stmt） = 读 64 位（r64）（源 = 代码块语句数组（g_block_stmts），偏移 = （起始索引 + 当前序号） * 8）
            令 新语句（new_stmt） = 泛型实例化：克隆树（gen_clone_tree）（旧语句）
            写 64 位（w64）（目标 = 代码块语句数组，偏移 = （新起始索引 + 当前序号） * 8，值 = 新语句）
            令 当前序号 = 当前序号 + 1
        令 代码块语句计数 = 新起始索引 + 数量
        返回 新起始索引

### 测试要点
1. 数量 = 0 或 数量 小于 0 时返回 -1，不做任何修改。
2. 正常情况：分配新空间并逐条克隆，返回首个新语句的索引。
3. 克隆期间可能触发代码块语句数组的容量扩展。

## 函数 泛型实例化：连续克隆（gen_clone_consecutive）

### 作用
克隆 AST 数组中连续的一段节点。每个节点通过 泛型实例化：克隆树（gen_clone_tree） 追加到 AST 数组末尾，新节点自然形成连续块。

### 逻辑

    函数 泛型实例化：连续克隆（起始索引 开始（start）：整数，数量 count：整数）-> 整数：
        如果 数量 小于等于 0 或 起始索引 小于 0，那么：
            返回 -1
        // 克隆后的节点由 泛型实例化：克隆树 逐一追加到 AST 节点数组，自然连续排列
        令 首个新节点索引（first_new） = AST 节点计数（g_ast_count）
        令 当前序号（i） = 0（可变）
        循环：
            如果 当前序号 大于等于 数量，那么：
                跳出循环
            泛型实例化：克隆树（gen_clone_tree）（起始索引 + 当前序号）
            令 当前序号 = 当前序号 + 1
        返回 首个新节点索引

### 测试要点
1. 数量 小于等于 0 或 起始索引 < 0 时返回 -1。
2. 正常克隆后返回的 首个新节点索引 指向第一个克隆节点在 AST 节点数组 中的位置。
3. 克隆 3 个连续节点后，新节点在 AST 节点数组 中也连续排列（因为通过 AST 访问器：分配（ast_alloc） 顺序追加）。

## 函数 泛型实例化：克隆树（gen_clone_tree）

### 作用
深度克隆一个 AST 子树，同时执行泛型类型参数替换。核心算法：
1. 去重检查：若节点已克隆过则返回已有副本。
2. 标识符节点：检查是否为泛型参数引用；若是则替换为基础类型或具名类型引用；否则原样克隆。
3. 根据不同 AST 节点类别递归克隆子节点。
4. 所有克隆后的节点记录到去重表中。

### 测试要点
1. 空节点（节点（node） < 0）：返回 -1。
2. 去重命中：同一节点被多次引用时，只克隆一次，后续返回缓存的副本索引。
3. 标识符节点泛型参数替换："泛型参数" 替换为 "整数" 时，因为 "整数" 是基础类型，生成类别 = 0 的节点（类型值 = 类型类别：整数）。
4. 标识符节点泛型参数替换为具名类型："泛型参数" 替换为 "我的结构体（MyStruct）" 时，保持标识符类别，整数值替换为 "我的结构体" 的驻留索引。
5. 标识符节点非泛型参数：原样克隆。
6. 空表达式含 第一子节点（结构体字段包装）：递归克隆 变量甲。
7. 空表达式不含子节点：原样复制。
8. 叶子节点（整数、浮点、布尔等）：字段原样复制后返回。
9. 单子节点（返回、让出、移动等）：递归克隆 变量甲。
10. 双子节点（二元运算、赋值等）：递归克隆 变量甲 和 变量乙。
11. 条件节点三子节点：递归克隆 第一子节点（条件）、第二子节点（真分支）、第三子节点（假分支，可为 -1 跳过）。
12. 代码块节点：通过 泛型实例化：克隆代码块 批量克隆。
13. 结构体构造 / 数组 / 元组 / 泛型应用：通过 泛型实例化：连续克隆 连续克隆，字段计数要考虑加倍（结构体字段每对占 2 AST 节点）。
14. 兜底分支：对未知节点类别保守递归克隆所有指针宽字段。
15. 深克隆不修改源 AST 节点——只追加新节点到 AST 节点数组 末尾。

## 函数 泛型实例化：查找缓存（gen_find_cached）

### 作用
在实例缓存中查找已特化的函数。匹配条件：原始函数索引相同且类型参数字符串驻留名一致。返回特化函数索引，未找到返回 -1。

### 逻辑

    函数 泛型实例化：查找缓存（函数索引 函数原生内建索引（func_ni）：整数，类型参数字符串 type_args：字符串）-> 整数：
        令 当前序号（i） = 0（可变）
        循环：
            如果 当前序号 大于等于 泛型实例表计数，那么：
                跳出循环
            如果 读 64 位（r64）（源 = 泛型实例表，偏移 = 当前序号 * 24） 等于 函数索引，那么：
                令 缓存参数名索引（cached_args_ni） = 读 64 位（r64）（源 = 泛型实例表，偏移 = 当前序号 * 24 + 8）
                如果 驻留字符串相等比较（istr_eq）（缓存参数名索引，类型参数字符串） 不等于 0，那么：
                    返回 读 64 位（r64）（源 = 泛型实例表，偏移 = 当前序号 * 24 + 16）
            令 当前序号 = 当前序号 + 1
        返回 -1

### 测试要点
1. 缓存命中：返回之前特化的函数索引。
2. 原始函数索引相同但类型参数不同：不匹配，继续查找。
3. 缓存为空：直接返回 -1。
4. 同函数多组类型参数的多个实例均能被正确匹配。

## 函数 泛型实例化：查找或创建（gen_find_or_create）

### 作用
公开接口（API）：查找缓存，若命中返回已有特化函数索引，否则创建新的特化实例并缓存。是外部代码调用单态化的唯一入口。

### 逻辑

    函数 泛型实例化：查找或创建（函数索引 函数原生内建索引（func_ni）：整数，类型参数字符串 type_args：字符串）-> 整数：
        令 缓存结果（cached） = 泛型实例化：查找缓存（gen_find_cached）（函数索引，类型参数字符串）
        如果 缓存结果 大于等于 0，那么：
            返回 缓存结果
        返回 泛型实例化：创建实例（gen_create_instance）（函数索引，类型参数字符串）

### 测试要点
1. 首次调用：缓存未命中 → 创建新实例 → 缓存 → 返回新函数索引。
2. 重复调用相同类型参数：缓存命中 → 直接返回已有索引，不重复创建。
3. 同一函数不同类型参数：分别创建，各自缓存。

## 函数 泛型实例化：创建实例（gen_create_instance）

### 作用
创建泛型函数的特化副本的核心流程：
1. 构建泛型参数到具体类型的替换映射。
2. 深克隆原函数的 AST 树（含类型替换）。
3. 构造修饰后的函数名（"原名[类型参数]"）。
4. 将新函数注册到 函数数组（g_funcs），复制参数类型和返回类型。
5. 缓存新函数索引到实例表。
6. 返回新函数索引。

        令 修饰名索引（mangled_ni） = 字符串驻留（str_intern）（修饰后的名称）
