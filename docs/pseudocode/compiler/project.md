## 函数 加载项目（load_project）
### 作用
读取项目目录下的配置文件，解析项目名；定位并读取（main.cr）源码入口文件。将项目根目录写入项目源码目录全局变量，将项目名写入项目名全局变量。返回（main.cr）的源码字符串。

### 逻辑
函数 加载项目（load_project）（目录路径（dir）：字符串）-> 字符串：
    令 源码目录（sd） = ""
    令 配置路径（toml_path） = ""

    如果 字符串相等比较（取字符串第（N）字符（目录路径，字符串长度（目录路径）- 1），"/"）不等于 0，那么：
        令 源码目录 = 目录路径
        令 配置路径 = 目录路径 +（文件名 "Core.toml"）
    否则：
        令 源码目录 = 目录路径 + "/"
        令 配置路径 = 目录路径 + "/" +（文件名 "Core.toml"）

    令 配置内容（tc） = 读取文件（配置路径）
    令 项目名称（pname） = ""
    如果 字符串长度（配置内容）大于 0，那么：
        令 项目名称 = 提取（TOML）键名（配置内容）

    令 项目名（全局） = 项目名称

    如果 字符串长度（项目名（全局））等于 0，那么：
        令 回退名称（fallback_name） = 取文件名（目录路径）
        如果 字符串相等比较（回退名称，"."）不等于 0，那么：
            令 当前工作目录（cwd） = 获取当前目录（）
            如果 字符串长度（当前工作目录）大于 0，那么：
                令 回退名称 = 取文件名（当前工作目录）
        如果 字符串长度（回退名称）等于 0，或 字符串相等比较（回退名称，"."）不等于 0，或 字符串相等比较（回退名称，".."）不等于 0，或 字符串相等比较（回退名称，"/"）不等于 0，那么：
            令 回退名称 =（字符串 "变量甲（a）.out"）
        令 项目名（全局） = 回退名称

    令 主文件路径（main_path） = 源码目录 +（字符串 "main.cr"）
    令 源码（source） = 读取文件（主文件路径）

    令 项目源码目录 = 源码目录

    如果 字符串长度（项目名称）大于 0，那么：
        输出（"  project: "）
        输出行（项目名称）
    如果 字符串长度（源码）大于 0，那么：
        输出（"  main.cr: "）
        输出行（主文件路径）

    返回 源码

### 测试要点
1. 传入以 "/" 结尾的目录路径，验证配置文件路径正确拼接
2. 传入不以 "/" 结尾的目录路径，验证配置文件路径正确拼接
3. 配置文件存在且含有效项目名，验证项目名全局变量被正确设置
4. 配置文件不存在或为空，验证回退名称正确计算：先用目录名，目录名为 "." 时用当前目录名
5. 回退名称为 "."、".."、"/" 或空时，验证最终回退为默认输出名
6. 入口文件不存在时，返回空字符串且不崩溃
7. 验证项目源码目录在函数返回前被正确设置为以 "/" 结尾的目录路径
