## 函数 加载项目（load_project）
### 作用
读取项目目录下的 Core.toml 配置文件，解析项目名；定位并读取 main.cr 源码入口文件。将项目根目录写入项目源码目录（g_project_source_dir）全局变量，将项目名写入项目名（g_project_name）全局变量。返回 main.cr 的源码字符串。
### 逻辑
函数 加载项目（目录路径：字符串）-> 字符串：
    令 源码目录 = ""
    令 toml路径 = ""
    如果 字符串相等比较（取字符串第 N 字符（目录路径，字符串长度（目录路径）- 1），"/"）不等于 0，那么：
        令 源码目录 = 目录路径
        令 toml路径 = 目录路径 + "Core.toml"
    否则：
        令 源码目录 = 目录路径 + "/"
        令 toml路径 = 目录路径 + "/Core.toml"

    令 toml内容 = 读取文件（toml路径）
    令 项目名称 = ""
    如果 字符串长度（toml内容）大于 0，那么：
        令 项目名称 = 提取 TOML 键名（toml内容）

    令 项目名（全局） = 项目名称
    如果 字符串长度（项目名（全局））等于 0，那么：
        令 回退名称 = 取文件名（目录路径）
        如果 字符串相等比较（回退名称，"."）不等于 0，那么：
            令 当前目录 = 获取当前目录()
            如果 字符串长度（当前目录）大于 0，那么：
                令 回退名称 = 取文件名（当前目录）
        如果 字符串长度（回退名称）等于 0，或 字符串相等比较（回退名称，"."）不等于 0，或 字符串相等比较（回退名称，".."）不等于 0，或 字符串相等比较（回退名称，"/"）不等于 0，那么：
            令 回退名称 = "a.out"
        令 项目名（全局） = 回退名称

    令 主文件路径 = 源码目录 + "main.cr"
    令 源码 = 读取文件（主文件路径）

    令 项目源码目录 = 源码目录
    如果 字符串长度（项目名称）大于 0，那么：
        输出（"  project: "）
        输出行（项目名称）
    如果 字符串长度（源码）大于 0，那么：
        输出（"  main.cr: "）
        输出行（主文件路径）

    返回 源码

### 测试要点
1. 传入以 "/" 结尾的目录路径，验证 Core.toml 路径正确拼接为 dir/Core.toml
2. 传入不以 "/" 结尾的目录路径，验证 Core.toml 路径正确拼接为 dir/Core.toml
3. Core.toml 存在且含有效项目名，验证项目名（g_project_name）被正确设置
4. Core.toml 不存在或为空，验证回退名称正确计算：先用目录名，目录名为 "." 时用当前目录名
5. 回退名称为 "."、".."、"/" 或空时，验证最终回退为 "a.out"
6. main.cr 文件不存在时，返回空字符串且不崩溃
7. 验证项目源码目录（g_project_source_dir）在函数返回前被正确设置为以 "/" 结尾的目录路径
