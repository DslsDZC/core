        如果 动态接收者 大于等于 0 且 IR 变量访问器：类型（irv_type）（动态接收者） 等于 类型信息：动态（TI_DYN），那么：
            令 动态调用目标 = 新建 IR 变量（new_ir_var）（"_dyncall", 类型信息：单元（TI_UNIT））
            发射指令（emit）（动态分发指令（IR_DYN_DISPATCH）, 动态调用目标, 动态接收者, 函数名字索引, 0, 0）
            返回 动态调用目标

    （—— 热补丁函数调用：发射 热补丁路由指令（IR_HOTPATCH_ROUTE） 而非 调用指令（IR_CALL） ——）
    如果 函数名字索引 大于等于 0 且 判断热补丁函数（is_hotpatch_func）（函数名字索引） 不等于 0，那么：
        发射指令（emit）（热补丁路由指令（IR_HOTPATCH_ROUTE）, 目标变量, 函数名字索引, 第一个参数变量, 实参计数）
        返回 目标变量

    （—— 外部函数调用：emit 外部调用指令（IR_CALL_EXTERN） 用于 外部函数接口（FFI） 派发 ——）
    如果 函数名字索引 大于等于 0，那么：
        令 函数信息索引 = 查找函数（find_func）（函数名字索引）
        如果 函数信息索引 大于等于 0，那么：
            令 函数AST节点 = 函数信息访问器：AST 数组（ast）节点（fi_ast_node）（函数信息索引）
            如果 函数AST节点 大于等于 0 且 AST 访问器：类别（ast_kind）（函数AST节点） 等于 外部声明表达式（EXPR_EXTERN），那么：
                发射指令（emit）（外部调用指令（IR_CALL_EXTERN）, 目标变量, 函数名字索引, 第一个参数变量, 实参计数, 0）
                返回 目标变量

    （—— 常规函数调用 ——）
    发射指令（emit）（调用指令（IR_CALL）, 目标变量, 第一个参数变量, 实参计数, 函数名字索引, 调用返回类型索引）

    （—— 惰性求值 惰性求值器（thunk） 包装：纯函数且低使用次数时包装为 惰性求值指令（IR_LAZY_THUNK） ——）
    如果 函数名字索引 大于等于 0，那么：
        令 调用函数索引 = 查找函数（find_func）（函数名字索引）
        如果 调用函数索引 大于等于 0 且 函数信息访问器：是否纯净（fi_ispure）（调用函数索引） 不等于 0，那么：
            扩展变量使用计数数组（grow_var_use_count）（目标变量 + 1）
            令 使用次数 = 从 变量使用计数数组（g_var_use_count）偏移（目标变量 * 8）处读取 64 位
            如果 使用次数 小于等于 1，那么：
                令 惰性变量 = 新建 IR 变量（new_ir_var）（"_lazy", IR 变量访问器：类型（irv_type）（目标变量））
                发射指令（emit）（惰性求值指令（IR_LAZY_THUNK）, 惰性变量, 目标变量, 0, 0, 0）
                返回 惰性变量

    返回 目标变量

### 测试要点
1. 赋值表达式（EXPR_ASSIGN） 解开 空值表达式（EXPR_NONE） 包装后正确处理 标识符指令（IDENT）/字段指令（FIELD）/下标指令（INDEX）/解引用指令（DEREF） 四种目标
2. 赋值表达式（EXPR_ASSIGN） 对 类型信息：动态（TI_DYN） 类型目标使用 动态打包指令（IR_DYN_PACK） 打包
3. 解引用写（*指针（ptr） = 值（val））正确使用 存储指针指令（IR_STORE_PTR）
4. 取地址 &数组（arr）[索引（i）] 直接生成 地址索引指令（IR_ADDR_INDEX）（第三个源操作数为 3）而非先加载后取地址
5. 取地址 &变量（var） 生成 引用指令（IR_REF），将 AST 访问器：整数值（ast_int_val）（node） 作为源操作数2传递
6. 解引用 *指针（ptr） 生成 解引用指令（IR_DEREF）
7. 其他一元运算符（负号/按位非）生成 一元运算指令（IR_UNARY）
8. 协程启动（go） 单协程：生成 函数地址指令（IR_FNADDR） + 调用指令（IR_CALL）（sched_go），无参数时 参数1（arg1） 传 0 常量
9. 协程启动（go） 范围（range）：为 [开始（start）, 结束（end）） 中每个值以 生成协程指令（IR_SPAWN） 派发协程，结果存入 存储索引指令（IR_STORE_INDEX） 数组
10. 范围（range） 计数小于等于 0 时返回 -1
11. @大小计算（sizeOf）/@对齐计算（alignOf） 在编译期求值并折叠为 常量指令（IR_CONST）
12. @字段列表（fields） 生成逗号分隔字段名列表字符串常量
13. @字段检查（hasField）/@字段（field） 检查字段存在性或返回偏移量（IR_CONST）
14. @地址（addr） 生成 函数地址指令（IR_FNADDR） 供 ELF 链接时修补
15. 方法调用（method）将 自身（self） 作为第一个参数压入参数数组
16. 参数数组容量不足时自动扩容（两倍增长，初始 64）
17. 泛型函数根据调用参数类型按 "intstringboolcharfloatunit" 格式拼装类型参数字符串
18. 单态化查找失败时通过 泛型实例化：查找或创建（gen_find_or_create） 创建，并替换 函数原生内建索引（func_ni） 继续调用发射
19. 参数不连续时（非相邻 IR 变量索引），每个参数通过 存储指令（IR_STORE） 创建独立打包变量
20. 动态方法派发（类型信息：动态（TI_DYN） 接收者）使用 动态分发指令（IR_DYN_DISPATCH）
21. 热补丁函数使用 热补丁路由指令（IR_HOTPATCH_ROUTE）
22. 外部（extern） 函数使用 外部调用指令（IR_CALL_EXTERN）
23. 纯净函数且单次使用的调用结果包装为 惰性求值指令（IR_LAZY_THUNK） 惰性求值
