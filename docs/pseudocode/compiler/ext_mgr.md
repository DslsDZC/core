# ext_mgr.cr 伪代码
> 源文件：src/compiler/ext_mgr.cr（93 行）
> 功能概要：编译器扩展管理器，提供插件注册表与钩子调度机制。插件通过 扩展：注册（ext_reg） 监听指定钩子，编译器核心在关键点位通过分发函数遍历注册表并调用对应插件的处理函数。

## 全局状态

- 扩展标志（g_ext_flags）：整数，初始值 0。环境变量「核心安全标记（CORE_SAFE）」=1 时设为 1，控制安全检查策略启用。
- 扩展已初始化标记（g_ext_inited）：整数，初始值 0。首次调用 扩展：初始化（ext_init） 后置为 1，防止重复初始化。
- 扩展注册数组（g_ext_reg）：字节缓冲区，可变。存储扁平化的 [钩子类型, 插件 ID] 对，每对 8 字节（前 4 字节钩子类型，后 4 字节插件 ID）。
- 扩展注册计数（g_ext_reg_count）：整数，可变。当前已注册的条目数。
- 扩展注册容量（g_ext_reg_cap）：整数，可变。当前数组容量（可存储的条目数上限）。
- 钩子类型：数组访问（EXT_HOOK_ARRAY_ACCESS）：整数常量，值 1。钩子类型：数组访问前触发。
- 钩子类型：二元运算（EXT_HOOK_BINARY_OP）：整数常量，值 2。钩子类型：二元运算后触发。

## 函数 扩展注册表容量（grow_ext_reg）

### 作用
确保扩展注册数组容量大于等于所需条目数 增长所需条数。若容量不足则分配新缓冲区并拷贝旧数据。

### 逻辑

    函数 扩展注册表容量（增长所需条数 增长所需条数：整数）：
        如果 增长所需条数 小于 扩展注册容量，那么：
            返回  // 容量充足，无需扩展
        令 新容量（ncap） = 扩展注册容量 * 2（可变）
        如果 新容量 小于 8，那么：
            令 新容量 = 8
        如果 新容量 小于 增长所需条数，那么：
            令 新容量 = 增长所需条数 + 8
        令 新缓冲区（nb） = 分配内存（新容量 * 8）
        内部：动态拷贝（_dyncpy）（源 = 扩展注册数组，大小 = 扩展注册容量 * 8，目标 = 新缓冲区）
        令 扩展注册数组 = 新缓冲区
        令 扩展注册容量 = 新容量

### 测试要点
1. 增长所需条数 小于当前容量时函数直接返回，不修改任何全局状态。
2. 增长所需条数 大于当前容量时正确计算新容量（取 max（容量*2, 8, 增长所需条数+8）），分配新数组，拷贝旧数据。
3. 初始容量为 0 时首次扩展（初始值 0，取 8 或 增长所需条数+8 中较大者）。
4. 扩展后旧数组的数据完整保留在新数组中。

## 函数 扩展：初始化（ext_init）

### 作用
初始化扩展管理器。检查环境变量「核心安全标记（CORE_SAFE）」设置扩展标志，调用内置安全检查插件的初始化函数。通过 扩展已初始化标记 保证幂等。

### 逻辑

    函数 扩展：初始化：
        如果 扩展已初始化标记 不等于 0，那么：
            返回  // 已初始化，跳过
        令 扩展已初始化标记 = 1
        令 扩展注册容量 = 0
        令 扩展注册计数 = 0
        // 读取环境变量「核心安全标记」，若值为 "1" 则启用安全检查扩展
        令 环境变量值（ev） = 获取环境变量（get_env）（参数 = "核心安全标记"）
        如果 字符串长度（str_len）（环境变量值） 大于 0 且 环境变量值 等于 "1"，那么：
            令 扩展标志 = 1
        // 内置插件初始化（未来从 .so 动态加载）
        扩展安全：初始化（ext_safety_init）（）

### 测试要点
1. 幂等性：首次调用执行初始化逻辑；再次调用时 扩展已初始化标记 非 0，直接返回。
2. 核心安全标记=1 时 扩展标志 被设为 1。
3. 核心安全标记 未设置或为空或非 "1" 时 扩展标志 保持 0。
4. 初始化后 扩展注册容量 与 扩展注册计数 均为 0。

## 函数 扩展：检查存在（ext_has）

### 作用
延迟初始化后返回扩展标志值。外部通过此函数查询安全检查是否启用。参数 扩展标志值（flag） 在当前实现中未被使用。

### 逻辑

    函数 扩展：检查存在（扩展标志值 flag：整数）-> 整数：
        如果 扩展已初始化标记 等于 0，那么：
            扩展：初始化（ext_init）（）
        返回 扩展标志

### 测试要点
1. 首次调用时若未初始化则先执行 扩展：初始化（ext_init），再返回 扩展标志。
2. 已初始化后直接返回 扩展标志 当前值。

## 函数 扩展：注册（ext_reg）

### 作用
将一个插件注册到指定钩子类型。在扁平数组中追加一条 [钩子类型, 插件 ID] 记录。每条记录占 8 字节：前 4 字节写钩子类型，后 4 字节写插件 ID。

### 逻辑

    函数 扩展：注册（钩子类型 hook_type：整数，插件 ID plugin_id：整数）：
        扩展注册表容量（扩展注册计数 + 1）
        写 64 位（w64）（目标 = 扩展注册数组，偏移 = 扩展注册计数 * 8，值 = 钩子类型）
        写 64 位（w64）（目标 = 扩展注册数组，偏移 = 扩展注册计数 * 8 + 4，值 = 插件 ID）
        令 扩展注册计数 = 扩展注册计数 + 1

### 测试要点
1. 注册第一条记录：扩展注册计数 从 0 变为 1，偏移 0 处写入钩子类型，偏移 4 处写入插件 ID。
2. 注册多条记录：每次在数组末尾追加，扩展注册计数 递增。
3. 扩展数组可能触发 扩展注册表容量（grow_ext_reg） 的容量扩展逻辑。

## 函数 扩展：分发数组访问（ext_dispatch_array_access）

### 作用
遍历注册表，对所有注册到 钩子类型：数组访问 钩子的插件调用对应的处理函数。在数组访问指令生成前被 通行证模块（pass.cr） 触发。返回 0 表示继续正常流程，非 0 表示跳过此次访问。

### 逻辑

    函数 扩展：分发数组访问（数组变量 arr_var：整数，索引变量 idx_var：整数，索引字面量 idx_lit：整数，数组长度字面量 arr_len_lit：整数）-> 整数：
        如果 扩展已初始化标记 等于 0，那么：
            扩展：初始化（ext_init）（）
        令 注册索引（ri） = 0（可变）
        循环：
            如果 注册索引 大于等于 扩展注册计数，那么：
                跳出循环
            令 钩子类型（ht） = 读 64 位（r64）（源 = 扩展注册数组，偏移 = 注册索引 * 8）
            令 插件 ID（pid） = 读 64 位（r64）（源 = 扩展注册数组，偏移 = 注册索引 * 8 + 4）
            如果 钩子类型 等于 钩子类型：数组访问，那么：
                如果 插件 ID 等于 1，那么：  // 安全检查插件
                    令 分发返回结果（r） = 扩展安全：数组访问检查（ext_safety_on_array_access）（数组变量，索引变量，索引字面量，数组长度字面量）
                    如果 分发返回结果 不等于 0，那么：
                        返回 分发返回结果
            令 注册索引 = 注册索引 + 1
        返回 0

### 测试要点
1. 注册表为空（扩展注册计数=0）时，循环不执行，直接返回 0。
2. 有多个注册条目但无匹配的钩子类型时，遍历完毕返回 0。
3. 匹配到数组访问钩子且插件 ID=1 时，调用安全检查处理函数；若其返回非 0 则提前返回。
4. 延迟初始化：若 扩展已初始化标记 为 0 则先调用 扩展：初始化（ext_init）。
